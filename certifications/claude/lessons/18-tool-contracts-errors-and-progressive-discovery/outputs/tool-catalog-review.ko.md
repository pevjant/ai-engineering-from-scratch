# 도구 카탈로그 리뷰: 지원(서포트) 증거

## 카탈로그 경계

정책 역할에는 활성 정책 검색과 소스 조회 도구가 주어집니다. 계정 도구나 쓰기 능력은 주어지지 않습니다. 모든 도구에는 테넌트(tenant, 사용자 그룹 단위)를 인식하는 실행 범위가 있습니다.

## 도구 계약

`search_active_policy`: 지원 정책이 답변을 규율할 때 사용합니다. 계정 정보나 공개 리서치에는 사용하지 않습니다. `read_assigned_account`: 인증된 케이스에 계정 정보가 필요할 때 사용합니다. 정책이나 다른 테넌트에는 사용하지 않습니다.

## 오류 매트릭스

검증 오류는 입력을 바꾼 뒤에만 재시도할 수 있습니다. 인가 오류는 접근이나 승인이 바뀌기 전에는 재시도할 수 없습니다. 의존성 타임아웃은 한 번만 재시도할 수 있으며, 부분 결과와 트레이스 ID를 보존합니다.

## 점진적 탐색(Progressive Discovery)

시작 화면에는 해당 역할에 허용된 능력 이름을 찾는 검색 기능만 노출됩니다. 전문적인 정의는 범위가 한정된 탐색이 이루어진 뒤에만 로드되며, 제한된 이름은 드러나지 않습니다.

## 인가

탐색(discovery)이 실행 권한을 주는 일은 결코 없습니다. 서비스는 매 호출마다 주체(principal), 테넌트, 현재 범위, 객체 소유권, 결합된 승인을 검사합니다.

## 선택 픽스처(테스트 케이스)

12개의 픽스처가 정책 대 계정 질문, 공개 리서치, 도구 없이 답하는 케이스, 검증, 인가, 충돌, 타임아웃, 부분 결과를 다룹니다.
