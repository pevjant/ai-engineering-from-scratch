# 마이그레이션 리뷰 체크리스트

## 전방(Forward) 동작

- 스키마와 데이터 전환 내용을 파악합니다.
- 현재 배포된 애플리케이션 버전과의 호환성을 확인합니다.
- 락(lock), 트랜잭션 지속 시간, 영향을 받는 행(row) 볼륨을 추정합니다.

## 롤백

- 롤백이 안전한지, 데이터 손실을 수반하는지, 아예 불가능한지 명시합니다.
- 파괴적인 정리(cleanup)는 호환성 마이그레이션과 분리해 둡니다.
- 되돌릴 수 없을 때는 복구 경로 또는 보상(compensating) 경로를 명시합니다.

## 증거

- 정확한 검증 명령과 결과를 기록합니다.
- 각 위험을 파일과 구문(statement)에 연결합니다.
- 프로덕션(운영 환경) 볼륨이나 호환성 증거가 없으면 결정을 차단(blocked) 상태로 둡니다.
