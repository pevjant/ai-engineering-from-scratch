# Claude 자격증 출처 검증 대장

> 커뮤니티 자료는 가르침의 빈틈을 찾아 줍니다. 사실로서의 커리큘럼이 되는 것을 결정하는 것은 공식 Anthropic 자료입니다.

**검증일:** 2026-08-09

## 권위 순서

1. 현재 공개 시험 가이드와 자격증 FAQ가 블루프린트, 시행 방식, 채점, 응시 자격,
   유효 기간, 가격, 재응시 정책을 정의한다.
2. 현재 Anthropic 제품 문서와 Academy 과목 목표가 제품 작동 방식과 권장 학습
   표면을 정의한다.
3. 커뮤니티 영상, 글, 연습 자료는 설명, 연습, 약점 영역을 제안할 수 있다.
   시험을 정의하지는 않는다.
4. 어떤 자료도 기밀 문항을 재구성하거나 합격을 약속하는 데 쓰이지 않는다.

## 검증된 프로그램 사실

- 등록은 현재 Claude Partner Network 조직으로 제한되며, 인식 가능한 회사
  도메인이 필요하다.
- Pearson이 온라인 감독관 시험이나 시험 센터로 시험을 시행한다.
- 각 시험에는 120분이 주어진다. 응시자는 예약 전체에 약 135분을 잡아 두는 것이
  좋다.
- 합격은 100~1,000 환산 점수에서 720이다. 원점수 백분율 환산이 아니다.
- 자격증은 12개월간 유효하다.
- 시험은 백지 시험이다. 문서, 노트, AI 어시스턴트, 브라우저 번역 도구는
  허용되지 않는다.
- 재응시 대기는 14일, 30일, 그다음 90일이고, 최근 12개월 동안 시험당 최대 네
  번까지만 응시할 수 있다.
- 이전 공식 연습 시험은 폐기됐다. 현재 시험 가이드에는 예시 문항이 들어 있다.
- 현재 정가는 Associate Foundations $99, Developer Foundations $125, Architect
  Foundations $125, Architect Professional $175다.
- Architect Foundations는 Architect Professional의 선수 지식이 아니며, 자동으로
  상위 자격으로 승급되지도 않는다.

## 커뮤니티 주장 조치

### 응시자 글

첨부된 응시자 리뷰는 정확한 작동 방식과 시나리오 판단의 우선순위를 정하는 데
유용합니다. 그 글의 작성 시점, 점수, 과정 완주 소요 추정, 시험 난이도 순위,
권장 응시 순서, 기억에 의존해 재구성한 문항 구성은 어디까지나 일인칭
경험입니다.

다음 두 주장은 공식 커리큘럼 사실이 되어서는 안 됩니다:

- 시험은 온라인 전용이 아니다. Pearson은 시험 센터 시행도 제공한다.
- 공개된 CCAR-P 사양에는 선다형(multiple-choice)과 다중 응답
  (multiple-response) 문항이 나온다. 한 응시자가 목격한 매칭이나 드롭다운
  인터페이스가 세 번째 공식 문항 유형이 되는 것은 아니다.

### 연습 PDF

제공된 60문항짜리 Associate 연습 패킷은 일곱 개의 공개 도메인 가중치를 따르며
해답 키도 방어할 만합니다. 독립적인 연습 자료로 남아 있고 문항 문구는 하나도
베끼지 않았습니다.

세 가지 주의 사항이 이 커리큘럼 자체의 해설에 반영됩니다:

- 내부 메모 워크플로는 그 내용이 비민감성이며 조직 정책에 따라 승인됐다고
  명시해야 한다.
- 프로젝트 지식은 검색 가능한 컨텍스트일 뿐, 자동으로 참이 아니다. 주장은
  여전히 검증이 필요하다.
- 75퍼센트 연습 목표는 학습용 경험칙일 뿐, 공식 환산 점수로 바꾸는 공식이
  아니다.

### 영상과 재생목록

자료별 전체 조치 내역은
[`youtube-source-review.md`](youtube-source-review.md)에서 관리합니다. 감사
대상 전체에서 오래 쓸 수 있는 신호는 실전 구축, 정확한 작동 방식 조회, 시나리오
트레이드오프, 오류 진단, 반복 복습이었습니다. 개인 점수, 공부 시간, 카탈로그
개수, 제품 순위, 기억에 의존한 문항, 특정 주제가 반드시 나온다는 주장은 사실
입력으로 기각됐습니다.

Academy 순위 영상은 네 번째 AI Fluency 역량을 "Dialogue"라고 잘못 부릅니다.
Anthropic 공식 프레임워크는 **Diligence(성실)**입니다. 이 커리큘럼은 Delegation,
Description, Discernment, Diligence를 가르칩니다.

## 제품 작동 방식 표류 통제

- stdio와 Streamable HTTP를 현재 MCP 전송 방식으로 다룬다. 역사적 맥락이 필요할
  때는 구식 HTTP+SSE를 폐기(deprecated)로 표기한다.
- 기계 계약이 필요하면 프롬프트만으로 JSON을 요구하는 방식보다 네이티브 구조화된
  출력이나 엄격한 도구 스키마를 선호한다.
- 속도, 노력(effort), 사고(thinking), 모델 선택은 영구 호환표가 아니라 날짜가
  표시된 결정 과정으로 가르친다.
- 정확한 Claude Code 플래그, 경로, 설정 우선순위, 훅, Agent SDK 라이프사이클
  필드는 출시 전에 현재 문서로 검증한다.
- 직접 Claude, Amazon Bedrock, Google Vertex AI, Microsoft Foundry는 배포
  선택지로 유지하되, 어울림 여부는 조달, 신원, 컴플라이언스, 클라우드 약정,
  운영 통제, 비용에 달려 있다.
