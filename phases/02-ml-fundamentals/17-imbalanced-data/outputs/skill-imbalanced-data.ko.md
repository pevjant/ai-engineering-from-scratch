# 불균형 데이터 전략

불균형 분류 문제를 다루기 위한 의사 결정 체크리스트입니다. 이 순서를 따라가면 문제에 맞는 접근 방식을 고를 수 있습니다.

## 단계 1: 불균형 측정

- 클래스별 샘플 수를 센다
- 불균형 비율(다수 / 소수)을 계산한다
- 약함: 비율 < 3:1 (예: 70/30)
- 중간: 비율 3:1~20:1 (예: 95/5)
- 심함: 비율 > 20:1 (예: 99/1)

## 단계 2: 올바른 지표 고르기

불균형 데이터셋에서는 정확도보다 정밀도/재현율/F1을 선호하세요. 문제에 따라 고르세요:

| 상황 | 1순위 지표 | 2순위 지표 |
|-----------|---------------|-----------------|
| 양성을 놓치는 것이 매우 비쌈(사기, 질병) | 재현율 | F2 점수 |
| 오탐이 비쌈(스팸 필터, 추천) | 정밀도 | F0.5 점수 |
| 둘 다 대략 비슷하게 중요 | F1 점수 | MCC |
| 하나의 순위용 지표가 필요 | AUPRC | AUC-ROC |
| 데이터셋 간 비교가 필요 | MCC | AUPRC |

## 단계 3: 재조정(rebalancing) 전략 고르기

### 불균형 심각도 기준

| 불균형 | 첫 시도 | 다음 시도 | 피할 것 |
|-----------|-----------|------------|-------|
| 약함 (< 3:1) | 클래스 가중치 | 임계값 튜닝 | 오버샘플링(불필요) |
| 중간 (3:1~20:1) | SMOTE + 클래스 가중치 | 그 위에 임계값 튜닝 | 언더샘플링(데이터 손실이 너무 큼) |
| 심함 (> 20:1) | SMOTE + 클래스 가중치 + 임계값 | 균형 배깅 앙상블 | 언더샘플링 단독 |

### 데이터셋 크기 기준

| 데이터셋 크기 | 선호 전략 | 이유 |
|-------------|-------------------|--------|
| 1,000개 미만 | 오버샘플링 또는 SMOTE | 다수 클래스 데이터를 잃을 여유가 없음 |
| 1,000~10,000 | SMOTE + 임계값 튜닝 | k-NN에 쓸 소수 샘플이 충분함 |
| 10,000 초과 | 클래스 가중치 또는 언더샘플링 | 빠르고, 소수 데이터가 충분함 |

## 단계 4: 기법 적용

### 클래스 가중치(항상 먼저 시도)
- sklearn에서는 `class_weight='balanced'`
- 데이터를 수정할 필요 없음
- 손실 기반 모델이라면 무엇과도 함께 동작
- 기댓값 측면에서 오버샘플링과 동등

### SMOTE
- 학습 데이터에만 적용(테스트/검증에는 절대 금지)
- k=5 이웃 사용(기본값)
- 최상의 결과를 위해 클래스 가중치와 결합
- 경계 근처의 잡음 섞인 합성 포인트 주의

### 임계값 튜닝
- 모델을 학습시키고 검증 세트에서 예측 확률을 얻음
- 임계값을 0.05부터 0.95까지 훑음
- 선택한 지표를 최대화하는 임계값을 고름
- 항상 검증 데이터에서 튜닝, 테스트 데이터에서는 절대 금지

## 단계 5: 올바르게 검증

- 층화 교차 검증(stratified cross-validation)을 사용(각 폴드의 클래스 비율 유지)
- 원본(리샘플링하지 않은) 테스트 세트에서 지표를 보고
- 분할 전에 SMOTE를 적용하지 않음 -- 학습 폴드에만 적용
- "항상 다수 클래스 예측" 베이스라인과 비교

## 단계 6: 피해야 할 흔한 실수

- train/test 분할 전에 데이터셋 전체에 SMOTE를 적용(데이터 누수)
- 평가 지표로 정확도를 사용
- 클래스 가중치를 먼저 시도하지 않음(가장 단순한 접근이고 종종 충분함)
- 오버샘플링한 뒤 교차 검증(합성 포인트가 폴드를 넘어 새어나감)
- 임계값 튜닝을 무시(재학습 없이 공짜로 얻는 성능)
- 작은 데이터셋에서 무작위 언더샘플링(데이터를 너무 많이 버림)

## 빠른 의사 결정 트리

1. 불균형 비율이 < 3:1인가? -> 클래스 가중치만 시도
2. 데이터셋이 10,000 샘플을 넘는가? -> 클래스 가중치 + 임계값 튜닝
3. 데이터셋이 1,000 샘플 미만인가? -> SMOTE + 클래스 가중치
4. 그 외 -> SMOTE + 클래스 가중치 + 임계값 튜닝
5. 그래도 충분하지 않은가? -> 균형 배깅 앙상블
