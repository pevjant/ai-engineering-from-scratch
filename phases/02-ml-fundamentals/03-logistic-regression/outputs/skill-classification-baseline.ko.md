# 분류 베이스라인 가이드

복잡한 모델을 시도하기 전에 로지스틱 회귀로 베이스라인을 먼저 세우세요. 몇 초 만에 학습되고, 확률을 출력하며, 완전히 해석 가능합니다. 놀랄 만큼 많은 실제 문제가 그 이상의 화려한 모델을 필요로 하지 않습니다.

## 결정 체크리스트

1. 결정 경계가 선형일 가능성이 높은가?
   - 예: 로지스틱 회귀로도 충분할 가능성이 높다
   - 아니오: 그래도 개선 폭을 측정하기 위한 베이스라인으로는 로지스틱 회귀가 필요하다

2. 특성(feature)이 몇 개인가?
   - 50개 미만: 표준 로지스틱 회귀로 충분하다
   - 50개 ~ 10,000개: L2 정규화(Ridge)를 추가한다
   - 10,000개 초과(예: TF-IDF 텍스트 특성): L1 정규화(Lasso) 또는 LinearSVC를 사용한다

3. 데이터셋이 불균형인가?
   - 5:1 미만 비율: 조정 없이도 괜찮을 가능성이 높다
   - 5:1 ~ 50:1: sklearn에서 `class_weight="balanced"`를 사용한다
   - 50:1 초과: 클래스 가중치에 적절한 지표(정밀도, 재현율, F1)를 함께 사용한다

4. 특성들의 스케일이 서로 다른가?
   - 로지스틱 회귀 전에는 반드시 표준화하세요. 경사 기반 최적화를 쓰기 때문에, 스케일이 맞지 않는 특성은 수렴을 느리게 하거나 결정 경계를 왜곡합니다.

5. 결측값이 있는가?
   - 피팅 전에 대체(imputation)하세요. 로지스틱 회귀는 NaN을 처리할 수 없습니다.
   - 수치형 열은 중앙값 대체, 범주형은 최빈값 대체를 사용하세요.

## 로지스틱 회귀로 충분한 경우

- 대체로 선형인 특성 관계를 가진 이진 분류
- 확률 출력이 필요할 때(클래스 레이블만이 아니라)
- 해석 가능성이 요구될 때(표준화 후에는 계수가 특성 중요도의 방향과 상대적 크기를 나타냄)
- 학습 데이터가 적을 때(수백~수천 개 샘플)
- 실시간 서빙에 쓸 빠른 모델이 필요할 때(추론 시점에는 점곱 하나면 끝)
- 규제·컴플라이언스 요건상 설명 가능성이 필요할 때

## 언제 업그레이드해야 하나

- 정확도가 목표보다 훨씬 낮은 지점에서 정체되고, 특성 엔지니어링은 이미 시도했을 때
- 특성과 타깃의 관계가 명확히 비선형일 때(잔차 플롯으로 확인)
- 큰 테이블 데이터(1만 행 이상)를 다룰 때: 그래디언트 부스팅(XGBoost 또는 LightGBM)을 시도
- 다항 특성으로는 잡아낼 수 없는 복잡한 특성 상호작용이 있을 때
- 이미지, 텍스트, 시퀀스 데이터일 때: 원시 입력에 로지스틱 회귀는 동작하지 않음

## 분류 베이스라인을 위한 전처리 단계

1. **학습/테스트 분할**을 다른 전처리보다 먼저 합니다. 데이터 누수(data leakage)를 막아 줍니다.
2. **결측값 처리**: 수치형은 중앙값, 범주형은 최빈값으로 대체합니다.
3. **범주형 인코딩**: 고유값이 적으면(10개 미만) 원-핫, 많으면 타깃 인코딩. 타깃 인코딩은 학습 폴드에서만 피팅합니다(누수를 막으려면 out-of-fold 인코딩을 사용).
4. **수치형 스케일링**: StandardScaler(평균 0, 분산 1). 학습 데이터로 피팅하고 학습·테스트 양쪽에 변환을 적용합니다.
5. `C=1.0`(기본 정규화)으로 **로지스틱 회귀를 피팅**합니다.
6. **평가**: 오차 행렬(Confusion Matrix), 정밀도, 재현율, F1. 정확도만 보지 마세요.
7. **임계값 조정**: 기본값 0.5는 거의 최적이 아닙니다. 0.1부터 0.9까지 훑어보며 정밀도/재현율 우선순위에 맞는 임계값을 고르세요.

## 흔한 실수

- 불균형 데이터에서 정확도만 평가하기(다수 클래스만 예측하는 모델도 점수는 높지만 쓸모가 없음)
- 특성 스케일링 잊기(스케일이 맞지 않으면 로지스틱 회귀 학습이 느리고 더 나쁜 해에 수렴함)
- 테스트셋으로 결정 임계값을 튜닝하기(검증셋이나 교차 검증을 사용할 것)
- 베이스라인을 건너뛰고 바로 XGBoost로 뛰어들기(해석 가능성을 잃고 비교 기준점도 없어짐)
- 다중공선성 검사 생략하기(서로 강하게 상관된 특성은 계수 분산을 부풀림)

## 빠른 참조

| 시나리오 | 모델 | 정규화 | 핵심 설정 |
|----------|-------|---------------|-------------|
| 특성이 적고 해석이 중요 | LogisticRegression | L2 (기본) | C=1.0 |
| 특성이 많고 일부는 불필요 | LogisticRegression | L1 | penalty="l1", solver="saga" |
| 고차원 희소(텍스트) | SGDClassifier | L1 또는 ElasticNet | loss="log_loss" |
| 클래스 불균형 | LogisticRegression | L2 | class_weight="balanced" |
| 확률이 필요 | LogisticRegression | L2 | predict_proba() |
| 클래스 레이블만 필요 | LinearSVC | L2 | 대량 데이터에서 LR보다 빠름 |
