# SVM 커널 선택 가이드

SVM은 두 가지 선택으로 정의됩니다. 커널(결정 경계의 모양을 결정)과 정규화 파라미터(마진 폭과 분류 오류 사이의 트레이드오프를 조절)입니다. 이것들을 제대로 고르는 것이 쓸모없는 모델과 강한 모델의 차이를 만듭니다.

## 결정 체크리스트

1. 데이터가 선형 분리 가능한가(또는 그에 가까운가)?
   - 예: 선형 커널을 사용합니다. 더 빠르고 해석하기 쉽습니다.
   - 아니오: 2번으로 갑니다.

2. 특성(feature)과 샘플 중 어느 쪽이 많은가?
   - 특성 >> 샘플(예: TF-IDF를 쓴 텍스트): 선형 커널을 사용합니다. 고차원 데이터는 종종 선형 분리 가능합니다. RBF는 이득 없이 복잡도만 더합니다.
   - 샘플 >> 특성(예: 특성 10-50개짜리 테이블 데이터): RBF 커널이 기본 선택입니다.

3. 결정 경계가 매끄러울 것으로 예상되는가?
   - 매끄럽고 연속적인 경계: RBF 커널
   - 다항식 모양의 경계: 다항 커널(차수 2 또는 3부터 시작)
   - 도메인 지식이 특정 상호작용 항을 가리킴: 맞는 차수의 다항 커널

4. 데이터셋은 얼마나 큰가?
   - 10,000 샘플 미만: 어떤 커널이든 동작하며, RBF가 안전한 기본값
   - 10,000 ~ 100,000: 선형 커널 또는 LinearSVC(원형 정식화, 에포크당 O(n))
   - 100,000 초과: 커널 SVM을 쓰지 마세요. 선형 SVM, 그래디언트 부스팅, 또는 신경망으로 전환합니다.

5. 특성을 스케일링했는가?
   - SVM에는 특성 스케일링이 필요합니다. 피팅 전에 반드시 표준화하세요(평균 0, 분산 1). 스케일이 맞지 않는 특성은 마진 기하학을 왜곡합니다.

## 커널 선택 플로차트

```
Start
  |
  v
Features > 1000 or features >> samples?
  Yes --> Linear kernel (LinearSVC for speed)
  No  --> Dataset < 10k samples?
            Yes --> Try RBF first (best general-purpose kernel)
            No  --> Linear kernel (kernel SVMs are O(n^2) to O(n^3))
```

RBF가 잘 안 되면 차수 2-3의 다항 커널을 시도합니다. 그래도 안 되면 그 문제는 SVM과 맞지 않을 수 있습니다.

## C(정규화) 튜닝

C는 오분류에 대한 벌점을 조절합니다. 정규화 세기와는 반비례 관계입니다.

| C 값 | 효과 | 언제 사용 |
|---------|--------|-------------|
| 0.001 - 0.01 | 넓은 마진, 많은 위반 허용 | 노이즈가 많은 데이터, 일반화를 원할 때 |
| 0.1 - 1.0 | 균형 | 좋은 시작 범위 |
| 10 - 1000 | 좁은 마진, 위반이 적음 | 깨끗한 데이터, 높은 정확도가 필요할 때 |

튜닝 전략:
- C=1.0부터 시작
- 로그 스케일로 탐색: [0.001, 0.01, 0.1, 1, 10, 100, 1000]
- 교차 검증으로 최적값 선택
- 최적 C가 범위 끝에 붙었다면, 그쪽으로 범위를 넓힙니다

## gamma(RBF 커널) 튜닝

gamma는 하나의 학습 점이 얼마나 멀리까지 영향을 미치는지 조절합니다. 가우시안의 폭을 정의합니다.

| gamma 값 | 효과 | 언제 사용 |
|-------------|--------|-------------|
| 작음 (0.001) | 각 점이 넓은 영역에 영향. 매끄럽고 단순한 경계 | 과소적합이거나 특성이 적을 때 |
| 중간 (auto: 1/n_features) | sklearn 기본값. 무난한 시작점 | 일반적인 용도 |
| 큼 (10 이상) | 각 점이 바로 근처에만 영향. 복잡하고 구불구불한 경계 | 과적합 위험 |

튜닝 전략:
- gamma="scale"(1 / (n_features * X.var()), sklearn 기본값)부터 시작
- 로그 스케일로 탐색: [0.001, 0.01, 0.1, 1, 10]
- 낮은 gamma + 높은 C는 과적합 경향
- 높은 gamma + 낮은 C는 과소적합 경향

## C와 gamma 동시 튜닝

C와 gamma는 서로 상호작용합니다. 항상 독립적으로가 아니라 함께 튜닝하세요.

권장 접근:
1. 성긴 그리드 탐색: C는 [0.01, 0.1, 1, 10, 100], gamma는 [0.001, 0.01, 0.1, 1, 10] (25가지 조합)
2. 가장 좋은 영역을 찾습니다
3. 그 영역 주위에서 촘촘한 그리드 탐색(예: C는 [5, 10, 20, 50], gamma는 [0.05, 0.1, 0.2])
4. 전 과정에서 5폴드 교차 검증을 사용합니다

## 흔한 실수

- 고차원 희소 데이터에 RBF 커널 쓰기(선형이 더 좋고 100배 빠름)
- 특성 스케일링 잊기(SVM 실수 중 단연 1위)
- 노이즈가 많은 데이터에서 C를 너무 높게 잡기(경계를 학습하는 대신 노이즈를 외워 버림)
- 5만 샘플이 넘는 데이터셋에 커널 SVM 쓰기(학습 시간이 감당 불가)
- C와 gamma를 따로 튜닝하기(둘은 서로를 보완하며 움직임)
- 다항 커널 차수 5 이상을 기본으로 쓰기(공격적으로 과적합됨. 먼저 2 또는 3을 시도)

## 빠른 참조

| 커널 | 언제 사용 | 핵심 파라미터 | 학습 복잡도 |
|--------|------------|----------------|-------------------|
| Linear | 텍스트/TF-IDF, 특성 많음, 대용량 데이터 | C만 | 에포크당 O(n) |
| RBF | 범용, 1만 샘플 미만 | C, gamma | O(n^2) ~ O(n^3) |
| Polynomial | 다항 관계가 알려진 경우 | C, degree, coef0 | O(n^2) ~ O(n^3) |
| Sigmoid | 거의 쓸모 없음(2층 신경망과 동등) | C, gamma, coef0 | O(n^2) ~ O(n^3) |
