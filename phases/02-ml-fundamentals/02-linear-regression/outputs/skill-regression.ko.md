# 회귀 전략 가이드

회귀는 연속적인 값을 예측합니다. 알맞은 접근법은 특성과 타깃 사이의 관계, 특성 개수, 과적합 위험에 따라 달라집니다.

## 의사 결정 체크리스트

1. 특성과 타깃 사이의 관계가 대략 선형인가?
   - 예: 일반 선형 회귀로 시작
   - 아니오: 다항 특성 또는 비선형 모델 시도

2. 샘플 대비 특성이 몇 개인가?
   - 특성은 적고 샘플은 많음: 일반 선형 회귀로 충분
   - 특성이 많고 샘플은 적음: 정규화 사용 (Ridge 또는 Lasso)
   - 샘플보다 특성이 많음: 특성 선택에는 Lasso (L1), 모든 가중치 축소에는 Ridge (L2)

3. 해석 가능성이 필요한가?
   - 예: 특성이 적은 선형 회귀, 또는 자동 특성 선택을 위한 Lasso
   - 아니오: 다항 특성, 또는 트리 기반 모델이나 신경망으로 이동

4. 데이터셋이 작은가(1만 행 미만)?
   - 속도를 위해 정규방정식(닫힌 형태 해) 사용
   - 신뢰할 수 있는 평가를 위해 교차 검증 필수

5. 데이터셋이 큰가(수백만 행)?
   - 확률적 경사 하강법(SGD) 또는 미니배치 경사 하강법 사용
   - 정규방정식은 O(n^3) 행렬 역산 때문에 너무 느림

## 각 접근법을 언제 쓸까

**일반 선형 회귀(OLS)**: 모든 회귀 작업의 베이스라인. 여기서 시작하세요. R-제곱이 만족스럽고 모델이 단순하면 여기서 끝내도 됩니다.

**다항 회귀**: 산점도가 직선이 아니라 곡선을 보여 줄 때. 2차부터 시작하세요. 검증 성능이 정당화할 때만 올립니다. 5차를 넘기면 거의 항상 과적합합니다.

**릿지 회귀(Ridge, L2)**: 서로 상관된 특성이 많을 때. 모든 가중치가 0 쪽으로 줄어들지만 정확히 0이 되는 것은 없습니다. 모든 특성이 기여한다고 믿을 때 좋습니다.

**라쏘 회귀(Lasso, L1)**: 특성이 많고 소수만 중요할 것으로 의심될 때. 라쏘는 불필요한 특성의 가중치를 정확히 0으로 밀어 버려 자동 특성 선택을 수행합니다.

**엘라스틱 넷(Elastic Net)**: L1과 L2 페널티를 결합합니다. 상관된 특성이 많으면서 어느 정도의 특성 선택도 원할 때 사용하세요.

## 자주 하는 실수

- 경사 하강법 전에 특성 스케일링 건너뛰기 (수렴이 극도로 느려집니다)
- 테스트 세트 성능으로 하이퍼파라미터 조율하기 (검증 세트나 교차 검증을 쓰세요)
- 검증 오차 확인 없이 고차 다항식 피팅하기 (훈련 R^2는 차수가 오르면 항상 늘어납니다)
- 잔차 그림 무시하기 (잔차에 패턴이 보이면 R^2는 오해의 소지가 있습니다)
- R^2를 유일한 지표로 대하기 (잔차 분포, MAE, 도메인별 기준도 확인하세요)

## 빠른 참고표

| 방법 | 언제 쓰나 | 정규화 | 특성 선택 |
|--------|------------|---------------|-------------------|
| OLS | 베이스라인, 특성이 적을 때 | 없음 | 수동 |
| Ridge | 특성이 많고 모두 관련 있을 때 | L2 (축소) | 아니오 |
| Lasso | 특성이 많고 일부만 관련 있을 때 | L1 (0으로 만듦) | 자동 |
| Elastic Net | 상관된 특성이 많을 때 | L1 + L2 | 부분 |
| Polynomial | 비선형 관계 | 그 위에 Ridge/Lasso 추가 | 수동 차수 선택 |
