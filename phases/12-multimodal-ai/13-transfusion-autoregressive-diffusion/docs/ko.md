# Transfusion: 하나의 트랜스포머에서 자기회귀 텍스트 + 확산 이미지

> Chameleon과 Emu3는 모든 것을 이산 토큰에 걸었습니다. 되긴 하지만 양자화 병목이 눈에 보입니다 — 이미지 품질이 연속 공간 확산 모델보다 낮은 곳에서 정체되죠. Transfusion(메타, Zhou 등, 2024년 8월)은 정반대로 겁니다: 이미지는 연속으로 유지하고, VQ-VAE를 완전히 버리고, 하나의 트랜스포머를 두 손실로 학습합니다. 텍스트 토큰에는 다음 토큰 예측을, 이미지 패치에는 플로우 매칭/확산 손실을 줍니다. 두 목표 모두 같은 가중치를 최적화합니다. Stable Diffusion 3(MMDiT)의 바탕 아키텍처는 이와 가까운 사촌입니다. 이 레슨에서는 Transfusion의 테제를 읽고, 장난감 두-손실 트레이너를 만들며, 하나의 트랜스포머로 두 역할을 하게 해 주는 어텐션 마스크를 추적합니다.

**유형:** 빌드
**언어:** Python (표준 라이브러리, MNIST 규모 장난감 위의 두-손실 트레이너)
**선수 지식:** 페이즈 12 · 11 (Chameleon), 페이즈 8 (생성형 AI)
**시간:** 약 180분

## 학습 목표

- 하나의 백본 위에서 두 손실(텍스트 토큰 NTP, 이미지 패치 확산 MSE)을 도는 트랜스포머를 조립한다.
- 이미지 패치 전체의 쌍방향 어텐션 + 텍스트 토큰의 인과적(causal) 어텐션이 왜 맞는 마스크 선택인지 설명한다.
- Transfusion 스타일(연속 이미지, 확산 손실)을 Chameleon 스타일(이산 이미지, NTP)과 연산량·품질·코드 복잡도 기준으로 비교한다.
- MMDiT의 기여를 말할 수 있다: 블록마다 모달리티별 가중치, 잔차 스트림에서의 공동 어텐션.

## 문제 상황

이산 vs 연속 이미지 토큰 논쟁은 LLM보다 오래됐습니다. 연속 표현(원시 픽셀, VAE 잠재값)은 디테일을 보존합니다. 이산 토큰(VQ 인덱스)은 트랜스포머의 기본 어휘에 맞지만 양자화 단계에서 디테일을 잃죠.

Chameleon / Emu3는 이산으로 갔습니다: 손실 하나, 아키텍처 하나, 하지만 이미지 충실도는 토크나이저 품질에 갇힙니다.

확산 모델은 연속으로 갔습니다: 뛰어난 이미지 품질, 하지만 LLM과 별개의 모델, 복잡한 노이즈 스케줄 엔지니어링, 텍스트 생성과의 깔끔한 통합 부재.

Transfusion은 묻습니다: 둘 다 가질 수는 없을까? 이미지는 연속으로 유지하되, 여전히 모델 하나로 학습하고, 두 손실을 하나의 그래디언트 스텝에 이어 붙이면요.

## 개념

### 두-손실 아키텍처

하나의 디코더 전용 트랜스포머가 다음을 담은 시퀀스를 처리합니다:

- 텍스트 토큰 (이산, BPE 어휘에서).
- 이미지 패치 (연속, 16x16 픽셀 블록을 선형 임베딩으로 히든 차원에 투영 — ViT 인코더의 입력과 동일).
- 연속 패치가 어디 사는지 표시하는 `<image>`와 `</image>` 태그.

순전파는 한 번 돕니다. 손실은 토큰마다 두 헤드 중 하나를 고릅니다:

- 텍스트 토큰: 어휘-로짓 헤드에 대한 표준 크로스 엔트로피.
- 이미지 패치: 연속 패치에 대한 확산 손실 — 각 패치에 더해진 노이즈를 예측.

그래디언트는 공유 트랜스포머 본체를 흐릅니다. 두 손실이 공유 가중치를 동시에 개선합니다.

### 어텐션 마스크: 인과적 텍스트 + 쌍방향 이미지

텍스트 토큰은 인과적이어야 합니다 — 텍스트 토큰이 미래 텍스트를 봐 버리면 teacher forcing이 깨지죠. 하지만 이미지 패치는 하나의 스냅샷을 나타내므로, 같은 이미지 블록 안에서는 서로 쌍방향으로 봐야 합니다.

마스크:

```
M[i, j] = 1 if:
  (i is text and j is text and j <= i)   # 텍스트는 인과적
  OR (i is image and j is image and same_image_block(i, j))   # 이미지 내부는 쌍방향
  OR (i is text and j is image and j < i_image_end)   # 텍스트는 이전 이미지를 봄
  OR (i is image and j is text and j < i_image_start)   # 이미지는 앞선 텍스트를 봄
```

학습과 추론에서 블록 삼각형 마스크로 구현됩니다.

### 트랜스포머 안의 확산 손실

확산 손실은 표준입니다: 이미지 패치에 노이즈를 더하고, 모델에게 그 노이즈(또는 동등하게 깨끗한 패치)를 예측하게 합니다. Transfusion의 버전은 플로우 매칭을 씁니다 — 노이즈에서 깨끗한 상태로의 속도장(velocity field)을 예측합니다.

학습 중:
1. 이미지 패치 x0마다 무작위 타임스텝 t를 샘플링.
2. 노이즈 ε를 샘플링하고 xt = (1-t) * x0 + t * ε 계산(플로우 매칭의 선형 보간).
3. 트랜스포머가 v_theta(xt, t)를 예측; 손실 = MSE(v_theta(xt, t), ε - x0).
4. 같은 시퀀스의 텍스트 NTP 손실과 함께 역전파.

추론 때 생성은:
- 텍스트 토큰: 표준 자기회귀 샘플링.
- 이미지 패치: 앞선 텍스트 토큰을 조건으로 하는 확산 샘플링 루프(보통 10-30 스텝).

### MMDiT: Stable Diffusion 3의 변형

Stable Diffusion 3(Esser 등, 2024년 3월)는 Transfusion과 비슷한 시기에 MMDiT(Multimodal Diffusion Transformer)를 출시했습니다. 두 아키텍처는 형제입니다.

MMDiT의 핵심 차이:

- 블록별 모달리티 전용 가중치. 각 트랜스포머 블록은 텍스트 토큰용과 이미지 패치용으로 분리된 Q, K, V, MLP 가중치를 가집니다. 어텐션은 공동(교차 모달리티)이고, 나머지는 모달리티별입니다.
- 정류 흐름(rectified flow) 학습. 샘플링이 잘 알려지고 DDPM보다 수학이 단순한 특정 플로우 매칭 변형.
- 스케일. MMDiT는 SD3(2B 및 8B 파라미터 변형)의 백본입니다. Transfusion 논문은 7B까지 확장합니다.

둘 다 같은 핵심 아이디어로 수렴합니다: 하나의 트랜스포머가 텍스트에는 NTP를, 연속 이미지 표현에는 확산을 돌린다.

### 왜 Chameleon 스타일을 이기나

이미지 생성에서 연속-확산과 이산-NTP의 품질 격차는 측정 가능합니다. Transfusion 논문이 보고하는 것:

- 7B 파라미터에서 같은 크기의 Chameleon 스타일 모델을 FID로 3-5점 이김.
- 토크나이저 학습 불필요 — 이미지 인코더가 더 단순함(히든으로의 선형 투영, ViT 입력층과 동일).
- 추론에서 이미지 패치 디노이징을 병렬화할 수 있음, 자기회귀 이미지 토큰과는 다르게.

단점: Transfusion은 이중 손실 모델이라 학습 다이내믹스가 더 까다롭습니다. 손실 가중치 튜닝이 필요하고, NTP와 확산 사이 스케줄 불일치로 한 헤드가 지배할 수 있습니다.

### 그 아래 계승되는 것들

Janus-Pro(레슨 12.15)는 이해용과 생성용 비전 인코더를 분리하되(SigLIP 하나, VQ 하나) 트랜스포머 본체를 공유하는 식으로 Transfusion의 아이디어를 다듬습니다. Show-o(레슨 12.14)는 확산을 이산 확산(마스크 예측)으로 바꿉니다. Transfusion 이후 통합 생성 계열은 빠르게 갈라집니다.

이미지를 내놓는 2026년 프로덕션(운영 환경) VLM들 — Gemini 3 Pro, GPT-5, Claude Opus 4.7의 이미지 생성 경로 — 은 거의 틀림없이 이 계열의 어떤 후손을 씁니다. 세부는 비공개입니다.

## 직접 써보기

`code/main.py`는 아주 작은 MNIST 유사 문제 위에 장난감 Transfusion을 만듭니다:

- 텍스트 캡션은 숫자(0-9)를 묘사하는 짧은 정수 시퀀스.
- 이미지는 바이트의 4x4 그리드.
- 공유 가중치 선형 투영 한 쌍이 트랜스포머 대역을 맡음; 텍스트에는 NTP 손실, 노이즈 낀 패치에는 MSE 손실.
- 학습 루프는 두 손실을 번갈아 돌리고, 어텐션 마스크는 명시적.
- 생성은 순전파 한 번으로 텍스트 캡션과 4x4 이미지를 함께 내놓음.

트랜스포머는 장난감입니다. 진짜 산출물은 두-손실 배관, 어텐션 마스크 구성, 추론 루프입니다.

## 연습 문제

1. Transfusion 스타일 모델이 텍스트 토큰 70%, 이미지 패치 30%로 학습됩니다. 이미지 확산 손실의 크기가 텍스트 NTP 손실의 약 10배입니다. 두 손실의 균형을 맞추는 가중치는 무엇인가요?

2. 시퀀스 `[T, T, <image>, P, P, P, P, </image>, T]`의 블록 삼각형 마스크를 구현하세요. 각 항목을 0 또는 1로 표시하세요.

3. MMDiT는 모달리티별 QKV 가중치를 가집니다. 완전 공유 트랜스포머인 Transfusion 대비 이게 추가하는 파라미터 수 오버헤드는 얼마인가요? 7B 파라미터에서 그만한 가치가 있나요?

4. 생성: 텍스트 프롬프트가 주어지면, 모델이 50토큰 NTP를 돌리고, `<image>`를 만나고, 20 스텝 디노이즈로 256개 패치에 확산을 돌립니다. 총 순전파는 몇 번인가요?

5. SD3 논문의 3절을 읽어 보세요. 정류 흐름(rectified flow)이 무엇이고, 왜 DDPM보다 적은 추론 스텝으로 수렴하는지 설명하세요.

## 핵심 용어

| 용어 | 사람들이 말하는 표현 | 실제 의미 |
|------|-----------------|------------------------|
| 두-손실 학습 | "NTP + 확산" | 하나의 트랜스포머가 같은 그래디언트 스텝에서 텍스트 토큰의 크로스 엔트로피와 연속 이미지 패치의 MSE를 함께 최적화 |
| 플로우 매칭 | "정류 흐름" | 노이즈에서 깨끗한 데이터로의 속도장을 예측하는 확산 변형; DDPM보다 수학이 단순 |
| MMDiT | "멀티모달 DiT" | Stable Diffusion 3의 아키텍처: 공동 어텐션, 모달리티별 MLP와 노름 |
| 블록 삼각형 마스크 | "인과 텍스트 + 쌍방향 이미지" | 텍스트 전체는 인과적이되 이미지 영역 안에서는 쌍방향인 어텐션 마스크 |
| 연속 이미지 표현 | "VQ 없음" | 이미지 패치를 정수 코드북 인덱스가 아닌 실수 벡터로 표현 |
