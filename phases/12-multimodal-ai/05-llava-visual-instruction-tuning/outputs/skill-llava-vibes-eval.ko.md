> 🇰🇷 이 문서는 한국어 번역본입니다(ELI5 스타일). 원문: [skill-llava-vibes-eval.md](skill-llava-vibes-eval.md)

LLaVA 계열 VLM(LLaVA-1.5, LLaVA-NeXT, LLaVA-OneVision 또는 커뮤니티 포크)과 테스트 이미지 세트가 주어지면, 캡셔닝·VQA·추론·거절·형식 준수를 다루는 10개 프롬프트 스모크 테스트를 실행합니다. 프로젝터와 LLM이 올바르게 연결됐는지 확인하는 스코어카드를 만들어 냅니다.

산출물:

1. 기대 동작 설명이 붙은 열 개의 프롬프트:
   - 캡셔닝 3개 (짧게, 자세히, 창의적으로).
   - VQA 3개 (개수 세기, 색깔, 객체 존재 여부).
   - 추론 2개 (두 영역 비교, 원인과 결과).
   - 거절 2개 (특정 개인, 개인정보(PII) 식별).
2. 프롬프트별 점수. 통과 / 부분 / 실패와 한 줄 근거.
3. 전체 패턴 진단. 캡셔닝은 통과하는데 VQA가 실패하면 스테이지 2 데이터 믹스를 의심하세요. 상세 캡셔닝에서 환각이 보이면 ShareGPT4V 스타일 데이터가 부족한 걸 의심하세요. 거절이 실패하면 안전 데이터 공백을 표시하세요.
4. 해상도 점검. OCR이 필요한 프롬프트 하나를 336x336 기본 해상도로 한 번, AnyRes로 한 번 더 실행하고 차이를 기록합니다. 저해상도 실패는 예상된 일이지만, 고해상도(AnyRes) 실패는 AnyRes 설정이 잘못됐다는 뜻입니다.
5. 후속 조치 제안. 특정 카테고리가 실패할 때 실행할 수 있는 구체적인 학습 데이터 추가 아이템 3가지.

하드 리젝(거절 사항):
- 바이브스 스위트를 돌리지 않고 벤치마크 점수만으로 VLM을 평가하는 요청. 벤치마크는 조작할 수 있지만, 바이브스는 실제 배포 준비 상태를 드러냅니다.
- 환각과 문체적 장황함을 섞어서 말하는 것. 지어낸 객체가 무엇인지, 단지 자세하게 묘사된 것인지 구분해서 표시하세요.
- 최종 답만 보고 추론 프롬프트를 통과로 처리하는 것. 추론 과정(chain)까지 확인해야 합니다.

거절 규칙:
- API 접근 없이 독점 VLM(Gemini, Claude, GPT-5V)을 바이브스 평가해 달라고 하면 거절 — 테스트에는 실제 추론이 필요합니다.
- 대상 사용 사례가 의료 진단이나 법률 자문이면 거절 — 바이브스 평가는 인증이 아니며, 고위험 도메인에 사용해서는 안 됩니다.
- 이미지가 제공되지 않으면 거절 — 이 테스트는 정의상 이미지 기반입니다.

출력: 10개 행(프롬프트, 이미지, 기대, 실제, 통과/부분/실패)으로 된 스코어카드, 전체 패턴 진단, 3개 항목의 후속 조치 목록. 마지막에 "다음에 읽을 것" 문단으로 마무리합니다 — 해상도 관련 실패면 레슨 12.06(AnyRes), 데이터 믹스 튜닝이면 레슨 12.07(ablation)을 가리킵니다.
