# Show-o와 이산 확산 통합 모델

> Transfusion은 연속 표현과 이산 표현을 섞었습니다. Show-o(Xie 등, 2024년 8월)는 반대 방향으로 갑니다: 텍스트 토큰은 인과적 다음 토큰 예측을, 이미지 토큰은 MaskGIT 정신의 마스크 이산 확산(masked discrete diffusion)을 씁니다. 둘이 하이브리드 어텐션 마스크를 낀 하나의 트랜스포머 안에 들어갑니다. 그 결과 하나의 백본, 모달리티당 토크나이저 하나, 하나의 손실 공식(다음 토큰 예측을 마스크 예측으로 확장한 것)으로 VQA, 텍스트-이미지, 인페인팅, 혼합 모달리티 생성이 통합됩니다. 이 레슨에서는 Show-o 설계 — 마스크 이산 확산이 왜 병렬적이고 적은 스텝의 이미지 생성기인가 — 를 따라가고, Transfusion과 Emu3와 대조합니다.

**유형:** 학습
**언어:** Python (표준 라이브러리, 마스크 이산 확산 샘플러)
**선수 지식:** 페이즈 12 · 13 (Transfusion)
**시간:** 약 120분

## 학습 목표

- 마스크 이산 확산을 설명한다: 토큰을 균등하게 마스크한 뒤 트랜스포머에게 되찾게 하는 스케줄.
- 병렬 이미지 디코딩(Show-o, MaskGIT)과 자기회귀 이미지 디코딩(Chameleon, Emu3)을 속도와 품질 기준으로 비교한다.
- Show-o가 체크포인트 하나로 처리하는 세 가지 과제를 말할 수 있다: T2I, VQA, 이미지 인페인팅.
- 마스킹 스케줄(코사인, 선형, 절단형)을 고르고, 샘플 품질에 미치는 효과를 추론한다.

## 문제 상황

Transfusion의 두-손실 학습은 되지만 다이내믹스가 더 까다롭습니다 — 연속 확산 손실이 이산 NTP 손실과 다른 수치 스케일에 살기 때문이죠. 손실 가중치 균형은 하이퍼파라미터 탐색입니다. 아키텍처는 효과적이지만 복잡합니다.

Show-o의 답: 두 모달리티 모두 이산으로 유지하되(Chameleon처럼), 이미지는 순차 생성 대신 마스크 이산 확산으로 병렬 생성합니다. 학습 목표는 다음 토큰 예측을 자연스럽게 일반화하는 단일 마스크 토큰 예측이 됩니다.

## 개념

### 마스크 이산 확산 (MaskGIT)

원조인 Chang 등(2022)의 MaskGIT 트릭은 우아합니다. 완전히 마스크된 이미지(모든 토큰이 특별한 `<MASK>` ID)에서 시작합니다. 각 스텝에서 마스크된 토큰 전부를 병렬로 예측하고, 가장 확신도 높은 top-K 예측만 확정하고 나머지는 다시 마스크합니다. 약 8-16회 반복하면 모든 토큰이 채워집니다. 스텝마다 몇 개를 언마스크할지의 스케줄은 튜닝 대상인데 — 코사인 스케줄이 잘 통합니다.

학습은 단순합니다: [0, 1]에서 마스킹 비율을 균등하게 샘플링하고, 이미지의 VQ 토큰에 적용하고, 트랜스포머가 마스크된 것들을 복구하게 학습합니다. 텍스트로 BERT가 한 일을 이미지 생성으로 확장한 것이죠.

### Show-o: 트랜스포머 하나, 하이브리드 마스크

Show-o는 MaskGIT을 인과적 언어 모델 트랜스포머 안에 넣습니다. 어텐션 마스크는:

- 텍스트 토큰: 인과적(표준 LLM).
- 이미지 토큰: 이미지 블록 내부 완전 쌍방향(마스크된 토큰이 예측 중에 다른 모든 이미지 토큰을 볼 수 있게).
- 텍스트-이미지: 텍스트는 이전 이미지를 보고, 이미지는 이전 텍스트를 봄.

학습은 다음을 번갈아 합니다:
1. 텍스트 시퀀스에 표준 NTP.
2. T2I 샘플: 텍스트 → 마스크된 이미지 토큰이 있는 이미지, 마스크 토큰 예측 손실.
3. VQA 샘플: 이미지 → 마스크된 텍스트 토큰이 있는 텍스트(실상은 그냥 NTP).

통합 손실은 `<MASK>` 토큰에 대한 크로스 엔트로피인데, 이게 텍스트 NTP("마스크"된 게 마지막 토큰뿐)와 이미지 마스크 확산(무작위 부분집합이 마스크됨)을 모두 커버합니다.

### 병렬 샘플링

Show-o는 이미지를 약 16 스텝에 만듭니다. 자기회귀 토큰당 방식의 약 1000 스텝이나, 확산의 약 20 스텝과 비교됩니다. 매 스텝에서 마스크된 토큰 전부를 병렬 예측하고; 확신도 top-K를 확정하고; 반복합니다.

비교:
- Chameleon / Emu3 (토큰 위 자기회귀): N_tokens 회의 순전파, 이미지당 보통 1024-4096.
- Transfusion (연속 확산): 약 20 스텝, 각 스텝이 트랜스포머 풀 패스.
- Show-o (마스크 이산 확산): 약 16 스텝, 각 스텝이 트랜스포머 풀 패스.

비슷한 규모의 모델에서 Show-o는 Chameleon보다 빠르고, Transfusion과 스텝 수는 대략 같으면서 스텝당 비용이 낮습니다(연속 MSE 손실 대비 이산 어휘 로짓).

### 체크포인트 하나의 과제들

Show-o는 프롬프트 형식으로 선택되는 네 과제를 추론 때 지원합니다:

- 텍스트 생성: 표준 자기회귀 텍스트 출력.
- VQA: 이미지 입력, 텍스트 출력.
- T2I: 텍스트 입력, 마스크 이산 확산으로 이미지 출력.
- 인페인팅: 일부 토큰이 마스크된 이미지를 받아 채우기.

인페인팅 능력은 마스크 예측 학습에서 공짜로 나옵니다. VQ 토큰 그리드의 한 영역을 마스크하고, 나머지 + 텍스트 프롬프트를 넣고, 마스크된 토큰을 예측하면 됩니다.

### 마스킹 스케줄

스텝마다 몇 개의 토큰을 언마스크할지의 스케줄이 품질을 결정합니다. Show-o는 코사인을 권합니다:

```
mask_ratio(t) = cos(pi * t / (2 * T))   # t = 0..T
```

스텝 0에서는 모든 토큰이 마스크(비율 1.0). 스텝 T에서는 마스크 없음. 코사인은 예측이 가장 정보적인 중간 비율대에 질량을 몰아줍니다. 선형 스케줄도 되지만 더 빨리 정체됩니다.

### Show-o2

Show-o2(2025년 후속작, arXiv 2506.15564)는 Show-o를 확장합니다: 더 큰 LLM 베이스, 더 나은 토크나이저, 개선된 마스크 스케줄. 아키텍처 패턴은 동일합니다.

### Show-o의 위치

2026년 분류표에서:

- 이산 토큰 + NTP: Chameleon, Emu3. 단순하지만 추론이 느림.
- 이산 토큰 + 마스크 확산: Show-o, MaskGIT, LlamaGen, Muse. 병렬 샘플링, 여전히 토크나이저가 손실의 원인.
- 연속 + 확산: Transfusion, MMDiT, DiT. 최고 품질, 더 복잡한 학습.
- VLM 안의 연속 + 플로우 매칭: JanusFlow, InternVL-U. 가장 최신.

과제로 고르세요: 합리적인 속도로 오픈 모델 하나에서 T2I + 인페인팅 + VQA를 원하면 Show-o. 품질이 최우선이고 두-손실 배관을 감당할 수 있으면 Transfusion.

## 직접 써보기

`code/main.py`는 Show-o 샘플링을 시뮬레이션합니다:

- 16개 VQ 토큰의 장난감 그리드.
- 프롬프트와 현재 언마스크된 토큰을 기반으로 로짓을 예측하는 모의 "트랜스포머".
- 코사인 스케줄로 8 스텝 병렬 마스크 샘플링.
- 중간 상태들(마스크 패턴의 변화)과 최종 토큰을 출력.

실행해 보세요. 마스크가 스텝마다 녹아 없어지는 걸 지켜보세요.

## 출시하기

이 레슨은 `outputs/skill-unified-gen-model-picker.md`를 만들어 냅니다. 오픈 웨이트 제약 아래 이해(VQA, 캡셔닝)와 생성(T2I, 인페인팅)을 모두 필요로 하는 제품이 주어지면, Show-o 계열, Transfusion/MMDiT 계열, Emu3 / Chameleon 계열 사이에서 구체적인 트레이드오프와 함께 골라 줍니다.

## 연습 문제

1. 마스크 이산 확산은 약 16 스텝에 샘플링합니다. 왜 1이 아닐까요? 스텝 0에서 모든 걸 언마스크하면 무엇이 깨질까요?

2. 인페인팅은 마스크 확산에서 공짜입니다. Show-o의 인페인팅이 전문 모델을 이기는 제품 사용 사례를(실제든 가상이든) 제안해 보세요.

3. 코사인 스케줄 vs 선형 스케줄: T=8일 때 스텝별 언마스크 토큰 수를 추적해 보세요. 어느 쪽이 더 균형적이나요?

4. 512x512 Show-o 이미지는 1024토큰입니다. 어휘 K=16384에서 모델이 내보내는 데이터는 1024 * log2(16384) = 14,336비트(약 1.75 KiB)입니다. Stable Diffusion은 512*512*24비트 = 6,291,456비트(약 768 KiB)의 원시 픽셀을 내놓죠. 압축 비율은 얼마이고, 그 압축이 사 주는 품질은 무엇인가요?

5. LlamaGen(arXiv:2406.06525)을 읽어 보세요. LlamaGen의 클래스 조건부 자기회귀 이미지 모델은 Show-o의 마스크 방식과 어떻게 다른가요?

## 핵심 용어

| 용어 | 사람들이 말하는 표현 | 실제 의미 |
|------|-----------------|------------------------|
| 마스크 이산 확산 | "MaskGIT 스타일" | 마스크된 토큰을 예측하도록 학습; 추론 때 가장 확신도 높은 예측부터 반복적으로 언마스크 |
| 코사인 스케줄 | "언마스크 스케줄" | 추론 스텝에 걸친 마스크 비율의 감소; 확신도 성장을 중간 구간에 집중 |
| 병렬 디코딩 | "모든 토큰을 한 번에" | 매 스텝이 마스크된 토큰 전체를 한 번의 순전파로 예측한 뒤 top-K를 확정 |
| 하이브리드 어텐션 | "인과 + 쌍방향" | 텍스트 토큰 위에서는 인과적이고 이미지 블록 안에서는 쌍방향인 마스크 |
| 인페인팅 | "채우기 생성" | 일부 토큰이 마스크된 이미지를 조건으로 빠진 토큰을 예측; 학습 목표에서 공짜로 나옴 |
| 확정 비율 | "스텝당 top-K" | 반복당 "완료"로 선언되는 토큰 수; 추론 속도 vs 품질의 트레이드오프를 조절 |
