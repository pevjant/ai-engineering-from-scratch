# CLIP에서 BLIP-2까지 — 모달리티 브리지로서의 Q-Former

> CLIP은 이미지와 텍스트를 정렬하지만 캡션을 만들거나, 질문에 답하거나, 대화를 이어가지는 못합니다. BLIP-2(Salesforce, 2023)는 작은 학습 가능한 브리지로 이 문제를 풀었습니다. 학습 가능한 쿼리 벡터 32개가 크로스 어텐션으로 동결된 ViT의 특성 위에 어텐션하고, 그 결과가 동결된 LLM의 입력 스트림에 그대로 끼어 들어가는 방식입니다. 1억 8800만 파라미터짜리 브리지가 110억 파라미터 LLM을 ViT-g/14에 연결했습니다. 2026년까지의 어댑터 기반 VLM 전부(MiniGPT-4, InstructBLIP, LLaVA의 사촌들)가 그 후손입니다. 이 레슨은 Q-Former의 아키텍처를 읽고 2단계 학습을 설명하며, 시각 토큰을 동결된 텍스트 디코더에 먹이는 장난감 버전을 만듭니다.

**유형:** Build
**언어:** Python (stdlib, 크로스 어텐션 + 학습형 쿼리 데모)
**선수 지식:** 페이즈 12 · 02(CLIP), 페이즈 7(트랜스포머)
**소요 시간:** 약 180분

## 학습 목표

- 동결된 비전 인코더와 동결된 LLM 사이의 학습 가능한 병목이 비용과 안정성 면에서 엔드투엔드 파인튜닝을 이기는 이유를 설명할 수 있습니다.
- 고정된 학습형 쿼리 집합이 외부 이미지 특성(feature)에 어텐션하는 크로스 어텐션 블록을 구현할 수 있습니다.
- BLIP-2의 2단계 사전학습을 따라갈 수 있습니다. 표현 학습(ITC + ITM + ITG) 다음 생성 학습(동결된 디코더로 LM 손실)입니다.
- Q-Former를 LLaVA의 더 단순한 MLP 프로젝터와 비교하고 각 선택이 이기는 경우를 논할 수 있습니다.

## 문제 상황

이미지당 1408차원 패치 토큰 256개를 내놓는 동결된 ViT가 있습니다. 4096차원 토큰 임베딩을 기대하는 동결된 7B LLM도 있습니다. 뻔한 브리지(1408에서 4096으로 가는 선형 계층)도 동작하지만, 256개 패치 토큰 전부를 LLM 컨텍스트에 넣으면 이미지당 토큰 256개가 추가로 듭니다. 이미지 32장 배치라면 시각 모달리티만으로 토큰 8192개를 소비합니다.

BLIP-2의 질문: 256토큰짜리 이미지 표현을 LLM이 캡션을 만들고, 질문에 답하고, 이미지에 대해 추론하기에 충분한 정보를 지키면서 훨씬 적은 토큰(예: 32개)으로 압축할 수 있을까? 그리고 동결된 백본을 건드리지 않고 브리지 파라미터만 학습 비용으로 지불하면서 이 브리지를 학습시킬 수 있을까?

답은 Q-Former입니다. ViT의 패치 토큰에 크로스 어텐션하는 학습 가능한 "쿼리" 벡터 32개가 LLM이 소비하는 32토큰짜리 시각 요약을 만들어 냅니다. 총 1억 8800만 파라미터입니다. LLM을 건드리기 전에 대조, 매칭, 생성 목표로 학습됩니다.

## 개념

### 학습형 쿼리

Q-Former의 핵심 기교: LLM의 텍스트 토큰이 이미지 패치에 어텐션하게 두는 대신, 새로운 학습형 쿼리 벡터 32개 집합 `Q`를 도입하고 *그것들이* 이미지 패치에 어텐션하게 합니다. 쿼리는 모델의 파라미터입니다. 학습 중에 배우고, 모든 이미지에 똑같은 32개의 쿼리를 씁니다.

크로스 어텐션 뒤에 각 쿼리는 이미지의 압축된 요약을 담습니다. "주요 사물 묘사", "배경 묘사", "사물 개수 세기" 같은 것들이죠. 쿼리가 말 그대로 의미 레이블에 특화되는 것은 아닙니다. 다운스트림 손실을 떨어뜨리는 인코딩이면 무엇이든 배웁니다.

### 아키텍처

Q-Former는 두 갈래 경로를 가진 작은 트랜스포머입니다(12층, 약 1억 파라미터):

1. 쿼리 경로: 32개 쿼리 벡터가 셀프 어텐션(서로 간)을 흐르고, 동결된 ViT의 패치 토큰에 대한 크로스 어텐션을 지나, FFN으로 갑니다.
2. 텍스트 경로: BERT 계열 텍스트 인코더가 쿼리 경로와 셀프 어텐션·FFN 가중치를 공유합니다. 텍스트 경로에서는 크로스 어텐션이 비활성화됩니다.

학습 때는 두 경로가 모두 돌아갑니다. 쿼리와 텍스트가 공유 셀프 어텐션을 통해 상호작용하므로, 필요한 작업(ITM, ITG)에서는 쿼리가 텍스트에 조건을 맞출 수 있습니다. VLM 인계를 위한 추론 때는 쿼리만 흘러가 32개의 시각 토큰을 만듭니다.

### 2단계 학습

BLIP-2는 두 단계로 사전학습합니다:

1단계: 표현 학습(LLM 없음). 세 가지 손실:
- ITC(이미지-텍스트 대조): 풀링된 쿼리 토큰과 텍스트 CLS 토큰 사이의 CLIP식 대조 손실.
- ITM(이미지-텍스트 매칭): 이진 분류기. 이 이미지-텍스트 쌍이 서로 맞는가? 하드 네거티브 마이닝으로 추출된 쌍을 씁니다.
- ITG(이미지에 근거한 텍스트 생성): 쿼리에 조건화된 텍스트용 causal LM 헤드. 쿼리가 텍스트로 생성 가능한 내용을 인코딩하도록 강제합니다.

Q-Former만 학습합니다. ViT는 동결입니다. LLM은 개입하지 않습니다.

2단계: 생성 학습. 동결된 LLM을 붙입니다(OPT-2.7B 또는 Flan-T5-XL 등). 32개 쿼리 출력을 작은 선형 계층으로 LLM의 임베딩 차원에 투영합니다. 텍스트 프롬프트 앞에 붙입니다. 이어 붙인 프롬프트 + 이미지 + 캡션 시퀀스에 대해 LM 손실로 선형 투영과 Q-Former만 학습합니다.

2단계가 끝나면 Q-Former + 투영이 시각 어댑터 전체입니다. 추론 흐름: 이미지 → ViT → Q-Former → 선형 투영 → 텍스트 앞에 부착 → 동결된 LLM이 출력을 뱉습니다.

### 파라미터 경제학

ViT-g/14(11억, 동결) + OPT-6.7B(67억, 동결) + Q-Former(1.88억, 학습) = 전체 80억, 학습은 1.88억입니다. Q-Former 하나는 전체 스택 파라미터의 약 2.4%입니다. 학습 비용이 이를 반영합니다. 소수의 A100로 며칠이면 끝나고, 엔드투엔드라면 몇 주가 걸립니다.

품질: BLIP-2는 크기가 50분의 1이면서 제로샷 VQA에서 Flamingo-80B와 맞먹거나 이깁니다. 브리지가 통합니다.

### InstructBLIP과 명령어 인지 Q-Former

InstructBLIP(2023)은 Q-Former에 입력을 하나 더합니다. 바로 명령어(instruction) 텍스트 자체입니다. 크로스 어텐션 때 쿼리가 이제 이미지 패치와 명령어 양쪽에 접근할 수 있습니다. 쿼리는 단일 고정 요약을 배우는 대신 명령어별로("차량 개수 세기", "분위기 묘사") 특화할 수 있습니다. 홀드아웃 과제에서 벤치마크 향상을 보였습니다.

### MiniGPT-4와 프로젝터 전용 방식

MiniGPT-4는 Q-Former를 유지하되 나머지는 모두 동결한 채 출력 선형 투영만 학습했습니다. 싸지만 대가는 품질입니다. 쿼리는 BLIP-2의 것이지 여러분의 것이 아닙니다. 빠른 반복에는 좋지만 최선의 아키텍처는 아닙니다.

### LLaVA가 더 단순하게 간 이유

LLaVA(2023, 레슨 12.05)는 Q-Former를 평범한 2층 MLP로 대체했습니다. 모든 ViT 패치 토큰을 LLM 공간으로 투영하는 것이죠. 24x24 격자 기준 이미지당 576토큰이 전부 LLM으로 들어갑니다. 압축은 나쁘지만 LLM이 날것의 패치 위에서 어텐션할 수 있습니다. 당시에는 논쟁적이었지만, 2023년 말에는 지배적이 됐습니다. 시각 명령 데이터(LLaVA-Instruct-150k)가 MLP를 학습시켜 충분한 신호를 보존할 수 있음을 증명했기 때문입니다. 트레이드오프: LLaVA는 컨텍스트가 더 빨리 차지만 다중 이미지와 비디오로 자연스럽게 확장됩니다.

2026년까지 이 분야는 갈렸습니다. 토큰 예산이 중요한 곳(긴 비디오, 많은 이미지)에는 Q-Former가 살아남았고, 토큰당 날것 품질이 우선인 곳에는 MLP 프로젝터가 지배합니다.

### 게이티드 크로스 어텐션: 조상인 Flamingo

Flamingo(레슨 12.04)는 BLIP-2보다 앞서 같은 크로스 어텐션 아이디어를 썼지만, 단일 브리지가 아니라 동결된 LLM의 모든 층에서 사용했습니다. BLIP-2는 입력층으로만 압축해도 동작한다는 것을 보여 줬습니다. Gemini와 Idefics는 둘을 결합합니다. 인터리브된 입력 토큰에 더해 인컨텍스트 few-shot을 위한 선택적 게이티드 크로스 어텐션을 쓰죠.

### 2026년의 후손들

- Q-Former: BLIP-2, InstructBLIP, MiniGPT-4, 그리고 토큰 예산 때문에 쓰이는 대부분의 비디오-언어 모델.
- Perceiver 리샘플러: Flamingo의 변형(레슨 12.04). Idefics 계열, Eagle, OmniMAE.
- MLP 프로젝터: LLaVA, LLaVA-NeXT, LLaVA-OneVision, Cambrian-1.
- 어텐션 풀: VILA, PaliGemma.

네 방식 모두 유효합니다. 결정적인 질문은 토큰 예산이 제약인지, 토큰당 품질이 제약인지입니다.

## 사용해 보기

`code/main.py`는 stdlib로 Q-Former식 크로스 어텐션을 만듭니다:

1. 이미지 패치 토큰 256개(차원 128)를 시뮬레이션합니다.
2. 학습형 쿼리 32개(차원 128)를 인스턴스화합니다.
3. 스케일드 점곱 크로스 어텐션을 실행합니다(Q는 쿼리에서, K/V는 패치에서).
4. 선형 계층으로 LLM 차원(512)에 투영합니다.
5. LLM에 바로 먹일 수 있는 시각 토큰 32개를 출력합니다.

모든 수학은 순수 Python입니다(벡터 위의 중첩 루프). 장난감이지만 모양은 올바릅니다. 어텐션 가중치 행렬이 출력되므로 각 쿼리가 어느 패치에서 가져왔는지 볼 수 있습니다.

## 출시하기

이 레슨은 `outputs/skill-modality-bridge-picker.md`를 만들어 냅니다. 목표 VLM 구성(비전 인코더 토큰 수, LLM 컨텍스트 예산, 배포 제약, 품질 목표)이 주어지면 짧은 근거와 함께 Q-Former 대 MLP 대 Perceiver 리샘플러를 추천하고 브리지별 파라미터 수 추정치를 냅니다.

## 연습 문제

1. PyTorch로 크로스 어텐션 블록을 구현합니다. 쿼리 32개, 키/값 256개일 때 어텐션 가중치 행렬이 32 x 256이고 softmax 뒤 각 행의 합이 1이 되는지 확인합니다.

2. BLIP-2 1단계에서 Q-Former는 세 가지 손실(ITC, ITM, ITG)을 동시에 돌립니다. 각각의 forward 시그니처를 의사코드로 씁니다. 어느 것이 텍스트 인코더 경로가 활성화되어야 합니까?

3. 파라미터 수를 비교합니다. Q-Former(12층, 히든 768) 대 2층 MLP 프로젝터(1408 → 4096, 두 층). 어떤 LLM 스케일에서 1.88억짜리 Q-Former 비용이 학습 효율로 본전을 뽑을까요?

4. Q-Former 초기화 방법에 관한 BLIP-2 논문(arXiv:2301.12597)의 3.2절을 읽습니다. 무작위가 아니라 BERT-base에서 초기화하면 수렴이 빨라지는 이유를 설명합니다.

5. 1 FPS로 샘플링해 60프레임이 된 10분짜리 비디오에서 프레임당 토큰 비용을 계산합니다. (Q-Former → 프레임당 32토큰) 대 (MLP 프로젝터 → 프레임당 576토큰). 어느 쪽이 128k 토큰짜리 LLM 컨텍스트 윈도우에 들어갈까요?

## 핵심 용어

| 용어 | 흔히 하는 말 | 실제 의미 |
|------|----------------|------------------------|
| Q-Former | "쿼리 트랜스포머" | 동결된 ViT 특성에 크로스 어텐션하는 학습형 쿼리 벡터 32개를 가진 작은 트랜스포머 |
| 학습형 쿼리 | "비전용 소프트 프롬프트" | 크로스 어텐션의 쿼리 쪽을 담당하는 고정된 파라미터 집합. 모델별로 학습되고 모든 입력에 공유됨 |
| 크로스 어텐션 | "Q는 여기서, K/V는 저기서" | 쿼리, 키, 값이 서로 다른 출처에서 오는 어텐션. 쿼리들이 ViT 패치에서 끌어오는 방식 |
| ITC | "이미지-텍스트 대조" | Q-Former의 풀링된 쿼리 대 텍스트 CLS에 적용한 CLIP식 손실 |
| ITM | "이미지-텍스트 매칭" | 하드 네거티브 마이닝 쌍에 대한 이진 분류기. 쿼리가 세밀한 불일치를 구별하도록 강제 |
| ITG | "이미지에 근거한 텍스트 생성" | 쿼리에 조건화해 텍스트를 생성하는 causal LM 손실. 쿼리가 텍스트로 디코딩 가능한 내용을 담도록 강제 |
| 2단계 사전학습 | "표현 다음 생성" | 1단계는 Q-Former만 학습(ITC/ITM/ITG). 2단계는 동결 LLM을 붙이고 투영 + Q-Former만 학습 |
| 동결 백본 | "파인튜닝 금지" | 비전 인코더와 LLM 가중치는 고정. 브리지만 학습 |
| 투영 헤드 | "LLM 차원으로의 선형" | Q-Former 출력을 LLM 임베딩 차원으로 사상하는 마지막 선형 계층 |
| Perceiver 리샘플러 | "Flamingo 버전" | 비슷한 학습형 쿼리 크로스 어텐션. Flamingo는 단일 브리지가 아니라 모든 층에서 사용 |
