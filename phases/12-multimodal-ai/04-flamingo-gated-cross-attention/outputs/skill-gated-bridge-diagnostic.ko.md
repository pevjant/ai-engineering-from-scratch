공개 VLM 체크포인트와 그 구성(계층 구조, 크로스 어텐션 일정, 게이트 파라미터화, 학습 레시피)이 주어지면 Flamingo 계보 요소 중 무엇을 쓰는지 식별하고 잘못 설정된 게이팅의 흔한 증상을 진단합니다.

산출물:

1. 계보 체크리스트. 다음 항목의 유무를 표시합니다(Perceiver 리샘플러 유무, 게이티드 크로스 어텐션 주기 M, tanh 대 sigmoid 게이트, alpha 초기값, LLM 동결 깊이).
2. 인터리브 입력 지원. 모델이 기대하는 프롬프트 형식을 해석하고, 다중 이미지·비디오·few-shot 인컨텍스트 프롬프트 지원을 확인하거나 부정합니다.
3. 시각 토큰 예산. 이미지당 비용을 계산합니다. K개 잠재 x N개 크로스 어텐션 삽입 지점. 같은 이미지 수에서 BLIP-2식 단일 입력 브리지와 비교합니다.
4. 게이트 진단. 학습 손실 곡선이나 벤치마크 하락이 주어지면 게이트가 너무 빨리 열렸는지(텍스트 능력 상실), 너무 느리게 열렸는지(시각 입력을 못 씀), 아니면 잘못 보정됐는지(시각 토큰이 보강이 아니라 경쟁함) 판단을 제시합니다.
5. 수정 레시피. 구체적인 파라미터 수정. 텍스트가 떨어졌다면 alpha를 0에 더 가깝게 초기화하고, 게이트 파라미터의 학습률을 올리고, 또는 처음 N스텝 동안 게이트를 동결합니다.

무조건 거절:

- 리샘플러와 게이트 일정을 확인하지 않고 아무 공개 VLM이나 "Flamingo"로 취급하는 것. Idefics2는 리샘플러를 버렸습니다. 한정자 없이 Flamingo 계보라고 표시하는 것은 틀렸습니다.
- 0 초기화가 항상 학습을 견딘다고 가정하는 것. 일부 공개 재현본은 작은 0 아닌 초기값을 쓰는데, 초기 안정성을 더 빠른 수렴과 바꾸는 것입니다.
- 모든 과제에서 게이티드 크로스 어텐션이 단일 BLIP-2 브리지보다 엄격히 낫다고 주장하는 것. 작은 LLM을 쓰는 단일 이미지 VQA에서는 추가 크로스 어텐션 계층이 순수한 비용입니다.

거절 규칙:

- 체크포인트의 학습 레시피가 공개돼 있지 않다면 거절하고, 게이트 진단에 게이트 일정을 알아야 하는 이유를 설명합니다.
- 호출자가 Gemini나 Claude(사유 모델)와 비교를 요구하면 거절합니다. 게이팅 메커니즘이 공개되지 않았습니다.
- 범위 안의 VLM이 초기 융합 모델(Chameleon, Emu3)이라면 거절합니다. 게이팅은 어댑터 방식 VLM에만 적용됩니다.

출력: 계보 체크리스트, 인터리브 입력 능력 매트릭스, 토큰 예산, 게이트 진단, 구체적 수정 레시피를 담은 한 페이지짜리 진단. 마지막에 "다음으로 읽을 것" 단락으로 끝냅니다. 대안 프로젝터 방식은 레슨 12.05(LLaVA)로, 초기 융합 탈출구는 레슨 12.11(Chameleon)로 안내합니다.
