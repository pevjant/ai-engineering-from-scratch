# Flamingo와 few-shot VLM을 위한 게이티드 크로스 어텐션

> DeepMind의 Flamingo(2022)는 누구보다 먼저 두 가지를 해냈습니다. 하나의 모델이 이미지, 비디오, 텍스트가 임의로 섞인 시퀀스를 처리할 수 있음을 보여 줬고, VLM이 인컨텍스트로 학습할 수 있음을 보여 줬습니다. 예시 (이미지, 캡션) 쌍 세 개가 담긴 few-shot 프롬프트를 주면 모델이 그래디언트 스텝 하나 없이 새 이미지의 캡션을 만드는 것이죠. 메커니즘은 게이티드 크로스 어텐션 계층입니다. 동결된 LLM의 기존 계층 사이에 삽입되고, tanh 게이트가 0에서 시작해 초기화 시점에 LLM의 텍스트 능력이 보존됩니다. 이 레슨은 Flamingo의 Perceiver 리샘플러와 게이티드 크로스 어텐션 아키텍처, 즉 Gemini의 인터리브 입력과 Idefics2의 시각 토큰의 조상을 따라갑니다.

**유형:** Learn
**언어:** Python (stdlib, 게이티드 크로스 어텐션 + Perceiver 리샘플러 데모)
**선수 지식:** 페이즈 12 · 03(BLIP-2 Q-Former)
**소요 시간:** 약 120분

## 학습 목표

- 게이티드 크로스 어텐션이 tanh(gate) = 0을 통해 초기화 시점에 동결된 LLM의 텍스트 능력을 어떻게 보존하는지 설명할 수 있습니다.
- Perceiver 리샘플러를 따라갈 수 있습니다. N개 이미지 패치 → 크로스 어텐션을 거쳐 K개의 고정된 "잠재(latent)" 쿼리.
- Flamingo가 이미지 배치를 존중하는 인과 마스킹으로 인터리브된 이미지-텍스트 시퀀스를 어떻게 다루는지 설명할 수 있습니다.
- few-shot 멀티모달 프롬프트 구조(예시 (이미지, 캡션) 쌍 3개 다음에 쿼리 이미지)를 재현할 수 있습니다.

## 문제 상황

BLIP-2는 시각 토큰 32개를 동결된 LLM의 입력층에 먹입니다. 프롬프트당 이미지 한 장이면 잘 됩니다. 하지만 텍스트 사이사이에 *여러* 이미지를 넣고 싶다면 어떨까요? "여기 이미지 A, 캡션 달아 줘. 여기 이미지 B, 캡션 달아 줘. 이제 이미지 C, 캡션 달아 줘"처럼요. LLM의 셀프 어텐션이 이미지 토큰과 텍스트 토큰을 한 스트림에서 처리해야 하고, 어느 위치가 어느 이미지에 어텐션할 수 있는지 문제가 성가셔집니다.

Flamingo의 답: LLM의 입력 스트림을 전혀 바꾸지 않습니다. 기존 LLM 블록 사이에 크로스 어텐션 계층을 몇 개 끼워 넣습니다. 텍스트 토큰은 여전히 예전처럼 LLM의 인과 셀프 어텐션을 흐릅니다. 몇 개의 LLM 블록마다 텍스트 토큰이 새로운 게이티드 계층을 통해 이미지 특성(feature)에 크로스 어텐션하기도 합니다. 게이트(0으로 초기화) 덕분에 0스텝에서는 새 계층이 아무것도 하지 않습니다(no-op). 모델이 사전학습된 LLM과 완전히 똑같이 행동합니다. 학습이 진행되면서 게이트가 열리고 시각 정보가 흐르기 시작합니다.

Flamingo가 답한 두 번째 질문: 프롬프트당 이미지 수가 변할 수 있을 때(0, 1, 또는 여러 장) 어떻게 처리할까? Perceiver 리샘플러입니다. 가지고 있는 패치 수가 얼마든 받아서 고정된 수의 시각 잠재 토큰을 만들어 내는 작은 크로스 어텐션 모듈이죠. 프롬프트에 이미지가 몇 장이든 LLM 크로스 어텐션 계층은 똑같은 모양을 봅니다.

## 개념

### 동결된 LLM

Flamingo는 동결된 Chinchilla 70B LLM에서 출발합니다. 700억 개 가중치 전부 손대지 않습니다. 기존 텍스트 셀프 어텐션과 FFN은 평소대로 동작합니다.

### Perceiver 리샘플러

프롬프트의 각 이미지에 대해 ViT가 N개 패치 토큰을 만듭니다. Perceiver 리샘플러는 고정된 학습형 잠재(latent) K개를 갖습니다(Flamingo는 K=64). 리샘플러 블록 하나는 두 개의 하위 단계입니다:

1. 크로스 어텐션: K개 잠재가 N개 패치 토큰 위에 어텐션합니다(Q는 잠재에서, K/V는 패치에서).
2. 잠재들 사이의 셀프 어텐션 + FFN.

리샘플러 블록 6개를 지나면 ViT가 패치를 몇 개 만들었든 출력은 차원 1024의 시각 토큰 K=64개입니다. 224x224 이미지(패치 196개)와 480x480 이미지(패치 900개)가 모두 리샘플러 토큰 64개로 나옵니다.

비디오에는 리샘플러가 시간 축으로 적용됩니다. 각 프레임의 패치가 잠재 64개를 만들고, 시간 위치 인코딩이 모델이 t=0과 t=N을 구분하게 합니다. 비디오 전체는 T * 64개의 시각 토큰이 됩니다.

### 게이티드 크로스 어텐션

동결된 LLM의 M층마다(Flamingo는 M=4) 새로운 게이티드 크로스 어텐션 블록을 삽입합니다:

```
x_after_llm_block = llm_block(x_before)
cross = cross_attn(x_after, resampler_output)
gated = tanh(alpha) * cross + x_after
x_before_next_block = gated
```

- `alpha`는 0으로 초기화되는 학습형 스칼라입니다.
- `tanh(0) = 0`이므로 초기화 시점에 게이티드 분기의 기여는 0입니다.
- `alpha`가 0에서 멀어질수록 크로스 어텐션 기여가 부드럽게 커집니다.
- 잔차 연결(residual) 덕분에 게이트가 완전히 열려도 LLM의 텍스트 표현을 덮어쓰지 않습니다. 그 위에 시각 정보를 더할 뿐입니다.

이것이 Flamingo에서 가장 중요한 설계 선택 하나입니다. 시각 조건화는 가산적이고, 게이트가 있으며, 초기화 시점에 0입니다. 0스텝의 Flamingo는 텍스트 전용 입력에 대해 완벽한 Chinchilla 70B입니다.

### 인터리브 입력을 위한 마스크드 크로스 어텐션

"<이미지 A> 캡션 A <이미지 B> 캡션 B <이미지 C> ?" 같은 프롬프트에서 각 텍스트 토큰은 시퀀스에서 자기보다 앞에 온 이미지만 봐야 합니다. 크로스 어텐션 마스크가 이를 강제합니다. 위치 `t`의 텍스트 토큰은 이미지 인덱스가 `i < i_t`인 이미지 리샘플러 토큰에만 어텐션합니다. 여기서 `i_t`는 위치 `t` 이전의 가장 최근 이미지입니다. "바로 앞의 마지막 이미지만 본다"와 "앞선 모든 이미지를 본다" 둘 다 유효한 선택이지만 Flamingo는 전자를 골랐습니다.

### 인컨텍스트 few-shot 학습

Flamingo 프롬프트는 이런 모양입니다:

```
<image1> A photo of a cat. <image2> A photo of a dog. <image3> A photo of a
```

모델은 완성 패턴을 보고 "bird"(또는 image3에 나오는 무엇이든)를 출력합니다. 그래디언트 스텝은 없습니다. 동결된 LLM의 인컨텍스트 학습 능력이 게이티드 크로스 어텐션을 통해 그대로 전달됩니다. 이것이 논문의 백미이자 이 방식이 중요한 이유입니다.

### 학습 데이터

Flamingo는 세 개 데이터셋으로 학습했습니다:

1. MultiModal MassiveWeb(M3W): 이미지와 텍스트가 섞인 웹 페이지 4,300만 개. 읽기 순서를 복원합니다.
2. 이미지-텍스트 쌍(ALIGN + LTIP): 44억 쌍.
3. 비디오-텍스트 쌍(VTP): 짧은 비디오 클립 2,700만 개.

OBELICS(2023)는 인터리브 웹 코퍼스의 공개 재현본입니다. Idefics, Idefics2, 그리고 대부분의 공개 "Flamingo 유사" 모델이 이것으로 학습합니다.

### OpenFlamingo와 Otter

OpenFlamingo(2023)는 공개 재현본입니다. 아키텍처는 동일합니다(동결된 LLaMA 또는 MPT 위의 Perceiver 리샘플러 + 게이티드 크로스 어텐션). 체크포인트는 3B, 4B, 9B입니다. 베이스 LLM이 작고 데이터가 적어 품질은 Flamingo에 뒤처집니다.

Otter(2023)는 OpenFlamingo 위에 MIMIC-IT(멀티모달 명령 데이터셋)로 명령 튜닝을 얹어, 게이티드 크로스 어텐션이 명령 수행에도 통한다는 것을 보여 줬습니다.

### 후손들

- Idefics / Idefics2 / Idefics3: Hugging Face의 게이티드 크로스 어텐션 계보. 점점 더 단순해졌습니다(Idefics2는 리샘플러를 버리고 적응형 풀링을 거친 직접 패치 토큰으로 갔습니다).
- Flamingo에서 Chameleon으로의 전환: 2024년까지 많은 팀이 초기 융합(early-fusion)으로 갈아탔습니다(레슨 12.11). 백본 동결이 필요한 곳에서는 Flamingo식 게이티드 크로스 어텐션이 여전히 프로덕션(운영 환경)에 있습니다.
- Gemini의 인터리브 입력: 정확한 메커니즘은 사유(Proprietary)지만 개념적으로 Flamingo의 인터리브 형식 유연성을 물려받았습니다.

### BLIP-2와의 비교

| | BLIP-2 | Flamingo |
|---|---|---|
| 시각 브리지 | 입력에서 한 번 쓰는 Q-Former | M층마다 게이티드 크로스 어텐션 |
| 시각 토큰 | 이미지당 32개 | 이미지당, 크로스 어텐션 계층마다 64개 |
| 동결 LLM | 예 | 예 |
| few-shot 인컨텍스트 | 약함 | 강함 — 논문의 백미 |
| 인터리브 입력 | 네이티브 지원 없음 | 예, 설계 목표 |
| 학습 데이터 | 1.3억 쌍 | 13억 쌍 + 인터리브 페이지 4,300만 |
| 파라미터 수 | 학습 1.88억 | 학습 약 100억(크로스 어텐션 계층) |
| 컴퓨팅 | A100 8장으로 며칠 | TPUv4 수천 개로 수주 |

## 사용해 보기

`code/main.py`는 다음을 시연합니다:

1. 학습형 잠재 8개로 가짜 패치 토큰 36개에 대한 Perceiver 리샘플러(순수 Python 크로스 어텐션).
2. `alpha = 0`인 게이티드 크로스 어텐션 스텝 → 출력이 입력과 같음(LLM 불변), 이어서 `alpha = 2.0` → 시각 기여가 섞여 들어감.
3. "(이미지 1) (텍스트 1) (이미지 2) (텍스트 2)" 시퀀스의 2D 어텐션 마스크를 만드는 인터리브 마스크 빌더.

## 출시하기

이 레슨은 `outputs/skill-gated-bridge-diagnostic.md`를 만들어 냅니다. 공개 VLM의 구성(리샘플러 유무, 크로스 어텐션 주기, 게이트 방식)이 주어지면 Flamingo 계보 요소를 식별하고 동결 전략을 설명합니다. 파인튜닝이 텍스트 성능을 떨어뜨린 이유를 디버깅할 때 유용합니다(답: 게이트가 너무 빨리 너무 많이 열렸습니다).

## 연습 문제

1. Flamingo-9B의 시각 파라미터 수를 계산합니다. 9B LLM + 14억 개 게이티드 크로스 어텐션 계층 + 6,400만 개 리샘플러. 학습되는 파라미터는 전체의 몇 퍼센트일까요?

2. 게이티드 잔차 `y = tanh(alpha) * cross + x`를 PyTorch로 구현합니다. `alpha=0`일 때 초기화 시점에 `y==x`가 정확히 성립함을 실험으로 보입니다.

3. 프롬프트마다 이미지 수가 다를 때 배치 안의 여러 이미지를 어떻게 처리하는지 OpenFlamingo 3.2절(arXiv:2308.01390)을 읽습니다. 패딩 전략을 설명합니다.

4. Flamingo의 크로스 어텐션 마스크는 텍스트 토큰이 앞선 모든 이미지가 아니라 *가장 최근* 이미지에만 어텐션하게 합니다. 왜일까요? Flamingo 논문 2.4절을 읽고 트레이드오프를 설명합니다.

5. 인컨텍스트 few-shot: 새 Flamingo 변형을 위해 "이미지 → 주요 사물의 색" 예시 4개로 프롬프트를 구성합니다. 예시 수를 0에서 8까지 바꿀 때 예상되는 정확도 패턴을 설명합니다.

## 핵심 용어

| 용어 | 흔히 하는 말 | 실제 의미 |
|------|----------------|------------------------|
| Perceiver 리샘플러 | "고정 잠재 크로스 어텐션" | 가변 개수의 입력 패치에서 고정된 토큰 K개를 만들어 내는 모듈 |
| 게이티드 크로스 어텐션 | "tanh 게이트 브리지" | 잔차 계층 `y = tanh(alpha)*cross + x`. 학습형 alpha, 초기값 0 |
| 인터리브 입력 | "섞인 시퀀스" | 이미지와 텍스트가 읽기 순서대로 자유롭게 섞인 프롬프트 형식 |
| 동결 LLM | "LLM 그래디언트 없음" | 텍스트 LLM의 가중치는 갱신되지 않음. 리샘플러 + 크로스 어텐션 계층만 학습 |
| few-shot | "인컨텍스트 예시" | 프롬프트에 (이미지, 답) 쌍 몇 개를 줌. 모델이 파인튜닝 없이 일반화 |
| OBELICS | "인터리브 웹 코퍼스" | 이미지와 텍스트가 읽기 순서대로 담긴 웹 페이지 1.41억 개의 공개 데이터셋 |
| Chinchilla | "70B 동결 베이스" | Flamingo의 동결된 텍스트 LLM. DeepMind의 Chinchilla 논문 출신 |
| 게이트 스케줄 | "alpha가 움직이는 속도" | 학습 중 크로스 어텐션 게이트가 열리는 속도 |
| 크로스 어텐션 주기 | "M층마다" | 게이티드 크로스 어텐션 블록을 얼마나 자주 삽입하는지. Flamingo는 M=4 |
| OpenFlamingo | "공개 재현본" | MosaicML/LAION의 3~9B 공개 체크포인트. 아키텍처는 Flamingo와 동일 |
