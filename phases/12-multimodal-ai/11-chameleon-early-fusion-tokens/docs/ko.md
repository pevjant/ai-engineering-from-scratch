# 카멜레온과 얼리 퓨전 토큰 전용 멀티모달 모델

> 지금까지 본 모든 VLM은 이미지와 텍스트를 따로 취급했습니다. 시각 토큰은 비전 인코더에서 나와 프로젝터로 흘러들어가고, LLM 내부에서 비로소 텍스트를 만납니다. 비전 어휘와 텍스트 어휘는 결코 겹치지 않죠. Chameleon(메타, 2024년 5월)은 이렇게 물었습니다: 어휘를 공유하면 어떨까? 이미지를 공유 어휘에서 뽑은 이산 토큰 시퀀스로 바꾸는 VQ-VAE를 학습합니다. 그러면 모든 멀티모달 문서가 하나의 시퀀스가 됩니다 — 텍스트 토큰과 이미지 토큰이 섞인, 단 하나의 자기회귀 손실. 부산물: 모델이 혼합 모달리티 출력을 낼 수 있습니다 — 추론 호출 한 번에서 텍스트와 이미지 토큰을 번갈아 생성하는 거죠. 이 레슨에서는 얼리 퓨전(early fusion) 테제를 읽고, 장난감 버전을 끝까지 만들어 봅니다.

**유형:** 빌드
**언어:** Python (표준 라이브러리, VQ-VAE 토크나이저 + 인터리브 디코더)
**선수 지식:** 페이즈 12 · 05, 페이즈 8 (생성형 AI)
**시간:** 약 180분

## 학습 목표

- 공유 어휘 + 단일 손실이 모델의 능력을 어떻게 바꾸는지 설명한다.
- VQ-VAE가 이미지를 트랜스포머의 다음 토큰 예측 목표와 호환되는 이산 시퀀스로 토큰화하는 방식을 설명한다.
- Chameleon의 학습 안정화 트릭을 말할 수 있다: QK-Norm, 드롭아웃 배치, LayerNorm 순서.
- Chameleon과 BLIP-2의 Q-Former 접근을 비교하고, 각각이 옳은 선택인 경우를 설명한다.

## 문제 상황

어댑터 기반 VLM(LLaVA, BLIP-2, Qwen-VL)은 텍스트와 이미지를 별개의 것으로 봅니다. 텍스트 토큰은 `embed(text_token)`을 거치고, 이미지는 `visual_encoder(image) → projector → ... pseudo_tokens`를 거칩니다. 모델에는 중간에서 합쳐지는 두 개의 입력 경로가 있는 거죠.

세 가지 결과:

1. LLM은 이미지를 소비만 할 수 있고 내보낼 수 없습니다. 출력은 텍스트뿐입니다.
2. 혼합 모달리티 문서(기사처럼 문단과 이미지가 번갈아 나오는 것)는 다루기 불편합니다 — 모델 밖에서 멀티모달 입력을 파싱하거나 생성을 연쇄해야 하죠.
3. 분포 불일치. 시각 토큰과 텍스트 토큰이 히든 공간의 다른 영역에 살아서, 미묘한 정렬 문제가 생깁니다.

Chameleon은 이 전제를 거부합니다: 이미지는 공유 어휘에서 온 이산 토큰의 시퀀스일 뿐이다. 인터리브된 문서로, 손실 하나, 자기회귀 디코더 하나로 모델을 학습시키면, 혼합 모달리티 생성이 공짜로 열립니다.

## 개념

### 이미지 토크나이저로서의 VQ-VAE

토크나이저는 벡터 양자화 변분 오토인코더(vector-quantized variational autoencoder)입니다. 아키텍처:

- 인코더: 이미지를 공간 특성 맵(예: 차원 256의 32x32 특성)으로 바꾸는 CNN + ViT.
- 코드북: K개 벡터(Chameleon은 8192 사용)의 학습된 어휘, 역시 차원 256.
- 양자화: 각 공간 특성에 대해 L2 거리로 가장 가까운 코드북 항목을 찾는다. 연속 특성을 정수 인덱스로 교체.
- 디코더: 양자화된 특성을 다시 픽셀로 되돌리는 CNN.

학습: VAE 재구성 손실 + commitment 손실 + 코드북 손실. 코드북 인덱스가 이미지의 이산 알파벳이 됩니다.

Chameleon 기준으로: 이미지 한 장이 8192 어휘에서 뽑힌 32*32 = 1024개 토큰이 됩니다. 텍스트 토큰(LLM의 BPE 어휘, 예: 32000)과 연결하면 최종 어휘는 40192. 트랜스포머는 하나의 시퀀스, 하나의 손실을 봅니다.

### 공유 어휘

Chameleon의 어휘는 텍스트 토큰, 이미지 토큰, 모달리티 구분자를 합칩니다. 각 토큰은 단일 ID를 갖고, 입력 임베딩 층이 모든 ID를 D차원 히든 벡터로 바꿉니다. 출력 투영은 히든을 다시 어휘 로짓으로 보내고요. 소프트맥스가 다음 토큰을 고릅니다 — 어떤 모달리티든.

구분자가 중요합니다: `<image>`와 `</image>` 태그가 이미지 토큰 시퀀스를 감쌉니다. 생성 때 모델이 `<image>`를 내놓으면, 다운스트림 소프트웨어는 다음 1024개 토큰이 픽셀 렌더링을 위해 디코더로 보낼 VQ 인덱스임을 압니다.

### 혼합 모달리티 생성

추론은 공유 어휘에서의 다음 토큰 예측입니다. 예시 프롬프트: "고양이를 그리고 묘사해라." Chameleon은 이렇게 내놓습니다:

```
<image> 4821 1029 2891 ... (1024 image tokens) </image>
The cat is orange, sitting on a windowsill...
```

순서는 모델이 자율적으로 고릅니다 — 이미지 먼저 텍스트가 올 수도, 텍스트 먼저 이미지가 올 수도, 섞일 수도 있죠. 같은 디코더, 같은 손실.

생성이 텍스트 전용인 어댑터 VLM과 비교해 보세요. Chameleon은 모델 출력 모달리티라는 질문을 다시 열었습니다.

### 학습 안정성 — QK-Norm, 드롭아웃, LayerNorm 순서

얼리 퓨전 학습은 대규모에서 불안정합니다. Chameleon 논문은 세 가지 트릭을 문서화했습니다:

- QK-Norm. 어텐션 내부의 쿼리·키 투영에 점곱(dot product) 전에 LayerNorm을 적용한다. 깊은 층에서 로짓 크기가 폭발하는 걸 막습니다. 2024년 이후 여러 대형 모델이 사용합니다.
- 드롭아웃 배치. 어텐션과 MLP 뒤뿐만 아니라 모든 잔차 합(residual-add) 뒤에 드롭아웃을 둔다. 이미지 토큰에서 오는 그래디언트가 지배할 수 있을 때 더 많은 정규화가 필요하기 때문입니다.
- LayerNorm 순서. 잔차 분기에는 Pre-LN(표준), 마지막 블록의 스킵 연결에는 추가 LN 하나. 마지막 층 그래디언트 흐름을 안정화합니다.

이 트릭들 없이는 340억 파라미터 Chameleon 학습이 여러 체크포인트에서 발산했습니다. 있으면 수렴합니다. 학습 레시피가 아키텍처만큼이나 기여입니다.

### 토크나이저의 재구성 천장

VQ-VAE는 손실이 있습니다. 8192 코드북 항목, 512x512 이미지당 1024토큰에서 재구성 PSNR은 대략 26-28dB가 한계입니다. 알아볼 수 있는 이미지 생성에는 충분하지만, 연속 공간 확산(Stable Diffusion 3는 32dB+)보다는 눈에 띄게 나쁩니다.

토크나이저가 병목입니다. 더 나은 토크나이저(MAGVIT-v2, IBQ, SBER-MoVQGAN)가 그 천장을 올립니다. Emu3(레슨 12.12)는 더 나은 토크나이저 하나만으로 SDXL 품질 생성을 달성합니다.

### Chameleon vs BLIP-2 / LLaVA

Chameleon (얼리 퓨전, 공유 어휘):
- 손실 하나, 디코더 하나.
- 혼합 모달리티 출력을 생성.
- 토크나이저가 품질 천장.
- 비쌈: 추론 경로에서 생성 이미지마다 VQ-VAE 디코더가 돕니다.

BLIP-2 / LLaVA (레이트 퓨전, 별도 타워):
- 비전 입력, 텍스트 출력만.
- 사전학습된 LLM을 재사용.
- 이해에는 토크나이저 병목이 없음.
- 셈: 순전파 한 번이면 끝.

과제로 고르세요. 이미지 생성이 필요하면 Chameleon 계열. 이해만 필요하면 어댑터 VLM이 더 단순하고 사전학습 연산을 더 많이 재사용합니다.

### Fuyu와 AnyGPT

Fuyu(Adept, 2023)는 관련 접근입니다: 별도 비전 인코더를 아예 생략하고, 원시 이미지 패치를 토큰처럼 LLM의 입력 투영으로 넣습니다. 토크나이저 없이요. Chameleon보다 단순하지만 공유 어휘 출력 생성은 잃습니다.

AnyGPT(Zhan 등, 2024)는 Chameleon을 네 모달리티로 확장합니다: 텍스트, 이미지, 음성, 음악. 각각에 같은 VQ-VAE 트릭을 쓰는 공유 트랜스포머. 모든 것에서 모든 것으로(any-to-any) 생성이죠. 레슨 12.16에서 더 다룹니다.

## 직접 써보기

`code/main.py`는 장난감 얼리 퓨전 모델을 끝까지 만듭니다:

- 8x8 패치를 코드북 인덱스(K=16)로 바꾸는 작은 VQ-VAE 스타일 양자화기.
- (텍스트 ID 0..31) + (이미지 ID 32..47) + (구분자 48, 49)로 이뤄진 공유 어휘.
- 합성 캡션 + 이미지 토큰 시퀀스로 학습한 장난감 자기회귀 디코더(바이그램 테이블).
- 프롬프트가 주어지면 텍스트 + 이미지 토큰을 번갈아 내놓는 샘플링 루프.

코드는 의도적으로 트랜스포머를 아주 작게(바이그램) 유지해서, 신호 흐름을 끝까지 따라갈 수 있게 합니다.

## 연습 문제

1. Chameleon은 K=8192 코드북 항목과 512x512 이미지당 1024토큰을 씁니다. 24비트 RGB 이미지 대비 압축 비율을 추정하세요. 손실 압축인가요? 얼마나 손실인가요?

2. 같은 VQ-VAE 밀도에서 4K 이미지(3840x2160)는 이미지 토큰이 몇 개인가요? Chameleon 스타일 모델이 추론 호출 한 번으로 4K 이미지를 만들어 낼 수 있나요? 먼저 깨지는 건 무엇일까요 — 컨텍스트, 토크나이저 품질, KV 캐시?

3. QK-Norm을 순수 Python으로 구현하세요. 64차원 쿼리와 키가 주어졌을 때 LayerNorm 전후의 점곱을 보이세요. 깊은 층에서 크기 제어가 왜 중요한가요?

4. Chameleon의 학습 안정성에 관한 2.3절을 읽어 보세요. QK-Norm 없이 34B에서 논문이 관찰한 정확한 실패 모드를 설명하세요. "노름 폭발(norm explosion)"의 징후는 무엇이었나요?

5. 장난감 디코더를 확장해 텍스트 전용 프롬프트로 혼합 모달리티 응답을 내놓게 해 보세요. 학습 데이터 분포가 텍스트 우선 60% / 이미지 우선 40%일 때 모델이 이미지 우선과 텍스트 우선을 고르는 빈도를 측정하세요.

## 핵심 용어

| 용어 | 사람들이 말하는 표현 | 실제 의미 |
|------|-----------------|------------------------|
| 얼리 퓨전(Early fusion) | "통합 토큰" | 이미지를 스텝 1부터 트랜스포머 어휘를 공유하는 이산 토큰으로 변환 |
| VQ-VAE | "이미지 토크나이저" | 이미지를 트랜스포머가 예측할 수 있는 정수 인덱스로 바꾸는 CNN + ViT + 코드북 |
| 공유 어휘 | "하나의 사전" | 텍스트 + 이미지 + 모달리티 구분자를 모두 담는 단일 토큰 ID 공간 |
| QK-Norm | "어텐션 안정기" | 쿼리와 키의 점곱 전에 적용하는 LayerNorm, 노름 폭발을 방지 |
| 혼합 모달리티 생성 | "텍스트 + 이미지 출력" | 한 번의 패스에서 텍스트와 이미지 토큰을 자율적으로 섞어 내놓는 추론 |
| 코드북 크기 | "K 항목" | VQ-VAE가 양자화할 수 있는 이산 벡터 수; 압축과 충실도를 맞바꿈 |
| 토크나이저 천장 | "재구성 한계" | VQ 토큰 디코딩으로 도달할 수 있는 최고 PSNR; 모델의 이미지 품질 상한을 정함 |
