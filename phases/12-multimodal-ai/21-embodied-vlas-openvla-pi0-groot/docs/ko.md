# 구현된 VLA: RT-2, OpenVLA, π0, GR00T

> 어떤 모델이 웹사이트에서 레시피를 읽어 주방 로봇으로 실행한 첫 순간은 RT-2(Google DeepMind, 2023년 7월)였습니다. RT-2는 행동을 텍스트 토큰으로 이산화하고, VLM을 웹 데이터 + 로봇 행동 데이터로 함께 파인튜닝했으며, 웹 규모의 시각-언어 지식이 로봇 제어로 전이된다는 것을 증명했습니다. OpenVLA(2024년 6월)는 오픈 7B 참조 모델을 내놓았습니다. Physical Intelligence의 π0 시리즈(2024~2025)는 흐름 매칭 행동 전문가를 더했고, NVIDIA의 GR00T N1(2025년 3월)은 휴머노이드 로봇을 위한 듀얼 시스템(System 1 / System 2) 제어를 대규모로 제공했습니다. VLA 원시 개념 — 시각-언어-행동, 보고 읽고 행동하는 단일 모델 — 은 이 페이즈의 이해 모델과 Phase 15의 자율 시스템 사이를 잇는 다리입니다.

**유형:** 학습
**언어:** Python (표준 라이브러리, 행동 토크나이저 + VLA 추론 스켈레톤)
**선수 지식:** Phase 12 · 05 (LLaVA), Phase 15 (Autonomous Systems, 참조)
**소요 시간:** ~180분

## 학습 목표

- 행동 토큰화를 설명할 수 있다: 이산 빈 인코딩(RT-2), FAST 효율 행동 토큰, 연속 흐름 매칭 행동(π0).
- 웹 + 로봇 데이터 공동 파인튜닝이 일반 지식의 새로운 과제로의 전이를 지키는 이유를 설명할 수 있다.
- 같은 로봇 과제에서 OpenVLA(오픈 7B Llama+VLM), π0(흐름 매칭), GR00T N1(듀얼 시스템)을 비교할 수 있다.
- Open X-Embodiment 데이터셋과 RT-X 학습 코퍼스로서의 역할을 설명할 수 있다.

## 문제 상황

자연어 지시로 집안일을 하는 로봇은 1970년대부터 연구 과제였습니다. 2020년대의 답: 시각-언어-행동(VLA) 모델입니다. VQA에 쓰는 것과 같은 VLM 아키텍처이되, 출력이 텍스트 대신 행동(관절 토크, 말단 장치 pose, 이산 명령)인 것이죠.

VLA에 특화된 과제들:

1. 행동 공간은 연속적(관절 각도, 힘)이고 고차원입니다(7-DOF 팔 + 3-DOF 그리퍼 = 30Hz에서 10차원).
2. 로봇 전용 학습 데이터는 희소합니다. Open X-Embodiment는 약 100만 궤적; 웹 텍스트-이미지는 50억 개 이상.
3. 제어 주기가 중요합니다. 30Hz 제어 루프는 행동당 33ms 예산을 의미합니다.
4. 안전. 잘못된 행동은 하드웨어, 사람, 재산을 손상시킵니다.

## 개념

### 행동 토큰화 (RT-2)

RT-2의 트릭: 각 관절 목표를 양자화된 텍스트 토큰으로 표현하는 것입니다. 정규화된 [-1, 1] 범위를 256개 빈으로 나누고, 각 빈을 어휘 ID에 매핑합니다. 10-DOF 행동은 제어 스텝마다 10개 토큰이 됩니다.

PaLM-X VLM을 다음 혼합물로 공동 파인튜닝합니다:

- 웹 이미지-텍스트 쌍(캡셔닝, VQA).
- 로봇 시연 데이터, 행동은 토큰으로.

모델은 "빨간 큐브를 집어라"(언어) → 이미지(비전) → 10토큰 행동 시퀀스(이산화된 관절 목표)를 봅니다. 웹 사전학습 덕분에 일반 지식 전이가 유지됩니다. RT-2는 "빠르게 움직이는 물체 쪽으로 이동해" 같은 지시를 따를 수 있습니다. 학습 데이터에 "빠르게 움직이는"이 없어도요.

RT-2 논문 기준 추론은 3~5Hz로, VLM의 자기회귀 디코드가 병목입니다.

### OpenVLA — 오픈 7B 참조 모델

OpenVLA(Kim et al., 2024년 6월)는 오픈 웨이트의 RT-2 격입니다. 7B Llama 백본, DINOv2 + SigLIP 듀얼 비전 인코더, 256빈 기반 행동 토큰화.

Open X-Embodiment(22개 로봇에 걸친 97만 궤적)로 학습했습니다. 새 로봇에 적응시키기 위한 LoRA 파인튜닝 지원과 함께 배포됩니다.

추론: 양자화 기준 A100에서 4~5Hz. 느린 조작에는 충분하지만 고주파 제어에는 부족합니다.

### FAST 토크나이저 — 더 빠른 행동 디코드

Pertsch et al. (2024)은 이산 빈 토큰화가 비효율적임을 보였습니다 — 대부분의 행동은 빈 공간의 작은 영역에 몰려 있거든요. FAST(Frequency-domain Action Sequence Tokenizer)는 행동 시퀀스를 DCT로 압축하고 계수를 양자화합니다.

30스텝 행동 궤적이 300개 이산 빈 토큰 대신 약 10개 FAST 토큰이 됩니다. 품질 손실 없이 추론이 3~5배 빨라집니다.

### π0와 흐름 매칭 행동

Physical Intelligence의 π0(Black et al., 2024년 10월)는 이산 행동 토큰을 흐름 매칭 행동 전문가로 바꿉니다:

- 작은 행동 트랜스포머가 VLM의 은닉 상태를 읽고, 정정 흐름으로 연속적인 50스텝 행동 시퀀스를 출력합니다.
- 행동 헤드는 흐름 매칭 손실로 학습합니다; VLM 사전학습은 그대로 유지됩니다.
- 추론: 전체 행동 시퀀스를 약 5회 디노이징 스텝으로 출력, 사실상 50Hz 제어.

π0의 주장: 다양한 조작 과제 모음에서 OpenVLA와 Octo를 이긴다는 것입니다. 연속 행동 정식화는 이산화가 파괴하는 매끄러움을 보존합니다.

π0.5와 π0-FAST는 점진적 업그레이드입니다. π0-FAST는 FAST 토큰화를 흐름 매칭과 결합합니다.

### GR00T N1 — 휴머노이드를 위한 듀얼 시스템

NVIDIA의 GR00T N1(2025년 3월)은 휴머노이드 로봇(30DOF 이상, 전신)을 위해 만들어졌습니다:

- System 2: 장면 + 지시를 읽는 큰 VLM이 약 1Hz로 상위 서브골을 만들어 냅니다.
- System 1: 작은 행동 헤드 트랜스포머가 서브골을 조건으로 50~100Hz의 하위 관절 명령을 만들어 냅니다.

이 분리는 카너먼의 빠른-느린 사고에 대응합니다. System 2가 계획하고, System 1이 행동합니다. 이점: 느린 VLM급 계획이 빠른 제어를 막지 않고, System 1은 지연 시간을 위해 작게 유지됩니다.

GR00T N1.7(2025년 말)은 데이터 스케일링을 개선했습니다. GR00T는 Omniverse의 시뮬레이션-실전(sim-to-real) 데이터로 파인튜닝됩니다.

### Open X-Embodiment

학습 데이터입니다. RT-X(2023년 10월)는 22개 로봇에 걸친 100만 궤적을 아우르는 22개 데이터셋을 모았습니다. Open X-Embodiment는 모두가 쓰는 코퍼스입니다:

- ALOHA / Bridge V2 / Droid / RT-2 Kitchen / Language Table.
- 각 샘플: (로봇 상태, 카메라 뷰, 지시, 행동 시퀀스).
- 학습 위생: 행동 공간 통일, 관절 범위 정규화, 카메라 해상도 통일.

OpenVLA와 π0는 Open X-Embodiment로 학습합니다. 특정 로봇과의 도메인 격차는 100~1000개의 과제별 시연으로 LoRA 파인튜닝하면 좁혀집니다.

### 공동 파인튜닝 vs 로봇 전용

공동 파인튜닝은 웹 VQA 데이터를 로봇 궤적과 섞습니다. 비율이 중요합니다. VQA가 너무 많으면 모델이 행동을 잊고, 로봇 데이터가 너무 많으면 일반 지식을 잃습니다.

RT-2의 비율: 약 1:1. OpenVLA: 웹 대 로봇 약 0.5:1. π0: 유사합니다. 정확한 비율은 데이터셋 크기에 맞춰 조정하는 하이퍼파라미터입니다.

로봇 전용 학습은 과제 특화 모델을 만들고, 분포 밖 지시에서 실패합니다. 공동 파인튜닝의 유무가 "(시연했던) 빨간 큐브를 집어라"와 "(새로운 표현인) 왼쪽에서 세 번째로 큰 물체를 집어라"의 차이를 만듭니다.

### 안전과 행동 한계

모든 프로덕션 VLA에는 다음이 함께 탑재됩니다:

- 하드 관절 한계(사양을 넘는 토크 불가).
- 속도 한계(소프트 클리핑).
- 작업 공간 경계(말단 장치는 테이블을 벗어날 수 없음).
- 새로운 과제에 대한 휴먼 인 더 루프 승인.

이것들은 VLA 밖의 제어 계층 검사로 배치됩니다. VLA의 출력은 명령이 아니라 제안입니다.

```figure
mm-action-tokens
```

## 직접 해보기

`code/main.py`:

- 256빈 행동 토큰화와 역토큰화를 구현합니다.
- DCT + 양자화 기반 FAST 토크나이저의 스케치를 담고 있습니다.
- (이산 빈, FAST, 연속 흐름)별 스텝당 토큰 수를 비교합니다.
- RT-2 → OpenVLA → π0 → GR00T 계보 요약을 출력합니다.

## 출시하기

이 레슨은 `outputs/skill-vla-action-format-picker.md`를 만듭니다. 로봇 과제(조작, 내비게이션, 휴머노이드 전신)가 주어지면 이산 빈 + RT-2, FAST + OpenVLA, 흐름 매칭 + π0, 듀얼 시스템 + GR00T 중 하나를 골라 줍니다.

## 연습 문제

1. 30Hz 제어 주기의 10-DOF 팔입니다. 256빈 이산 빈 토큰화는 초당 토큰을 몇 개 내보낼까요? 7B VLM이 따라갈 수 있을까요?

2. FAST 토큰화는 30스텝 궤적을 약 10토큰으로 압축합니다. 궤적에 고주파 움직임(예: 드럼 연주)이 있으면 무엇을 잃게 될까요?

3. π0의 흐름 매칭 헤드는 약 5스텝으로 디노이징합니다. OpenVLA의 4~5Hz 자기회귀 디코드와 처리량을 비교해 보세요.

4. GR00T의 System 1 / System 2 분리는 카너먼에 대응합니다. 두 발 걷기에 도움이 될 수 있는 다른 분리(System 3?)를 제안해 보세요.

5. Open X-Embodiment의 4절(데이터셋 큐레이션)을 읽어 보세요. 도메인 누수를 막는 세 가지 큐레이션 규칙을 꼽아 보세요.

## 핵심 용어

| 용어 | 사람들이 말하는 표현 | 실제 의미 |
|------|-----------------|------------------------|
| VLA | "Vision-language-action" | 이미지 + 지시를 받아 행동 명령을 출력하는 모델 |
| 행동 토큰화 (Action tokenization) | "이산 빈" | 연속적인 관절 목표를 차원별로 256개 빈으로 양자화해 각각을 어휘 ID로 |
| FAST 토크나이저 | "주파수 행동 토큰" | DCT + 양자화로 30스텝 궤적을 약 10토큰으로 압축 |
| 공동 파인튜닝 (Co-fine-tune) | "웹 + 로봇 혼합" | 일반 지식을 지키기 위해 웹 VQA 데이터를 로봇 시연과 함께 학습 |
| 흐름 매칭 행동 헤드 | "π0 연속 출력" | 정정 흐름으로 50스텝 행동 시퀀스를 출력하는 작은 트랜스포머 |
| System 1 / System 2 | "듀얼 시스템 제어" | 큰 VLM이 느리게 계획하고 작은 행동 헤드가 빠르게 행동; GR00T 패턴 |
| Open X-Embodiment | "RT-X 데이터셋" | 100만 궤적의 로봇 간 데이터셋; 그 학습 코퍼스 |
