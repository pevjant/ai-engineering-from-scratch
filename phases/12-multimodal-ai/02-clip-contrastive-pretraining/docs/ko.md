# CLIP과 대조 시각-언어 사전학습

> OpenAI의 CLIP(2021)은 향후 5년을 움직일 만큼 큰 단 하나의 아이디어를 증명했습니다. 지저분한(noisy) 웹의 이미지-캡션 쌍과 대조 손실만으로 이미지 인코더와 텍스트 인코더를 같은 벡터 공간에 정렬한다는 것이죠. 지도 레이블은 0개, 쌍은 4억 개. 만들어진 임베딩 공간은 제로샷 분류와 이미지-텍스트 검색을 해내고, 2026년의 모든 VLM에 비전 타워로 꽂힙니다. SigLIP 2(2025)는 softmax를 sigmoid로 바꿔 더 낮은 비용으로 CLIP을 추월했습니다. 이 레슨은 InfoNCE부터 sigmoid 쌍별 손실까지 수학을 따라가고 학습 스텝을 stdlib Python으로 만듭니다.

**유형:** Build
**언어:** Python (stdlib, InfoNCE + sigmoid 손실 구현)
**선수 지식:** 페이즈 12 · 01(ViT 패치), 페이즈 7(트랜스포머)
**소요 시간:** 약 180분

## 학습 목표

- 상호 정보량에서 InfoNCE 손실을 유도하고 수치적으로 안정적인 벡터화 버전을 구현할 수 있습니다.
- sigmoid 쌍별 손실(SigLIP)이 softmax가 요구하는 all-gather 오버헤드 없이 배치 32768 이상으로 확장되는 이유를 설명할 수 있습니다.
- 텍스트 템플릿(`a photo of a {class}`)을 만들고 코사인 유사도의 argmax를 취해 제로샷 ImageNet 분류를 실행할 수 있습니다.
- CLIP / SigLIP 사전학습이 주는 네 가지 레버를 꼽을 수 있습니다. 배치 크기, 온도, 프롬프트 템플릿, 데이터 품질입니다.

## 문제 상황

CLIP 이전의 비전은 지도 학습이었습니다. 레이블 데이터셋을 모으고(ImageNet: 120만 장, 1,000클래스) CNN을 학습시키고 출시합니다. 레이블은 비싸고, 레이블러들이 합의할 수 있는 것에 치우치며, 파인튜닝 없이는 새 작업으로 전이되지 않습니다.

이미지-캡션 웹에는 느슨하게 레이블된 쌍이 10억 개 이상 공짜로 널려 있습니다. 골든 리트리버 사진에 "my dog Max in the park"라는 대체 텍스트가 붙어 있다면 그것은 감독 신호입니다. 텍스트가 이미지를 묘사하니까요. 질문은 이것을 유용한 학습으로 바꿀 수 있는가입니다.

CLIP의 답: 이미지-캡션 쌍을 매칭 과제로 취급합니다. N개 이미지와 N개 캡션의 배치가 주어지면, N-1개의 방해자를 상대로 각 이미지를 자기 캡션과 맞추도록 학습합니다. 감독 신호는 "이 둘은 한 쌍이다. 저 N-1개는 아니다."입니다. 클래스 레이블도, 사람의 주석도 없습니다. 대조 손실 하나뿐입니다.

만들어진 임베딩 공간은 CLIP이 학습된 것 이상을 해냅니다. ImageNet 제로샷이 동작하는 이유는 "a photo of a cat"이 고양이로 명시적 레이블된 적 없는 고양이 사진 근처에 임베딩되기 때문입니다. 2026년의 모든 VLM을 낳은 내기가 바로 이것입니다.

## 개념

### 듀얼 인코더(쌍둥이 타워)

CLIP에는 타워가 둘 있습니다:

- 이미지 인코더 `f`: ViT 또는 ResNet. 이미지당 D차원 벡터를 출력합니다.
- 텍스트 인코더 `g`: 작은 트랜스포머. 캡션당 D차원 벡터를 출력합니다.

두 타워 모두 출력을 단위 길이로 정규화합니다. 둘 다 단위 노름이므로 유사도는 `cos(f(x), g(y)) = f(x)^T g(y)`입니다.

N개의 (이미지, 캡션) 쌍 배치에 대해 형태가 `(N, N)`인 유사도 행렬 `S`를 만듭니다:

```
S[i, j] = cos(f(x_i), g(y_j)) / tau
```

여기서 `tau`는 학습되는 온도입니다(CLIP은 0.07로 초기화하고 로그 공간에서 학습합니다).

### InfoNCE 손실

CLIP은 행과 열에 걸친 대칭 교차 엔트로피를 씁니다:

```
loss_i2t = CE(S, labels=identity)     # 각 이미지의 양성은 자기 캡션
loss_t2i = CE(S^T, labels=identity)   # 각 캡션의 양성은 자기 이미지
loss = (loss_i2t + loss_t2i) / 2
```

이것이 InfoNCE입니다. CE의 softmax는 배치 안의 다른 모든 캡션보다 자기 캡션과 더 잘 맞도록 각 이미지를 강제합니다. "음성(negative)"은 배치의 다른 모든 항목입니다. 배치가 크다 = 음성이 많다 = 신호가 강하다. CLIP은 배치 32k로 학습했습니다. 스케일이 중요합니다.

### 온도(Temperature)

`tau`는 softmax의 날카로움을 조절합니다. tau가 낮으면 → 분포가 뾰족해지고 하드 네거티브 마이닝 효과가 생깁니다. tau가 높으면 → 부드러워지고 모든 샘플이 기여합니다. CLIP은 log(1/tau)를 학습하고 붕괴를 막기 위해 클리핑합니다. SigLIP 2는 초기 tau를 고정하고 대신 학습되는 편향을 씁니다.

### sigmoid가 더 잘 확장되는 이유(SigLIP)

softmax는 전체 유사도 행렬이 동기화되어야 합니다. 분산 학습에서는 모든 임베딩을 모든 레플리카로 all-gather한 뒤 softmax를 해야 합니다. 통신량이 월드 크기의 제곱으로 늘어납니다.

SigLIP는 softmax를 요소별(element-wise) sigmoid로 바꿉니다. 각 쌍 `(i, j)`에 대해 손실은 "이 둘이 맞는 쌍인가?"라는 이진 분류입니다. 양성 클래스 레이블은 대각선이고 나머지는 모두 음성입니다. 손실은:

```
L = -1/N sum over (i, j) [ y_ij log sigmoid(S[i,j]) + (1-y_ij) log sigmoid(-S[i,j]) ]
```

`i == j`이면 `y_ij = 1`, 아니면 0입니다. 각 쌍의 손실이 서로 독립입니다. all-gather가 필요 없습니다. 각 GPU가 자기 로컬 블록을 계산하고 합산합니다. CLIP이라면 비례해서 더 많은 통신이 필요할 배치 32k~512k까지 SigLIP 2는 싸게 확장됩니다.

### 제로샷 분류

N개의 클래스 이름이 주어지면 클래스마다 텍스트 템플릿을 만듭니다:

```
"a photo of a {class}"
```

각 템플릿을 텍스트 인코더로 임베딩합니다. 이미지를 이미지 인코더로 임베딩합니다. 코사인 유사도의 argmax가 예측 클래스입니다. 대상 클래스에 대한 학습은 없습니다.

프롬프트 템플릿도 중요합니다. CLIP 원논문은 클래스당 80개 템플릿(일반, 예술적, 사진, 회화 등)을 쓰고 임베딩을 평균 냈습니다. ImageNet에서 +3점이었습니다. 현대에는 보통 템플릿 한두 개를 고릅니다.

### 선형 프로브와 파인튜닝

제로샷은 베이스라인입니다. 선형 프로브(동결한 CLIP 특성 위에서 대상 클래스용 선형 계층 하나를 학습)는 인도메인 과제에서 제로샷을 이깁니다. 완전 파인튜닝은 인도메인에서 선형 프로브를 이기지만 제로샷 전이를 해칠 수 있습니다. 세 가지 체제, 세 가지 트레이드오프입니다.

### SigLIP 2: NaFlex와 조밀 특성

SigLIP 2(2025)는 다음을 추가합니다:
- NaFlex: 모델 하나로 다양한 종횡비와 해상도를 처리합니다.
- 세그멘테이션과 깊이 추정을 위한 더 나은 조밀 특성. VLM에서 동결 백본으로 쓰일 목표입니다.
- 다국어: 영어뿐이던 CLIP과 달리 100개 이상 언어로 학습했습니다.
- CLIP이 4억에서 정체된 반면 10억 파라미터 스케일에 도달했습니다.

2026년 오픈 VLM에서 기본 비전 타워는 SigLIP 2 SO400m/14입니다. LAION-2B 학습 분포가 쿼리 패턴과 맞는 순수 이미지-텍스트 검색에는 CLIP이 여전히 기본입니다.

### ALIGN, BASIC, OpenCLIP, EVA-CLIP

ALIGN(Google, 2021): CLIP과 같은 아이디어를 18억 쌍, 그중 90%가 노이즈인 규모로 실행했습니다. 노이즈 있는 데이터도 확장된다는 것을 증명했죠. OpenCLIP(LAION): LAION-400M / 2B에서 CLIP을 재현한 공개 구현. 여러 스케일로 나와 있으며 오픈 체크포인트의 표준입니다. EVA-CLIP: 마스크 이미지 모델링으로 초기화합니다. VLM용 강한 백본입니다. BASIC: Google의 CLIP+ALIGN 하이브리드. 전부 같은 계열이고 데이터와 튜닝만 다릅니다.

### 제로샷 한계선

CLIP급 모델은 ImageNet 제로샷에서 약 76%에 머뭅니다(CLIP-G, OpenCLIP-G). 그 이상은 훨씬 더 큰 데이터(SigLIP 2는 80% 이상)나 아키텍처 변경(지도 헤드, 더 많은 파라미터)이 필요합니다. 벤치마크는 포화 상태이고, 진짜 가치는 다운스트림 VLM이 소비하는 임베딩 공간에 있습니다.

## 사용해 보기

`code/main.py`는 다음을 구현합니다:

1. 장난감 듀얼 인코더(해시 기반 이미지 특성, 텍스트 문자 특성). numpy 없이도 InfoNCE 모양을 볼 수 있습니다.
2. 순수 Python의 InfoNCE 손실(log-sum-exp로 수치 안정성 확보).
3. 비교용 sigmoid 쌍별 손실.
4. 제로샷 분류 루틴. 텍스트 프롬프트 집합에 대해 코사인 유사도를 계산하고 argmax로 예측합니다.

실행해서 손실 곡선을 지켜보세요. 절대 숫자는 장난감 수준이지만, 모양은 진짜 CLIP 트레이너가 내놓는 것과 같습니다.

## 연습 문제

1. 4쌍 배치에 대해 InfoNCE를 손으로 구현합니다. 4x4 유사도 행렬을 만들고, softmax를 돌리고, 대각선을 뽑아 교차 엔트로피를 계산합니다. Python 구현이 이 손계산과 일치하는지 확인합니다.

2. SigLIP는 온도 외에 편향 파라미터 `b`를 씁니다: `S'[i,j] = S[i,j]/tau + b`. 배치에 큰 클래스 불균형이 있을 때(행당 양성보다 음성이 훨씬 많을 때) `b`는 어떤 역할을 할까요? SigLIP 3절(arXiv:2303.15343)을 읽어 보세요.

3. 고양이 대 개 제로샷 분류기를 만듭니다. `a photo of a {class}`와 `a picture of a {class}` 두 프롬프트 템플릿을 시험합니다. 테스트 이미지 100장에서 정확도를 측정합니다. 템플릿 앙상블이 단일보다 나은가요?

4. 배치 32k로 512 GPU를 쓰는 실행에서 softmax InfoNCE와 sigmoid 쌍별 손실의 통신 비용을 계산합니다. 어느 쪽이 O(N), 어느 쪽이 O(N^2)으로 확장되나요? SigLIP 4절을 인용합니다.

5. OpenCLIP 스케일링 법칙 논문(arXiv:2212.07143, Cherti 등)을 읽습니다. 그림에서 데이터 확장에 관한 그들의 결론을 재현합니다. 고정된 모델 크기에서 ImageNet 제로샷 정확도와 학습 데이터 크기 사이의 로그-선형 관계는 무엇인가요?

## 핵심 용어

| 용어 | 흔히 하는 말 | 실제 의미 |
|------|----------------|------------------------|
| InfoNCE | "대조 손실" | 배치 유사도 행렬에 대한 교차 엔트로피. 각 항목의 양성은 짝지어진 항목, 음성은 나머지 전부 |
| Sigmoid 손실 | "SigLIP 손실" | 쌍별 이진 교차 엔트로피. softmax도 all-gather도 없고 분산 학습에서 싸게 확장됨 |
| 온도(Temperature) | "tau" | softmax/sigmoid 전에 로짓을 스케일하는 스칼라. 분포의 날카로움을 조절 |
| 제로샷 | "파인튜닝 없는 분류" | 텍스트 프롬프트로 클래스 임베딩을 만들고 코사인 유사도로 분류. 대상 클래스에 대한 학습 없음 |
| 프롬프트 템플릿 | "a photo of a ..." | 클래스 이름을 감싸는 텍스트 비계. 제로샷 정확도에 1~5점 영향 |
| 듀얼 인코더 | "투 타워" | 이미지 인코더 하나 + 텍스트 인코더 하나. 공유 D차원 공간에 출력 |
| 하드 네거티브 | "괴악한 방해자" | 양성과 충분히 비슷해 모델이 구분하느라 애써야 하는 음성 |
| 선형 프로브 | "동결 + 계층 하나" | 동결된 특성 위에 선형 분류기만 학습. 특성 품질을 측정 |
| NaFlex | "네이티브 유연 해상도" | 리사이즈 없이 임의의 종횡비와 해상도의 이미지를 받아들이는 SigLIP 2 능력 |
| 온도 스케일링 | "로그 파라미터화된 tau" | CLIP은 `log(1/tau)`로 파라미터화해 그래디언트가 잘 동작하게 하고, tau가 0 근처로 무너지지 않게 클리핑 |
