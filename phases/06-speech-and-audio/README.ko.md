**선수 지식:** 페이즈 1의 벡터, 행렬, 확률. 첫 번째 데모는 Python 표준 라이브러리만 사용합니다.

**첫 레슨:** [오디오 기초](01-audio-fundamentals/)

저장소 루트에서 다음 명령을 실행하세요:

```bash
python3 phases/06-speech-and-audio/01-audio-fundamentals/code/main.py
```
