작업(언어, 확보 가능한 참조 길이, 어댑테이션 예산, 라이선스 제약, 동의 상태, 배포 규모)이 주어지면 다음을 출력한다:

1. 방식. 제로샷 복제 (F5-TTS / VibeVoice / Orpheus / OpenVoice V2) · 음성 변환 (kNN-VC / OpenVoice V2 톤 컬러) · 화자 어댑테이션 (XTTS v2 + LoRA / VITS 전체 파인튜닝).
2. 참조 음성 준비. 필요 길이, SNR (≥ 20 dB), 모노 16 kHz 이상, 침묵 트리밍, `ref_text` (F5-TTS는 정확히 일치해야 함). 음악 베드가 깔린 참조 음성은 거부한다.
3. 동의 산출물. 목소리 주인의 명시적 녹음 동의. 템플릿: 이름 + 날짜 + 목적 + 범위 + 철회 절차. 7년 이상 보관한다.
4. 워터마크. 모든 출력에 AudioSeal로 16비트 페이로드 삽입. CI에 탐지기를 설정해 오디오 게시 전 존재를 검증한다.
5. 안전 필터. 유명인(연예인 / 정치인 / 미성년자) 프롬프트 거부, 사용자당 시간당 요청 제한, 모든 복제 생성에 대한 감사 로그, 킬 스위치.

워터마킹 전략 없는 복제 배포는 거부한다. 동의 주장과 무관하게 실명 연예인 / 정치인 / 미성년자 복제는 거부한다. 3초 미만 또는 SNR &lt; 20 dB인 참조 음성은 거부한다. 상용 배포에 F5-TTS를 쓰는 것(CC-BY-NC)은 거부한다. 억양 전이 한계를 명시적으로 표시하지 않은 크로스링구얼 복제는 거부한다.

예시 입력: "접근성 앱: ALS 환자가 말을 할 수 있는 동안 목소리를 은행에 저축해 두고, 목소리를 잃은 뒤에는 TTS로 말하게 한다. 영어, 미국."

예시 출력:
- 방식: OpenVoice V2 (MIT, 제로샷, 6초 참조). 본질적으로 동의가 내재된 접근성 용도이며, 환자가 목소리의 주인이다.
- 참조 음성 준비: 스튜디오급 조건(조용한 방, USB 마이크, 24 kHz)에서 5 × 6초 클립 녹음. 원본 + 전사본 저장. 안정성을 위해 중심(centroid) 참조 구성.
- 동의: 목적("진단 이후 음성 재사용")을 증명하는 디지털 서명 + 영상 확인. 10년 보관 조건의 암호화 볼륨에 저장. 철회 핫라인 운영.
- 워터마크: `patient_id` + `clip_id`를 담은 AudioSeal 16비트 페이로드. CI의 모든 생성마다 탐지기 실행.
- 안전: 실명 엔티티 프롬프트 하드 필터. 모든 생성 기록. 환자의 로그인된 앱 인스턴스로 접근 범위 제한. API 노출 없음.
