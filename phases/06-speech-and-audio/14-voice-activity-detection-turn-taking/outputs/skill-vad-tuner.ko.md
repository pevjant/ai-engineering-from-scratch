워크로드(소비자 / 콜센터 / 엣지 / 접근성, 소음 프로파일, 언어 조합, 지연 시간)가 주어지면 다음을 출력한다:

1. VAD. Silero VAD (기본) · Cobra (상용 정확도) · pyannote segmentation (화자 분리 등급) · WebRTC VAD (레거시 / 초소형). 한 문장 근거.
2. 파라미터. 임계값 (0.3-0.5), 최소 발화 (200-300 ms), 침묵 행오버 (400-800 ms), 프리롤 (250-500 ms).
3. 의미적 턴 탐지. 켜기 (LiveKit turn-detector 또는 자체 MLP) 또는 끄기. 예상되는 사용자 발화 패턴에 근거한 이유.
4. 플러시 트릭. 켜기 (STT가 지원하는 경우 — Kyutai / Deepgram) 또는 끄기. 예상 지연 시간 절감.
5. 가드. 최소 길이보다 짧은 발화는 거부. 프리롤은 항상 보관. 사용자별 침묵 행오버 오버라이드는 상한 제한. VAD 서비스가 죽으면 페일오픈 (모든 것을 음성으로 취급).

프로덕션에서 에너지 전용 VAD는 거부한다 — 소음에 너무 약하다. 침묵 행오버 0은 거부한다 — 사용자 말을 끊는다. 전용 Silero가 있는데 Whisper 기반 VAD를 쓰는 것은 거부한다 (더 느리고 덜 정확하다).

예시 입력: "항공사 좌석 재예약 콜센터 IVR. 시끄러운 배경 (공항). 영어 + 스페인어. 턴 탐지 &lt; 500 ms."

예시 출력:
- VAD: Cobra (상용). 소음 저항이 강점. 비용이 부담되면 Silero로 폴백.
- 파라미터: 임계값 0.4 (공항 소음 바닥이 높음). 최소 발화 300 ms. 침묵 행오버 600 ms (사용자는 IVR에서 항공편 번호를 읽느라 자주 멈춤). 프리롤 400 ms.
- 의미적 턴: LiveKit turn-detector 켬 — 문장 중간 멈춤이 흔함 ("항공편을 바꾸고 싶은데... 내일 걸로요").
- 플러시 트릭: Deepgram 스트리밍에서 켬. 예상 절감: 턴 종료 지연 400 ms → 150 ms.
- 가드: Cobra/Deepgram에 접근 불가 시 페일오픈. 튜닝을 위해 모든 VAD 발화 이벤트를 감사 로그에 기록.
