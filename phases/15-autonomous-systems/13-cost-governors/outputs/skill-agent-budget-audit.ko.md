제안된 에이전트 배포가 주어지면, 12계층 기준 스택을 기준으로 비용 거버너 스택을 감사하고, 어떤 계층이 없거나, 느슨하게 설정되었거나, 지나치게 타이트한지 표시합니다.

작성할 내용:

1. **계층 목록.** 12개 기준 계층(요청별 상한, 태스크별 토큰 예산, 태스크별 달러 예산, 도구별 상한, 반복 상한, 분/시간/일/월 롤링 상한, 속도 제한, 계층형 라우팅, 프롬프트 캐싱, 컨텍스트 윈도잉, HITL 체크포인트, 킬 스위치) 각각에 대해 설정되어 있는지, 그리고 어떤 값으로 되어 있는지 밝힙니다.
2. **실패 양상 대응.** 각 시간 규모 실패(폭주 루프, 느린 누출, 나쁜 릴리스, 정당한 급증)에 대해 그것을 잡는 구체적인 계층과 얼마나 빨리 잡는지를 명시합니다.
3. **도구별 상한.** 에이전트가 호출할 수 있는 모든 도구를 나열합니다. 각각에 대해 세션별 상한과 이유를 명시합니다. 명시적 상한이 없는 도구는 열린 루프입니다.
4. **경보 임계값.** 상한과는 별개로: 어느 지출 속도에서 사람이 호출(paged)되는가? 관찰된 전자상거래 사례($1,200 → $4,800)는 월간 상한 문제가 아니라 주간 대비 성장 문제였습니다.
5. **킬 스위치 경로.** 상한이 발동하면 무슨 일이 일어나는가? 깨끗한 중단, 롤백, 경보, 재활성화 절차. 킬 스위치가 에이전트 외부에 있는지(에이전트가 자기 상한을 수정할 수 없는지) 확인합니다.

하드 리젝(무조건 거부):
- 태스크별 달러 예산 없는 자율 배포.
- 속도 제한 없는 무인 장기 실행.
- 새 도구(30일 미만) 추가에 도구별 상한이 없는 도구 표면.
- 에이전트 자신이 수정할 수 있는 킬 스위치.
- 월간 상한이 유일한 상한인 배포 (다른 모든 시간 규모가 무방비).

거부 규칙:
- 사용자가 오늘의 모델 가격으로 최악의 실행 가격을 매기지 못하면 거부하고, 비용 산정 추정치를 요구하세요.
- 제안된 예산이 조직이 단일 실수에서 감수할 수 있는 손실을 넘으면 거부하고, 더 낮은 상한을 요구하세요.
- 사용자가 Auto Mode 분류기(레슨 10)를 예산의 대체물로 취급하면 거부하세요. 분류기는 비용과 직교합니다; 두 계층이 모두 필요합니다.

출력 형식:

다음을 포함한 비용 거버너 감사를 반환합니다:
- **계층 표** (계층 이름, 설정 여부 y/n, 값)
- **실패 양상 커버리지** (4행: 루프 / 누출 / 릴리스 / 급증)
- **도구별 상한** (도구, 상한, 이유)
- **경보 임계값** (속도, 담당자, 채널)
- **킬 스위치 경로** (트리거, 행동, 재활성화 절차)
- **준비도** (프로덕션 / 스테이징 / 연구 전용)
