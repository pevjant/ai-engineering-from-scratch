# 왜 트랜스포머인가 — RNN의 문제점

> 🇰🇷 이 문서는 한국어 번역본입니다(ELI5 스타일). 원문: [en.md](en.md)

> RNN은 토큰을 한 번에 하나씩 처리합니다. 트랜스포머는 모든 토큰을 한꺼번에 처리합니다. 이 단 하나의 아키텍처 선택이 2017년 이후 딥러닝의 모든 스케일링 곡선을 바꿔 놓았습니다.

**유형:** 학습(Learn)
**언어:** Python
**선수 지식:** 페이즈 3 (딥러닝 핵심), 페이즈 5 · 09 (시퀀스-투-시퀀스), 페이즈 5 · 10 (어텐션 메커니즘)
**시간:** 약 45분

## 문제 상황

2017년 이전에는 세상의 모든 최신 시퀀스 모델 — 언어, 번역, 음성 — 이 순환 신경망(recurrent neural network)이었습니다. LSTM과 GRU는 5년 동안 ImageNet에 버금가는 번역 벤치마크를 석권했습니다. 그것이 유일한 도구였으니까요.

하지만 치명적인 약점이 세 가지 있었습니다. 첫째, 계산이 순차적이라는 점 — 시간축을 따라 병렬화할 수 없었습니다. 토큰 `t+1`은 토큰 `t`의 은닉 상태가 필요하니까요. 1,024개 토큰 시퀀스는 주기당 100만 번의 부동소수점 연산을 해내는 GPU 위에서 1,024번의 직렬 단계를 뜻했습니다. 병렬 처리용으로 설계된 하드웨어에서 학습 시간이 시퀀스 길이에 비례해 늘어난 겁니다.

둘째, 기울기 소실(vanishing gradient) — 50 토큰 앞의 정보는 이미 50겹의 비선형성을 통과하며 뭉개진 상태였습니다. 게이트가 달린 순환 유닛(LSTM, GRU)이 압박을 완화했지만 없애지는 못했습니다. "작년 여름 교토로 가는 비행기에서 읽은 책은…" 같은 장거리 의존성은 일상적으로 실패했습니다.

셋째, 고정 폭 은닉 상태 — 인코더가 소스 시퀀스 전체를 디코더가 아무것도 보기 전에 단 하나의 벡터로 짜 넣어야 했습니다. 소스가 5 토큰이든 500 토큰이든, 병목의 모양은 똑같습니다.

2017년 논문 "Attention Is All You Need"는 급진적인 것을 제안했습니다: 순환 구조를 완전히 버리자. 모든 위치가 모든 위치를 병렬로 주시하게 하자. 1,024번의 순차 곱셈 대신 한 번의 큰 행렬 곱셈으로 학습하자는 것입니다.

그 결과가 2026년에는 모든 모달리티를 지배합니다. 언어(GPT-5, Claude 4, Llama 4), 비전(ViT, DINOv2, SAM 3), 오디오(Whisper), 생물학(AlphaFold 3), 로봇공학(RT-2). 같은 블록, 다른 입력일 뿐입니다.

## 핵심 개념

![RNN의 순차 연산 vs 트랜스포머의 병렬 어텐션](../assets/rnn-vs-transformer.svg)

**순환 구조는 병목입니다.** RNN은 `h_t = f(h_{t-1}, x_t)`를 계산합니다. 각 단계가 이전 단계에 의존하니 `h_4`가 나오기 전에는 `h_5`를 계산할 수 없습니다. 10,000개 이상의 병렬 코어를 가진 최신 GPU에서 이 구조는 긴 시퀀스를 처리할 때 실리콘의 99%를 낭비합니다.

**어텐션은 방송(broadcast)입니다.** 셀프 어텐션은 모든 쌍 `(i, j)`에 대해 `output_i = sum_j(a_ij * v_j)`를 동시에 계산합니다. N×N 어텐션 행렬 전체가 한 번의 배치 행렬 곱셈(batched matmul)으로 채워집니다. 어느 단계도 다른 단계에 의존하지 않습니다. GPU가 사랑하는 구조죠.

**가속은 고정된 수가 아닙니다.** `O(N)` 직렬 깊이와 `O(1)` 직렬 깊이의 차이입니다. 실제로 같은 하드웨어에서 N=512일 때 트랜스포머는 에포크당 5-10배 빠르게 학습되고, 시퀀스가 길어질수록 격차가 벌어지다가 어텐션의 `O(N²)` 메모리 벽에 부딪힙니다(이 벽은 나중에 Flash Attention이 해결 — 레슨 12 참고).

**트랜스포머의 대가.** 어텐션 메모리는 `O(N²)`로 늘어납니다. 2K 컨텍스트는 괜찮습니다. 하지만 128K 컨텍스트에서는 슬라이딩 윈도우, RoPE 외삽, Flash Attention 타일링, 선형 어텐션 변형 중 하나가 필요합니다. 순환 구조는 시간과 메모리 둘 다 `O(N)`이었으므로, 트랜스포머는 메모리를 희생해 시간을 사고, 다시 병렬화로 그 시간을 되찾는 셈입니다.

**귀납 편향(inductive bias)의 변화.** RNN은 지역성(locality)과 최근성(recency)을 가정합니다. 트랜스포머는 아무것도 가정하지 않습니다 — 모든 쌍이 어텐션 후보입니다. 그래서 트랜스포머는 잘 학습하려면 더 많은 데이터가 필요하지만, 데이터가 충분해지면 훨씬 더 멀리 나아갑니다. Chinchilla(2022)가 이를 정리했습니다: 토큰이 충분히 주어지면 트랜스포머는 항상 같은 파라미터 수의 RNN을 이깁니다.

## 만들어 보기

여기엔 신경망이 없습니다 — 핵심 병목을 수치로 시뮬레이션해서 노트북에서 그 격차를 직접 느껴 보게 하는 것입니다.

### 단계 1: 직렬 깊이 측정하기

`code/main.py`를 보세요. 함수 두 개를 만듭니다. 하나는 시퀀스를 덧셈 사슬로 인코딩합니다(직렬, RNN처럼). 하나는 병렬 축소(reduction)로 인코딩합니다(방송, 어텐션처럼). 같은 수학, 다른 의존성 그래프입니다.

```python
def rnn_style(xs):
    h = 0.0
    for x in xs:
        h = 0.9 * h + x   # 병렬화 불가: h가 이전 h에 의존
    return h

def attention_style(xs):
    return sum(xs) / len(xs)  # 모든 x가 서로 독립
```

10만 개까지의 시퀀스로 두 함수의 시간을 잽니다. RNN 버전은 O(N)이며 단일 CPU 파이프라인입니다. 순수 파이썬에서도 길이 1,000 이상부터는 어텐션 스타일 축소가 이깁니다. 파이썬의 `sum()`은 C로 구현되어 있어 단계마다 인터프리터 오버헤드 없이 순회하기 때문입니다.

### 단계 2: 이론적 연산 수 세기

두 알고리즘 모두 N번의 덧셈을 합니다. 차이는 *의존성 깊이*입니다. 즉, 다음 연산을 시작하기 전까지 순차적으로 일어나야 하는 연산이 몇 개인가입니다. RNN 깊이 = N. 어텐션은 트리 축소로 하면 log(N), 병렬 스캔(parallel scan)으로 하면 1입니다. GPU 시간을 결정하는 것은 연산 개수가 아니라 깊이입니다.

### 단계 3: 긴 시퀀스에서의 실측 스케일링

O(N) 격차가 눈에 보이는 타이밍 표를 출력합니다. 2026년 맥 노트북 기준으로 1,000개 미만 시퀀스는 너무 빨라 측정이 안 됩니다. 10만 개 시퀀스에서는 깔끔한 선형 스캔이 보입니다. 이를 12층 LSTM에 해당하는 16,384 토큰 트랜스포머로 확장해 보면 2016년에 학습 시간이 왜 발목을 잡았는지 알 수 있습니다.

## 활용하기

2026년에도 RNN을 고를 상황:

| 상황 | 선택 |
|-----------|------|
| 한 번에 토큰 하나씩, 고정 메모리로 스트리밍 추론 | RNN 또는 상태 공간 모델(Mamba, RWKV) |
| 어텐션 메모리가 폭발하는 초장기 시퀀스 (100만 토큰 초과) | 선형 어텐션, Mamba 2, Hyena |
| 행렬 곱셈 가속기가 없는 엣지 기기 | FLOPs/와트 기준으로 깊이별 분리(depthwise-separable) RNN이 여전히 우세 |
| 그 외 모든 경우 (학습, 배치 추론, 128K까지의 컨텍스트) | 트랜스포머 |

Mamba 같은 상태 공간 모델(SSM)은 본질적으로 구조화된 매개변수화를 입힌 RNN으로, 양쪽의 장점을 다 갖습니다: `O(N)` 스캔 메모리, 선택적 스캔(selective scan)을 통한 병렬 학습입니다. 트랜스포머 품질의 90%를 회복하면서 더 나은 장기 컨텍스트 확장성을 보여 줍니다. 2026년에는 대부분의 프론티어 연구실이 SSM+트랜스포머 하이브리드 모델(예: Jamba, Samba)을 학습시킵니다 — 순환 구조는 죽지 않았고, 이제는 구성 요소입니다.

## 연습 문제

1. **쉬움.** `code/main.py`의 `rnn_style`에서 스칼라 은닉 상태를 길이 64짜리 은닉 상태 벡터로 바꿔 보세요. 다시 시간을 재고, 직렬 오버헤드가 은닉 상태 차원에 따라 얼마나 늘어나는지 확인합니다.
2. **보통.** 병렬 접두사 합계(Hillis-Steele 스캔)를 순수 파이썬으로 구현합니다. 길이 1024에서 직렬 스캔과 같은 수치 출력을 내는지 검증하고, 깊이를 세어 봅니다.
3. **어려움.** 어텐션 스타일 축소를 GPU 위의 PyTorch로 옮깁니다. 시퀀스 길이를 64에서 65,536까지 바꿔 가며 두 방식의 시간을 재고, 곡선 모양을 그려서 설명합니다.

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|-----------------|-----------------------|
| 순환 구조 (Recurrence) | "RNN은 순차적이다" | 단계 `t`가 단계 `t-1`에 의존해 시간축을 따라 직렬 실행이 강제되는 계산. |
| 직렬 깊이 (Serial depth) | "그래프가 얼마나 깊은가" | 의존 연산의 가장 긴 사슬; 무한한 하드웨어에서도 벽시계 시간의 상한을 정한다. |
| 어텐션 (Attention) | "토큰끼리 서로를 본다" | 가중합 `sum_j a_ij v_j`. `a_ij`는 위치 i와 j 사이 유사도 점수에서 나온다. |
| 컨텍스트 윈도우 | "모델이 얼마나 보는가" | 어텐션 층이 입력으로 받을 수 있는 위치 수; 이차원 메모리 비용이 여기 붙는다. |
| 귀납 편향 (Inductive bias) | "아키텍처에 구워진 가정" | 데이터가 어떻게 생겼는지에 대한 사전 믿음; CNN은 평행 이동 불변성을, RNN은 최근성을 가정한다. |
| 상태 공간 모델 (State-space model) | "대수학을 얹은 RNN" | 구조화된 상태 공간 행렬로 매개변수화해 병렬 학습이 가능하게 만든 순환 구조. |
| 이차원 병목 | "컨텍스트가 왜 비싼가" | 어텐션 메모리 = 시퀀스 길이의 `O(N²)`; Flash Attention은 상수항만 숨겨 줄 뿐 스케일링은 그대로다. |

## 더 읽을거리

- [Vaswani et al. (2017). Attention Is All You Need](https://arxiv.org/abs/1706.03762) — 주류 NLP에서 순환 구조를 무찌른 논문.
- [Bahdanau, Cho, Bengio (2014). Neural MT by Jointly Learning to Align and Translate](https://arxiv.org/abs/1409.0473) — 어텐션이 탄생한 곳. RNN에 얹힌 형태였습니다.
- [Hochreiter, Schmidhuber (1997). Long Short-Term Memory](https://www.bioinf.jku.at/publications/older/2604.pdf) — 원조 LSTM 논문. 기록을 위해 남겨 둡니다.
- [Gu, Dao (2023). Mamba: Linear-Time Sequence Modeling with Selective State Spaces](https://arxiv.org/abs/2312.00752) — 트랜스포머에 대한 현대적 순환 구조의 답변.
