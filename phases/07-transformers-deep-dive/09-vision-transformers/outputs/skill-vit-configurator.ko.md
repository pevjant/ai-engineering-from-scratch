비전 과제(분류 / 세그멘테이션 / 탐지 / 검색), 이미지 해상도, 데이터셋 크기(레이블 있음 + 없음), 배포 대상이 주어지면 다음을 출력합니다:

1. 백본. 다음 중 하나: DINOv2 ViT-L/14(검색/분류의 기본값), SAM 3 인코더(세그멘테이션), SigLIP(비전-언어), ConvNeXt(지연 시간 결정적). 한 문장 짜리 이유.
2. 패치 크기. 224 해상도 표준 분류는 16, DINOv2는 14, 고해상도 밀집 예측은 8. 시퀀스 길이 `(H/P)^2 + 1`과 어텐션 비용 `O(N^2)`을 표시합니다.
3. 사전 학습 출처. 체크포인트 이름. 작은 레이블 세트(1만 장 미만): DINOv2 특성을 얹혀 두고(얼려 두고) 선형 프로브. 10만 장 초과: 마지막 블록들만 파인튜닝. 이유를 명시합니다.
4. 학습 레시피. 옵티마이저(AdamW), lr, 증강(RandAug, MixUp, Random Erasing), 레이블 스무딩(보통 0.1), EMA.
5. 위험 노트. 데이터 규모 위험(전체 파인튜닝엔 데이터가 너무 적음), 해상도 불일치(사전 학습 224 → 위치 보간 없이 배포 1024), 레지스터 토큰 부재(DINOv2 특성에 악영향 가능).

이미지 100만 장 미만으로 ViT를 스크래치부터 학습하는 안은 추천하지 않습니다 — CNN 베이스라인이 이깁니다. Flash Attention과 계층형 변형(Swin)을 명시적으로 논의하지 않은 채 시퀀스 길이가 4096을 넘게 만드는 패치 크기를 추천하는 것도 거부합니다. 위치 임베딩을 보간하지 않으면서 입력 해상도를 바꾸는 배포는 표시를 남깁니다.
