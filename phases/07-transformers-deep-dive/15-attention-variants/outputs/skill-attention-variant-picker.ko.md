# 어텐션 변형 선택기

개발자가 새 트랜스포머, 또는 더 긴 컨텍스트로 확장하려는 기존 트랜스포머의 어텐션 위상을 선택하고 정당화하도록 돕습니다.

## 수집할 입력

1. **목표 컨텍스트 길이** — 학습 시와 추론 시(흔히 다릅니다 — 많은 모델이 16K로 학습하고 추론에서 확장합니다).
2. **검색 요구도** — 1~5 척도: 1 = 순수 채팅, 5 = 바늘 건짐 / RAG / 긴 저장소 컨텍스트를 다루는 코드.
3. **추론 메모리 예산** — 요청당 KV 캐시 허용량(토큰당 레이어당 바이트가 올바른 단위입니다).
4. **학습 비용 허용치** — SWA를 처음부터 학습하는 건 값쌉니다; 사전학습된 모델에 차등 어텐션을 나중에 얹는 건 비쌉니다.
5. **하드웨어 대상** — Hopper 이상은 FlashAttention-3 풀 지원, Ada는 FA2, 더 오래된 GPU는 마스크 제약이 있습니다.

## 결정 규칙

- **컨텍스트 ≤ 16K이고 검색 ≤ 3**: FlashAttention을 얹은 풀 어텐션. 미리 최적화하지 마세요.
- **컨텍스트 16~128K이고 검색 ≤ 3**: 5:1 비율의 SWA + 글로벌 혼합, 윈도우 1024(Gemma 3 형태). KV를 꺾으면서도 검색이 동작하게 유지합니다.
- **컨텍스트 > 128K**: 4~6레이어마다 글로벌 레이어를 하나 둔 순수 SWA에 위치 보간 / YaRN 스케일링(레슨 04)을 더합니다.
- **검색 = 5이고 학습 예산이 허락하면**: 상위 4개 레이어에만 차등 어텐션을 고려합니다(KV 두 배화는 절반만 치르고 싱크 상쇄 이득은 대부분 챙깁니다).
- **공개 API를 출시하는 중이라면**: 안정적인 패턴(풀, SWA, Gemma-3 혼합)을 선호합니다. 커널 엔지니어가 없다면 네이티브 희소 / DIFF는 건너뜁니다.
- **베이스 모델을 바꿀 수 없다면**: SWA는 마스킹으로 추론 시점에 나중에 얹을 수 있습니다; 차등과 희소는 안 됩니다.

## 항상 표시할 것

- 7B 미만의 순수 SWA 모델은 추론 벤치마크에서 측정 가능한 손해를 보는 경우가 흔합니다. 추천하지 않습니다.
- 윈도우 크기 512 미만은 거의 항상 틀립니다. 더 키우거나 다른 위상을 쓰세요.
- 차등 어텐션의 논문 보고치는 소형 모델(3~7B) 기준입니다. 2026년 초 기준 스케일업 근거는 얇습니다.
- 모든 변형은 RoPE / YaRN 스케일링(레슨 04)과 상호작용합니다. 위치 방식을 명시적으로 밝히세요.

## 출력 형식

다음을 반환합니다:

1. **추천** — 이름 붙은 위상 하나(예: "Gemma-3 mix, W=1024, 5:1 SWA:글로벌").
2. **정당화** — 각 입력을 위의 결정 규칙에 대응시킵니다.
3. **KV 캐시 추정치** — 목표 컨텍스트 기준, 토큰당 레이어당 바이트와 배치 1 기준 GB.
4. **이전 경로** — 베이스 모델이 이미 학습돼 있다면 어떻게 나중에 얹을지.
5. **알려진 위험** — 어떤 벤치마크 / 작업이 나빠질 수 있는지.
