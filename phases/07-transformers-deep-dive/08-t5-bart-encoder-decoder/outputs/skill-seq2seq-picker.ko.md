seq2seq 과제(번역 / 요약 / 음성-텍스트 / 구조화된 추출 / 고쳐 쓰기), 입력과 출력 길이 분포, 품질 vs 지연 시간 우선순위가 주어지면 다음을 출력합니다:

1. 아키텍처. 다음 중 하나: 인코더-디코더(T5 / BART / Whisper 스타일), 디코더 전용 인스트럭션 튜닝, 인코더 전용 + 프롬프트 템플릿. 한 문장 짜리 이유.
2. 사전 학습 목적 함수. 스팬 망가뜨리기(T5), 노이즈 제거(BART), 다음 토큰(디코더 전용), 또는 "사전 학습 생략, 기존 체크포인트 파인튜닝". 체크포인트 이름을 명시합니다.
3. 입력 형식. 과제 접두사 문자열(T5 스타일) vs 시스템 프롬프트(디코더 전용) vs 날 토큰(BART). BOS/EOS 처리도 포함합니다.
4. 디코딩 전략. 빔 서치 폭과 길이 패널티(번역/요약), 또는 nucleus/min-p(채팅형 과제). 이 과제에는 무엇을 쓰는지 명시합니다.
5. 평가. 과제에 맞는 지표: BLEU / ROUGE / WER / F1 / 정확 일치. 테스트 분할 크기도 포함합니다.

생성형 출력에 인코더 전용을 추천하는 일은 거부합니다. 입력이 이미 대화일 때 인코더-디코더를 추천하는 것도 거부합니다 — 대화 기억은 디코더 전용이 자연스럽게 소화합니다. 음성-텍스트에 디코더 전용을 고르면서 이겨야 할 베이스라인으로 Whisper를 언급하지 않으면 표시를 남깁니다.
