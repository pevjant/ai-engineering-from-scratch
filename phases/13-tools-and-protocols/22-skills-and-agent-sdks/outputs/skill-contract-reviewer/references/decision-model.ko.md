# 프리미티브 의사 결정 모델

책임을 기준으로 고르세요. 프리미티브를 둘 이상 고르는 것이 옳을 수도 있습니다.

| 필요 | 프리미티브 | 경계 |
|---|---|---|
| 일회성 지시 | 프롬프트 | 현재 상호작용에서만 존재 |
| 저장소 전체 기본값 | AGENTS.md | 그 저장소 스코프에서 작업하는 동안 적용 |
| 재사용 가능한 작업 방법 | 에이전트 스킬 | 작업을 위한 절차 지식을 로드 |
| 외부 연산이나 데이터 | MCP 도구 | 입력 계약을 갖춘 호출 가능한 기능을 노출 |
| 런타임 이벤트에 대한 반응 | 훅 | 호스트가 정의한 생명주기 지점에서 실행 |
| 결정론적 변환 | 평범한 코드 | 모델 판단 없이 재현 가능한 출력 생성 |
| 격리되거나 병렬인 컨텍스트 | 서브에이전트 | 한정된 작업을 별도 컨텍스트 윈도우로 위임 |

원격 서비스에 질의하는 릴리스 리뷰 방법은 에이전트 스킬과 MCP 도구를 함께 쓸 수 있습니다. 저장소 테스트 관례에는 AGENTS.md가 추가될 수 있습니다. 도구 실행 후 감사에는 훅이 추가될 수 있습니다. 안정적인 파싱은 평범한 코드에 맡깁니다. 컨텍스트 격리가 도움이 되는 독립적인 조사에는 서브에이전트를 쓸 수 있습니다.
