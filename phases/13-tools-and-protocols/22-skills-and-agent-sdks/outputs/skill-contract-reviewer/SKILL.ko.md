# 스킬 계약 리뷰어

어떤 워크플로가 재사용 가능한 에이전트 산출물이 되려는 시점에 이 스킬을 사용하세요.

1. 설치된 이 `SKILL.md`가 들어 있는 절대 경로 디렉터리를 `SKILL_ROOT`로 설정합니다. 프로세스 작업 디렉터리가 곧 번들이라고 가정하지 마세요.
2. 원래 작업 공간의 절대 경로 작업 디렉터리를 `TARGET_ROOT`로 설정하고, 그 루트 아래에서 제안된 스킬 디렉터리를 확정합니다.
3. `$SKILL_ROOT/references/contract.md`를 읽고 이식 가능한 `SKILL.md` 식별 필드를 검증합니다.
4. `$SKILL_ROOT/references/decision-model.md`를 읽고 저장소 컨텍스트, 재사용 가능한 방법, 외부 기능, 생명주기 시점, 결정론적 로직, 격리된 위임을 구분합니다.
5. 실행 전에 확정된 인자 벡터를 그대로 보여 줍니다. `python3 "$SKILL_ROOT/scripts/check_skill.py" "$TARGET_SKILL"`을 실행하세요. `TARGET_SKILL`은 `TARGET_ROOT` 아래의 제안된 스킬 디렉터리 절대 경로입니다.
6. JSON 보고서를 살펴봅니다. 호스트 전용 확장을 논하기 전에 모든 오류를 고치세요.
7. 제안된 산출물을 `$SKILL_ROOT/assets/task-shapes.json`과 비교하고, 조합 가능한 가장 작은 프리미티브 집합을 돌려줍니다.

런타임 확장이 이식 가능한 계약의 일부라고 주장하지 마세요. 유효한 스킬을 스크립트 실행이나 도구 접근 권한으로 취급하지도 마세요.

검증 보고서, 선택된 프리미티브, 각 선택을 설명하는 한 문장을 돌려줍니다. 실행 증거로 확정된 스크립트 경로, 확정된 대상 경로, cwd, 정확한 argv, 종료 코드를 포함하세요. 호스트가 이 관측 값 중 하나를 노출할 수 없다면 만들어내지 말고 '미확인'으로 표시하세요.
