# 발견 계약

발견에는 세 가지 공개 수준이 있습니다:

1. 카탈로그: 라우팅에 필요한 `name`, `description`, 스코프, 경로를 읽습니다.
2. 활성화: 선택된 SKILL.md 본문을 명시적인 크기 예산 안에서 로드합니다.
3. 실행 지원: `references/schema.md` 같이 직접 이름이 언급된 파일만, 필요할 때 로드합니다.

스코프 위치, 우선순위, 충돌 동작, 예산은 호스트가 소유합니다. 카탈로그 빌더는 이 선택들이 출력에 그대로 드러나게 유지해야 합니다.

이식 가능한 1홉(hop) 참조는 스킬 디렉터리 안의 일반 파일이거나 바로 아래 하위 디렉터리 안의 일반 파일입니다. 절대 경로, `..`, 백슬래시, 심볼릭 링크, 더 깊은 사슬은 거부합니다.
