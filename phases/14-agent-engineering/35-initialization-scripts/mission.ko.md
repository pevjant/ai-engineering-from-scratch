# 미션 - 에이전트를 위한 초기화 스크립트

## 목표
런타임, 의존성, 테스트 명령, 환경 변수, 상태 신선도를 점검하는 `init_agent.py`를 만들고, `init_report.json`을 쓰며, 차단 심각도 점검이 실패하면 큰 소리로 세션을 멈추게 합니다.

## 입력
- `requirements.txt`(또는 이에 준하는 파일)와 테스트 명령, 그리고 레슨 34의 워크벤치 상태 파일이 있는 저장소
- 레슨의 점검 표 (런타임, 의존성, 경로, 환경 변수, 상태 신선도, 마지막 정상 커밋)

## 산출물
- 점검마다 하나의 함수가 `(name, status, detail)`을 반환하는 `init_agent.py`
- 전체 점검 결과와 타임스탬프를 담은 `init_report.json`
- 차단 심각도 점검이 하나라도 실패하면 0이 아닌 종료 코드

## 통과 기준
- 정상 경로에서 `python3 code/main.py`가 종료 코드 0으로 끝난다
- 연달아 두 번 실행해도 타임스탬프 외에는 아무 변화가 없다
- 일부러 빠뜨린 환경 변수 점검이 리포트에 나타나고 종료 코드를 바꾼다

## 범위 밖
- 빠진 의존성 자동 설치. 스크립트는 멈춰서 보고할 뿐이고, 고치는 것은 사람의 몫입니다.
- 점검 안에서 LLM 호출하기. 점검은 결정론적 배관으로 유지합니다.
