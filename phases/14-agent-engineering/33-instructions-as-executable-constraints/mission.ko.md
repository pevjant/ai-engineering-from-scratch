# 미션 - 실행 가능한 제약으로서의 에이전트 지시

## 목표
산문 지시를 다섯 카테고리에 걸친 기계 검증 가능 규칙으로 바꾸고, 리뷰어가 채점할 수 있는 규칙 보고서를 출력합니다.

## 입력
- 제목 하나당 규칙 하나씩, 각 규칙에 슬러그, 카테고리, 설명, `check` 필드가 있는 `docs/agent-rules.md`
- 두 규칙을 의도적으로 위반하는 데모 에이전트 실행

## 산출물
- `agent-rules.md`를 데이터클래스로 읽어 들이는 파서
- 참조되는 `check`마다 하나씩 있는 `rule_checker.py` 스타일 함수
- 규칙별 통과/실패와 집계 심각도가 담긴 `rule_report.json`

## 수용 기준
- `python3 code/main.py`가 종료 코드 0으로 끝남
- 출력에 파싱된 규칙 집합, 실행 트레이스, 규칙별 통과/실패가 표시됨
- `rule_report.json`이 두 개의 의도적 위반을 잡아 냄

## 범위 밖
- 검사기를 CI에 연결하기. 레슨은 보고서가 작성된 지점에서 끝납니다.
- 프레임워크 가드레일(OpenAI SDK, LangGraph 인터럽트). 규칙 집합은 그것들이 구현하는 사람이 읽는 계약입니다.

## 참조
- `docs/en.md` - 전체 레슨
- `code/main.py` - 참조 구현
- `outputs/skill-rule-set-builder.md` - 추출된 스킬
