> 🇰🇷 이 문서는 한국어 번역본입니다(ELI5 스타일). 원문: [skill-memory-blocks.md](skill-memory-blocks.md)

대상 런타임, 본 모델, (더 강할 수도 있는) sleep-time 모델이 주어지면, 명시적인 블록 타입과 비동기 정리를 갖춘 3계층 메모리 시스템을 만들어 냅니다.

산출물:

1. `label`, `value`, `limit`, `description`, `version`, `history`를 가진 `Block` 타입. 모든 쓰기는 버전을 올리고 이전 값을 기록합니다. `near_limit(threshold=0.8)`을 노출합니다.
2. 최소한 세 개의 기본 블록을 가진 `BlockStore`: `human`(사용자에 대한 사실), `persona`(에이전트의 자기 인식), `task`(현재 범위). 사용자 정의 블록을 허용합니다.
3. `Recall` 저장소 — 세션별로 페이지가 나뉜 턴 로그. 모든 턴을 자동 기록합니다. 꼬리는 상한에서 축출되지만 여전히 검색 가능합니다.
4. `Archival` 저장소 — 최소 두 백엔드(벡터, KV). 삽입은 레코드 id를 반환합니다. 충돌이 나면 삭제가 아니라 무효화합니다.
5. 턴을 처리하고 raw 쓰기만 발행하는 `PrimaryAgent`. 임계 경로 위에서는 요약을 하지 않습니다.
6. 턴 사이에서 도는 `SleepTimeAgent`: 임계값을 넘은 블록을 요약하고, 충돌된 아카이벌 레코드를 무효화하고, `learned_context`를 공유 블록에 씁니다.

절대 거부 항목:

- 직접 조회를 제외하고 사용자 대면 턴 동안 동기로 도는 메모리 연산. 요약, 정리, 무효화는 sleep-time 패스의 소관입니다.
- 충돌 시 아카이벌 레코드를 삭제하는 것. 이력이 감사 가능하도록 무효화하세요.
- 검토 단계 없이 Persona나 Safety 블록에 쓰는 것. 이 블록들은 행동을 전역으로 형성합니다. 조용한 쓰기는 버그를 가립니다.

거부 규칙:

- 런타임이 세션을 넘어 블록을 지속할 수 없다면 "메모리"라고 묘사된 제품을 출시하는 것을 거부합니다. 주장 수준을 낮추세요.
- sleep-time 에이전트에 트레이스 출력이 없다면 거부합니다. 조용한 정리는 디버깅 죽음의 구역입니다.
- "무효화 없이 항상 최신 쓰기를 믿는다"고 요청하면, 과거 주장이 중요한 도메인(컴플라이언스, 의료, 법률)에서는 거부합니다.

출력: 컴포넌트별 파일 하나씩, 그리고 기본 블록, sleep-time 주기, 충돌 해결 정책을 명시하는 `README.md`. 마지막은 "다음에 읽을 것"으로 끝냅니다. 에이전트가 메모리 위의 그래프 추론이 필요하면 레슨 09, 제품이 메모리 연산 위의 OTel 스팬이 필요하면 레슨 23을 가리킵니다.
