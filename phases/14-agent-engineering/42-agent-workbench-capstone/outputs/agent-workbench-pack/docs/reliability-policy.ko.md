# 신뢰성 정책

워크벤치는 업계에서 반복되는 다섯 가지 실패 양상을 흡수합니다:

1. 환각된 행동 — 규칙 집합 + 검증 게이트가 잡습니다.
2. 범위 확산 — 범위 계약의 diff 검사가 잡습니다.
3. 연쇄 에러 — 피드백 기록 + null 종료 코드 진행 거부가 잡습니다.
4. 컨텍스트 상실 — 저장소 메모리가 흡수합니다. 채팅은 단일 진실 공급원이 아닙니다.
5. 도구 오용 — 리뷰어 루브릭의 검증 품질 차원이 잡습니다.

이 정책은 검증 게이트가 강제합니다. 재정의 경로는 서명되고 감사되며, 에이전트가 스스로 재정의할 수 없습니다.
