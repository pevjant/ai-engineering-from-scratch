# 리뷰어 루브릭

다섯 차원, 0에서 2점.

1. 문제 부합 — 이 변경이 말해진 태스크를 해결했는가?
2. 범위 규율 — 편집이 계약 안에 갇혀 있었는가?
3. 가정 — 숨겨진 가정이 기록되어 있는가?
4. 검증 품질 — 수용 검증이 실제로 목표를 증명하는가?
5. 핸드오프 준비도 — 다음 세션이 깔끔하게 이어받을 수 있는가?

총점 7 이상이고 0점이 없으면: 통과. 총점 5~6: 소프트 실패. 5 미만이거나 0점이 하나라도: 하드 실패.
