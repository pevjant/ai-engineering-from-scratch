# 페이즈 14: 에이전트 엔지니어링

> 현대 AI 엔지니어링의 핵심입니다. 제1원리부터 에이전트를 만들어 봅니다.

## GitHub에서 이 페이즈 시작하기

**선수 지식:** 페이즈 11 LLM 엔지니어링과 페이즈 13 도구와 프로토콜.

**첫 번째 레슨:** [에이전트 루프](01-the-agent-loop/)

페이즈 전체가 필요 없을 때는 집중 학습 경로 두 개를 이용할 수 있습니다:

- [에이전트 협업 엔지니어링](../../learning-paths/using-coding-agents.json)은 과제 프레이밍, 저장소 증거, 하네스, 격리, 검증, 리뷰, 오래 남는 피드백을 다룹니다.
- [제품 판단력과 전달](../../learning-paths/shaping-the-build.json)은 성과 결과, 워크플로 발견, 가정, 슬라이스, 명세, 지표, 단계적 출시, 피드백 소유권을 다룹니다.

저장소 루트에서 이 명령을 실행하세요:

```bash
python3 phases/14-agent-engineering/01-the-agent-loop/code/main.py
```

명령, 종료 코드, 생각-행동-관찰(thought-action-observation) 추적, 최종 답변,
턴 수, 그리고 실행을 끝낸 정확한 정지 조건을 기록해 두세요.

[ReWOO와 Plan-and-Execute](02-rewoo-plan-and-execute/)로 계속 진행하세요.
