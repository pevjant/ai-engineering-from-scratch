# Tree of Thoughts와 LATS: 신중한 탐색

> 단일 사고 연쇄(chain-of-thought) 궤적에는 되돌아갈 여지가 없습니다. ToT(Yao 등, 2023)는 추론을 각 노드에 자기 평가가 붙은 트리로 바꿉니다. LATS(Zhou 등, 2024)는 ToT를 ReAct, Reflexion과 함께 몬테카를로 트리 탐색(MCTS) 아래로 통합합니다. Game of 24는 4%(CoT)에서 74%(ToT)로 오르고, LATS는 HumanEval에서 92.7% pass@1을 기록합니다.

**유형:** Build
**언어:** Python (표준 라이브러리)
**선수 지식:** 페이즈 14 · 01 (에이전트 루프), 페이즈 14 · 03 (Reflexion)
**시간:** ~75분

## 학습 목표

- 추론을 탐색으로 바꿔 봅니다. 노드는 "생각", 간선은 "확장", 값은 "얼마나 유망한가"입니다.
- 자기 평가 점수를 갖춘 표준 라이브러리 기반 ToT식 BFS 트리 탐색을 구현합니다.
- 선택/확장/시뮬레이션/역전파 단계를 갖춘 장난감 LATS MCTS 루프로 확장합니다.
- 탐색에 토큰 배수를 치를 가치가 있는 때(Game of 24, 코드 생성)와 단일 궤적으로 충분한 때(간단한 질의응답)를 판단합니다.

## 문제 상황

사고 연쇄는 직선 걷기입니다. 첫 단계가 틀리면 이후 모든 단계가 나쁜 전제 위에서 돕니다. Game of 24(네 개 숫자에 + − × ÷를 써서 24를 만들기)에서 GPT-4 CoT는 4% 정확도에 그칩니다. 모델이 초반에 잘못된 부분식을 골라 만회하지 못합니다.

추론에 필요한 것은 여러 후보를 제안하고, 평가하고, 유망한 것을 고르고, 막다른 길이 보이면 되돌아가는 능력입니다. 그것이 탐색입니다. Tree of Thoughts와 LATS가 바로 그 두 가지 표준 정식화입니다.

## 개념

### Tree of Thoughts (Yao 등, NeurIPS 2023)

각 노드는 하나의 응집된 중간 단계("생각")입니다. 각 노드는 K개의 자식 생각으로 확장될 수 있습니다. LLM이 점수 프롬프트로 각 노드를 스스로 평가합니다. 탐색이 트리를 살펴 봅니다 — BFS, DFS, 또는 빔.

```
                     (루트: "4 6 4 1로 24 만들기")
                    /               |            \
           ("6 - 4 = 2")    ("4 + 1 = 5")    ("4 * 6 = 24")  <- 점수: 높음
              /   \              |                  |
          ...    ...          ...                finish
```

자기 평가가 빠지면 안 되는 기둥입니다. 논문은 세 가지 변형을 보여 줍니다. `sure / likely / impossible` 분류, `1..10` 수치 점수, 후보 간 투표. 세 가지 모두 Game of 24에서 CoT를 크게 이깁니다(GPT-4로 4% → 74%).

### LATS (Zhou 등, ICML 2024)

LATS는 ToT, ReAct, Reflexion을 MCTS 아래로 통합합니다. LLM이 세 가지 역할을 맡습니다:

- **정책(Policy)**: 다음 행동 후보를 제안합니다(ReAct식).
- **가치 함수(Value function)**: 부분 궤적을 채점합니다(ToT식 자기 평가).
- **자기 반성기(Self-reflector)**: 실패하면 자연어 반성문을 쓰고(Reflexion식) 그것으로 미래 롤아웃의 출발점을 다시 심습니다.

환경 피드백(관찰)이 가치 함수에 섞여 들어가므로, 탐색은 모델의 견해만이 아니라 실제 도구 결과를 근거로 움직입니다. 논문 시점 결과: GPT-4로 HumanEval pass@1 92.7%(당시 SOTA), GPT-3.5로 WebShop 평균 75.9(경사 기반 파인튜닝에 근접).

### MCTS, 최소한으로

반복 한 번당 네 단계:

1. **선택(Select)** — UCT(트리용 상한 신뢰 기준)로 루트에서 잎까지 걸어갑니다.
2. **확장(Expand)** — 정책으로 자식 K개를 생성합니다.
3. **시뮬레이션(Simulate)** — 자식 하나에서 정책으로 롤아웃을 돌리고, 가치 함수(또는 환경 보상)로 잎을 채점합니다.
4. **역전파(Backpropagate)** — 경로를 거슬러 올라가며 방문 횟수와 가치 추정치를 갱신합니다.

UCT 공식: `Q(s, a) + c * sqrt(ln N(s) / N(s, a))`. 첫 항은 활용(exploitation)이고, 둘째 항은 탐색(exploration)입니다. `c`는 과제별로 조정하세요.

### 비용의 현실

탐색은 토큰을 폭발시킵니다. Game of 24에서 ToT는 CoT 대비 100~1000배의 토큰을 씁니다. LATS도 비슷합니다. 공짜가 아니므로 탐색은 이럴 때 아껴 쓰세요:

- 단일 궤적으로 명백히 부족한 과제(Game of 24, 복잡한 코드).
- 실제 걸리는 시간보다 정확성이 더 중요한 과제.
- 값싸고 신뢰할 수 있는 가치 함수가 있는 과제(코드의 단위 테스트, 수학의 명시적 목표).

과제에 정답이 하나뿐인데 평가기가 시끄럽다면, 탐색은 종종 상황을 악화시킵니다. "점수 좋은" 틀린 답을 찾아내니까요.

### 2026년의 위상

프로덕션(운영 환경) 에이전트 대부분은 LATS를 돌리지 않습니다. 도구에 근거한 검증(CRITIC, 레슨 05)과 함께 ReAct를 돌립니다. 탐색은 전문 분야에서 등장합니다:

- 테스트를 가치 함수로 쓰는 코딩 에이전트(HumanEval식).
- 여러 질의 경로를 탐색하는 딥 리서치 에이전트.
- LangGraph 서브그래프 안의 계획 중심 워크플로.

AlphaEvolve(레슨 11)는 2025년의 극단 사례입니다. 코드 위의 진화적 탐색, 기계가 검사 가능한 적합도, 프론티어 급 성과(56년 만의 첫 4x4 행렬 곱 개선).

## 만들어 보기

`code/main.py`는 다음을 구현합니다:

- 단순화된 "산술 연산 고르기" 과제 위의 아주 작은 ToT BFS.
- 같은 과제 위의 장난감 LATS MCTS 루프(선택/확장/시뮬레이션/역전파)와 UCT 선택.
- 기호 점수에 자기 평가 점수를 합친 가치 함수.

실행:

```
python3 code/main.py
```

트레이스는 ToT가 BFS로 노드마다 후보 셋을 확장하는 모습과, LATS가 MCTS로 최선의 롤아웃에 수렴하는 모습을 나란히 보여 줍니다. 양쪽의 토큰 수도 출력됩니다.

## 활용하기

LangGraph는 ToT식 탐색을 서브그래프 패턴으로 제공하고, LangChain 팀의 LATS 블로그 글(2024년 5월)이 참조 튜토리얼입니다. LlamaIndex는 `TreeOfThoughts` 에이전트를 제공합니다. 2026년 대부분의 프로덕션 에이전트에서 이 패턴은 `if task_complexity > threshold: use_search()` 게이트 뒤에 있습니다 — 레슨 05의 평가자-최적화자 패턴을 참고하세요.

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|----------------|------------------------|
| Tree of Thoughts | "갈라지는 CoT" | Yao 등 — 자기 평가가 붙은 생각 노드 트리 |
| LATS | "LLM용 MCTS" | Zhou 등 — ToT + ReAct + Reflexion을 MCTS 아래로 통합 |
| UCT | "상한 신뢰 한계" | 활용(Q)과 탐색(ln N / n)의 균형을 잡는 선택 공식 |
| 가치 함수(Value function) | "이 상태가 얼마나 좋은가" | 프롬프트로 얻는 LLM 점수 또는 환경 보상, 역전파로 흘러 들어감 |
| 정책(Policy) | "행동 제안자" | ReAct식 생성기, 다음 생각/행동 후보를 내보냄 |
| 롤아웃(Rollout) | "시뮬레이션된 궤적" | 정책으로 노드에서 잎까지 걷고, 가치로 채점 |
| 역전파(Backpropagate) | "조상 갱신" | 잎의 보상을 경로 위로 밀어 올리며 방문 횟수와 Q를 갱신 |
| 탐색 비용(Search cost) | "토큰 폭발" | Game of 24에서 CoT의 100~1000배, 채택 전에 예산부터 |
