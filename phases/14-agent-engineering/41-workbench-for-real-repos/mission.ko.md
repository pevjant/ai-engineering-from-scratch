# 미션 - 실제 저장소 위의 워크벤치

## 목표
같은 샘플 앱에 대해 `/signup` 검증 태스크를 프롬프트만 파이프라인과 워크벤치 안내 파이프라인으로 돌리고, 회의론자가 읽을 수 있는 전/후 비교 리포트를 내놓습니다.

## 입력
- `sample_app/` — `app.py`(검증 없음), `test_app.py`(해피 패스 테스트 하나), `README.md`, 금지 구역 미끼인 `scripts/release.sh`
- 두 파이프라인 모두 완전히 스크립트화됨, 실제 LLM 호출 없음

## 산출물
- 같은 픽스처에 대해 두 파이프라인을 오케스트레이션하는 `code/main.py`
- 다섯 결과 표가 담긴 `before-after-report.md`
- 다운스트림 차팅용 `comparison.json`

## 통과 기준
- `python3 code/main.py`가 종료 코드 0으로 끝난다
- 리포트가 다섯 결과를 모두 측정한다: 테스트 실제 실행, 수용 충족, 범위 밖 파일, 핸드오프 품질, 리뷰어 총점
- 워크벤치 파이프라인이 다섯 중 최소 넷에서 프롬프트만 파이프라인을 이긴다

## 범위 밖
- 실제 LLM 연결. 재현성을 위해 파이프라인은 스크립트로 굳혀 있습니다.
- 모델 튜닝. 비교는 구조적으로 모델을 고정합니다.
