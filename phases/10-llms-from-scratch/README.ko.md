# 페이즈 10: LLM 처음부터 만들기

> 대규모 언어 모델을 직접 만들고, 학습시키고, 이해합니다.

## GitHub에서 이 페이즈 시작하기

**선수 지식:** 페이즈 5 NLP 기초. 모델을 만드는 레슨들 전에는 페이즈 7
트랜스포머를 꼭 들을 것을 권합니다.

**첫 번째 레슨:** [토크나이저](01-tokenizers/)

저장소 루트에서 다음 명령을 실행하세요:

```bash
python3 phases/10-llms-from-scratch/01-tokenizers/code/main.py
```

명령줄 출력, 종료 코드, 인코딩/디코딩 왕복 결과, 학습된 병합(merge) 수,
압축률을 기록해 두세요. `tiktoken`은 선택 사항인 비교 대상입니다.

들여다본 뒤, [토크나이저 직접 만들기](02-building-a-tokenizer/)로 계속
진행하세요.
