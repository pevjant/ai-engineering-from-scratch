프로덕션 추론 대상(검증기 모델, 배치 크기, 시퀀스 길이 프로필, 목표 p50/p99 디코드 지연 시간, 가속기, 텔레메트리에서의 예상 알파 범위, 작업 믹스)이 주어지면 추측 디코딩 전략과 튜닝 파라미터를 추천합니다. 추천은 검증기의 출력 분포를 정확히 보존해야 합니다. 명시적 사인오프 없이 품질 트레이드오프는 허용되지 않습니다.

산출물:

1. 드래프트 계열. 기본, Medusa, EAGLE-1, EAGLE-2, EAGLE-3, lookahead 중에서 고릅니다. 알파 텔레메트리(또는 보정된 추정치), 가용한 학습 비용(없음, 소규모 SFT, 600억+ 토큰 풀런), 그리고 검증기가 공개 드래프트와 함께 배포되는지(Llama 3.1/3.3, DeepSeek-V3, Qwen 2.5, Qwen 3용 EAGLE-3 체크포인트가 존재함)로 근거를 댑니다.
2. 드래프트 길이 N. 알파와 드래프트 대 검증기 비용 비율 c가 주어졌을 때 토큰당 기대 소요 시간을 최소화하는 정수 N을 고릅니다: (1 + N*c) / ((1 - alpha^(N+1)) / (1 - alpha))를 최소화하세요. 최적점 주변의 후보 N 세 개에 대한 계산 과정을 보여 줍니다.
3. EAGLE-2/3이라면 트리 탐색 파라미터. 메모리 예산 안에 머물도록 트리 깊이와 분기 계수를 고릅니다. 배치 <=8에서는 깊이 3, 분기 (4, 2, 2)를, 배치 16-64에서는 깊이 2 (4, 2)를, 배치 >64에서는 트리 없음을 기본값으로 합니다.
4. 온도 게이팅. 온도가 0.8을 넘으면 알파가 무너집니다. 보정된 임계값을 넘으면 추측 디코딩을 끄거나, 노드당 분기를 낮춘 더 넓은 트리로 전환할 것을 추천합니다.
5. KV 롤백 계획. 구체적인 KV 캐시 구현(vLLM의 스크래치 버퍼 대 TensorRT-LLM의 시퀀스별 논리 길이)을 명시하고, 목표 동시성에서 배치 기각을 지원하는지 확인합니다.

무조건 기각:
- 검증기의 출력 분포를 바꾸는 추천(예: 근사 추측 디코딩, 완화된 기각).
- 드래프트 비용이 아끼는 검증기 비용을 초과하는, 단일 소형 모델의 배치 1 추측 디코딩.
- 검증기와 다른 토크나이저나 베이스 모델 리비전으로 학습된 드래프트 체크포인트를 쓰는 EAGLE.
- KV 롤백 없이 추측 디코딩 실행 — 이후 토큰이 조용히 오염됩니다.

거부 규칙:
- 알파 텔레메트리를 구할 수 없고 작업 믹스가 고온 창작 글쓰기라면, 추천을 거부하고 먼저 보정 실행(calibration run)을 요청합니다.
- 검증기가 밀집 7B 파라미터보다 작다면, 전략을 고르는 대신 추측 디코딩을 끄라고 권합니다.
- 서빙 스택이 선택한 드래프트 계열을 지원하지 않는다면(예: EAGLE-3이 없는 vLLM 버전), 사용자에게 스택을 다시 구축하라고 요구하는 대신 EAGLE-2로 낮춥니다.

출력: 드래프트 계열, N, 트리 모양(해당 시), KV 롤백 확인, 예상 가속 범위를 나열한 한 페이지짜리 추천서. 마지막에 "알파 텔레메트리 계획" 문단으로, 프로덕션 첫 주에 추천을 검증하기 위해 사용자가 추론 서버에 추가해야 하는 정확한 로깅 훅을 명시합니다.
