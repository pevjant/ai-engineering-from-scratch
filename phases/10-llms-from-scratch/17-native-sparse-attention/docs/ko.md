# 네이티브 희소 어텐션(DeepSeek NSA)

> 64k 토큰에서는 어텐션이 디코드 지연 시간의 70-80%를 잡아먹습니다. 모든 오픈 모델 연구실이 이것을 고칠 계획을 갖고 있죠. 그중 자리를 잡은 것이 DeepSeek의 NSA(ACL 2025 최우수 논문)입니다. 압축된 거친(coarse) 토큰, 선별적으로 보존한 세밀한(fine-grained) 토큰, 로컬 컨텍스트를 위한 슬라이딩 윈도우라는 세 개의 병렬 어텐션 가지를 학습된 게이트로 결합합니다. 하드웨어 정렬(커널 친화적)이고, 네이티브하게 학습 가능하며(추론에 뒤늦게 붙이는 것이 아니라 사전 학습에서 작동), 64k 디코드에서 FlashAttention보다 빠르게 돌면서 완전 어텐션 품질에 필적하거나 능가합니다. 이 레슨은 세 가지를 엔드투엔드로 만들고 희소성이 왜 엔드투엔드 미분 가능한지 보여 줍니다.

**유형:** 빌드
**언어:** Python (표준 라이브러리)
**선수 지식:** 페이즈 7 · 12 (KV 캐시, flash-attention), 페이즈 7 · 15 (어텐션 변형), 페이즈 10 · 16 (차등 어텐션)
**시간:** 약 60분

## 학습 목표

- NSA의 세 가지 어텐션 가지와 각각이 무엇을 포착하는지 서술합니다
- 기존 희소 어텐션 방법이 추론 전용이었던 것과 달리 NSA가 "네이티브하게 학습 가능"한 이유를 설명합니다
- 64k 컨텍스트에서 압축 블록 크기와 선택 top-k의 함수로서 NSA 대 완전 어텐션의 연산 절감량을 계산합니다
- 짧은 합성 시퀀스에서 표준 라이브러리 Python으로 세 가지의 결합을 구현하고 게이트 가중치가 제대로 작동하는지 검증합니다

## 문제

시퀀스 길이 N에서 완전 어텐션은 시간 `O(N^2)`, 레이어당 KV 캐시 `O(N)`이 듭니다. 64k 토큰에서는 연산과 메모리 대역폭 수치가 재앙 수준입니다. NSA 논문의 이론적 추정치: 64k에서 전체 디코드 지연 시간의 70-80%가 어텐션입니다. 그 아래의 모든 것, TTFT, 초당 토큰 수, 백만 토큰당 비용이 어텐션 비용이 지배합니다.

희소 어텐션이 뻔한 답입니다. 기존 시도는 두 부류로 나뉩니다. 고정 패턴 희소성(슬라이딩 윈도우, 스트라이드, 블록 로컬)은 정보를 버리므로 원거리 회상 과제에서 실패합니다. 추론 시점 희소성(KV 캐시 프루닝, H2O, StreamingLLM)은 밀집 어텐션으로 사전 학습된 모델에 나중에 적용하는 것이라, 모델이 희소 패턴을 통해 정보를 보내도록 요구받은 적이 없기 때문에 잠재 가속의 일부만 회수합니다.

Native Sparse Attention(Yuan et al., DeepSeek + PKU + UW, ACL 2025 최우수 논문, arXiv:2502.11089)는 둘 다 합니다. 모델이 사전 학습 중에 배우는 희소 패턴을, 추론에서 실제로 연산 절감을 전달하는 커널 정렬 알고리즘으로 구현한 것이죠. 2년 뒤에는 NSA나 그 직계 후손이 모든 최전선 긴 컨텍스트 모델의 기본 어텐션이 되어 있을 것입니다.

## 개념

### 세 개의 병렬 가지

각 질의마다 NSA는 KV 캐시의 서로 다른 세 가지 시각에 대해 어텐션을 세 번 돌립니다:

1. **압축 가지.** 토큰을 크기 `l`(보통 32 또는 64)의 블록으로 묶습니다. 각 블록은 작은 학습된 MLP를 통해 요약 토큰 하나로 압축됩니다. 질의는 이 압축 토큰들에 어텐션하여 전체 시퀀스의 거친 시각을 얻습니다.

2. **선택 가지.** 압축 가지의 어텐션 점수를 이용해 현재 질의와 가장 관련 높은 상위 k개 블록을 찾습니다. 그 블록들의 세밀한(압축되지 않은) 토큰을 읽어 질의가 전부에 어텐션합니다. 압축 가지 어텐션을 선택의 라우팅 신호로 생각하면 됩니다.

3. **슬라이딩 윈도우 가지.** 질의는 로컬 컨텍스트를 위해 가장 최근의 `W`개 토큰(보통 512)에 어텐션합니다. 이 가지는 다른 둘이 놓칠 수 있는 구조가 짙은 짧은 범위 패턴(구문, 국소 공지시)을 포착합니다.

세 가지 출력은 학습된 위치별 게이트로 결합됩니다:

```
out = g_cmp * out_cmp + g_sel * out_sel + g_win * out_win
```

`g_cmp, g_sel, g_win`은 질의의 작은 MLP가 내놓는 게이트 가중치입니다. 합이 1일 필요가 없습니다. 가지별로 독립적으로 가중할 수 있습니다.

### "네이티브하게 학습 가능"한 이유

선택 단계(상위 k개 블록)는 이산적입니다. 이산 연산은 그레이디언트 흐름을 끊습니다. 기존 희소 어텐션 연구는 선택을 통한 역전파를 건너뛰거나(학습이 제한됩니다) 추론에서 진짜 희소성을 주지 못하는 연속 완화를 썼습니다.

NSA는 이것을 비껴갑니다. 압축 가지 어텐션은 그 자체로 전체 시퀀스에 대한 미분 가능한 거친 어텐션입니다. top-k 연산은 어떤 세밀한 블록을 읽어 들일지 고르는 데 압축 가지의 상위 어텐션 점수를 재활용할 뿐입니다. 그레이디언트는 압축 가지 점수(압축 출력과 선택 로직 둘 다에 영향을 줍니다)로 흐르고, 선택된 블록이 최종 출력에 기여하는 부분 역시 미분 가능합니다. 미분 불가능한 `top_k` 연산은 순전파 계산 그래프에서 아무 일도 하지 않습니다(no-op). 메모리에서 어떤 블록을 읽을지만 제어합니다.

NSA를 사전 학습에서 엔드투엔드로 쓸 수 있는 이유가 바로 이것입니다. 모델은 세 가지를 통해 정보를 함께 보내는 법을 배우고, 추론에서 약속된 가속을 실제로 전달하는 희소 패턴을 만들어 냅니다.

### 하드웨어 정렬 커널

NSA의 커널은 현대 GPU 메모리 계층에 맞춰 설계되었습니다. 커널은 쿼리를 GQA 그룹별로 읽고(바깥 루프), 그룹마다 대응하는 희소 KV 블록을 가져와(안쪽 루프) SRAM 위에서 어텐션을 돌립니다. 각 쿼리 그룹이 같은 선택된 블록을 보기 때문에(선택은 쿼리 헤드 단위가 아니라 쿼리 그룹 단위) KV 읽기 비용이 그룹 전체에 분할상환됩니다. 산술 강도는 높게 유지됩니다.

논문은 Triton 커널이 64k 디코드에서 FlashAttention보다 9배 빠르게 돌며, 가속 비율이 시퀀스 길이에 따라 커진다고 보고합니다. 순전파와 역전파 커널이 모두 제공됩니다.

### 연산 예산

시퀀스 길이를 `N`, 압축 블록 크기를 `l`, top-k 선택 수를 `k`, 슬라이딩 윈도우를 `w`, 선택된 블록 크기를 `b`(보통 `l`과 같음)라 하겠습니다.

- 압축 가지: 질의당 `O(N/l)`개 키, 전체로는 `O(N * N / l)`.
- 선택 가지: 질의당 `O(k * b)`개 키, 전체로는 `O(N * k * b)`.
- 슬라이딩 가지: 질의당 `O(w)`개 키, 전체로는 `O(N * w)`.

총계: `O(N * (N/l + k*b + w))`.

`N = 64k, l = 64, k = 16, b = 64, w = 512`일 때: 질의당 비용은 `1000 + 1024 + 512 = 2536 keys`입니다. 완전 어텐션은 `64000 keys`입니다. 연산 25배 절감입니다.

`N = 128k, l = 64, k = 16, b = 64, w = 512`일 때: 질의당 비용은 `2000 + 1024 + 512 = 3536 keys`입니다. 완전 어텐션은 `128000 keys`입니다. 36배 절감. 이득은 시퀀스 길이에 따라 커지는데, 그것이 바로 요점입니다.

## 만들어 보기

`code/main.py`는 짧은 합성 시퀀스 위에 세 가지를 구현하고 다음을 보여 줍니다:

- 압축 MLP(교육적 명료함을 위해 단순 평균 풀링 베이스라인을 씁니다. 실제 NSA는 학습된 MLP를 씁니다).
- 압축 가지 점수가 이끄는 top-k 블록 선택.
- 마지막 `w`개 토큰에 대한 슬라이딩 윈도우 어텐션.
- 게이트 결합.
- 완전 어텐션과 비교한 연산량 출력.

### 단계 1: 토큰을 블록으로 압축

```python
def compress(K, l):
    n = len(K)
    n_blocks = (n + l - 1) // l
    out = []
    for b in range(n_blocks):
        start, end = b * l, min((b + 1) * l, n)
        block = K[start:end]
        summary = [sum(row[d] for row in block) / len(block) for d in range(len(K[0]))]
        out.append(summary)
    return out
```

### 단계 2: 압축 가지 어텐션

질의가 압축된 키에 대해 소프트맥스 어텐션을 돌립니다. 압축 가지 점수는 top-k 선택의 신호를 겸합니다.

### 단계 3: top-k 블록 선택

점수가 가장 높은 압축 블록 `k`개의 인덱스를 고릅니다. 그 블록들에서 원래의 압축되지 않은 토큰을 읽어 그 위에서 어텐션을 돌립니다.

### 단계 4: 슬라이딩 윈도우 어텐션

마지막 `w`개 토큰을 가져와 그들에 대해 표준 어텐션을 돌립니다.

### 단계 5: 게이트 + 결합

질의 위의 작은 MLP가 게이트 가중치 세 개를 만듭니다. 최종 출력은 세 가지 출력의 가중 합입니다.

### 단계 6: 연산량 세기

가지별로 질의가 어텐션하는 키 수와 총계를 출력합니다. `N`(완전 어텐션)과 비교합니다. `l = 32, k = 4, w = 128`인 1024토큰 합성 데이터에서 NSA는 질의당 `32 + 128 + 128 = 288`개 키를 보는 반면 완전 어텐션은 1024개입니다. 3.5배 적습니다.

## 사용해 보기

NSA는 DeepSeek 자체의 긴 컨텍스트 사전 학습 파이프라인에 실려 있습니다. 2026년 4월 기준 공개 추론 스택의 통합 현황:

- **DeepSeek 내부**: 네이티브. 공개된 가중치는 NSA나 그 후속인 DSA(Deepseek Sparse Attention)를 사용합니다.
- **vLLM**: DeepSeek-V3.x 가중치용 실험적 NSA 지원이 개발 중입니다.
- **SGLang**: NSA 벤치마크가 공개됨. 프로덕션 경로는 vLLM을 따릅니다.
- **llama.cpp / CPU**: 미지원. CPU 처리량 수준에서는 커널 분해의 오버헤드가 값어치를 못 합니다.

NSA를 쓰면 좋은 경우:

- 진지한 컴퓨트 예산으로 64k 이상 컨텍스트를 겨냥하는 사전 학습 또는 추가 학습 실행.
- DeepSeek 자체의 긴 컨텍스트 체크포인트 추론. 가중치가 NSA 네이티브입니다.

쓰지 말아야 할 때:

- 기존 밀집 어텐션 사전 학습 모델을 서빙할 때. 추가 학습 없이 NSA를 나중에 붙일 수는 없습니다.
- 16k 미만 컨텍스트. 세 가지 오버헤드가 절감분을 압도합니다.
- 배치-1 대화형 채팅. 지연 시간 민감 디코드에 이득이지만, 긴 컨텍스트에서만입니다.

## 연습 문제

1. 1024토큰 합성 데이터로 `code/main.py`를 실행해 보세요. 세 가지 프리셋에 걸쳐 `(l, k, w)`를 쓸어 보며 연산량을 출력합니다. 바늘 건초 더미 테스트에서 완전 어텐션 대비 95% 회상을 유지하면서 질의당 키 수가 가장 낮은 프리셋을 찾아 보세요.

2. 평균 풀링 압축기를 작은 학습 MLP(2계층, 은닉 32)로 바꿔 보세요. 신호가 블록의 평균인 합성 과제로 학습시킵니다. 홀드아웃 데이터에서 평균 풀링 베이스라인 대비 퍼플렉시티 격차를 측정합니다.

3. 게이트 MLP를 구현해 보세요. 질의를 입력받아 스칼라 세 개를 출력합니다. 게이트가 합리적으로 행동함을 보여 주세요. 무작위 질의에서는 거의 균등한 가중치, 질의가 아득히 뒤쪽 블록을 가리킬 때는 선택 가지에 무거운 가중치.

4. 128k 컨텍스트에서 NSA를 쓰는 70B 모델의 KV 캐시 메모리 예산을 계산해 보세요. KV 헤드는 8, 헤드 차원 128, BF16입니다. 완전 어텐션 및 MLA와 비교합니다(페이즈 10 · 14에서 MLA 수치를 다뤘습니다). NSA의 세밀한 가지 KV 캐시가 완전 어텐션과 같아지는 시퀀스 길이를 찾아 보세요.

5. NSA 논문(arXiv:2502.11089)의 4절을 읽고, 별도의 라우팅 점수를 계산하는 대신 압축 가지의 어텐션 점수를 top-k 선택에 재활용하는 이유를 세 문장으로 설명합니다. 답을 그레이디언트 흐름과 묶어 보세요.

## 핵심 용어

| 용어 | 사람들이 말하는 방식 | 실제 의미 |
|------|----------------|------------------------|
| 압축 가지 | "거친 시각" | 블록 평균 키에 대한 어텐션. 질의당 O(N/l)개 키로 전역 컨텍스트를 제공 |
| 선택 가지 | "상위 k개 블록" | 압축 가지 점수가 가장 높은 `k`개 블록에 대한 세밀한 어텐션 |
| 슬라이딩 윈도우 | "로컬 컨텍스트" | 짧은 범위 패턴을 위한 마지막 `W`개 토큰 어텐션 |
| 네이티브 학습 가능성 | "희소성을 켠 채 사전 학습" | 희소 패턴을 추론에 뒤늦게 붙이는 게 아니라 사전 학습 중에 학습함 |
| 압축 블록 크기 l | "거친 시각의 그룹 크기" | 몇 개 토큰을 요약 하나로 합치는지. 보통 32-64 |
| Top-k | "남길 블록 수" | 압축되지 않은 토큰을 읽어 올 압축 블록 수. 보통 16 |
| 슬라이딩 윈도우 W | "로컬 어텐션 반경" | 보통 512. 짧으면 국소 일관성이 상하고, 길면 연산이 낭비됨 |
| 가지 게이트 | "셋을 섞는 법" | 세 가지의 기여에 가중치를 주는 위치별 MLP 출력 |
| 하드웨어 정렬 | "커널 친화적 희소성" | 실제 GPU 커널이 이론적 가속을 달성하도록 고른 희소 패턴 |
| DSA | "NSA의 후속" | Deepseek Sparse Attention. DeepSeek 계보에서 NSA를 이은 아키텍처 |
