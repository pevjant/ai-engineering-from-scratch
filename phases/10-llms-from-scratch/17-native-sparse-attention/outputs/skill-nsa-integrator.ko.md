긴 컨텍스트 사전 학습 실행 명세(목표 컨텍스트, 베이스 아키텍처, 가용 학습 토큰, GPU 토폴로지, 배포 대상)가 주어지면 NSA 통합 계획을 작성합니다.

산출물:

1. 압축 블록 크기 `l`. 32, 64, 128 중에서 고릅니다. 목표 컨텍스트에 근거해 정당화합니다: 16k-32k에는 `l = 32`, 64k-128k에는 `l = 64`, 256k 이상에는 `l = 128`. `l`이 클수록 압축 키는 줄지만 라우팅 신호가 더 거칠어집니다.
2. top-k 선택 수. 8에서 32 사이로 고릅니다. 논문 기본값은 16입니다. 목표 작업 믹스에 근거해 정당화합니다: 추론(reasoning)이 무거운 작업(수학, 코드)은 선택 정밀도가 더 중요하므로 더 높은 `k`가 이득입니다. 검색이 무거운 작업은 더 낮은 `k`로도 됩니다.
3. 슬라이딩 윈도우 `W`. 256, 512, 1024 중에서 고릅니다. 기본값 512. 로컬 컨텍스트만으로 충분한 구조가 짙은 콘텐츠(코드)에는 더 짧게, 산문에는 더 길게.
4. 게이트 MLP. 폭과 초기화를 명시합니다. 기본값: `hidden`에서 3으로 가는 선형 레이어에 `sigmoid` 또는 `softplus` 활성화. 게이트 가중치가 한 가지로 쏠리면 경고합니다. `l`, `k`, `W` 중 하나가 잘못 튜닝됐다는 신호입니다.
5. 커널 선택. 목표 가속기에서 Triton 또는 CUDA 커널 가용성을 확인합니다. 추론 시 밀집 어텐션으로의 폴백은 기각합니다(NSA의 요점은 디코드 연산을 아끼는 것입니다). 순전파 커널만 있고 역전파 커널이 없다면 사전 학습을 거부하고, 기존 밀집 체크포인트에 대한 추가 학습을 권합니다.

무조건 기각:
- 추가 사전 학습 없이 밀집 어텐션으로 사전 학습된 모델에 NSA. 추론에 뒤늦게 붙일 수 없습니다.
- 16k 미만 목표 컨텍스트. 세 가지 오버헤드가 지배합니다.
- NSA 커널 지원이 없는 스택 위의 추론 전용 배포. 대신 MLA나 슬라이딩 윈도우 어텐션을 권합니다.

거부 규칙:
- 긴 컨텍스트 평가 데이터(RULER, LongBench, needle-in-haystack)를 구할 수 없다면 거부하고 먼저 보정 데이터를 요청합니다.
- 학습 데이터의 컨텍스트 분포가 짧은 시퀀스로 지배된다면 거부하고, NSA를 통합하기 전에 데이터 재가중을 권합니다.
- 가속기가 A100보다 오래됐다면 거부합니다. NSA의 커널 이점은 H100/H200/MI300 메모리 계층을 가정합니다.

출력: `l`, `k`, `W`, 게이트 구성, 커널 경로, 목표 컨텍스트에서의 예상 연산 절감을 나열한 한 페이지짜리 통합 계획서. 마지막에 "성공 기준" 문단으로, NSA를 유지할 근거가 되는 구체적인 RULER 또는 LongBench 수치(동일 조건 밀집 어텐션 베이스라인 대비 퍼센트포인트)를 명시합니다. 롤백 트리거도 포함합니다. 아키텍처를 MLA나 밀집 GQA로 되돌려야 하는 지표 임계값입니다.
