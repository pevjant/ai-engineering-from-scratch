# 에이전트 경제, 토큰 인센티브, 평판

> 장기적으로 자율적으로 일하는 에이전트(METR의 1시간 → 8시간 작업 곡선)에게는 경제적 자율성이 필요합니다. 떠오르는 **5계층 스택**은 이렇습니다: **DePIN**(물리적 컴퓨팅) → **신원(Identity)**(W3C DID + 평판 자본) → **인지(Cognition)**(RAG + MCP) → **정산(Settlement)**(계정 추상화) → **거버넌스**(에이전틱 DAO). 프로덕션(운영 환경)에서 돌아가는 에이전트 인센티브 네트워크로는 **Bittensor**(TAO 서브넷이 태스크 특화 모델에 보상 지급), **Fetch.ai / ASI Alliance**(ASI-1 Mini LLM + FET 토큰), **Gonka**(트랜스포머 기반 PoW로 컴퓨팅을 생산적인 AI 태스크에 재배분)가 있습니다. 학계 연구로는 AAMAS 2025의 탈중앙화 LaMAS가 **샤플리 값(Shapley-value) 크레딧 배분**으로 기여한 에이전트들에게 공정하게 보상을 돌리고, Google Research의 "Mechanism design for large language models"는 단조 집합(monotone aggregation) 조건에서 2가격 지불 방식의 **토큰 경매**를 제안합니다. 이 레슨에서는 최소한의 에이전트 마켓플레이스를 만들고, 멀티 에이전트 파이프라인에 샤플리 값 크레딧 배분을 적용하고, 2가격 토큰 경매를 실행해 보며 게임 이론 장치를 구체적으로 체득합니다.

**유형:** Learn
**언어:** Python (표준 라이브러리)
**선수 지식:** 페이즈 16 · 16 (Negotiation and Bargaining), 페이즈 16 · 09 (Parallel Swarm Networks)
**시간:** 약 75분

## 문제

에이전트들이 함께 가치를 만들어 내는데 각자 개별적으로 보상받아야 한다면, 멀티 에이전트 시스템은 복잡해집니다. 고전적인 방식들 — 균등 분배, 마지막 기여자가 전부 가져가기 — 은 불공평하거나 허점을 파고들 수 있습니다. 샤플리 값 기반 연합 보상은 구조적으로 공정하지만 계산 비용이 큽니다. 2025~2026년 문헌은 실용적인 근사 기법들을 밀어 주고 있습니다: 샤플리 샘플링, 단조 집합 경매, 그리고 검증된 기여에서 쌓이는 온체인 평판이 그것입니다.

크레딧 배분을 넘어, 이 분야는 진짜 경제적 에이전트로 나아가고 있습니다. Bittensor TAO는 서브넷 특화 모델을 파인튜닝하는 컴퓨팅 채굴에 보상을 주고, Fetch.ai/ASI는 ASI-1 Mini LLM 사용에 FET 토큰으로 보상하며, Gonka는 트랜스포머 작업 증명(PoW)을 생산적인 AI 태스크 쪽으로 재배분합니다. 자율적으로 거래하는 에이전트는 이미 존재합니다. 문제는 인센티브를 어떻게 정렬하느냐입니다.

이 레슨은 에이전트 경제를 구체적인 문제군 — 크레딧 배분, 메커니즘 설계, 평판 — 으로 다루면서, 개념이 확실히 남도록 최소한의 수학으로 각각을 구현해 봅니다.

## 개념

### 5계층 에이전트 경제 스택

1. **DePIN (물리적 컴퓨팅).** GPU, 스토리지, 대역폭을 빌려 주는 탈중앙화 인프라입니다. Bittensor 서브넷, Render Network, Akash. 에이전트 고유의 계층은 아니고, 에이전트가 사용하는 쪽입니다.
2. **신원(Identity).** W3C 탈중앙화 식별자(DID)는 어떤 플랫폼에도 종속되지 않는 에이전트 고유의 영구 ID를 부여합니다. 평판은 DID에 쌓입니다. Agent Network Protocol(ANP)은 DID를 탐색 계층으로 사용합니다.
3. **인지(Cognition).** 에이전트의 추론 루프: LLM + RAG + MCP. 다른 페이즈들이 만드는 바로 그것입니다.
4. **정산(Settlement).** 계정 추상화(ERC-4337)는 에이전트가 ETH를 직접 들고 있지 않아도 자기 잔고에서 가스비를 낼 수 있게 합니다. 에이전트는 서비스, 다른 에이전트, 컴퓨팅에 지불할 수 있습니다.
5. **거버넌스.** 에이전틱 DAO: 사람 *그리고* 에이전트가 프로토콜 변경 사항에 투표하는 거버넌스 구조이며, 투표권은 평판에 연동됩니다.

모든 프로덕션 시스템이 다섯 계층을 다 쓰는 것은 아닙니다. Bittensor는 1, 2와 3·4를 일부 사용하고 5는 사용하지 않습니다. OpenAI 에이전트는 3을 제외하면 어떤 것도 사용하지 않습니다. 이 스택은 참고용 지도이지 필수 사항이 아닙니다.

### Bittensor, Fetch.ai, Gonka — 실제로 돌아가는 것들

**Bittensor (TAO).** 서브넷은 특화된 태스크들입니다(언어 모델링, 이미지 생성, 예측). 마이너가 모델 출력을 제출하면, 밸리데이터가 순위를 매기고 스테이크 가중 평가 점수에 따라 TAO 보상이 분배됩니다. 서브넷마다 자체 평가 기준이 있습니다. 경제학적 교훈: 사용된 컴퓨팅이 아니라 태스크별 출력 품질에 지불하라는 것입니다.

**Fetch.ai / ASI Alliance.** ASI-1 Mini LLM이 Fetch.ai 네트워크에서 실행되고, 사용자는 추론에 FET 토큰을 지불합니다. "에이전트가 대등한 주체(peer)"라는 서사가 더 강한 곳입니다. Fetch 위의 에이전트는 다른 에이전트에게 태스크를 맡기고 FET로 지불할 수 있습니다.

**Gonka.** 트랜스포머 작업 증명: "일(work)"이란 트랜스포머의 순전파(forward pass)입니다. 마이너는 정답이 알려진(학습 데이터에서 온) 추론 태스크를 실행해서 보상을 받습니다. 해시 기반 PoW가 아니라 자원을 생산적으로 쓰는 PoW입니다.

세 가지 모두 2026년 4월 기준 프로덕션 등급입니다. 보상 분배 방식은 서로 다릅니다. Bittensor는 서브넷 밸리데이터 기준 품질에 보상하고, Fetch는 지불하는 사용자가 측정한 실용성에 보상하며, Gonka는 검증 가능한 추론 작업에 보상합니다.

### 샤플리 값 크레딧 배분

에이전트 셋이 태스크에 협업했습니다. 출력 점수는 0.8입니다. 누가 얼마나 기여했을까요?

샤플리 값: 효율성, 대칭성, 선형성, 무기여(null) 네 가지 공리를 만족하는 유일한 크레딧 배분입니다. 에이전트 `i`에 대해:

```
shapley(i) = (1/N!) * sum over all orderings O of (v(S_i_O ∪ {i}) - v(S_i_O))
```

여기서 `S_i_O`는 순서 `O`에서 `i`보다 앞선 에이전트들의 집합입니다. 실전에서는: 모든 순열을 나열하고, 각 순열에서 각 에이전트의 한계 기여를 기록한 뒤, 평균을 냅니다.

에이전트가 N=3이면 순열은 6개입니다. N=10이면 362만 개 — 그래서 실전에서는 나열 대신 순서를 샘플링합니다.

### 집계를 위한 2가격 경매

Google Research("Mechanism design for large language models")는 LLM 출력을 집계하기 위한 2가격(second-price) 토큰 경매를 제안합니다. 구조: N명의 에이전트가 각자 완성(completion)을 제안하고, 각자 선택될 경우의 개인 가치를 갖고 있습니다. 경매 주관자는 가장 높은 가치의 제안을 뽑되 *두 번째로 높은* 가치를 지불합니다. 단조 집합 조건(가치가 어떤 제안이 선택됐는지에만 의존하고 입찰 수에는 의존하지 않음)에서 이 메커니즘은 진실한(truthful) — 에이전트들이 자신의 진짜 가치를 입찰하게 됩니다.

LLM 시스템에서 중요한 이유: 완성 태스크를 가격이 서로 다른 여러 에이전트에게 외주 줄 수 있습니다. 경매가 최고 제안을 골라 공정하게 지불하고, 에이전트들에게 허위 보고를 할 유인이 생기지 않습니다.

### 평판 자본

DID에 묶인 평판 점수는 검증된 기여에서 쌓입니다. 간단한 갱신 규칙:

```
rep(i, t+1) = alpha * rep(i, t) + (1 - alpha) * contribution_quality(i, t)
```

감쇠 계수 `alpha`는 1에 가깝게 둡니다. 평판은:

- 라우팅 결정에 읽는 비용이 쌉니다("어려운 태스크는 평판 높은 에이전트에게 보낸다").
- 위조 비용이 큽니다(시간이 지나며 쌓이고, DID에 묶여 있습니다).
- 삭감(slashing)할 수 있습니다: 검증에 실패한 기여는 점수를 깎습니다.

### AAMAS 2025 탈중앙화 LaMAS

LaMAS 제안(AAMAS 2025)은 DID 신원, 샤플리 값 크레딧 배분, 간단한 경매 메커니즘을 결합합니다. 핵심 주장: 크레딧 배분 단계를 탈중앙화하면 시스템이 감사 가능해지고 단일 지점 조작에 면역이 된다는 것입니다.

### 경제학이 무너지는 지점

- **가격 오라클 조작.** 크레딧 함수를 속일 수 있다면, 에이전트들은 반드시 속입니다. 모든 메커니즘에는 적대적 테스트가 필요합니다.
- **시빌(Sybil) 공격.** 한 운영자가 가짜 에이전트 N개를 만들어 자기 기여를 부풀립니다. DID는 이를 늦출 뿐 막지는 못하고, 평판의 위조 비용이 완화책입니다.
- **검증 비용.** 크레딧 배분은 검증기만큼 공정합니다. 검증이 싸면(작은 LLM) 속일 수 있고, 비싸면(사람 패널) 확장되지 않습니다.
- **규제 부담.** 에이전트 경제는 금융 규제와 겹칩니다. 2026년 현재 Bittensor, Fetch, Gonka 모두 일부 관할권에서 법적 회색 지대에 있습니다.

### 에이전트 경제가 성립하는 조건

- **이질적인 운영자들이 있는 열린 네트워크.** 한 팀이 모든 에이전트를 통제하지 않는 환경.
- **검증 가능한 출력.** 검증이 없으면 크레딧 배분은 추측에 불과합니다.
- **장기 워크플로.** 일회성 태스크는 평판 축적의 이득이 없습니다.
- **당신의 관할권에서 토큰 결제가 법적으로 가능할 때.**

폐쇄적인 기업 내부 시스템에서는 경제학이 더 단순한 할당 방식에 자리를 내어 줍니다(관리자가 업무를 배정하고, 지표는 내부용). 경제학 문헌은 대체로 열린 네트워크에 적용됩니다.

## 직접 만들기

`code/main.py`는 다음을 구현합니다:

- `shapley(value_fn, agents)` — 작은 N에 대해 나열 방식으로 정확한 샤플리 값을 계산합니다.
- `second_price_auction(bids)` — 진실한 메커니즘; 낙찰자는 두 번째로 높은 입찰가를 지불합니다.
- `Reputation` — 지수 감쇠와 삭감(slashing) 기능이 있는 DID 기반 평판.
- 데모 1: 세 에이전트가 협업하고, 정확한 샤플리 값이 크레딧을 배분합니다.
- 데모 2: 다섯 에이전트가 태스크 슬롯에 입찰하고, 2가격 경매가 낙찰자와 지불액을 정합니다.
- 데모 3: 이질적인 평판을 가진 에이전트들에게 100회 태스크를 배정합니다. 평판 가중 라우팅이 무작위보다 우수합니다.

실행:

```
python3 code/main.py
```

예상 출력: 에이전트별 샤플리 값; 진실 입찰 균형을 보여 주는 경매 결과; 워밍업 이후 평판 가중 라우팅이 무작위 대비 10~20% 품질 향상을 보이는 결과.

## 출시하기

2026년에 에이전트 경제를 운영한다면:

- **토큰이 아니라 평판으로 시작하세요.** 평판은 구현 비용이 낮고 그것만으로도 가치가 있습니다. 토큰은 법적·경제적 복잡성을 더합니다.
- **보상하기 전에 검증하세요.** 독립적인 검증 단계 없이 크레딧을 지급하지 마세요. 자기 보고식 품질은 시빌 게임을 부릅니다.
- **샤플리 정확 계산이 아니라 샤플리 샘플링을 하세요.** 100~1000개 순서를 샘플링하세요. 정확한 나열은 확장되지 않습니다.
- **감쇠 계수에 상한을 두고 평판에 하한을 두세요.** 무제한 감쇠는 정당한 기여자를 지워 버리고, 너무 느린 감쇠는 낡은 고평판 에이전트를 계속 이롭게 합니다.
- **메커니즘을 적대적으로 감사하세요.** 네트워크를 열기 전에 레드팀 시나리오를 돌리세요. 모든 메커니즘에는 게임 이론이 있습니다. 공격자가 아니라 구멍을 먼저 찾으세요.

## 핵심 용어

| 용어 | 사람들이 말하는 표현 | 실제 의미 |
|------|----------------|------------------------|
| DePIN | "탈중앙화 물리 인프라" | 토큰 인센티브 기반 컴퓨팅/스토리지/대역폭. Bittensor, Akash, Render. |
| DID | "탈중앙화 식별자" | 휴대 가능한 ID를 위한 W3C 표준. 에이전트 평판은 플랫폼이 아닌 DID에 묶임. |
| ERC-4337 | "계정 추상화" | 가스비를 대납할 수 있는 컨트랙트 계정으로, 에이전트 지불을 가능하게 함. |
| 샤플리 값 | "공정한 크레딧 배분" | 효율성, 대칭성, 선형성, 무기여 공리를 만족하는 유일한 배분. |
| 2가격 경매 | "빅프리 경매" | 진실한 메커니즘: 낙찰자가 두 번째로 높은 입찰가를 지불. 단조 집합과 호환. |
| 평판 자본 | "누적 품질 점수" | 검증된 기여에서 쌓이는 DID 기반 점수; 시간이 지나면 감쇠. |
| 에이전틱 DAO | "에이전트 + 인간이 통치" | 에이전트 유권자가 일급 시민이고 투표권이 평판에 연동된 DAO. |
| TAO / FET / GPU 크레딧 | "토큰 단위" | Bittensor TAO, Fetch.ai FET, 각종 DePIN 토큰. |
