# 에이전트를 위한 합의와 비잔틴 장애 허용(BFT)

> 고전적인 분산 시스템 BFT가 확률론적인 LLM을 만났습니다. 2025~2026년에 세 갈래 연구 방향이 나타났습니다: **CP-WBFT**(arXiv:2511.10400)는 신뢰도 탐침으로 각 표의 가중치를 매기고, **DecentLLMs**(arXiv:2507.14928)는 지도자 없이 병렬 작업자 제안과 기하 중앙값 집계로 갑니다, **WBFT**(arXiv:2505.05103)는 가중 투표와 계층 구조 클러스터링을 결합해 코어와 엣지 노드를 나눕니다. "Can AI Agents Agree?"(arXiv:2603.01213)의 정직한 실증 결과는 오늘날 스칼라 값조차도 합의가 무척 깨지기 쉽다는 것 — 속이는 에이전트 하나가 Mixture-of-Agents 전체를 무너뜨릴 수 있습니다. BFT는 필요하지만 충분하지 않습니다. 이 레슨은 최소한의 BFT 프로토콜을 만들고, 에이전트 특유의 세 가지 공격(비잔틴 거짓말, 아첨형 동조, 상관 오차 단일배양)을 주입한 뒤, 각 합의 변형이 어떻게 대응하는지 측정합니다.

**유형:** 학습 + 빌드
**언어:** Python(표준 라이브러리)
**선수 지식:** 페이즈 16 · 07(마인드 소사이어티와 토론), 페이즈 16 · 13(공유 메모리)
**시간:** 약 75분

## 문제

N개의 LLM 에이전트가 각자 답을 만들어 냅니다. 그런데 의견이 갈립니다. 다수결이 틀린 답을 고릅니다. 두 에이전트가 서로 상관되어 있기 때문입니다(같은 베이스 모델, 같은 학습 데이터, 같은 실패 양상). 세 번째 에이전트는 우연히 새로운 방식으로 틀렸습니다 — 그래서 다수는 거짓 다수입니다.

여기에 속이는 에이전트를 하나 더해 봅시다. 일부러 거짓말을 합니다. 아니면 아첨하는 에이전트: 마지막에 말한 사람에게 동의합니다. 고전적 BFT에서는 비잔틴 노드가 `f < n/3`의 비율이고 임의로 행동한다고 가정합니다. 2026년의 현실은 LLM 노드가 정직할 때조차 확률론적이고, 모델들 사이에서 상관되어 있으며, 서로의 출력에 영향을 받는다는 것입니다. 이들을 독립적인 베르누이 투표자로 다룰 수는 없습니다.

고전적 BFT(PBFT, 1999)가 틀린 게 아닙니다 — 불완전할 뿐입니다. 임의의 비트 반전은 다룹니다. 하지만 "정직한 세 에이전트가 같은 학습 데이터를 공유하기 때문에 같은 환각을 공유한다"는 다루지 못합니다. 이 레슨은 PBFT의 기반 위에 2025~2026년의 세 가지 적응을 층층이 얹습니다.

## 개념

### 고전적 BFT가 주는 것

실용 비잔틴 장애 허용(Castro & Liskov, OSDI 1999)은 `f < n/3`의 비잔틴 노드를 견딥니다. 프로토콜은 세 페이즈(pre-prepare, prepare, commit)와 두 프리미티브(서명된 메시지, 정족수 증명)를 갖습니다. `n >= 3f + 1`개의 정직하거나 악의적인 노드 사이에서 하나의 값에 대한 합의입니다.

보장은 강력하지만 다음을 가정합니다:

1. **독립적인 고장.** 비잔틴 노드들은 서로 협조하지 않습니다.
2. **정직한 노드는 진짜 정직하다.** 정직한 출력의 올바름은 문제가 아니며, 프로토콜은 불일치만 정렬합니다.
3. **질문에는 정답이 있다.** 틀린 사실에 대한 합의도 여전히 합의입니다.

LLM 에이전트는 이 셋을 모두 어깁니다. 같은 베이스 모델을 도는 두 에이전트는 고장을 공유합니다. "정직한" LLM도 여전히 환각을 일으킵니다. 그리고 모호한 질문에서 "진실"은 에이전트들이 결정하는 것입니다 — 외부의 신탁(oracle)이 없습니다.

### LLM 특유의 세 가지 공격

**비잔틴 거짓말.** 한 에이전트가 일부러 틀린 답을 출력합니다. `f < n/3`이면 고전적 BFT가 다룹니다.

**아첨형 동조(sycophantic conformity).** 한 에이전트가 투표 전에 다른 이들의 답을 읽고 마지막 발언자에게 맞춥니다. 악의는 없지만 가장 큰 목소리와 상관됩니다. 모든 서명 검사를 통과하기 때문에 고전적 BFT는 이걸 막지 못합니다.

**상관 오차 단일배양(correlated-error monoculture).** 세 에이전트가 같은 베이스 모델을 공유합니다. 셋이 같은 틀린 답을 환각으로 만듭니다. 다수가 틀립니다. 셋이 "정직하게" 동의하기 때문에 고전적 BFT는 도움이 되지 않습니다.

### 2025~2026년의 대응들

**CP-WBFT**(arXiv:2511.10400) — 신뢰도 탐침 가중 BFT(Confidence-Probed Weighted BFT). 각 투표자가 답변에 신뢰도 탐침을 붙입니다(자기 보고 확률 또는 별도 캘리브레이션 모델의 예측). 표 가중치는 신뢰도에 비례합니다. 완전 그래프에서 +85.71%의 BFT 개선이 보고되었습니다. 완화 대상: 아첨형 동조(동조하는 에이전트는 자발적으로 취한 입장에 낮은 신뢰도를 보이는 경향이 있습니다).

**DecentLLMs**(arXiv:2507.14928) — 지도자 없음. 작업자 에이전트들이 병렬로 제안하고, 평가자 에이전트들이 제안을 채점하며, 최종 답은 채점된 위치들의 기하 중앙값입니다. `f < n/2`에서 강건합니다. 완화 대상: 비잔틴 거짓말과 상관 오차(기하 중앙값은 이상치에 강건하고, 모델 편향이 있는 평균이 아니라 밀집된 군집 쪽으로 당깁니다).

**WBFT**(arXiv:2505.05103) — 계층 구조 클러스터링을 곁들인 가중 BFT. 표 가중치는 응답 품질과 기록에서 학습된 신뢰 점수로 매겨집니다. 에이전트를 코어와 엣지로 묶습니다. 코어 에이전트가 먼저 합의해야 하고, 엣지 에이전트는 그것을 따릅니다. 완화 대상: 확장성(코어 합의는 작고 빠릅니다)과 부분적으로 단일배양(코어를 다양성 기준으로 고를 수 있습니다).

### 실증: "Can AI Agents Agree?"(arXiv:2603.01213)

이 논문은 여러 프론티어 모델에 걸쳐 스칼라 합의(LLM 에이전트들이 하나의 수치 값에 동의하기)를 측정합니다. 결과는 불편합니다:

- 적대자가 전혀 없어도, LLM 에이전트들은 많은 벤치마크에서 30%를 넘는 비율로 스칼라 질문에서 의견이 갈립니다.
- 속이는 페르소나를 채택한 에이전트 하나가 Mixture-of-Agents 합의를 정직한 베이스라인에서 40퍼센트포인트 이상 벗어나게 만들 수 있습니다.
- 불일치율은 모델 다양성과 상관됩니다 — 이기종 앙상블이 동질 앙상블보다 더 많이 갈립니다(좋음: 오차가 상관되지 않음)만, 동시에 더 느리게 표류합니다(나쁨: 합의 도달 시간이 길어짐).

요점: BFT는 출력을 정렬하는 장치를 주지만, 정렬된 출력이 맞는지는 알려 주지 않습니다. 검증(페이즈 16 · 08 역할 특수화), 다양성(페이즈 16 · 15 토론 변형), 평가자 에이전트(페이즈 16 · 24 벤치마크)와 결합하세요.

### 핵심 프로토콜, 벗겨 내면

LLM 에이전트를 위한 최소 BFT 라운드:

```
1. 태스크가 도착; 각 에이전트 i가 답변 a_i를 생성
2. 각 에이전트가 [0, 1] 범위의 신뢰도 탐침 c_i를 붙임
3. 애그리게이터가 n개 에이전트 전부에서 (a_i, c_i)를 수집
4. 애그리게이터가 의미 군집별로 묶음(동치인 답변들)
5. 애그리게이터가 각 군집 C의 가중치를 계산:
     w(C) = sum_{i in C} c_i
6. max > threshold * sum(c_i)이면 최대 가중치 군집이 승자
   아니면: 재시도 또는 에스컬레이션
7. 소수 군집은 사후 감사를 위해 출처와 함께 기록
```

의미 군집화 단계가 LLM 특유의 비틀기입니다. "그 연구는 4.2%라고 보고한다"와 "4.2% 개선"은 같은 군집입니다. 순진한 문자열 동등성 검사라면 이걸 놓칩니다. 프로덕션에서는 값싼 임베딩 모델이나 명시적 정규화(canonicalization)를 쓰세요.

### 임계값 튜닝

`threshold` 파라미터가 언제 받아들이고 언제 재시도할지 결정합니다. 너무 낮으면: 약한 다수를 받아들입니다. 너무 높으면: 아무것도 받아들이지 못합니다. 실증 범위: `n=5~7` 에이전트에서 0.5~0.67, 더 작은 `n`에서는 더 높게. 임계값 미만이면 사람이나 다른 에이전트 앙상블로 에스컬레이션하세요.

### 합의가 도움이 되지 않는 곳

- **모호한 질문.** 질문에 정답이 없다면 합의는 하나의 의견입니다. 그렇게 부르세요.
- **복합 질문.** "코드를 쓰고 설명하라" — 답이 두 개입니다. 각각 독립적으로 투표하세요.
- **적대적인 다중 라운드.** 에이전트가 이전 라운드를 관찰하고 흉내 낼 수 있다면(Du 2023 토론), 진실과 무관하게 서로 동의하기 시작합니다. 라운드 수를 제한하세요(보통 2~3).

## 만들어 보기

`code/main.py`는 다음을 구현합니다:

- `AgentVoter` — (답변, 신뢰도)를 지닌 스크립트형 정책.
- `MajorityVote` — 고전적 다수결.
- `CPWBFT` — 의미 군집화가 있는 신뢰도 가중 투표.
- `DecentLLMs` — 채점된 제안에 대한 기하 중앙값 집계.
- `Scenario` — 세 공격 패턴 아래에서 각 애그리게이터를 실행.

구현된 공격 패턴:

1. `byzantine`: 한 에이전트가 높은 신뢰도로 거짓말합니다.
2. `sycophancy`: 한 에이전트가 처음 본 답을 같은 신뢰도로 복제합니다.
3. `monoculture`: 세 에이전트가 중간 신뢰도로 같은 틀린 답(상관 오차)을 공유합니다.

실행:

```
python3 code/main.py
```

예상 출력: (공격, 애그리게이터) → 최종 답변 표, 정답이 강조됨. 다수결은 단일배양 사례에서 실패합니다. CPWBFT의 신뢰도 가중치는 아첨을 완화합니다. DecentLLMs의 기하 중앙값은 단일배양이 인구의 절반 미만일 때 정직한 군집 쪽으로 당깁니다.

- **모든 소수 군집을 출처와 함께 기록**하세요. 소수 군집은 상관 오차의 조기 경보 시스템입니다.
- **라운드 수 상한을 강제**하세요. "합의할 때까지 계속 토론"은 안 됩니다 — 아첨에 보상하는 셈입니다.
- **합의와 올바름을 분리**하세요. 합의 출력은 검증자로 가고, 검증자는 앙상블과 독립적이어야 합니다.
- **합의율을 모니터링**하세요. 급상승은 동조 편향, 급하락은 모델 드리프트입니다.

## 연습 문제

1. `code/main.py`를 실행하세요. 다수결이 단일배양 공격에 실패하는지, 그리고 단일배양의 신뢰도가 0.7 미만일 때 CPWBFT가 부분적으로 완화하는지 확인하세요.
2. 네 번째 공격 패턴을 추가하세요: **침묵 기권** — 한 에이전트가 ("모르겠다"며) 답하기를 거부합니다. 각 애그리게이터는 기권을 어떻게 다뤄야 할까요? 당신의 선택을 구현하세요.
3. 의미 군집화를 문자열 정규화에서 임베딩 유사도로 바꿔 보세요(아무 오픈소스 임베딩 모델이나 사용). 아첨 공격에는 무슨 일이 생기나요?
4. CP-WBFT(arXiv:2511.10400)를 읽으세요. 신뢰도 탐침 캘리브레이션 단계를 구현해 보세요(별도의 캘리브레이션 모델이 각 에이전트의 자기 보고 신뢰도를 검사). 단일배양 시나리오에서 정확도 향상을 측정하세요.
5. "Can AI Agents Agree?"(arXiv:2603.01213)를 읽고 단순화된 스칼라 합의 실험을 재현해 보세요: 에이전트 셋, 스칼라 질문 하나, 속이는 페르소나 프롬프트. CPWBFT나 DecentLLMs가 이걸 잡아내나요?

## 핵심 용어

| 용어 | 사람들이 말하는 표현 | 실제 의미 |
|------|----------------|------------------------|
| BFT | "비잔틴 장애 허용" | `f < n/3` 임의 고장에서 합의를 이루는 Castro-Liskov 1999 프로토콜. |
| 비잔틴(Byzantine) | "이상한 행동 전부" | 거짓말, 메시지 유실, 조용한 실패 등 — 안전한 크래시 빼고는 뭐든 하는 노드. |
| 신뢰도 탐침(confidence probe) | "얼마나 확신하나?" | 표에 붙는, 자기 보고 또는 캘리브레이터가 예측한 확률. |
| 의미 군집화(semantic clustering) | "같은 답, 다른 표현" | 표를 세기 전에 동치인 답변을 묶는 것. |
| 기하 중앙값(geometric median) | "강건한 중심" | 표본점들까지의 거리 합을 최소화하는 점. 평균과 달리 이상치에 강건함. |
| 단일배양(monoculture) | "같은 모델, 같은 실패" | 에이전트들이 학습 데이터나 베이스 모델을 공유할 때의 상관 오차. |
| 아첨형 동조(sycophantic conformity) | "큰 목소리에 동의" | 에이전트의 표가 먼저/크게 말한 쪽으로 기우는 것. |
| 코어/엣지(Core/Edge) | "계층형 BFT" | WBFT의 분할: 작은 코어 합의가 먼저, 엣지 노드가 뒤따름. 지연 시간을 제한. |
