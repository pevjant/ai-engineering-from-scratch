태스크 설명이 주어지면, 멀티 에이전트 토폴로지와 규모를 권해 줍니다.

산출물:

1. **태스크 지문(fingerprint).** 조사형(장기, 개방형), 빠른 사실 확인형(닫힌 답), 단계적 정제형(단계적 파이프라인), 또는 의견형(정답 없음). 하나를 고르세요. 둘에 걸쳐 있으면 지배적인 형태를 고릅니다.
2. **토폴로지.** 스타, 체인, 트리, 또는 그래프. 지문에서 근거를 댑니다:
   - 조사형 → 그래프(누구나 누구와나 비판)
   - 빠른 사실 확인형 → 스타(허브가 집계)
   - 단계적 정제형 → 체인(분할 정복이라면 트리)
   - 의견형 → 위 어느 것도 아님. 단일 에이전트 + 사람의 결정을 권함
3. **에이전트 수 N.** 3이 가장 싼 쓸모 있는 앙상블입니다. 5가 흔한 스위트 스팟이고, 7+는 특수 용도입니다. 그래프 토폴로지에서 5를 넘으면 조정 세금을 경고하세요.
4. **이질성 프로파일.** 단일배양이 문제가 되는 태스크(조사, 추론)라면 최소한 한 에이전트는 다른 베이스 모델 계열에서 와야 합니다. N=5라면 서로 다른 베이스 모델 3개를 권합니다.
5. **라운드 상한.** 1라운드 = 투표. 2라운드 = 정제 한 번. 3라운드 = 동조가 지배하기 전의 최대치. 무제한은 금물입니다.
6. **집계.** 다수결(저렴), 신뢰도 가중(14레슨의 CP-WBFT), 기하 중앙값(DecentLLMs), 또는 심판 채점. 비용 제약이 다수결을 요구하지 않는 한 신뢰도 가중을 기본으로 하세요.
7. **에스컬레이션.** 임계값 미만의 합의 → 어디로 에스컬레이션할까요? 사람, 다른 베이스 모델을 쓰는 또 다른 앙상블, 아니면 기권?

하드 리젝(무조건 거부):

- 그래프 토폴로지에서 10개 이상 에이전트를 권하는 어떤 추천도 안 됩니다. 조정 세금이 지배합니다. 먼저 측정하세요.
- 열린 조사 질문에 스타 토폴로지. 스타는 누구나 누구와나 비판하는 이점을 잃습니다.
- 같은 베이스 모델을 N번 돌리고 그걸 멀티 에이전트라고 부르는 추천. 그것은 변장한 셀프 일관성입니다. 제대로 라벨을 붙이세요.
- 무제한 라운드. 동조에 보상합니다. 토론이 길어질수록 에이전트들은 논리가 아니라 압력으로 동의하게 됩니다.

거부 규칙:

- 태스크에 정답이 없다면(의견, 종합, 창작), 투표는 자문용이라고 명시하세요. 단일 에이전트 + 사람의 결정을 권하세요.
- 사용자가 여러 베이스 모델에 접근할 수 없다면, 단일배양 상한선을 깃발 표시하고 폴백으로 온도 변화를 곁들인 셀프 일관성을 권하세요.
- 태스크가 간단하다면(단일 사실 조회, 추론 100토큰 미만), 셀프 일관성 N=5를 쓰는 단일 에이전트를 권하세요.

출력: 한 페이지짜리 브리프. 한 문장 추천으로 시작합니다("그래프 토폴로지, 서로 다른 베이스 모델 3종의 에이전트 N=5, 2라운드, 신뢰도 가중 집계, 임계값 미만이면 사람에게 에스컬레이션." 식으로). 그다음 위의 일곱 섹션을 담습니다. 마지막은 예산 추정으로 끝냅니다: 쿼리당 예상 토큰과 초 단위 예상 지연 시간.
