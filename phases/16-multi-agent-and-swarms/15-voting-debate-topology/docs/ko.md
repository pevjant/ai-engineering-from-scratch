# 투표, 셀프 일관성, 토론 토폴로지

> 가장 값싼 집계 방식: 독립적인 에이전트 N개를 샘플링하고 다수결을 한다. Wang et al. 2022의 셀프 일관성(self-consistency)은 모델 하나를 N번 샘플링해 이걸 했습니다. 멀티 에이전트는 여기에 **이기종** 에이전트를 더해 단일배양(monoculture)을 탈출합니다 — 다른 모델, 다른 프롬프트, 다른 온도, 다른 컨텍스트. 다수결을 넘어서면 토론 토폴로지가 중요해집니다. MultiAgentBench(arXiv:2503.01935, ACL 2025)는 스타/체인/트리/그래프 조정 방식을 평가해 연구 태스크에서는 **그래프가 가장 좋다**는 것, 그리고 에이전트 약 4개를 넘으면 "조정 세금(coordination tax)"이 붙는다는 것을 발견했습니다. AgentVerse(ICLR 2024)는 두 가지 창발 패턴 — 자원 행동과 동조 행동 — 을 기록했는데, 동조는 특징이기도 하고(합의 발견) 위험이기도 합니다(집단 사고, 24레슨). 이 레슨은 토폴로지 공간을 지도화하고, 각 변형을 만들어 보며, 조정 세금을 측정합니다.

**유형:** 학습 + 빌드
**언어:** Python(표준 라이브러리)
**선수 지식:** 페이즈 16 · 07(마인드 소사이어티와 토론), 페이즈 16 · 14(합의와 BFT)
**시간:** 약 75분

## 문제

토론은 정확도를 높일 수도 있고(Du et al., arXiv:2305.14325), 떨어뜨릴 수도 있습니다. 토론이 도움이 되는지는 네 가지 구조적 선택에 달려 있습니다:

1. 누가 누구와 말하는가(토폴로지).
2. 몇 라운드인가(Du 2023: 라운드 수와 에이전트 수는 각각 독립적으로 중요합니다).
3. 에이전트들이 이기종인가(다른 베이스 모델은 단일배양을 깹니다).
4. 적대적인 목소리가 있는가(스틸맨(steel-manning, 상대 논지를 최선으로 세워 반박) vs. 허수아비 공격(straw-manning)).

"에이전트 5개를 돌리고 투표하자"를 태스크에 얹은 팀들은 단일 에이전트보다 오히려 후퇴하곤 합니다. 실패는 무작위가 아닙니다. 토폴로지와 이질성을 따라갑니다. 이 레슨이 바로 토폴로지 지도입니다.

## 개념

### 셀프 일관성, 단일 모델 베이스라인

Wang et al. 2022("Self-Consistency Improves Chain of Thought Reasoning")는 같은 모델을 온도 > 0으로 N번 샘플링하고, 추론 경로별 답변에 다수결을 했습니다. GSM8K에서의 결과: 단일 그리디 디코딩 대비 N=40 샘플에서 실질적인 향상. 셀프 일관성은 멀티 에이전트 투표의 단일 에이전트 선조격입니다.

한계: 셀프 일관성은 베이스 모델 하나를 씁니다. 오차는 구조적으로 상관됩니다. 모델에 체계적 편향이 있다면 N개 샘플 전부가 그것을 공유합니다.

### 멀티 에이전트 투표, 이기종 확장

N개 샘플을 N개의 *서로 다른* 에이전트로 바꿉니다. 다른 베이스 모델(Claude, GPT, Llama), 다른 프롬프트, 다른 도구 접근. 이점: 상관되지 않은 오차. 비용: 에이전트마다 비용이 다르고, 조율에 오버헤드가 붙습니다.

이기종 토론의 2026년 표준 명칭은 **A-HMAD** — 적대적 이기종 멀티 에이전트 토론(Adversarial Heterogeneous Multi-Agent Debate)입니다. 보편적으로 채택된 이름은 아니지만, 논문들은 "다른 모델들이 토론하여 단일배양 붕괴로 인한 상관 오차를 줄인다"는 의미로 이 용어를 씁니다.

### 네 가지 토폴로지

```
star                chain               tree                graph
(스타)              (체인)              (트리)              (그래프)

    ┌─A─┐           A─B─C─D         ┌──A──┐              A───B
    │   │                           │     │              │ × │
    B   C                           B     C              D───C
    │   │                          / \   / \
    D   E                         D   E F   G           (완전 연결)
```

스타: 허브가 하나이고, 나머지는 허브와만 대화합니다. 뒷채널 없는 슈퍼바이저-작업자와 같습니다.
체인: 선형. 각 에이전트는 이전 에이전트의 출력을 봅니다. 파이프라인과 비슷합니다.
트리: 계층형. 계층형 에이전트 시스템(06레슨)이 씁니다.
그래프: 누구나 누구와나. 완전 연결 클리크와 임의의 DAG를 포함합니다.

### 조정 세금(MultiAgentBench)

MultiAgentBench(MARBLE, ACL 2025, arXiv:2503.01935)는 조사·코딩·계획을 포함한 태스크 모음에서 스타, 체인, 트리, 그래프를 벤치마크했습니다. 측정된 핵심 결과:

- **그래프** 토폴로지가 조사 태스크에서 이깁니다. 정보가 누구에게나 흐르고, 에이전트들이 서로 비판할 수 있습니다.
- **스타**는 빠른 답변이 필요한 사실 확인 태스크에서 이깁니다. 허브가 걸러 주고 하나로 모읍니다.
- **체인**은 단계별 파이프라인(단계적 정제)에서 이깁니다.
- **조정 세금**은 그래프 토폴로지에서 에이전트 약 4개를 넘으면 나타납니다. 실제 걸리는 시간과 토큰 비용이 품질보다 빨리 자랍니다.

4에이전트 천장은 실증적일 뿐 근본적인 것은 아닙니다. 2026년 LLM 컨텍스트 용량의 반영입니다: 각 에이전트의 컨텍스트가 동료들의 출력으로 차고, 모두가 모두를 볼 수 있으면 에이전트 N+1을 더하는 한계 가치가 떨어집니다.

### 멀티 에이전트 토론 전략("Should we be going MAD?")

arXiv:2311.17371은 2023년 MAD 전략 조사입니다. 다른 연구들이 재현한 핵심 발견: 셀프 일관성과 *구조적으로 유사한*(독립 샘플링 + 집계) MAD 변형들은 같은 예산에서 셀프 일관성보다 못한 경우가 잦습니다. MAD가 가장 돕는 때는 에이전트들이 진짜로 이기종이고 토론에 적대적 구조가 있을 때(한 에이전트가 반대 입장을 논함)입니다.

### AgentVerse의 창발 패턴

AgentVerse(ICLR 2024, https://proceedings.iclr.cc/paper_files/paper/2024/file/578e65cdee35d00c708d4c64bce32971-Paper-Conference.pdf)는 명시적 설계 없이도 멀티 에이전트 토론에서 창발하는 두 행동을 기록했습니다:

- **자원(volunteer).** 에이전트가 요청받지 않고 도움을 제안합니다("다음 단계를 제가 맡을 수 있습니다"). 유용합니다: 서브태스크를 가장 유능한 에이전트에게 배분합니다.
- **동조(conformity).** 에이전트가 비판자와 입장을 맞춥니다. 비판자가 틀렸을 때조차. 이것은 아첨(14레슨)의 토론 버전입니다.

동조가 있기 때문에 "합의할 때까지 토론"은 강한 자에게 보상합니다. 라운드 상한과 별도의 심판이 이를 완화합니다.

### 이질성: 실제로 정확도를 움직이는 손잡이

실무 문헌에서 2024~2026년의 패턴: N개 에이전트 중 하나를 다른 베이스 모델로 바꾸는 것이 N을 1 늘리는 것보다 더 큰 정확도 상승을 줍니다. 직관은 단일배양입니다 — 새로운 독립 오차 원천 하나가 상관된 샘플 하나보다 가치가 큽니다.

극한으로 가면, 이질성이 수량을 이깁니다. 정답이 분명한 대부분의 태스크에서 서로 다른 모델 셋이 같은 모델 다섯 벌을 이깁니다.

### 배심 방법

Sibyl 프레임워크(Minsky-LLM 문헌에서 인용)는 "배심"을 형식화합니다 — 각 단계에서 투표로 답을 다듬는 소수의 전문 에이전트 집단입니다. 단순 다수결과 달리 배심에는 역할이 있습니다: 한 에이전트는 심문하고, 하나는 맥락을 대고, 하나는 개연성을 채점합니다. 배심 방법은 단순 투표(저렴, 단일배양 위험)와 풀 MAD(비쌈, 동조 위험)의 중간점입니다.

### 투표+토론이 지배하는 경우

- 질문에 정답이 있습니다(사실, 수학, 코드 동작). 투표 수렴이 의미 있습니다.
- 에이전트들이 서로 다른 자료나 도구에 접근할 수 있습니다(이질성을 확보할 수 있음).
- 라운드가 제한되어 있고(보통 2~3) 별도의 심판이나 검증자가 있습니다.
- 예산이 에이전트 3~5개를 허용합니다. 그래프 토폴로지에서 5~7개를 넘으면 조정 세금이 지배합니다.

### 투표+토론이 해를 끼치는 경우

- 질문이 의견 형태입니다. 에이전트들은 가장 올바른 답이 아니라 가장 자신 있어 보이는 답으로 수렴합니다.
- 모든 에이전트가 베이스 모델을 공유합니다. 단일배양은 합의를 무의미하게 만듭니다.
- 라운드가 무제한입니다. 동조가 언제나 이깁니다.
- 태스크가 간단합니다. N=5 셀프 일관성을 쓰는 단일 에이전트가 더 싸고 똑같이 정확합니다.

## 만들어 보기

`code/main.py`는 다음을 구현합니다:

- `run_star(agents, hub, question)` — 허브가 각 작업자를 폴링하고 집계합니다.
- `run_chain(agents, question)` — 순차 정제.
- `run_tree(root, children, question)` — 깊이-2 집계가 있는 계층 구조.
- `run_graph(agents, question, rounds)` — 전원 대 전원 토론, 라운드 제한.
- 스크립트형 이질성 다이얼: 각 에이전트는 자기만의 체계적 오류 성향을 나타내는 `error_bias`를 지닙니다.
- 각 토폴로지를 N=3, 5, 7로 돌리고 (정확도, 총 토큰, 시뮬레이션 소요 시간)을 보고하는 측정 하네스.

실행:

```
python3 code/main.py
```

예상 출력: 토폴로지 × N → (정확도, 토큰, 지연 시간) 표. 조사 스타일 태스크에서는 N=3~5에서 그래프가 이기고, 빠른 사실 확인 태스크에서는 스타가 이기며, N=7 그래프는 조정 세금을 보여 줍니다(지연 시간이 정확도보다 빨리 부풀어 오름).

## 출시하기

앙상블이라면 무엇이든:

- 강한 베이스 모델 하나로 **N=5 셀프 일관성**부터 시작하세요. 값싼 베이스라인입니다.
- 정확도가 중요하면 **N=3 이기종 투표**로 올리세요. 증분을 측정하세요.
- 태스크에 구조(조사, 다단계)가 있고 라운드 제한이 가능할 때만 **토론 토폴로지**로 올리세요.
- 항상 소수 군집을 기록하세요. 소수가 꾸준히 옳다면 그것은 다양성 신호입니다.
- 정확도와 함께 실제 소요 시간과 토큰을 벤치마크하세요. "10배 비용으로 더 나은 정확도"는 비즈니스 결정입니다.

## 연습 문제

1. `code/main.py`를 실행하세요. 그래프 토폴로지의 조정 세금 곡선을 그려 보세요: 정확도 vs N, 토큰 vs N. 어느 N에서 곡선이 꺾이나요?
2. A-HMAD를 구현해 보세요: 일부러 편향이 다른 에이전트 셋. 14레슨의 단일배양 공격에서 모두 같은 편향인 베이스라인과 A-HMAD는 어떻게 비교되나요?
3. 그래프 토폴로지에 투표하지 않고 최종 합의만 채점하는 "심판" 역할을 추가해 보세요. 창발하는 동조 행동이 달라지나요?
4. AgentVerse 논문(ICLR 2024)을 읽으세요. 당신의 구현이 가장 강하게 보이는 창발 행동이 무엇인지 찾아보세요. 프롬프트 변경으로 반대 행동을 유도할 수 있나요?
5. MultiAgentBench(arXiv:2503.01935) 4절(토폴로지 실험)을 읽으세요. 논문의 태스크 하나에 대해 당신의 하네스로 "연구에서는 그래프가 이긴다"는 결과를 재현해 보세요.

## 핵심 용어

| 용어 | 사람들이 말하는 표현 | 실제 의미 |
|------|----------------|------------------------|
| 셀프 일관성(self-consistency) | "N번 샘플링해서 투표" | Wang 2022. 단일 모델, 온도>0 샘플 N개, 추론 경로별 다수결. |
| 이질성(heterogeneity) | "모델을 섞는 것" | 다른 베이스 모델이나 프롬프트 계열의 앙상블. 단일배양을 깸. |
| MAD | "멀티 에이전트 토론" | 에이전트들이 라운드에 걸쳐 비판을 주고받는 것을 이르는 일반 용어. Du 2023 참고. |
| A-HMAD | "적대적 이기종 MAD" | 다른 모델 + 적대적 구조를 강조하는 MAD 변형. |
| 토폴로지(topology) | "누가 누구와 말하나" | 스타, 체인, 트리, 그래프. 정보 흐름을 결정. |
| 조정 세금(coordination tax) | "체감되는 한계 수익" | 그래프에서 에이전트 약 4개를 넘으면 비용이 품질보다 빨리 자람. |
| 자원 행동(volunteer behavior) | "요청 안 한 도움" | AgentVerse 창발 패턴: 에이전트가 단계를 맡겠다고 나섬. |
| 동조 행동(conformity behavior) | "압박 아래의 동의" | AgentVerse 창발 패턴: 에이전트가 비판자에게 맞춤. |
| 배심(jury) | "작은 전문 패널" | 역할(심문자, 맥락 제공자, 채점자)이 있는 Sibyl 방식 앙상블. |
