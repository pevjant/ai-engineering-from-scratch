# 시각 자기회귀 모델링(VAR): Next-Scale Prediction

> 확산 모델은 시간축에서 반복적으로 샘플링합니다(디노이징 스텝). VAR은 스케일축에서 반복적으로 샘플링합니다 — 1x1 토큰을 예측한 다음 2x2, 4x4 순으로 최종 해상도까지 올라가며, 각 스케일은 이전 스케일을 조건으로 삼습니다. 2024년 논문은 VAR이 이미지 생성에서 GPT 스타일의 스케일링 법칙을 따른다는 것, 그리고 같은 연산량 예산에서 DiT를 이긴다는 것을 보였습니다. 이 레슨에서는 그 핵심 메커니즘을 직접 만들어 봅니다.

**유형:** 빌드
**언어:** Python (PyTorch 사용)
**선수 지식:** 페이즈 7 레슨 03(멀티헤드 어텐션), 페이즈 8 레슨 06(DDPM)
**시간:** 약 90분

## 문제 상황

자기회귀(autoregressive) 생성은 언어 모델링을 지배해 왔습니다. 예측 가능하게 확장되기 때문입니다 — 연산을 늘리고, 파라미터를 늘리면 퍼플렉시티가 내려가고 결과물이 좋아집니다. 이미지 생성은 2024년 이전에 자기회귀 방식으로 두 번 크게 시도된 적이 있습니다: PixelRNN/PixelCNN(픽셀 단위)과 DALL-E 1 / Parti / MuseGAN(VQ-VAE 코드 기반 토큰 단위)입니다.

두 방식 모두 생성 순서 문제에 시달렸습니다. 픽셀과 토큰은 2D 격자에 놓여 있는데, 자기회귀 모델은 이들을 1D 래스터 순서로 방문해야만 합니다. 초반에 찍는 구석 픽셀은 이 이미지가 최종적으로 무엇이 될지 전혀 모르는 상태입니다. 그래서 생성 품질이 텍스트에 대한 GPT만큼 잘 확장되지 못했고, 같은 연산량에서 확산 모델 품질에 한 번도 미치지 못했습니다.

VAR은 무엇을 생성하는지를 바꿔서 이 생성 순서 문제를 해결합니다. 이미지 토큰을 공간상에서 하나씩 예측하는 대신, VAR은 해상도를 점점 높여 가며 이미지 전체를 예측합니다. 1단계: 1x1 토큰(이미지 전체의 "요약")을 예측합니다. 2단계: 2x2 토큰 격자(거친 특징)를 예측합니다. 3단계: 4x4 격자를 예측합니다. K단계: 최종 (H/8)x(W/8) 격자를 예측합니다.

각 스케일은 이전의 모든 스케일을 어텐션으로 봅니다(스케일 순서 기준 인과적), 그리고 자기 스케일 내부에서는 병렬로 처리합니다. 순서 문제가 사라집니다: 스케일 k에서의 이미지 전체가 트랜스포머 패스 한 번으로 만들어집니다.

## 핵심 개념

### VQ-VAE 멀티스케일 토크나이저

VAR에는 **멀티스케일 이산(discrete) 토크나이저**가 필요합니다. 이미지 x가 주어지면, 점점 해상도가 높아지는 토큰 격자의 수열을 만들어 냅니다:

```
x -> encoder -> latent f
f -> tokenize at 1x1: token grid z_1 of shape (1, 1)
f -> tokenize at 2x2: token grid z_2 of shape (2, 2)
...
f -> tokenize at (H/p)x(W/p): token grid z_K of shape (H/p, W/p)
```

각 z_k는 같은 코드북을 사용합니다(일반적으로 크기 4096~16384). 각 스케일에서의 토큰화는 서로 독립적이지 않습니다 — 각 스케일의 잔차(residual, 뺄셈 후 남은 것)를 모두 더하면 f가 복원되도록 학습됩니다:

```
f ≈ upsample(embed(z_1), target_size) + ... + upsample(embed(z_K), target_size)
```

이것은 **잔차 VQ(residual VQ)**의 변형입니다. 스케일 k는 스케일 1..k-1이 놓친 부분을 잡아 냅니다. 디코더는 모든 스케일 임베딩의 합을 받아 이미지를 만들어 냅니다.

멀티스케일 VQ 토크나이저는 한 번 학습한 뒤(VQGAN처럼) 얼려 둡니다(freeze). 실제 생성 작업은 전부 그 위에 얹힌 자기회귀 모델이 수행합니다.

### 다음 스케일 예측(Next-Scale Prediction)

생성 모델은 이전 스케일들의 토큰을 모두 보고 다음 스케일의 토큰을 예측하는 트랜스포머입니다.

입력 시퀀스 구조:
```
[START, z_1 tokens, z_2 tokens, z_3 tokens, ..., z_K tokens]
```

위치 임베딩은 스케일 인덱스와 스케일 내 공간적 위치를 함께 인코딩합니다. 어텐션은 스케일 순서 기준으로 인과적(causal)입니다: 스케일 k의 (i, j) 위치 토큰은 스케일 1..k의 모든 토큰을 볼 수 있고, 스케일 k 자체 내에서는 사용 중인 스케일 내 순서에서 앞서 온 토큰들을 볼 수 있습니다(VAR은 스케일 내 인과성 없이 고정된 위치 어텐션을 사용합니다 — 스케일 내 모든 위치는 병렬로 한 번에 예측됩니다).

학습 손실: 각 스케일 k마다, 이전 스케일 토큰들이 주어졌을 때 z_k를 예측합니다. 이산 VQ 코드에 대한 교차 엔트로피 손실입니다. "시퀀스"가 이제 스케일 구조를 가진다는 점만 빼면 GPT와 같은 구조입니다.

### 생성

추론 시:
```
generate z_1 = sample from p(z_1)                    # 1 token
generate z_2 = sample from p(z_2 | z_1)              # 4 tokens in parallel
generate z_3 = sample from p(z_3 | z_1, z_2)         # 16 tokens in parallel
...
decode: f = sum of embed-and-upsample scales 1..K
image = VAE_decoder(f)
```

K = 10개 스케일이면 생성은 트랜스포머 포워드 패스 10번입니다. 각 패스는 자기 스케일 전체를 병렬로 만들어 냅니다 — 스케일 안에서의 토큰 단위 자기회귀는 없습니다. 256x256 이미지 기준으로 대략 10번 패스로 DiT의 28~50번과 비교됩니다.

### 다음 토큰 예측보다 다음 스케일 예측이 이기는 이유

구조적인 이득이 세 가지입니다:
1. **거친 것에서 섬세한 것으로 가는 순서가 자연 이미지의 통계와 맞습니다.** 인간의 시각 지각도 이미지 데이터셋도 스케일에 따른 규칙성을 보입니다: 저주파 구조는 안정적이고 예측하기 쉽고, 고주파 디테일은 저주파 내용에 조건부입니다. 다음 스케일 예측은 바로 이 성질을 활용합니다.
2. **스케일 내 병렬 생성.** GPT 스타일 토큰 자기회귀와 달리, VAR은 한 스케일의 모든 토큰을 한 스텝에 만들어 냅니다. 실효 생성 길이가 선형이 아니라 로그 스케일로 줄어듭니다.
3. **생성 순서 편향이 없습니다.** 스케일 k의 토큰은 스케일 k-1 전체를 봅니다. "왼쪽"이나 "위쪽" 같은 편향이 없어서, 나중에 올 문맥을 못 본 채 초반 토큰이 억지로 확정되는 일이 없습니다.

### 스케일링 법칙

Tian et al.은 VAR이 ImageNet FID에 대해 거듭제곱(power-law) 스케일링 곡선을 따른다는 것을 보였습니다 — GPT가 퍼플렉시티에 대해 그러하듯이. 파라미터나 연산량을 두 배로 늘리면 오차가 확실히 절반으로 줄어듭니다. 언어 모델만큼 깔끔하게 이런 스케일링 행동을 보인 최초의 이미지 생성 모델이었습니다. 그 결과, VAR 규모에서의 성능 예측이 아키텍처마다의 경험적 추측이 아니라 연산량으로부터 예측 가능해집니다.

### 확산 모델과의 관계

VAR과 확산 모델은 같은 "데이터 압축" 이야기를 공유합니다. 둘 다 생성 문제를 더 쉬운 하위 문제들의 수열로 쪼갭니다.

- 확산: 점점 노이즈를 더하고, 한 스텝을 되돌리는 법을 배운다.
- VAR: 점점 해상도를 더하고, 다음 스케일을 예측하는 법을 배운다.

같은 문제를 다른 축으로 접근하는 것입니다. 둘 다 다루기 쉬운 조건부 분포를 얻습니다. 경험적으로 VAR은 추론이 더 빠르고(패스 수가 적고, 스케일 내부는 전부 병렬) 클래스 조건부 ImageNet에서 DiT와 맞먹거나 이깁니다. 텍스트 조건부 VAR(VARclip, HART)은 활발히 연구 중인 방향입니다.

## 직접 만들기

`code/main.py`에서 할 일:
1. 합성 "이미지" 데이터(2D 가우시안 링)로 작은 **멀티스케일 VQ 토크나이저**를 만듭니다.
2. **VAR 스타일 트랜스포머**를 학습해 다음 스케일 토큰을 예측하게 합니다.
3. 트랜스포머를 4번 호출(4개 스케일)하고 디코딩해서 샘플링합니다.
4. 스케일 순서로 학습하면 스케일 내 생성이 병렬로 동작하는지 확인합니다.

토이 구현입니다. 목적은 스케일 구조의 어텐션 마스크와 스케일 내 병렬 생성이 실제로 동작하는 모습을 보는 것입니다.

## 연습 문제

1. **스케일 수 소거 실험(ablation).** 스케일 4, 6, 8, 10개로 VAR을 학습합니다. 재구성 품질 대비 자기회귀 패스 수를 측정합니다. 스케일이 많을수록 = 잔차가 더 섬세 = 품질이 좋지만 패스가 더 많아집니다.

2. **코드북 크기.** 코드북 크기 512, 4096, 16384로 토크나이저를 학습합니다. 큰 코드북은 재구성은 좋아지지만 예측은 어려워집니다. 무릎(knee) 지점을 찾아 보세요.

3. **스케일 내 병렬성 확인.** 학습된 VAR에서 어텐션 패턴을 직접 측정합니다. 스케일 k 내부에서 모델은 스케일 간 위치에는 어텐션하고 스케일 내 위치에는 하지 않는지요? 마스크 구현을 검증하세요.

4. **VAR vs DiT 스케일링.** 같은 ImageNet 클래스 조건부 태스크에서, 맞춰진 파라미터 예산(예: 33M, 130M, 458M)으로 VAR과 DiT를 학습합니다. FID 대비 연산량을 그래프로 그립니다. 각 크기에서 VAR이 DiT를 앞서야 합니다 — 논문 결과를 소규모로 재현해 보세요.

5. **텍스트 조건화.** VAR이 텍스트 임베딩(CLIP pooled)을 adaLN을 통한 추가 조건 입력으로 받도록 확장합니다. 이것이 HART 레시피입니다. 텍스트 정렬 샘플링에서 FID가 얼마나 개선되는지요?

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|----------------|----------------------|
| VAR | "Visual AutoRegressive" | VQ 토큰 격자 피라미드 위에서 다음 스케일을 예측하는 이미지 생성 |
| Next-scale prediction | "거친 것부터, 그다음 섬세하게" | 모델이 해상도 스케일을 높여 가며 토큰을 예측하고, 모든 이전 스케일을 조건으로 삼음 |
| Multi-scale VQ tokenizer | "Residual VQ" | 해상도가 점점 높아지는 K개의 토큰 격자를 만들고, 디코더가 모든 스케일을 합산하는 VQ-VAE |
| Scale k | "피라미드 k층" | K개 해상도 레벨 중 하나. k=1에서 1x1부터 k=K에서 (H/p)x(W/p)까지 |
| Parallel-within-scale | "스케일당 포워드 한 번" | 스케일 k의 모든 토큰이 자기회귀가 아니라 트랜스포머 패스 한 번으로 예측됨 |
| Causal-across-scales | "스케일 순서 어텐션" | 스케일 k의 토큰은 스케일 1..k 전체는 볼 수 있지만 스케일 k+1..K는 볼 수 없음 |
| Residual VQ | "덧셈 토큰화" | 각 스케일의 토큰은 낮은 스케일이 남긴 잔차를 인코딩하며, 디코더는 모든 스케일 임베딩을 합산함 |
| VAR scaling law | "이미지 GPT 스케일링" | FID가 언어 모델의 퍼플렉시티처럼 연산량에 대해 예측 가능한 거듭제곱 법칙을 따름 |
| HART | "VAR + 텍스트 하이브리드" | MaskGIT 스타일 반복 디코딩과 VAR의 스케일 구조를 결합한 텍스트 조건부 VAR 변형 |
| Scale position embedding | "(scale, row, col) 트리플" | 위치 인코딩이 스케일 인덱스와 스케일 내 공간 좌표를 모두 담음 |
