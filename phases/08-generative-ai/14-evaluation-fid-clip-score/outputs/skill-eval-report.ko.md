> 🇰🇷 이 문서는 한국어 번역본입니다(ELI5 스타일). 원문: [skill-eval-report.md](skill-eval-report.md)

새 생성 모델 체크포인트, 레퍼런스 베이스라인, 모달리티(이미지 / 비디오 / 오디오 / 3D)가 주어지면 전체 평가 계획을 출력합니다:

1. 샘플 품질. 홀드아웃 실제 세트 대비 1만~3만 샘플의 FID / FD-DINO / CMMD. 해상도를 맞춥니다. 3시드 평균 +/- 표준편차를 보고합니다.
2. 순응도. 프롬프트-이미지 페어의 CLIP score / CMMD. 텍스트-이미지에는 HPSv2 + ImageReward + PickScore를 포함합니다. 비디오에는 시각-언어 지표(V-Eval)를 추가합니다. 오디오에는 CLAP + MOS.
3. 페어별 선호도. 베이스라인 대비 200~2000개 프롬프트의 블라인드 A/B. 인간 + LLM 심판 + PartiPrompts 커버리지.
4. 카테고리 분해. 프롬프트 카테고리별 성능(사람, 동물, 텍스트 렌더링, 구도, 스타일). 전역 지표가 좋아져도 카테고리별 하락은 표시합니다.
5. 안전 / 오용. 상위 K개 생성물에 대한 NSFW 분류기, 딥페이크 탐지기, 워터마크 검사, 저작권 유사성 스캔.
6. 사인오프. 명시적 게이트: FID가 베이스라인 +5% 이내이거나 인간 승률 &gt;55%이거나 문서화된 정성적 우위. 단일 지표 주장은 없습니다.

N &lt; 5000인 FID는 보고하지 않습니다. 모델이 학습에서 봤을 수 있는 프롬프트로 계산한 벤치마크는 출시하지 않습니다. 인간 교차 확인 없이 LLM 심판 결과만 보고하지 않습니다. 절대 기준값 보고 없이, 단일 시드 보고와 함께 "20% 올랐다"는 주장은 모두 표시합니다.
