# 생성 모델 — 분류와 역사

> 모든 이미지 모델, 텍스트 모델, 비디오 모델, 3D 모델은 다섯 바구니 중 하나에 들어갑니다. 잘못된 바구니를 고르면 수 주 동안 수학과 싸우게 되고, 올바른 바구니를 고르면 이 분야의 지난 12년 진보가 머릿속에 깔끔하게 쌓입니다.

**유형:** Learn
**언어:** Python
**선수 지식:** 페이즈 2(ML 기초), 페이즈 3(딥러닝 핵심), 페이즈 7 · 14(트랜스포머)
**시간:** 약 45분

## 문제 상황

생성 모델이 하는 일은 하나입니다: 어떤 미지의 분포 `p_data(x)`에서 뽑은 학습 샘플이 주어지면, 같은 분포에서 나온 것처럼 보이는 새 샘플을 출력하는 것입니다. 얼굴, 문장, MIDI 파일, 단백질 구조 — 눈을 가늘게 뜨고 보면 모두 같은 문제입니다.

문제는 `p_data`가 수백만 차원의 공간(512x512 RGB 이미지는 약 78만 6천 차원)에 살고, 샘플들은 그 공간 안의 얇은 다양체(manifold) 위에 놓여 있으며, 예시는 겨우 1천만 개 정도뿐이라는 점입니다. 밀도를 무작정 때려 맞추는 건 절망적이죠. 모든 생성 모델은 하나의 어려운 문제를 조금 덜 어려운 문제로 바꾸는 타협입니다.

다섯 계열이 지난 12년을 버텨 왔습니다. 각 계열이 어떤 타협을 하는지 알면, 왜 어떤 과제에서 이기고 어떤 과제에서 무너지는지가 보입니다.

## 개념

![생성 모델의 다섯 계열 — 무엇을 모델링하는지에 따른 분류](../assets/taxonomy.svg)

**1. 명시적 밀도, 계산 가능(tractable).** `log p(x)`를 실제로 계산할 수 있는 합으로 씁니다. 자기회귀 모델(PixelCNN, WaveNet, GPT)은 `p(x) = ∏ p(x_i | x_<i)`로 분해합니다. 정규화 플로우(normalizing flow, RealNVP, Glow)는 `p(x)`를 간단한 기저 분포의 가역 변환으로 만듭니다. 장점: 정확한 우도, 깔끔한 학습 손실. 단점: 자기회귀 추론은 순차적이라(긴 시퀀스에 느림), 플로우는 가역 아키텍처가 필요합니다(아키텍처 제약이 큼).

**2. 명시적 밀도, 근사.** `log p(x)`의 하한(ELBO)을 잡고 그 하한을 최적화합니다. VAE(Kingma, 2013)는 변분 사후 분포를 곁들인 인코더-디코더를 씁니다. 확산 모델(DDPM, Ho, 2020)은 가중 ELBO를 암묵적으로 최적화하는 디노이저를 학습합니다. 확산은 2026년 현재 이미지, 비디오, 3D의 지배적 백본입니다.

**3. 암시적 밀도.** 밀도를 완전히 건너뛰고, 샘플을 만들어 내는 생성자 `G(z)`와 진짜와 가짜를 구분하는 판별자 `D(x)`를 학습합니다. GAN(Goodfellow, 2014)입니다. 추론이 빠르지만(순전파 한 번) 학습 중 불안정하기로 악명 높습니다. StyleGAN 1/2/3은 2026년 현재까지도 고정 도메인 사실주의(얼굴, 침실)에서 최고 수준입니다.

**4. 점수 기반 / 연속 시간.** 로그 밀도의 그래디언트 `∇_x log p(x)`(점수, score)를 직접 학습합니다. Song & Ermon(2019)은 점수 매칭이 확산을 SDE로 일반화함을 보였습니다. 플로우 매칭(Lipman, 2023)은 2024~2026년의 화두입니다: 시뮬레이션 없는 학습, 더 곧은 경로, DDPM보다 4~10배 빠른 샘플링. Stable Diffusion 3, Flux, AudioCraft 2가 모두 플로우 매칭을 씁니다.

**5. 이산 코드 위의 토큰 기반 자기회귀.** 고차원 데이터를 VQ-VAE나 잔차 양자화기로 압축해 짧은 이산 토큰 시퀀스로 만들고, 트랜스포머로 그 토큰 시퀀스를 모델링합니다. Parti, MuseNet, AudioLM, VALL-E, Sora의 패치 토크나이저가 모두 이 방식을 씁니다. 바구니 1에 학습된 토크나이저를 얹은 것입니다.

## 다섯 질문 분류법

새 생성 모델 논문이 나오면, 방법론 섹션을 읽기 전에 이 다섯 질문에 답하세요.

1. **무엇을 모델링하는가?** 픽셀, 잠재 변수, 이산 토큰, 3D 가우시안, 메시, 파형?
2. **밀도가 명시적인가, 암시적인가?** `log p(x)`를 적어 두었는가?
3. **샘플링: 한 번에(one-shot)인가, 반복적인가?** 반복이면 추론이 느립니다; 한 번에면 보통 적대적이거나 증류된 모델입니다.
4. **조건화: 무조건, 클래스, 텍스트, 이미지, 포즈?** 이것이 손실과 아키텍처 뼈대를 결정합니다.
5. **평가: FID, CLIP 점수, IS, 인간 선호도, 과제 정확도?** 각각 알려진 실패 모드가 있습니다(레슨 14 참조).

이 페이즈의 모든 레슨에서 이 다섯 질문을 다시 답게 됩니다. 끝나면 반사적으로 답하게 될 겁니다.

## 만들어 보기

이 레슨의 코드는 가벼운 시각화입니다: 샘플로부터 1차원 가우시안 혼합을 세 가지 장난감 방식(커널 밀도, 이산 히스토그램, 최근접 샘플 'GAN 비슷한' 생성기)으로 피팅해, 한 화면에 인쇄할 수 있는 문제에서 명시적 밀도 vs 암시적 밀도의 차이를 눈으로 보여 줍니다.

`code/main.py`를 실행하세요. 두 개 모드의 가우시안 혼합에서 샘플 2,000개를 뽑은 뒤 다음을 출력합니다:

```
explicit density (histogram): p(x in [-0.5, 0.5]) ≈ 0.38
approximate density (KDE):     p(x in [-0.5, 0.5]) ≈ 0.41
implicit (nearest-sample gen): 20 new samples printed, no p(x)
```

주목할 점: 처음 둘은 "이 점이 나올 가능성이 얼마인가?"를 물을 수 있습니다. 셋째는 불가능합니다. 앞으로 모든 레슨에서 중요해질 *명시적 vs 암시적* 구분입니다.

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|-----------------|-----------------------|
| 생성 모델 | "새로운 것을 만든다" | `p_data(x)`의 샘플러를 학습하고, 선택적으로 `log p(x)`를 노출합니다. |
| 명시적 밀도 | "계산할 수 있다" | 모델이 닫힌 형태 또는 계산 가능한 `log p(x)`를 제공합니다. |
| 암시적 밀도 | "GAN 스타일" | 샘플러만 있음 — 주어진 점의 `p(x)`를 계산할 방법이 없습니다. |
| ELBO | "증거 하한" | `log p(x)`의 계산 가능한 하한; VAE와 확산이 이를 최적화합니다. |
| 점수(Score) | "로그 밀도의 그래디언트" | `∇_x log p(x)`; 확산과 SDE 모델이 이 장을 학습합니다. |
| 다양체 가설 | "데이터가 곡면 위에 산다" | 고차원 데이터는 저차원 다양체에 몰려 있다; 차원 축소가 동작하는 이유. |
| 자기회귀(Autoregressive) | "다음 조각을 예측" | 결합 분포를 조건부 분포의 곱으로 분해합니다. |
| 잠재 변수(Latent) | "압축된 코드" | 디코더가 입력을 재구성할 수 있는 저차원 표현. |

## 프로덕션 노트: 다섯 계열, 다섯 추론 모양

각 계열은 서로 다른 추론 서버 비용 곡선에 대응합니다. 프로덕션 추론 문헌은 LLM 추론을 프리필(prefill) + 디코드로 나누는데, 같은 분해가 여기에도 적용됩니다:

- **자기회귀(바구니 1과 5).** 순차 디코드가 지연 시간을 지배합니다; KV 캐시, 연속 배칭, 투기적 디코딩이 모두 그대로 적용됩니다.
- **VAE / 확산 / 플로우 매칭(바구니 2와 4).** LLM이 말하는 디코드가 없습니다. 비용 = `스텝 수 × 스텝 비용`이고, `스텝 비용`은 전체 잠재 해상도에서의 트랜스포머 또는 U-Net 순전파입니다. 프로덕션 다이얼은 스텝 수(DDIM / DPM-Solver / 증류), 배치 크기, 정밀도(bf16 / fp8 / int4)입니다.
- **GAN(바구니 3).** 순전파 한 번. 스케줄도, KV 캐시도 없습니다. TTFT ≈ 총 지연 시간입니다. StyleGAN이 좁은 도메인의 UX에서 아직도 이기는 이유입니다.

논문 초록에서 "확산보다 빠르다"는 문구를 보면 "스텝 수 감소 × 같은 스텝 비용" 또는 "같은 스텝 수 × 더 싼 스텝 비용"으로 번역하세요. 나머지는 마케팅입니다.
