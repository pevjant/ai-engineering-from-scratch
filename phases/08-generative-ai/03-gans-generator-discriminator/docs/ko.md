# GAN — 생성자 vs 판별자

> 2014년 Goodfellow의 트릭은 밀도를 완전히 건너뛴 것이었습니다. 네트워크 둘. 하나는 가짜를 만들고, 하나는 잡아냅니다. 가짜가 진짜와 구분 불가능해질 때까지 싸우죠. 작동할 리 없어 보입니다. 실제로 종종 작동하지 않습니다. 하지만 작동하는 순간, 좁은 도메인에서는 그 샘플들이 문헌상 여전히 가장 선명합니다.

**유형:** Build
**언어:** Python
**선수 지식:** 페이즈 3 · 02(역전파), 페이즈 3 · 08(옵티마이저), 페이즈 8 · 02(VAE)
**시간:** 약 75분

## 문제 상황

VAE가 흐릿한 샘플을 내는 이유는 MSE 디코더 손실이 *평균* 이미지에 대해 베이즈 최적이기 때문입니다 — 그럴듯한 숫자 여러 개의 평균은 흐릿한 숫자죠. 여러분이 원하는 것은 특정 타깃과의 픽셀별 근접성이 아니라 *그럴듯함*에 보상을 주는 손실입니다. 그럴듯함에는 닫힌 형태가 없습니다. 학습해 내야 합니다.

Goodfellow의 아이디어: 진짜 이미지와 가짜 이미지를 구분하는 분류기 `D(x)`를 학습시킵니다. `D`를 속이는 생성자 `G(z)`를 학습시킵니다. `G`에게 주어지는 손실 신호는, `D`가 현재 '진짜처럼 보이는 것'이라고 생각하는 무엇이든입니다. 이 신호는 `G`가 좋아질수록 갱신되며 움직이는 표적을 쫓습니다. 두 네트워크가 수렴하면 `G`는 `log p(x)`를 한 번도 적어 보지 않고 데이터 분포를 배운 것입니다.

이것이 적대적 학습입니다. 수학은 미니맥스 게임입니다:

```
min_G max_D  E_real[log D(x)] + E_fake[log(1 - D(G(z)))]
```

2026년 GAN은 더 이상 SOTA 생성기가 아닙니다(확산과 플로우 매칭이 그 왕관을 가져갔습니다). 하지만 StyleGAN 2/3은 여전히 역대 가장 선명한 얼굴 모델이고, GAN 판별자는 확산 학습에서 *지각 손실(perceptual loss)*로 쓰이며, 적대적 학습은 실시간 확산을 출시할 수 있게 해 주는 빠른 1스텝 증류(SDXL-Turbo, SD3-Turbo, LCM)를 떠받치고 있습니다.

## 개념

![GAN 학습: 미니맥스 속의 생성자와 판별자](../assets/gan.svg)

**생성자 `G(z)`.** 잡음 벡터 `z ~ N(0, I)`를 샘플 `x̂`로 사상합니다. 디코더 모양의 네트워크(dense 또는 전치 합성곱)입니다.

**판별자 `D(x)`.** 샘플을 스칼라 확률(또는 점수)로 사상합니다. 진짜 → 1, 가짜 → 0.

**손실.** 번갈아 수행하는 두 갱신:

- **`D` 학습:** `loss_D = -[ log D(x) + log(1 - D(G(z))) ]`. 진짜=1, 가짜=0에 대한 이진 교차 엔트로피.
- **`G` 학습:** `loss_G = -log D(G(z))`. 이것이 Goodfellow가 쓴 *비포화(non-saturating)* 형태입니다(원래의 `log(1 - D(G(z)))`는 `D`가 확신에 찼을 때 포화되어 그래디언트를 죽입니다).

**학습 루프.** `D` 한 스텝, `G` 한 스텝. 반복.

**작동하는 이유.** `G`가 `p_data`와 완벽히 일치하면 `D`는 운 이상은 못 하고 모든 곳에서 0.5를 출력합니다; `G`는 더 이상 그래디언트를 받지 못합니다. 평형 상태죠.

**무너지는 이유.** 모드 붕괴(`G`가 `D`가 분류 못 하는 모드 하나를 찾아 영원히 찍어냄), 사라지는 그래디언트(`D`가 너무 빨리 배워 `log D`가 포화됨), 학습 불안정(학습률, 배치 크기, 무엇이든).

## 만들어 보기

`code/main.py`는 1차원 데이터(두 가우시안의 혼합)에 아주 작은 GAN을 학습시킵니다. 생성자와 판별자는 은닉층 하나짜리 MLP입니다. 순전파, 역전파, 미니맥스 루프를 손으로 구현합니다. 목표는 두 핵심 실패 모드(모드 붕괴 + 사라지는 그래디언트)가 일어나는 순간을 직접 보는 것입니다.

### 단계 1: 비포화 손실

기본 Goodfellow 손실 `log(1 - D(G(z)))`는 D가 G의 가짜를 높은 확신으로 가짜로 분류하면 0으로 갑니다. 그 지점에서 G의 그래디언트는 사실상 0 — G는 개선할 수 없죠. 비포화 형태 `-log D(G(z))`는 반대 점근선을 갖습니다: D가 확신에 찰수록 폭발하며 G에게 강한 신호를 줍니다.

```python
def g_loss(d_fake):
    # log D(G(z)) 최대화  <=>  -log D(G(z)) 최소화
    return -sum(math.log(max(p, 1e-8)) for p in d_fake) / len(d_fake)
```

### 단계 2: 생성자 스텝마다 판별자 스텝 하나

```python
for step in range(steps):
    # train D
    real_batch = sample_real(batch_size)
    fake_batch = [G(z) for z in sample_noise(batch_size)]
    update_D(real_batch, fake_batch)

    # train G
    fake_batch = [G(z) for z in sample_noise(batch_size)]  # fresh fakes
    update_G(fake_batch)
```

G에는 새로운 가짜를 쓰세요. 그렇지 않으면 그래디언트가 오래된(stale) 것이 됩니다.

### 단계 3: 모드 붕괴 살피기

```python
if step % 200 == 0:
    samples = [G(z) for z in sample_noise(500)]
    mode_a = sum(1 for s in samples if s < 0)
    mode_b = 500 - mode_a
    if min(mode_a, mode_b) < 50:
        print("  [!] mode collapse: one mode is starved")
```

전형적인 증상: 진짜 두 모드 중 하나가 생성되기를 멈춥니다. 판별자는 그 모드를 가짜로 본 적이 없으므로 교정도 멈춥니다.

## 함정들

- **판별자가 너무 강함.** D의 학습률을 2~5배 줄이거나, 인스턴스/레이어 잡음을 더하세요. D의 정확도가 95%를 넘으면 G는 죽은 것입니다.
- **생성자가 모드 하나를 암기함.** D 입력에 잡음을 더하거나, 미니배치 판별자 레이어를 쓰거나, WGAN-GP로 전환하세요.
- **배치 정규화가 통계를 새는 문제.** 진짜 배치와 가짜 배치가 같은 BN 레이어를 통과하면 통계가 섞입니다. 인스턴스 정규화나 스펙트럼 정규화를 대신 쓰세요.
- **인셉션 점수 부정행위.** FID와 IS는 샘플 수가 적으면 잡음이 큽니다. 평가 때는 1만 개 이상의 샘플을 쓰세요.
- **조건부 과제에서 '한 번에 샘플링'은 거짓말.** 쓸 만한 출력을 얻으려면 여전히 CFG 스케일, 절단(truncation) 트릭, 재샘플링이 필요합니다.

GAN은 선명하지만 좁습니다. 도메인이 열리는 순간 — 사진, 임의 텍스트 프롬프트, 비디오 — 확산으로 갈아타세요. 적대적 트릭은 단독 생성기가 아니라 부품(지각 손실, 증류)으로 살아남습니다.

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|-----------------|-----------------------|
| 생성자(Generator) | "G" | 잡음-샘플 네트워크, `G: z → x̂`. |
| 판별자(Discriminator) | "D" | 분류기 `D: x → [0, 1]`, 진짜 vs 가짜. |
| 미니맥스(Minimax) | "그 게임" | 공동 목적에 대한 `min_G max_D`. |
| 비포화 손실 | "그 해결책" | G에는 `log(1 - D(G(z)))` 대신 `-log D(G(z))`를 씁니다. |
| 모드 붕괴 | "G가 하나를 통째로 외움" | 다양한 데이터에도 생성자가 몇 개 안 되는 서로 다른 출력만 냅니다. |
| WGAN | "바서슈타인" | BCE를 지구 이동기(earth-mover) 거리 + 그래디언트 페널티로 교체; 더 매끄러운 그래디언트. |
| 스펙트럼 정규화 | "립시츠 트릭" | D의 가중치 노름을 제약해 기울기를 묶음; 학습을 안정화합니다. |
| StyleGAN | "되는 그것" | 매핑 네트워크 + AdaIN; 얼굴에서는 최고 수준, 2026년에도. |

## 프로덕션 노트: 한 번에 끝나는 추론이 GAN의 지속적인 강점

GAN은 개방 도메인 생성의 샘플 품질에서는 더 이상 이기지 못하지만, 추론 비용에서는 여전히 이깁니다. 프로덕션 추론 문헌의 어휘로 GAN은:

- **프리필도 디코드 단계도 없음.** `G(z)` 순전파 한 번. TTFT ≈ 총 지연 시간.
- **KV 캐시 부담 없음.** 유일한 상태는 가중치입니다. 배치 크기는 캐시가 아니라 활성화 메모리로 제한됩니다.
- **자명한 연속 배칭.** 모든 요청이 같은 고정 FLOPs를 쓰므로, 서버의 목표 점유율에 맞춘 정적 배치가 보통 최적입니다. 실시간 스케줄러가 필요 없습니다.

이 때문에 GAN 증류(SDXL-Turbo, SD3-Turbo, ADD, LCM)가 2026년 빠른 텍스트-이미지의 지배적 기법입니다: 20~50스텝 확산 파이프라인을 1~4번의 GAN 스타일 순전파로 접어 내리면서도 확산 베이스의 분포를 유지합니다. 적대적 손실은 느린 생성기를 빠른 생성기로 바꾸는 학습 시점의 다이얼로 살아남았습니다.
