# 플로우 매칭과 정류 흐름(Rectified Flow)

> 확산 모델은 잡음에서 데이터까지 구부러진 경로를 걷기 때문에 샘플링 스텝 20-50번이 필요합니다. 플로우 매칭(Lipman 외, 2023)과 정류 흐름(Liu 외, 2022)은 곧은 경로를 학습시킵니다. 경로가 곧으면 스텝이 줄고, 스텝이 줄면 추론이 빨라집니다. Stable Diffusion 3, Flux.1, AudioCraft 2가 2024년 모두 플로우 매칭으로 갈아탔습니다.

**유형:** Build
**언어:** Python
**선수 지식:** 페이즈 8 · 06(DDPM), 페이즈 1 · 미적분
**시간:** 약 45분

## 문제 상황

DDPM의 역방향 과정은 `N(0, I)`에서 데이터 분포로 돌아가는 1000스텝짜리 확률적 보행입니다. DDIM은 이를 20-50스텝의 결정론적 보행으로 줄였습니다. 여러분은 더 적은 스텝 — 이상적으로는 한 스텝 — 을 원합니다. 걸림돌은 역방향 과정을 푸는 ODE가 강(stiff)하고 경로가 구부러져 있다는 점입니다.

잡음에서 데이터까지의 경로가 *직선*이 되도록 모델을 학습시킬 수 있다면, `t=1`에서 `t=0`으로 가는 Euler 스텝 한 번으로 끝납니다. 플로우 매칭은 이것을 직접 만듭니다: `x_1 ∼ N(0, I)`에서 `x_0 ∼ data`까지의 직선 보간을 정의하고, 그 시간 도함수와 일치하도록 벡터 장 `v_θ(x, t)`를 학습시킨 뒤, 추론 때 적분합니다.

정류 흐름(Liu 2022)은 한 발 더 나아갑니다: reflow 절차로 경로를 반복적으로 곧게 만들어 점점 선형에 가까운 ODE를 만들어 냅니다. reflow 두 번이면 2스텝 샘플러가 50스텝 DDPM 품질에 맞먹습니다.

## 개념

![플로우 매칭: 잡음과 데이터 사이의 직선 보간](../assets/flow-matching.svg)

### 직선 흐름

정의:

```
x_t = t · x_1 + (1 - t) · x_0,   t ∈ [0, 1]
```

여기서 `x_0 ~ data`이고 `x_1 ~ N(0, I)`입니다. 이 직선을 따르는 시간 도함수는 상수입니다:

```
dx_t / dt = x_1 - x_0
```

신경 벡터 장 `v_θ(x_t, t)`를 정의하고 이 도함수와 일치하도록 학습시킵니다:

```
L = E_{x_0, x_1, t} || v_θ(x_t, t) - (x_1 - x_0) ||²
```

이것이 **조건부 플로우 매칭** 손실입니다(Lipman 2023). 학습은 시뮬레이션 불필요(simulation-free)입니다: ODE를 펼쳐 놓을 필요가 전혀 없습니다. `(x_0, x_1, t)`를 샘플링하고 회귀만 하면 됩니다.

### 샘플링

추론 때는 학습된 벡터 장을 시간의 *반대 방향*으로 적분합니다:

```
x_{t-Δt} = x_t - Δt · v_θ(x_t, t)
```

`x_1 ~ N(0, I)`에서 시작해 Euler 스텝으로 `t=0`까지 내려갑니다.

### 정류 흐름 (Liu 2022)

직선 흐름은 작동하지만 학습된 경로는 *실제로 곧지는 않습니다* — 많은 `x_0`이 같은 `x_1`로 사상될 수 있어 휘어집니다. 정류 흐름의 reflow 단계:

1. 무작위 페어링으로 흐름 모델 v_1을 학습시킵니다.
2. v_1을 `x_1`에서 착지점 `x_0`까지 적분해 N개 페어 `(x_1, x_0)`를 샘플링합니다.
3. 그 페어 예시로 v_2를 학습시킵니다. 페어가 이제 "ODE로 맞춰진" 것이므로, 그 사이의 직선 보간은 진짜로 더 평평합니다.
4. 반복합니다.

실전에서는 reflow 두 번이면 거의 선형에 도달해 2-4스텝 추론이 가능해집니다. SDXL-Turbo, SD3-Turbo, LCM은 모두 플로우 매칭에서 증류된 모델입니다.

### 2024년 이미지에서 이긴 이유

세 가지 이유:

1. **시뮬레이션 불필요 학습** — 학습 중 ODE 전개가 없고 구현이 지극히 간단합니다.
2. **더 나은 손실 기하학** — 곧은 경로는 일관된 신호 대 잡음비를 가지는 반면, DDPM ε-손실은 스케줄의 끝단에서 SNR이 나쁩니다.
3. **더 빠른 추론** — SDXL-Turbo 품질에서 4-8스텝; 일관성 증류로 1스텝.

## 플로우 매칭 vs DDPM — 정확한 연결

가우시안 조건 경로를 쓰는 플로우 매칭은 *특정 잡음 스케줄을 쓰는* 확산입니다. `x_t = α(t) x_0 + σ(t) x_1` 스케줄을 고르면 플로우 매칭은 `v = α'·x_0 - σ'·x_1`인 스트라토노비치 재정식화 확산을 복원합니다. 가우시안 경로에 한해 둘은 대수적으로 동치입니다.

플로우 매칭이 더한 것: 타깃의 *명료함*(단순한 속도), 더 깔끔한 손실, 그리고 비가우시안 보간을 실험할 면허입니다.

## 만들어 보기

`code/main.py`는 두 모드 가우시안 혼합에 대해 1차원 플로우 매칭을 구현합니다. 벡터 장 `v_θ(x, t)`는 직선 타깃으로 학습되는 작은 MLP입니다. 추론 때는 Euler 스텝 1, 2, 4, 20번을 적분하며 샘플 품질을 비교합니다.

### 단계 1: 학습 손실

```python
def train_step(x0, net, rng, lr):
    x1 = rng.gauss(0, 1)
    t = rng.random()
    x_t = t * x1 + (1 - t) * x0
    target = x1 - x0
    pred = net_forward(x_t, t)
    loss = (pred - target) ** 2
    # 역전파 + 갱신
```

### 단계 2: 멀티스텝 추론

```python
def sample(net, num_steps):
    x = rng.gauss(0, 1)
    for i in range(num_steps):
        t = 1.0 - i / num_steps
        dt = 1.0 / num_steps
        x -= dt * net_forward(x, t)
    return x
```

### 단계 3: 스텝 수 비교

4스텝 샘플러가 이미 20스텝 품질에 맞먹을 겁니다 — 지연 시간 관점에서 대단한 일입니다.

## 함정들

- **시간 파라미터화.** 플로우 매칭은 `t ∈ [0, 1]`을 쓰고 `t=0`이 데이터, `t=1`이 잡음입니다. DDPM은 `t ∈ [0, T]`를 쓰고 `t=0`이 데이터, `t=T`가 잡음입니다. 방향은 같은데 스케일이 다릅니다. 논문들이 끊임없이 이걸 틀립니다.
- **스케줄 선택.** 정류 흐름의 직선이 "그" 플로우 매칭 스케줄이지만, 더 나은 스케일 커버리지를 위해 코사인이나 로짓-정규 t 샘플링(SD3가 씁니다)을 쓸 수도 있습니다.
- **reflow 비용.** reflow용 페어 데이터셋을 만들려면 샘플마다 전체 추론 패스가 필요합니다. 정말 1-2스텝 추론이 필요할 때만 reflow하세요.
- **Classifier-free guidance는 여전히 적용됩니다.** 선형 결합에서 ε를 v로 바꾸기만 하면 됩니다: `v_cfg = (1+w) v_cond - w v_uncond`.

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|-----------------|-----------------------|
| 플로우 매칭 | "직선 확산" | 보간 경로를 따라 `x_1 - x_0`과 일치하도록 `v_θ(x, t)`를 학습. |
| 정류 흐름 | "reflow" | 학습된 흐름을 곧게 펴는 반복 절차. |
| 속도 장 | "v_θ" | 모델의 출력 — `x_t`를 움직일 방향. |
| 직선 보간 | "그 경로" | `x_t = (1-t)·x_0 + t·x_1`; 타깃 도함수는 자명합니다. |
| Euler 샘플러 | "1차 ODE 솔버" | 가장 단순한 적분기; 경로가 곧을 때 잘 통합니다. |
| 로짓-정규 t | "SD3 샘플링" | 그래디언트가 가장 강한 중간값 쪽으로 `t` 샘플링을 몰아넣습니다. |
| 일관성 증류 | "1스텝 샘플러" | 임의의 `x_t`를 `x_0`로 직접 사상하도록 학생을 학습시킵니다. |
| 속도를 쓰는 CFG | "v-CFG" | `v_cfg = (1+w) v_cond - w v_uncond`; 같은 트릭, 새 변수. |

## 프로덕션 노트: Flux.1-schnell은 가장 빠른 플로우 매칭

플로우 매칭의 프로덕션 승리가 바로 Flux.1-schnell입니다 — Flux-dev급 품질을 유지하면서 1-4 추론 스텝으로 증류된 플로우 매칭 DiT죠. Niels의 "8GB 머신에서 Flux 돌리기" 노트북이 레퍼런스 배포 레시피입니다: T5 + CLIP 인코딩, 양자화된 MMDiT 잡음 제거(schnell은 4스텝, dev는 50스텝), VAE 디코드. 비용 계산은 이렇습니다:

| 변형 | 스텝 | L4에서 1024² 지연 시간 | 총 FLOPs (상대값) |
|---------|-------|------------------------|------------------------|
| Flux.1-dev (원본) | 50 | ~15 s | 1.0× |
| Flux.1-schnell | 4 | ~1.2 s | 0.08× (12배 빠름) |
| SDXL-base | 30 | ~4 s | 0.25× |
| SDXL-Lightning 2스텝 | 2 | ~0.3 s | 0.03× |

프로덕션 규칙: **플로우 매칭 베이스 + 증류 = 빠른 텍스트-이미지의 2026년 기본값.** 모든 주요 벤더가 이 조합을 출시합니다: SD3-Turbo(SD3 + 플로우 + 증류), Flux-schnell(Flux-dev + 정류 흐름 직선화), CogView-4-Flash. 순수 확산 베이스는 레거시 체크포인트에만 존재합니다.
