# StyleGAN

> 대부분의 생성자는 `z`를 모든 레이어에 한꺼번에 섞어 넣습니다. StyleGAN은 이를 갈라 놓았습니다: 먼저 `z`를 중간 표현 `w`로 사상한 뒤, AdaIN을 통해 모든 해상도 단계에 `w`를 *주입*합니다. 이 단 하나의 변화가 잠재 공간을 풀어 놓았고, 사실적 얼굴 생성을 7년 연속 풀린 문제로 만들었습니다.

**유형:** Build
**언어:** Python
**선수 지식:** 페이즈 8 · 03(GAN), 페이즈 4 · 08(정규화), 페이즈 3 · 07(CNN)
**시간:** 약 45분

## 문제 상황

DCGAN은 `z`를 전치 합성곱 층들에 통과시켜 이미지로 만듭니다. 문제는: `z`가 모든 것을 통제한다는 점입니다 — 포즈, 조명, 신원, 배경이 한데 얽혀 있죠. `z`의 한 축을 따라 움직이면 넷이 모두 변합니다. 모델에게 "같은 사람, 다른 포즈"를 요청할 수 없습니다. 표현이 그런 식으로 분해되지 않기 때문입니다.

Karras 외(2019, NVIDIA)가 제안한 것: `z`를 conv 층에 직접 먹이지 마세요. 학습된 상수 `4×4×512` 텐서를 네트워크 입력으로 주고, `z ∈ Z → w ∈ W`로 사상하는 8층 MLP를 학습합니다. *적응형 인스턴스 정규화*(AdaIN)로 모든 해상도에 `w`를 주입합니다: 각 conv 특성 맵을 정규화한 뒤, `w`의 아핀 사영으로 스케일하고 이동시킵니다. 확률적 디테일(피부 모공, 머리카락)을 위해 레이어별 잡음을 더합니다.

결과: `W`에는 "고수준 스타일"(포즈, 신원)과 "세부 스타일"(조명, 색)을 나타내는 거의 직교하는 축들이 생깁니다. 저해상도 단계에는 이미지 A의 `w`를, 고해상도 단계에는 이미지 B의 `w`를 써서 두 이미지 사이에 스타일을 섞을 수 있습니다. 이것이 편집, 교차 도메인 스타일화, 그리고 "StyleGAN 인버전" 연구 계열 전체를 열어 주었습니다.

## 개념

![StyleGAN: 매핑 네트워크 + AdaIN + 레이어별 잡음](../assets/stylegan.svg)

**매핑 네트워크.** `f: Z → W`, 8층 MLP. `Z = N(0, I)^512`. `W`는 가우시안일 것을 강요받지 않습니다 — 데이터에 맞춘 모양을 학습합니다.

**합성 네트워크.** 학습된 상수 `4×4×512`에서 시작합니다. 각 해상도 블록: `업샘플 → conv → AdaIN(w_i) → 잡음 → conv → AdaIN(w_i) → 잡음`. 해상도는 두 배씩 늘어납니다: 4, 8, 16, 32, 64, 128, 256, 512, 1024.

**AdaIN.**

```
AdaIN(x, y) = y_scale · (x - mean(x)) / std(x) + y_bias
```

여기서 `y_scale`과 `y_bias`는 `w`의 아핀 사영에서 나옵니다. 특성 맵별로 정규화한 뒤 스타일을 다시 입힙니다. 여기서 "스타일"이란 특성 맵의 1차·2차 통계량입니다.

**레이어별 잡음.** 각 특성 맵에 더해지는 단일 채널 가우시안 잡음으로, 학습된 채널별 계수로 스케일됩니다. 전역 구조를 흔들지 않으면서 확률적 디테일을 통제합니다.

**절단 트릭(truncation trick).** 추론 때 `z`를 샘플링하고, `w = mapping(z)`를 계산한 뒤, `w' = ŵ + ψ·(w - ŵ)`를 적용합니다. 여기서 `ŵ`는 수많은 샘플에 대한 평균 `w`입니다. `ψ < 1`이면 다양성을 품질과 맞바꿉니다. 거의 모든 StyleGAN 데모가 `ψ ≈ 0.7`을 씁니다.

## StyleGAN 1 → 2 → 3

| 버전 | 연도 | 혁신 |
|---------|------|------------|
| StyleGAN | 2019 | 매핑 네트워크 + AdaIN + 잡음 + progressive growing. |
| StyleGAN2 | 2020 | 가중치 디모듈레이션이 AdaIN을 대체(물방울 아티팩트 수정); 스킵/잔차 아키텍처; 경로 길이 정규화. |
| StyleGAN3 | 2021 | 앨리어스 프리 합성곱 + 등변 커널; 픽셀 그리드에 달라붙는 텍스처를 제거. |
| StyleGAN-XL | 2022 | 클래스 조건부, 1024², ImageNet. |
| R3GAN | 2024 | 더 강한 정규화로 리브랜딩; 파라미터를 20배 덜 쓰면서 FFHQ-1024에서 확산과의 격차를 해소. |

2026년 StyleGAN3는 (a) 높은 FPS가 필요한 좁은 도메인 사실주의, (b) 퓨샷 도메인 적응(이미지 100장으로 새 데이터셋 학습, 매핑은 고정), (c) 인버전 기반 편집(실제 사진을 재구성하는 `w`를 찾은 뒤 그 `w`를 편집)의 기본 선택지로 남아 있습니다. 오픈 도메인 텍스트-이미지에는 맞는 도구가 아닙니다 — 그건 확산의 영역입니다.

## 만들어 보기

`code/main.py`는 1차원으로 장난감 "스타일-GAN 라이트"를 구현합니다: 매핑 MLP, 학습된 상수 벡터를 `w`에서 유도한 스케일/바이어스로 변조하는 합성 함수, 레이어별 잡음. `w`를 아핀 변조로 주입하는 것이 `z`를 생성자 입력에 연결하는 것과 같거나 더 낫다는 것을 보여 줍니다.

### 단계 1: 매핑 네트워크

```python
def mapping(z, M):
    h = z
    for i in range(num_layers):
        h = leaky_relu(add(matmul(M[f"W{i}"], h), M[f"b{i}"]))
    return h
```

### 단계 2: 적응형 인스턴스 정규화

```python
def adain(x, w_scale, w_bias):
    mu = mean(x)
    sd = std(x)
    x_norm = [(xi - mu) / (sd + 1e-8) for xi in x]
    return [w_scale * xi + w_bias for xi in x_norm]
```

특성 맵별 스케일과 바이어스는 선형 사영을 통해 `w`에서 나옵니다.

### 단계 3: 레이어별 잡음

```python
def add_noise(x, sigma, rng):
    return [xi + sigma * rng.gauss(0, 1) for xi in x]
```

채널별 시그마는 학습 대상입니다.

## 함정들

- **물방울 아티팩트.** StyleGAN 1은 AdaIN이 평균을 0으로 만들면서 특성 맵에 물방울 같은 얼룩을 만들었습니다. StyleGAN 2의 가중치 디모듈레이션은 활성값 대신 합성곱 가중치를 스케일해서 이를 고칩니다.
- **텍스처 달라붙음.** StyleGAN 1과 2의 텍스처는 객체 좌표가 아니라 픽셀 좌표를 따랐습니다(보간할 때 드러남). StyleGAN 3의 앨리어스 프리 합성곱이 윈도우드 sinc 필터로 이를 고칩니다.
- **모드 커버리지.** 절단 `ψ < 0.7`은 깔끔해 보이지만 좁은 원뿔 안에서만 샘플링합니다. 다양성이 필요하면 `ψ = 1.0`을 쓰세요.
- **인버전은 손실이 있습니다.** 실제 사진을 `W`로 되돌리는 인버전은 보통 최적화나 인코더(e4e, ReStyle, HyperStyle)로 이루어집니다. 반복이 거듭될수록 결과가 흘러갑니다.

## 사용해 보기

| 사용 사례 | 접근 |
|----------|----------|
| 사실적인 인간 얼굴(애니메이션, 제품, 좁은 도메인) | StyleGAN3 FFHQ / 커스텀 파인튜닝 |
| 사진 한 장에서 얼굴 편집 | e4e 인버전 + StyleSpace / InterFaceGAN 방향 |
| 얼굴 교체 / 리인액트먼트 | StyleGAN + 인코더 + 블렌딩 |
| 아바타 파이프라인 | 저데이터 파인튜닝에 ADA를 얹은 StyleGAN3 |
| 이미지 몇 장으로 도메인 적응 | 매핑 네트워크 고정, 합성 네트워크만 파인튜닝 |
| 멀티모달 또는 텍스트 조건 생성 | 하지 마세요 — 확산을 쓰세요 |

정답이 "사람 얼굴 사진"인 제품급 데모에서 StyleGAN은 추론 비용(순전파 한 번, 4090에서 10ms 미만)과 같은 품질 기준에서의 선명함 면에서 확산을 이깁니다.

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|-----------------|-----------------------|
| 매핑 네트워크 | "그 MLP" | `f: Z → W`, 8층, 잠재 기하학을 데이터 통계에서 분리합니다. |
| W 공간 | "스타일 공간" | 매핑 네트워크의 출력; 대체로 분리되어 있음. |
| AdaIN | "적응형 인스턴스 정규화" | 특성 맵을 정규화한 뒤 `w` 사영으로 스케일 + 이동. |
| 절단 트릭 | "프사이(Psi)" | `w = mean + ψ·(w - mean)`, ψ<1이면 다양성을 품질과 맞바꿈. |
| 경로 길이 정규화 | "PL reg" | `w`의 단위 변화당 이미지 변화가 크면 벌줌; `W`를 매끄럽게 만듭니다. |
| 가중치 디모듈레이션 | "StyleGAN2의 수정" | 활성값 대신 conv 가중치를 정규화; 물방울 아티팩트 제거. |
| 앨리어스 프리 | "StyleGAN3의 트릭" | 윈도우드 sinc 필터; 픽셀 그리드에 달라붙는 텍스처를 제거. |
| 인버전 | "실제 이미지의 w 찾기" | `G(w) ≈ x`가 되도록 `x → w`를 최적화하거나 인코딩. |

## 프로덕션 노트: 2026년에도 StyleGAN이 출시되는 이유

4090의 StyleGAN3는 10ms 안에 1024² FFHQ 얼굴을 만들어 냅니다 — `num_steps = 1`, VAE 디코드 없음, 크로스 어텐션 패스 없음. 프로덕션 용어로 이것이 모든 이미지 생성기의 지연 시간 하한입니다. 같은 해상도의 50스텝 SDXL + VAE 디코드 파이프라인은 약 3초입니다. 그것은 **300배 격차**이고, 좁은 도메인 제품(아바타 서비스, 신분증 파이프라인, 스톡 얼굴 생성)에서는 TCO(총소유비용)에서 이깁니다.

운영상의 귀결 두 가지:

- **스케줄러도 배처도 필요 없음.** 목표 점유율에 맞춘 정적 배치가 최적입니다. 연속 배칭(LLM과 확산에 필수)은 모든 요청이 같은 FLOPs를 쓰기 때문에 아무 이득도 없습니다.
- **절단 `ψ`가 안전 노브입니다.** `ψ < 0.7`이면 매핑 네트워크 출력 범위의 좁은 원뿔 안에서 샘플링합니다. 샘플 분산에 대해 서빙 계층이 잡을 수 있는 유일한 레버입니다. 피크 부하에는 `ψ`를 낮추고, 프리미엄 사용자에게는 올리세요.
