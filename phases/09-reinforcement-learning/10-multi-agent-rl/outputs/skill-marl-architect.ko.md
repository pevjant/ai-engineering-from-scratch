> 🇰🇷 이 문서는 한국어 번역본입니다(ELI5 스타일). 원문: [skill-marl-architect.md](skill-marl-architect.md)

에이전트 `n`개가 있는 과제가 주어지면 다음을 출력합니다:

1. 체계 분류. 협력 / 적대 / 일반합. 근거를 댄다.
2. 알고리즘. IPPO / MAPPO / QMIX / 셀프 플레이 / 리그. 결합 밀도와 보상 구조에 근거한 이유를 붙인다.
3. 정보 접근. 중앙집중 학습(어떤 전역 정보를 크리틱에 준가)? 분산 실행인가?
4. 크레딧 할당. 반사실적 베이스라인, 가치 분해, 또는 보상 설계.
5. 탐험 계획. 에이전트별 엔트로피, 개체군 기반 학습, 또는 리그.

촘촘하게 결합된 협력 과제에는 독립 Q-러닝을 권하지 않는다. 순환 위험이 있는 일반합 상황에는 셀프 플레이를 권하지 않는다. 고정 상대 평가가 없는 MARL 파이프라인은 표시한다(뽑아 낸 셀프 플레이 수치는 흔하다).
