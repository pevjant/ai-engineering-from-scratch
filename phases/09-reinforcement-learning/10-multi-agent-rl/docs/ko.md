# 멀티 에이전트 강화 학습 (Multi-Agent RL)

> 🇰🇷 이 문서는 한국어 번역본입니다(ELI5 스타일). 원문: [en.md](en.md)

> 단일 에이전트 RL은 환경이 고정되어 있다고 가정합니다. 그런데 학습 중인 에이전트 둘을 같은 세계에 놓는 순간 이 가정은 무너집니다. 각 에이전트가 상대의 환경 일부가 되고, 둘 다 계속 변하기 때문입니다. 멀티 에이전트 RL은 마르코프 가정이 더 이상 성립하지 않을 때도 학습이 수렴하도록 만들어 주는 여러 가지 기법의 모음입니다.

**유형:** Build
**언어:** Python
**선수 지식:** 페이즈 9 · 04 (Q-러닝), 페이즈 9 · 06 (REINFORCE), 페이즈 9 · 07 (액터-크리틱)
**소요 시간:** 약 45분

## 문제 상황

방 안을 돌아다니는 법을 배우는 로봇은 단일 에이전트 RL 문제입니다. 하지만 축구팀은 그렇지 않습니다. AlphaStar가 StarCraft 상대와 겨루는 것도, 입찰 에이전트들이 모인 시장도, 두 자동차가 교차로에서 양보를 조율하는 상황도, 다대다로 얽힌 실세계 문제들도 모두 그렇지 않습니다.

모든 멀티 에이전트 상황에서, 어떤 한 에이전트의 눈으로 보면 다른 에이전트들 *자체가* 환경의 일부입니다. 다른 에이전트들이 학습하며 행동을 바꾸면 환경은 비정상적(non-stationary)이 됩니다. "다음 상태는 현재 상태와 내 행동에만 달려 있다"는 마르코프 성질이 깨집니다. 다음 상태가 *다른* 에이전트들의 선택에도 달려 있고, 그들의 정책은 끊임없이 움직이는 과녁이기 때문입니다.

이로 인해 테이블 기반 수렴 증명(Q-러닝의 수렴 보장은 정지된 환경을 가정합니다)도 깨지고, 순진한 딥 RL도 깨집니다. 에이전트들이 서로를 쫓는 루프에 빠져 안정적인 정책으로 수렴하지 못합니다. 그래서 멀티 에이전트 전용 기법이 필요합니다: 중앙집중 학습 / 분산 실행(centralized training / decentralized execution), 반사실적 베이스라인, 리그 플레이, 셀프 플레이가 그것입니다.

2026년의 응용 분야: 로봇 군집, 교통 경로 배차, 자율주행차 플릿, 시장 시뮬레이터, 멀티 에이전트 LLM 시스템(페이즈 16), 그리고 똑똑한 플레이어가 둘 이상인 모든 게임이 여기에 속합니다.

## 핵심 개념

![네 가지 MARL 체계: 독립 학습, 중앙집중식 크리틱, 셀프 플레이, 리그](../assets/marl.svg)

**형식화: 마르코프 게임(Markov Game).** MDP의 일반화입니다. 상태 `S`, 결합 행동(joint action) `a = (a_1, …, a_n)`, 전이 `P(s' | s, a)`, 그리고 에이전트별 보상 `R_i(s, a, s')`로 구성됩니다. 각 에이전트 `i`는 자신의 정책 `π_i` 아래에서 자신의 반환값을 최대화합니다. 보상이 모두 같으면 **완전 협력(cooperative)**, 합이 0이면 **적대적(adversarial)**, 섞여 있으면 **일반합(general-sum)** 상황입니다.

**핵심 난제:**

- **비정상성(non-stationarity).** 에이전트 `i`의 눈에 보이는 `P(s' | s, a_i)`는 `π_{-i}`(다른 에이전트들의 정책)에 의존하는데, 이것이 계속 변합니다.
- **크레딧 할당(credit assignment).** 보상을 공유한다면, 그 보상을 만든 주범이 누구인가?
- **탐험 조율.** 에이전트들은 같은 상태를 중복해서 탐험하는 게 아니라 서로 보완적인 전략을 탐험해야 합니다.
- **확장성.** 결합 행동 공간은 `n`에 대해 지수적으로 커집니다.
- **부분 관측 가능성.** 각 에이전트는 자기 관측만 볼 수 있고, 전역 상태는 숨겨져 있습니다.

**지배적인 네 가지 체계:**

**1. 독립 Q-러닝 / 독립 PPO (IQL, IPPO).** 각 에이전트가 자기만의 Q나 정책을 학습하고, 다른 에이전트는 환경의 일부로 취급합니다. 단순하고, 때로는 통합니다(특히 경험 리플레이가 상대를 부드럽게 모델링하는 완충 역할을 해 줄 때). 이론적 수렴 보장: 없음. 실제로는: 느슨하게 결합된 과제에는 충분하고, 촘촘하게 결합된 과제에는 나쁩니다.

**2. 중앙집중 학습, 분산 실행 (CTDE).** 요즘 가장 흔한 패러다임. 각 에이전트는 지역 관측 `o_i`에만 의존하는 자기만의 *정책* `π_i`를 가집니다 — 배포 시점에는 표준적인 분산 실행입니다. 반면 *학습* 때는 중앙집중식 크리틱(critic) `Q(s, a_1, …, a_n)`이 전역 상태와 결합 행동 전체를 입력으로 받습니다. 예시:
- **MADDPG**(Lowe 등, 2017): 에이전트마다 중앙집중식 크리틱을 둔 DDPG.
- **COMA**(Foerster 등, 2017): 반사실적 베이스라인 — "내가 행동 `a'`를 골랐더라면 보상이 어땠을까?"라고 물어 내 기여분만 분리해 냅니다.
- **MAPPO** / **공유 크리틱을 쓰는 IPPO**(Yu 등, 2022): 중앙집중식 가치 함수를 얹은 PPO. 2026년 협력 MARL의 주류입니다.
- **QMIX**(Rashid 등, 2018): 가치 분해 — 단조(monotonic) 믹싱으로 `Q_tot(s, a) = f(Q_1(s, a_1), …, Q_n(s, a_n))`을 근사합니다.

**3. 셀프 플레이(self-play).** 같은 에이전트의 두 복사본이 서로 대결합니다. 상대의 정책이란 곧 과거 스냅샷의 내 정책입니다. AlphaGo / AlphaZero / MuZero, OpenAI Five가 여기에 속합니다. 제로섬 게임에서 가장 잘 통합니다. 학습 신호가 대칭이기 때문입니다.

**4. 리그 플레이(league play).** 셀프 플레이를 일반합 / 적대적 환경으로 확장한 형태: 과거와 현재 정책들의 개체군을 유지하고, 리그에서 상대를 샘플링해 그와 싸우며 학습합니다. 여기에 익스플로이터(exploiter — 현재 최강자를 이기는 데 특화)와 메인 익스플로이터(익스플로이터를 이기는 데 특화)를 추가합니다. AlphaStar(StarCraft II)가 대표 사례입니다. 게임에 "가위바위보" 식 전략 순환이 있을 때 필요합니다.

**커뮤니케이션.** 에이전트들이 학습된 메시지 `m_i`를 서로 주고받게 할 수도 있습니다. 협력 상황에서 통합니다. Foerster 등(2016)은 에이전트 간 미분 가능한 통신을 엔드투엔드로 학습할 수 있음을 보였습니다. 오늘날의 LLM 기반 멀티 에이전트 시스템(페이즈 16)은 사실상 자연어로 소통합니다.

## 직접 만들기

이 레슨은 협력하는 두 에이전트가 있는 6×6 GridWorld를 사용합니다. 두 에이전트는 마주 보는 모서리에서 출발해 공유 목표에 함께 도착해야 합니다. 공유 보상: 어느 한쪽이라도 아직 움직이고 있는 동안에는 단계당 `-1`, 둘 다 도착하면 `+10`. 코드는 `code/main.py`에 있습니다.

### 단계 1: 멀티 에이전트 환경

```python
class CoopGridWorld:
    def __init__(self):
        self.size = 6
        self.goal = (5, 5)

    def reset(self):
        return ((0, 0), (5, 0))  # 두 에이전트

    def step(self, state, actions):
        a1, a2 = state
        new1 = move(a1, actions[0])
        new2 = move(a2, actions[1])
        done = (new1 == self.goal) and (new2 == self.goal)
        reward = 10.0 if done else -1.0
        return (new1, new2), reward, done
```

*결합* 행동 공간의 크기는 `|A|² = 16`입니다. 전역 상태는 두 위치입니다.

### 단계 2: 독립 Q-러닝

각 에이전트는 결합 상태를 키로 하는 자기만의 Q 테이블을 운영합니다. 매 단계마다: 둘 다 ε-탐욕(epsilon-greedy) 행동을 고르고, 결합 전이를 모으고, 각자 공유된 보상으로 자기 Q를 갱신합니다.

```python
def independent_q(env, episodes, alpha, gamma, epsilon):
    Q1, Q2 = defaultdict(default_q), defaultdict(default_q)
    for _ in range(episodes):
        s = env.reset()
        while not done:
            a1 = epsilon_greedy(Q1, s, epsilon)
            a2 = epsilon_greedy(Q2, s, epsilon)
            s_next, r, done = env.step(s, (a1, a2))
            target1 = r + gamma * max(Q1[s_next].values())
            target2 = r + gamma * max(Q2[s_next].values())
            Q1[s][a1] += alpha * (target1 - Q1[s][a1])
            Q2[s][a2] += alpha * (target2 - Q2[s][a2])
            s = s_next
```

보상이 촘촘하고 방향이 일치하는 이 과제에서는 잘 통합니다. 촘촘하게 결합된 과제(예: 한 에이전트가 다른 에이전트를 *기다려야* 하는 경우)에서는 실패합니다.

### 단계 3: 분해된 가치 갱신이 있는 중앙집중 Q

결합 행동 전체에 대한 하나의 Q `Q(s, a_1, a_2)`를 사용합니다. 공유 보상으로 갱신합니다. 실행 시에는 주변화(marginalization)로 분산시킵니다: `π_i(s) = argmax_{a_i} max_{a_{-i}} Q(s, a_1, a_2)`. 지수적으로 커지는 결합 행동 공간을 *올바른* 전역 시야와 맞바꾸는 셈입니다.

### 단계 4: 간단한 셀프 플레이 (적대적 2 에이전트)

같은 에이전트가 두 역할을 맡습니다. 에이전트 A를 에이전트 B 상대로 학습시키고, `K` 에피소드마다 A의 가중치를 B에 복사합니다. 대칭적인 학습, 꾸준한 진전. AlphaZero 레시피의 축소판입니다.

## 흔한 실수

- **비정상 리플레이.** 독립 에이전트에게 경험 리플레이는 단일 에이전트일 때보다 더 해롭습니다. 오래된 전이들은 이제는 쓸모없어진 상대들이 만들어 낸 것이기 때문입니다. 해결: 최근성(recency)에 따라 라벨을 다시 달거나 가중치를 주세요.
- **크레딧 할당 모호성.** 긴 에피소드 끝에 나오는 공유 보상은 누가 얼마나 기여했는지 알려 주지 않습니다. 해결: 반사실적 베이스라인(COMA)이나 에이전트별 보상 설계(reward shaping).
- **정책 표류 / 추격.** 각 에이전트의 최적 대응이 상대의 갱신 때마다 바뀝니다. 해결: 중앙집중식 크리틱, 낮은 학습률, 또는 한 번에 하나씩 고정(freeze).
- **협동을 통한 보상 해킹.** 설계자가 예상하지 못한 공동 익스플로잇을 에이전트들이 찾아냅니다. 경매 에이전트들이 입찰가 0으로 수렴하는 사례가 유명합니다. 해결: 신중한 보상 설계, 행동 제약.
- **탐험 중복.** 두 에이전트가 같은 상태-행동 쌍만 탐험합니다. 해결: 에이전트별 엔트로피 보너스, 또는 역할 조건화(role conditioning).
- **리그 순환.** 순수 셀프 플레이는 지배 순환에 갇힐 수 있습니다. 해결: 다양한 상대를 둔 리그 플레이.
- **샘플 폭발.** `n` 에이전트 × 상태 공간 × 결합 행동. 함수 근사로 근사하고, 행동 공간을 분해하세요(에이전트마다 정책 출력 헤드를 하나씩).

## 실전에서 활용하기

2026년 MARL 응용 지도:

| 도메인 | 방법 | 비고 |
|--------|--------|-------|
| 협력 내비게이션 / 조작 | MAPPO / QMIX | CTDE; 공유 크리틱 + 분산 액터. |
| 2인 게임(체스, 바둑, 포커) | MCTS 결합 셀프 플레이 (AlphaZero) | 제로섬; 대칭 학습. |
| 복잡한 멀티플레이(Dota, StarCraft) | 리그 플레이 + 모방 학습 사전학습 | OpenAI Five, AlphaStar. |
| 자율주행차 플릿 | 어텐션을 얹은 CTDE MAPPO / PPO | 부분 관측; 가변 팀 규모. |
| 경매 시장 | 게임이론적 균형 + RL | `n` → ∞일 때는 평균장(mean-field) RL. |
| LLM 멀티 에이전트 시스템(페이즈 16) | 자연어 통신 + 역할 조건화 | 에이전트 계획 레이어에서 도는 RL 루프. |

2026년 MARL의 가장 큰 성장 분야는 LLM 기반입니다. 협상하고, 토론하고, 소프트웨어를 만드는 언어 모델 에이전트 무리 말입니다. RL은 토큰 단위가 아니라 *궤적(trajectory) 단위* 산출물에 대한 선호 최적화로 나타납니다(페이즈 16 · 03).

## 연습 문제

1. **쉬움.** 2 에이전트 협력 GridWorld에서 독립 Q-러닝을 학습시켜 보세요. 평균 반환값이 0을 넘으려면 에피소드가 몇 번 필요한가요? 결합 학습 곡선을 그려 보세요.
2. **보통.** "협동" 과제를 추가해 보세요: 두 에이전트가 같은 턴에 목표 칸을 밟아야만 목표 도달로 인정됩니다. 독립 Q는 여전히 수렴할까요? 무엇이 깨질까요?
3. **어려움.** MAPPO 스타일 학습을 위한 중앙집중식 크리틱을 구현하고, 협동 과제에서 독립 PPO와 수렴 속도를 비교해 보세요.

## 핵심 용어

| 용어 | 사람들이 말하는 것 | 실제 의미 |
|------|-----------------|-----------------------|
| 마르코프 게임 | "멀티 에이전트 MDP" | `(S, A_1, …, A_n, P, R_1, …, R_n)`; 각 에이전트가 자기만의 보상을 가진다. |
| CTDE | "중앙집중 학습, 분산 실행" | 학습 때는 결합 크리틱; 각 에이전트의 정책은 지역 관측만 사용. |
| IPPO | "독립 PPO" | 각 에이전트가 따로 PPO를 돌린다. 단순한 베이스라인; 자주 저평가된다. |
| MAPPO | "멀티 에이전트 PPO" | 전역 상태에 조건화된 중앙집중식 가치 함수를 얹은 PPO. |
| QMIX | "단조 가치 분해" | `Q_tot = f_monotone(Q_1, …, Q_n)`로 분산 argmax가 가능해진다. |
| COMA | "반사실적 멀티 에이전트" | 어드밴티지 = 내 Q에서 내 행동에 대해 주변화한 기댓값 Q를 뺀 것. |
| 셀프 플레이 | "에이전트 vs 과거의 나" | 에이전트 하나가 두 역할을 맡는다; 제로섬 게임의 표준. |
| 리그 플레이 | "개체군 학습" | 과거 정책을 캐시에 두고 상대를 풀에서 샘플링; 전략 순환을 다룬다. |

## 더 읽을거리

- [Lowe et al. (2017). Multi-Agent Actor-Critic for Mixed Cooperative-Competitive Environments (MADDPG)](https://arxiv.org/abs/1706.02275) — 중앙집중식 크리틱을 얹은 CTDE.
- [Foerster et al. (2017). Counterfactual Multi-Agent Policy Gradients (COMA)](https://arxiv.org/abs/1705.08926) — 크레딧 할당을 위한 반사실적 베이스라인.
- [Rashid et al. (2018). QMIX: Monotonic Value Function Factorisation](https://arxiv.org/abs/1803.11485) — 단조성을 활용한 가치 분해.
- [Yu et al. (2022). The Surprising Effectiveness of PPO in Cooperative Multi-Agent Games (MAPPO)](https://arxiv.org/abs/2103.01955) — PPO가 MARL에서 의외로 강하다는 것을 보인 논문.
- [Vinyals et al. (2019). Grandmaster level in StarCraft II using multi-agent reinforcement learning (AlphaStar)](https://www.nature.com/articles/s41586-019-1724-z) — 대규모 리그 플레이.
- [Silver et al. (2017). Mastering the game of Go without human knowledge (AlphaGo Zero)](https://www.nature.com/articles/nature24270) — 제로섬 게임에서의 순수 셀프 플레이.
- [Sutton & Barto (2018). Ch. 15 — Neuroscience & Ch. 17 — Frontiers](http://incompleteideas.net/book/RLbook2020.pdf) — 교과서에서 멀티 에이전트 설정과, CTDE가 풀고자 하는 비정상성 문제를 짧게 다룬 부분.
- [Zhang, Yang & Başar (2021). Multi-Agent Reinforcement Learning: A Selective Overview](https://arxiv.org/abs/1911.10635) — 협력, 경쟁, 혼합 MARL과 수렴 결과를 다루는 서베이.
