# 퍼셉트론 패턴

퍼셉트론은 입력의 가중 합에 편향을 더한 뒤 계단 함수를 적용해 이진 출력을 만듭니다. 신경망의 기본 단위입니다.

```
output = step(w1*x1 + w2*x2 + ... + wn*xn + bias)
```

## 단일 퍼셉트론으로 충분한 경우

- 문제가 선형 분리 가능한 경우: 직선(또는 초평면) 하나로 두 클래스를 나눌 수 있음
- 논리 게이트: AND, OR, NOT, NAND
- 단순 임계값 결정: "점수가 X보다 높은가?"
- 겹치지 않는 두 영역으로 묶이는 데이터에 대한 이진 분류

## 여러 층이 필요한 경우

- 문제가 선형 분리 불가능한 경우: 어떤 직선으로도 클래스를 나눌 수 없음
- XOR 및 패리티(parity) 문제
- "이건 되고 저건 안 됨" 추론이 필요한 모든 작업(조건들의 조합)
- 실제 세계의 분류: 이미지, 텍스트, 오디오 - 거의 항상 비선형

## 의사 결정 체크리스트

1. 데이터를 그려 보거나 살펴보세요. 클래스 사이에 직선 경계 하나를 그릴 수 있나요?
   - 예: 단일 퍼셉트론으로 충분
   - 아니요: 최소 두 층 필요
2. 문제를 더 단순한 선형 결정들의 AND/OR로 분해할 수 있나요?
   - 이 분해가 최소 네트워크 구조를 알려줍니다
   - XOR = (A OR B) AND (NOT (A AND B)) = 2개 층의 퍼셉트론 3개
3. 클래스가 둘 이상인 문제에는 클래스당 출력 노드 하나가 필요합니다

## 학습 규칙

```
error = expected - predicted
weight_new = weight_old + learning_rate * error * input
bias_new = bias_old + learning_rate * error
```

예측이 맞으면 아무것도 바뀌지 않습니다. 틀리면 오차가 줄어들도록 가중치가 이동합니다. 이 규칙은 단일 층 퍼셉트론에만 동작합니다. 다층 네트워크에는 역전파가 필요합니다.

## 흔한 실수

- 단일 퍼셉트론으로 비선형 패턴을 배우려 함(영원히 수렴하지 않음)
- 학습률이 너무 높음(가중치가 진동) 또는 너무 낮음(학습이 끝나지 않음)
- 편향 항을 잊음(편향이 없으면 결정 경계가 원점을 지나야 함)
- 퍼셉트론 수렴(선형 분리 가능 데이터에서는 보장됨)과 일반적인 신경망 수렴(보장되지 않음)을 혼동
