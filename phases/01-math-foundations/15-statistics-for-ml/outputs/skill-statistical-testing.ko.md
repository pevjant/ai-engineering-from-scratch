# ML을 위한 통계 검정

모델을 비교하거나, A/B 실험을 돌리거나, 결과를 검증할 때 올바른 검정을 고르는 방법입니다.

## 판단 체크리스트

1. 무엇을 비교하나요? 평균, 비율, 분포, 아니면 상관?
2. 집단은 몇 개인가요? 표본 하나 vs 기준값, 두 집단, 아니면 여러 집단?
3. 관측치가 쌍을 이루나요(같은 테스트셋, 같은 폴드)? 아니면 독립인가요?
4. 데이터가 정규분포를 따르나요? n < 30이고 분명히 정규가 아니라면 비모수 검정을 쓰세요.
5. 데이터가 연속형인가요, 순서형인가요, 범주형인가요?
6. 검정을 몇 번이나 돌리나요? 하나보다 많으면 보정을 적용하세요.

## 의사결정 트리

```text
평균을 비교하는가?
  두 집단인가?
    쌍을 이루는가(같은 데이터 분할)? --> 대응표본 t-검정 (비정규면 Wilcoxon signed-rank)
    독립인가? --> Welch의 t-검정 (비정규면 Mann-Whitney U)
  여러 집단인가?
    쌍을 이루는가? --> 반복측정 ANOVA (또는 Friedman 검정)
    독립인가? --> 일원 ANOVA (또는 Kruskal-Wallis)

비율을 비교하는가?
  두 집단? --> 카이제곱 검정 또는 Fisher의 정확 검정 (작은 n)
  여러 집단? --> 카이제곱 검정

분포를 비교하는가?
  한 분포가 기준인가? --> Kolmogorov-Smirnov 검정
  둘 다 경험적 분포인가? --> 이표본 KS 검정

연관성을 측정하는가?
  둘 다 연속이고 대략 정규? --> 피어슨 상관
  순서형이거나 비정규? --> 스피어먼 순위 상관
  범주형 x 범주형? --> 카이제곱 독립성 검정

검정을 여러 번 돌리는가?
  본페로니 보정을 적용: alpha_adjusted = alpha / number_of_tests
  또는 Holm-Bonferroni 사용 (덜 보수적이면서도 패밀리별 오류율은 통제)
```

## 검정별 사용 시점

| 검정 | 데이터 유형 | 가정 | ML 사용 사례 |
|---|---|---|---|
| 대응표본 t-검정 | 연속형, 쌍 | 차이가 정규 | 같은 k폴드 분할에서 2개 모델 비교 |
| Wilcoxon signed-rank | 연속/순서형, 쌍 | 없음(비모수) | 2개 모델 비교, 작은 k(5-10폴드) |
| Welch의 t-검정 | 연속형, 독립 | 대략 정규 | 모델을 두 개별 데이터셋에서 비교 |
| Mann-Whitney U | 연속/순서형, 독립 | 없음 | 지연 시간 분포 비교 |
| ANOVA | 연속형, 3개 이상 집단 | 정규, 등분산 | 여러 모델 아키텍처 비교 |
| Kruskal-Wallis | 연속/순서형, 3개 이상 집단 | 없음 | 여러 모델 비교, 비정규 지표 |
| 카이제곱 | 범주형 빈도 | 기대 빈도 >= 5 | 클래스 분포 비교, 혼동 행렬 |
| Fisher의 정확 검정 | 범주형 빈도 | 작은 표본 | 희귀 사건 비교 |
| KS 검정 | 연속형 | 없음 | 예측이 기대 분포를 따르는지 확인 |
| 부트스트랩 CI | 모든 통계량 | 없음 | AUC, F1 등 어떤 지표든 신뢰 구간 |
| McNemar 검정 | 쌍을 이룬 이진형 | 없음 | 같은 테스트셋에서 두 분류기 비교 |

## 모델 비교 레시피

1. 실험을 돌리기 전에 지표와 유의수준(alpha = 0.05)을 정합니다.
2. 두 모델을 같은 k폴드 교차 검증 분할(k = 5 또는 10)로 돌립니다.
3. 쌍별 점수를 모읍니다: (a_1, b_1), (a_2, b_2), ..., (a_k, b_k).
4. 차이를 계산합니다: d_i = b_i - a_i.
5. 쌍 검정을 돌립니다(k <= 10이면 Wilcoxon, k > 10이거나 차이가 정규면 대응표본 t-검정).
6. 보고: p-값, 평균 차이, 95% 신뢰 구간, 효과 크기(Cohen's d).
7. p < alpha이고 효과 크기가 의미 있다면, 그 차이는 진짜이고 조치할 가치가 있습니다.

## 흔한 실수

- 데이터가 쌍을 이루는데 독립 검정을 쓰는 것. 두 모델을 같은 테스트 폴드로 평가했다면 반드시 쌍 검정을 써야 합니다. 독립 검정은 쌍 정보를 버려 통계적 검정력을 잃게 만듭니다.
- 효과 크기 없이 p < 0.05만 보고하는 것. 통계적으로 유의미한 0.1% 정확도 개선은 배포할 가치가 없습니다. 항상 Cohen's d나 평균 차이 원값을 계산하세요.
- 서로 다른 테스트셋으로 모델을 비교하는 것. 테스트셋은 반드시 두 모델 모두에게 동일해야 합니다. 테스트셋이 다르면 비교는 무의미합니다.
- 20번의 비교를 돌리고 본페로니 보정 없이 최고 하나만 보고하는 것. alpha = 0.05로 20번 검정하면 우연히 위양성 1개가 나올 것으로 예상해야 합니다.
- 불균형 데이터에 정확도를 쓰는 것. 다수 클래스가 99%면 무식한 분류기도 99%를 찍습니다. F1, precision-recall AUC, Matthews 상관계수(MCC)를 쓰세요.
- 교차 검증 폴드를 독립 표본처럼 다루는 것. 폴드들은 훈련 데이터를 공유하므로 독립 가정을 위반합니다. corrected resampled t-검정은 이를 보정합니다.

## 빠른 참조: 효과 크기 해석

| Cohen's d | 해석 |
|---|---|
| 0.2 | 작은 효과 |
| 0.5 | 중간 효과 |
| 0.8 | 큰 효과 |
| > 1.0 | 매우 큰 효과 |

| 보고할 것 | 이유 |
|---|---|
| p-값 | 차이가 진짜인가? |
| 신뢰 구간 | 차이가 얼마나 클 수 있는가? |
| 효과 크기(Cohen's d) | 차이가 의미 있는가? |
| 표본 크기(n 또는 k폴드) | 결과를 신뢰할 수 있는가? |
