# 머신러닝을 위한 통계학

> 통계학은 모델이 진짜 잘 동작하는지, 아니면 그냥 운이 좋았던 건지 알려 주는 도구입니다.

**유형:** Build(직접 만들기)
**언어:** Python
**선수 지식:** 페이즈 1, 레슨 06(확률과 분포), 07(베이즈 정리)
**시간:** 약 120분

## 학습 목표

- 기술통계량, 피어슨/스피어먼 상관계수, 공분산 행렬을 처음부터 직접 계산하기
- 가설 검정(t-검정, 카이제곱)을 수행하고 p-값과 신뢰 구간을 올바르게 해석하기
- 부트스트랩 재표본추출로 분포 가정 없이 어떤 지표든 신뢰 구간을 만들기
- 효과 크기 측정을 사용해 통계적 유의성과 실질적 유의성을 구별하기

## 문제 상황

모델 두 개를 학습했습니다. 모델 A는 테스트셋에서 0.87, 모델 B는 0.89를 기록했습니다. 모델 B를 배포합니다. 3주 뒤, 프로덕션(운영 환경) 지표는 예전보다 나빠졌습니다. 무슨 일이 있었던 걸까요?

사실 모델 B는 모델 A보다 나았던 게 아닙니다. 0.02 차이는 잡음이었던 겁니다. 테스트셋이 너무 작았거나 분산이 너무 컸거나 둘 다였죠. 여러분은 개선으로 포장된 무작위성을 출시한 겁니다.

이런 일은 끊이지 않습니다. Kaggle 리더보드가 뒤집히는 일. 재현되지 않는 논문. 몇백 개 샘플로 승자를 선언하는 A/B 테스트. 근본 원인은 언제나 같습니다. 누군가 통계를 건너뛴 겁니다.

통계학은 신호와 잡음을 구별할 도구를 줍니다. 차이가 진짜인지, 얼마나 확신할 수 있는지, 결과를 믿으려면 데이터가 얼마나 필요한지를 알려 줍니다. 모든 ML 파이프라인, 모든 모델 비교, 모든 실험에는 통계가 필요합니다. 통계 없이는 그냥 추측에 불과합니다.

## 핵심 개념

### 기술통계: 데이터 요약하기

무엇을 모델링하기 전에 데이터가 어떻게 생겼는지 알아야 합니다. 기술통계는 데이터셋을 그 모양을 담은 몇 개의 숫자로 압축합니다.

**중심 경향 측정**은 "가운데가 어디인가?"에 답합니다.

```
평균(Mean):   모든 값의 합 / 개수
        mu = (1/n) * sum(x_i)

중앙값(Median): 정렬했을 때 가운데 값
        이상치에 강건함. [1, 2, 3, 4, 1000]이 있으면 평균은 202지만
        중앙값은 3입니다.

최빈값(Mode):  가장 자주 나오는 값
        범주형 데이터에 유용. 연속 데이터에서는 정보가 별로 없음.
```

평균은 균형점입니다. 중앙값은 중간 지점이죠. 둘이 갈라지면 분포가 치우친(skewed) 것입니다. 소득 분포는 평균 >> 중앙값입니다(억지 부자들 때문에 오른쪽으로 치우침). 학습 중 손실 분포는 평균 << 중앙값인 경우가 많습니다(쉬운 샘플 때문에 왼쪽으로 치우침).

**산포 측정**은 "데이터가 얼마나 퍼져 있는가?"에 답합니다.

```
분산(Variance):   평균으로부터의 제곱 편차의 평균
            sigma^2 = (1/n) * sum((x_i - mu)^2)

표준편차:  분산의 제곱근
                     sigma = sqrt(sigma^2)
                     데이터와 같은 단위라 해석이 더 쉬움.

범위(Range):      max - min
            이상치에 민감함. 혼자 쓰면 거의 쓸모가 없음.

IQR:        Q3 - Q1 (사분위수 범위)
            가운데 50% 데이터의 범위.
            이상치에 강건함. 박스 플롯과 이상치 탐지에 사용.
```

**백분위수(percentile)**는 정렬된 데이터를 100등분합니다. 25백분위수(Q1)는 값의 25%가 그 지점 아래에 있다는 뜻입니다. 50백분위수는 중앙값이고, 75백분위수는 Q3입니다.

```
지연 시간 모니터링의 예:
  P50 = 중앙값 지연 시간        (일반적인 사용자 경험)
  P95 = 95백분위수       (나쁘지만 최악은 아님)
  P99 = 99백분위수       (꼬리 지연 시간, 흔히 중앙값의 10배)
```

ML에서는 추론 지연 시간, 예측 신뢰도 분포, 오류 분포 이해를 위해 백분위수를 봅니다. 평균 오차는 낮지만 P99 오차가 끔찍한 모델은 안전이 중요한 응용에서는 쓸모가 없을 수 있습니다.

**표본 통계 vs 모집단 통계.** 표본으로 분산을 계산할 때는 n이 아니라 (n-1)로 나눕니다. 이것이 베셀 보정(Bessel's correction)입니다. 표본 평균이 진짜 모평균이 아니라는 사실을 보정하는 거죠. 분모에 n을 쓰면 진짜 분산을 체계적으로 과소평가하게 됩니다. (n-1)을 쓰면 편향되지 않은 추정이 됩니다.

```
모집단 분산: sigma^2 = (1/N) * sum((x_i - mu)^2)
표본 분산:     s^2     = (1/(n-1)) * sum((x_i - x_bar)^2)
```

실전에서는: n이 크면(수천 개 샘플) 차이는 무시할 수 있습니다. n이 작으면(수십 개 샘플) 차이가 중요합니다.

### 상관: 변수가 함께 움직이는 방식

상관은 두 변수 사이 선형 관계의 강도와 방향을 측정합니다.

**피어슨 상관계수**는 선형 연관성을 측정합니다:

```
r = sum((x_i - x_bar)(y_i - y_bar)) / (n * s_x * s_y)

r = +1:  완벽한 양(+)의 선형 관계
r = -1:  완벽한 음(-)의 선형 관계
r =  0:  선형 관계 없음 (하지만 비선형 관계가 있을 수도!)

범위: [-1, 1]
```

피어슨은 관계가 선형이고 두 변수가 대략 정규분포를 따른다고 가정합니다. 이상치에 민감해서, 극단적인 점 하나가 r을 0.1에서 0.9로 끌어당길 수 있습니다.

**스피어먼 순위 상관**은 단조 연관성을 측정합니다:

```
1. 각 값을 그 순위(1, 2, 3, ...)로 바꾼다
2. 순위에 대해 피어슨 상관을 계산한다

스피어먼은 선형이 아니더라도 단조 관계면 잡아냅니다.
y = x^3이면 피어슨은 r < 1을 주지만 스피어먼은 rho = 1을 줍니다.
```

**각각 언제 쓰나:**

```
피어슨:    두 변수가 모두 연속이고 대략 정규분포.
            선형 관계에 특별히 관심이 있음.
            극단적인 이상치가 없음.

스피어먼:   순서형 데이터(순위, 평점).
            데이터가 정규분포가 아님.
            단조이지만 선형은 아닌 관계로 의심됨.
            이상치가 있음.
```

**황금 법칙:** 상관관계는 인과관계를 뜻하지 않습니다. 아이스크림 판매량과 익사 사망자는 상관되어 있지만, 둘 다 여름에 늘기 때문입니다. 여러분 모델의 정확도와 파라미터 수도 상관되어 있지만, 파라미터를 더한다고 정확도가 자동으로 좋아지지는 않습니다(과적합 참조).

### 공분산 행렬

두 변수 사이의 공분산은 함께 변하는 정도를 측정합니다:

```
Cov(X, Y) = (1/n) * sum((x_i - x_bar)(y_i - y_bar))

Cov(X, Y) > 0:  X와 Y는 함께 커지는 경향
Cov(X, Y) < 0:  X가 커질 때 Y는 작아지는 경향
Cov(X, Y) = 0:  선형적 동조 없음
```

d개 특성(feature)에 대해 공분산 행렬 C는 d x d 행렬이고 C[i][j] = Cov(feature_i, feature_j)입니다. 대각 성분 C[i][i]는 각 특성의 분산입니다.

```
C = | Var(x1)      Cov(x1,x2)  Cov(x1,x3) |
    | Cov(x2,x1)  Var(x2)      Cov(x2,x3) |
    | Cov(x3,x1)  Cov(x3,x2)  Var(x3)     |

성질:
  - 대칭: C[i][j] = C[j][i]
  - 양의 준정부호(positive semi-definite): 모든 고유값 >= 0
  - 대각 성분 = 분산
  - 비대각 성분 = 공분산
```

**PCA와의 연결.** PCA는 공분산 행렬을 고유분해합니다. 고유벡터가 주성분(분산이 최대인 방향)이고, 고유값이 각 성분이 담는 분산의 양을 알려 줍니다. 레슨 10에서 다룬 내용이지만, 이제 왜 공분산 행렬을 분해하는 게 맞는지 이해할 수 있습니다. 데이터의 모든 쌍별 선형 관계를 담고 있는 것이 바로 공분산 행렬이기 때문입니다.

**상관과의 연결.** 상관 행렬은 표준화된 변수들(각각을 표준편차로 나눈 것)의 공분산 행렬입니다. 상관은 공분산을 정규화해서 모든 값이 [-1, 1]에 들어오게 합니다.

### 가설 검정

가설 검정은 불확실성 아래에서 의사결정을 내리는 틀입니다. 주장에서 출발해 데이터를 모으고, 데이터가 그 주장과 일치하는지 판단합니다.

**설정:**

```
귀무가설(H0):        기본 가정. 보통 "효과 없음"
대립가설(H1): 여러분이 보이려는 것

예:
  H0: 모델 A와 모델 B의 정확도가 같다
  H1: 모델 B의 정확도가 모델 A보다 높다
```

**p-값**은 H0이 참이라고 가정할 때, 관측한 것만큼 극단적인 데이터를 볼 확률입니다. H0이 참일 확률이 아닙니다(NOT). 이것이 통계학에서 가장 흔한 오해입니다.

```
p-값 = P(이렇게 극단적인 데이터 | H0이 참)

p-값 < alpha(보통 0.05)이면:
    H0을 기각합니다. 결과가 "통계적으로 유의미"합니다.
p-값 >= alpha이면:
    H0을 기각하지 못합니다. 증거가 충분하지 않은 것입니다.
    이것은 H0이 참이라는 뜻이 아닙니다.
```

**신뢰 구간**은 파라미터에 대해 그럴듯한 값의 범위를 줍니다:

```
평균의 95% 신뢰 구간:
    x_bar +/- z * (s / sqrt(n))

여기서 95% 신뢰도일 때 z = 1.96

해석: 이 실험을 여러 번 반복하면, 계산된 구간의 95%가
진짜 평균을 담고 있을 것입니다. 이 특정 구간에 진짜 평균이
들어 있을 확률이 95%라는 뜻이 아닙니다.
```

신뢰 구간의 폭은 정밀도를 알려 줍니다. 넓으면 불확실성이 크고, 좁으면 추정이 정밀하다는 뜻입니다(다만 데이터가 편향돼 있으면 정밀해도 정확하지는 않을 수 있습니다).

### t-검정

t-검정은 평균을 비교합니다. 여러 종류가 있습니다.

**일표본 t-검정:** 모평균이 어떤 가설값과 다른가?

```
t = (x_bar - mu_0) / (s / sqrt(n))

자유도 = n - 1
```

**이표본 t-검정(독립):** 두 집단의 평균이 다른가?

```
t = (x_bar_1 - x_bar_2) / sqrt(s1^2/n1 + s2^2/n2)

이것은 등분산을 가정하지 않는 Welch의 t-검정입니다.
등분산을 가정할 특별한 이유가 없다면 항상 Welch를 쓰세요.
```

**대응표본 t-검정:** 측정이 쌍으로 올 때(같은 모델을 같은 데이터 분할로 평가):

```
각 쌍에 대해 d_i = x_i - y_i를 계산한다
그다음 d_i 값들로 mu_0 = 0에 대한 일표본 t-검정을 돌린다
```

ML에서는 대응표본 t-검정이 흔합니다. 두 모델을 같은 10개 교차 검증 폴드에서 돌리고 점수를 쌍별로 비교하는 거죠.

### 카이제곱 검정

카이제곱 검정은 관측 빈도가 기대 빈도와 일치하는지 확인합니다. 범주형 데이터에 유용합니다.

```
chi^2 = sum((observed - expected)^2 / expected)

예: 언어 모델의 출력 분포가 카테고리별로
학습 분포와 일치하는가?

카테고리    관측      기대
긍정       120        100
부정         80        100
chi^2 = (120-100)^2/100 + (80-100)^2/100 = 4 + 4 = 8

자유도 1에서 chi^2 = 8이면 p < 0.005입니다.
차이는 유의미합니다.
```

### ML 모델의 A/B 테스트

ML의 A/B 테스트는 웹 A/B 테스트와 같지 않습니다. 모델 비교에는 특유의 과제가 있습니다:

```
1. 같은 테스트셋:    두 모델 모두 동일한 데이터로 평가해야 합니다.
                     테스트셋이 다르면 비교 자체가 무의미합니다.

2. 여러 지표:        정확도 하나로는 부족합니다. 정밀도,
                     재현율, F1, 지연 시간, 공정성 지표가 필요합니다.

3. 분산:             점 추정만이 아니라 교차 검증이나 부트스트랩으로
                     각 지표의 분산을 추정합니다.

4. 데이터 누수:     모델 선택에 테스트셋을 썼다면 비교가
                     편향됩니다. 최종 테스트셋은 따로 남겨 둡니다.
```

**절차:**

```
1. 지표와 유의수준(alpha = 0.05)을 정한다
2. 두 모델을 같은 k폴드 교차 검증 분할로 돌린다
3. 쌍별 점수를 모은다: [(a1, b1), (a2, b2), ..., (ak, bk)]
4. 차이를 계산한다: d_i = b_i - a_i
5. 차이에 대해 대응표본 t-검정을 돌린다
6. 확인: 평균 차이가 유의미하게 0과 다른가?
7. 평균 차이의 신뢰 구간을 계산한다
8. 실질적 유의성을 판단하기 위해 효과 크기(Cohen's d)를 계산한다
```

### 통계적 유의성 vs 실질적 유의성

결과가 통계적으로 유의미해도 실질적으로는 무의미할 수 있습니다. 데이터가 충분하면 자명한 차이조차 통계적으로 유의미해집니다.

```
예:
  모델 A 정확도: 0.9234
  모델 B 정확도: 0.9237
  n = 1,000,000 테스트 샘플
  p-값 = 0.001

통계적으로 유의미한가? 그렇다.
실질적으로 유의미한가? 0.03% 개선은 새 모델을 배포할
엔지니어링 비용을 치르고 싶을 만큼 크지 않다.
```

**효과 크기**는 표본 크기와 무관하게 차이가 얼마나 큰지를 수치화합니다:

```
Cohen's d = (mean_1 - mean_2) / pooled_std

d = 0.2:  작은 효과
d = 0.5:  중간 효과
d = 0.8:  큰 효과
```

p-값과 효과 크기를 항상 함께 보고하세요. p-값은 차이가 진짜인지 알려 주고, 효과 크기는 차이가 의미 있는지 알려 줍니다.

### 다중 비교 문제

가설을 많이 검정하면 그중 일부는 우연히 "유의미"하게 나옵니다. alpha = 0.05로 20가지를 검정하면, 아무것도 진짜가 아니어도 위양성 1개를 예상해야 합니다.

```
P(최소 하나의 위양성) = 1 - (1 - alpha)^m

m = 20번의 검정, alpha = 0.05:
P(위양성) = 1 - 0.95^20 = 0.64

최소 하나의 위양성이 나올 확률이 64%입니다.
```

**본페로니 보정:** alpha를 검정 횟수로 나눕니다.

```
조정된 alpha = alpha / m = 0.05 / 20 = 0.0025

p-값 < 0.0025일 때만 H0을 기각합니다.
보수적이지만 단순합니다. 검정들이 독립일 때 유효합니다.
```

ML에서는 모델을 여러 지표로 비교하거나, 많은 하이퍼파라미터 구성을 테스트하거나, 여러 데이터셋으로 평가할 때 이 문제가 생깁니다.

### 부트스트랩 방법

부트스트랩은 데이터를 복원 추출해 통계량의 표집 분포를 추정합니다. 기저 분포에 대한 가정이 전혀 필요 없습니다.

**알고리즘:**

```
1. n개의 데이터 점이 있다
2. n개 샘플을 복원 추출한다 (어떤 점은 여러 번 나오고,
   어떤 점은 한 번도 안 나옴)
3. 이 부트스트랩 표본으로 통계량을 계산한다
4. B번 반복한다 (보통 B = 1000에서 10000)
5. 부트스트랩 통계량들의 분포가 표집 분포를 근사한다
```

**부트스트랩 신뢰 구간(백분위 방법):**

```
B개의 부트스트랩 통계량을 정렬한다
95% CI = [2.5백분위수, 97.5백분위수]
```

**ML에서 부트스트랩이 중요한 이유:**

```
- 테스트셋 정확도는 점 추정입니다. 부트스트랩은 신뢰 구간을 줍니다.
- 지표 분포가 정규분포라고 가정할 수 없습니다 (특히
  AUC, F1, precision at k).
- 부트스트랩은 모든 통계량에 동작합니다: 중앙값, 두 평균의 비,
  두 모델의 AUC 차이까지.
- 닫힌 공식이 필요 없습니다.
```

**모델 비교를 위한 부트스트랩:**

```
1. 같은 테스트셋에 대한 모델 A와 모델 B의 예측이 있다
2. 각 부트스트랩 반복마다:
   a. 테스트 인덱스를 복원 추출한다
   b. 재표본 집합에서 metric_A와 metric_B를 계산한다
   c. diff = metric_B - metric_A를 저장한다
3. 차이의 95% CI:
   [diff들의 2.5백분위수, diff들의 97.5백분위수]
4. CI가 0을 포함하지 않으면 차이가 유의미합니다
```

이 방법은 분포 가정을 하지 않기 때문에 대응표본 t-검정보다 더 강건합니다.

### 모수 검정 vs 비모수 검정

**모수 검정**은 특정 분포(보통 정규분포)를 가정합니다:

```
t-test:         데이터가 정규분포(또는 CLT 덕에 큰 n)라고 가정
ANOVA:          정규성과 등분산을 가정
Pearson r:      이변량 정규성을 가정
```

**비모수 검정**은 분포 가정을 하지 않습니다:

```
Mann-Whitney U:     두 집단 비교 (독립 t-검정 대체)
Wilcoxon signed-rank: 쌍을 이룬 데이터 비교 (대응표본 t-검정 대체)
Spearman rho:       순위에 대한 상관 (피어슨 대체)
Kruskal-Wallis:     여러 집단 비교 (ANOVA 대체)
```

**비모수 검정을 쓸 때:**

```
- 표본이 작고(n < 30) 데이터가 분명히 비정규일 때
- 순서형 데이터(평점, 순위)
- 제거할 수 없는 무거운 이상치
- 치우친 분포
```

**모수 검정을 쓸 때:**

```
- 표본이 클 때 (CLT가 검정 통계량을 대략 정규로 만듦)
- 데이터가 대략 대칭이고 극단적 이상치가 없을 때
- 통계적 검정력이 더 높음 (진짜 차이를 더 잘 찾아냄)
```

ML 실험에서는 보통 n이 작습니다(5 또는 10개 교차 검증 폴드). 그래서 Wilcoxon signed-rank 같은 비모수 검정이 t-검정보다 더 적절한 경우가 많습니다.

### 중심극한정리: 실전적 의미

중심극한정리(CLT)는 표본 평균의 분포가 n이 커질수록 정규분포에 가까워진다고 말합니다. 모집단 분포가 무엇이든 상관없습니다.

```
X_1, X_2, ..., X_n이 평균 mu, 분산 sigma^2인 iid라면:

    X_bar ~ Normal(mu, sigma^2 / n)    (n -> 무한대일 때)

대부분의 경우 n >= 30이면 성립합니다.
아주 치우친 분포에서는 n >= 100이 필요할 수도 있습니다.
```

**ML에서 중요한 이유:**

```
1. 집계된 지표에 대한 신뢰 구간과 t-검정을 정당화합니다
2. 개별 폴드가 크게 요동쳐도 교차 검증 폴드를 평균하면
   안정적인 추정이 나오는 이유를 설명합니다
3. 미니배치 경사 하강법이 동작하는 이유도 이것입니다.
   배치 평균 그래디언트가 진짜 그래디언트를 근사합니다(CLT의 실전)
4. 앙상블 방법: 많은 모델의 예측을 평균하면
   어떤 단일 모델보다 안정적인 출력을 냅니다
```

**CLT가 하지 않는 것:**

```
- 데이터를 정규분포로 만들지 않습니다. 표본의 평균을 정규분포로
  만들 뿐입니다.
- 무한 분산의 두꺼운 꼬리 분포(코시 분포)에는 동작하지 않습니다.
- 종속 데이터에는 적용되지 않습니다 (보정 없는 시계열).
```

### ML 논문의 흔한 통계 실수

1. **훈련셋으로 테스트하기.** 과적합이 보장됩니다. 학습 중 모델이 한 번도 보지 못한 데이터를 반드시 따로 남겨 두세요.

2. **신뢰 구간 없음.** 불확실성 없이 정확도 숫자 하나만 보고하면 결과를 재현할 수도 검증할 수도 없습니다.

3. **다중 비교 무시.** 50가지 구성을 테스트하고 보정 없이 최고 하나만 보고하면 위양성 비율이 부풀려집니다.

4. **통계적 유의성과 실질적 유의성 혼동.** 0.01% 정확도 개선에 대한 p-값 0.001은 의미가 없습니다.

5. **불균형 데이터에 정확도 사용.** 음성 클래스가 99%인 데이터셋에서 99% 정확도는 모델이 아무것도 배우지 못했다는 뜻입니다. 정밀도, 재현율, F1, AUC를 쓰세요.

6. **지표 골라 내기.** 우리 모델이 이기는 지표만 보고하기. 정직한 평가는 관련된 모든 지표를 보고합니다.

7. **훈련/테스트 분할 사이 정보 누수.** 분할하기 전에 정규화하거나, 미래 데이터로 과거를 예측하는 것.

8. **분산 추정 없는 작은 테스트셋.** 100개 샘플로 평가하고 2% 개선을 주장하는 것은 신호가 아니라 잡음입니다.

9. **독립이 아닌 데이터에 독립 가정.** 같은 환자의 의료 영상, 같은 문서의 여러 문장. 같은 그룹 안의 관측치는 상관되어 있습니다.

10. **p-해킹.** p < 0.05가 나올 때까지 다른 검정, 부분집합, 제외 기준을 시도하는 것. 결과는 탐색의 산물일 뿐입니다.

## 직접 만들기

구현할 것:

1. **기술통계 직접 구현** (평균, 중앙값, 최빈값, 표준편차, 백분위수, IQR)
2. **상관 함수** (피어슨과 스피어먼, 공분산 행렬 포함)

## 핵심 용어

| 용어 | 정의 |
|---|---|
| 평균 | 값의 합을 개수로 나눈 것. 이상치에 민감함. |
| 중앙값 | 정렬된 데이터의 가운데 값. 이상치에 강건함. |
| 표준편차 | 분산의 제곱근. 원래 단위로 산포를 측정함. |
| 백분위수 | 주어진 퍼센트의 데이터가 그 아래에 놓이는 값. |
| IQR | 사분위수 범위. Q3에서 Q1을 뺀 값. 가운데 50%의 산포. |
| 피어슨 상관 | 두 변수 사이 선형 연관성을 측정. 범위 [-1, 1]. |
| 스피어먼 상관 | 순위를 사용해 단조 연관성을 측정. |
| 공분산 행렬 | 모든 특성 쌍 사이의 공분산을 담은 행렬. |
| 귀무가설 | 효과나 차이가 없다는 기본 가정. |
| p-값 | 귀무가설이 참일 때 이렇게 극단적인 데이터가 나올 확률. |
| 신뢰 구간 | 주어진 신뢰 수준에서 파라미터의 그럴듯한 값 범위. |
| t-검정 | 평균이 유의미하게 다른지 검정. t-분포를 사용함. |
| 카이제곱 검정 | 관측 빈도가 기대 빈도와 다른지 검정. |
| 효과 크기 | 표본 크기와 무관한 차이의 크기. Cohen's d가 흔함. |
| 본페로니 보정 | 위양성을 통제하려고 유의수준을 검정 횟수로 나눔. |
| 부트스트랩 | 표집 분포를 추정하려고 복원 재표본추출을 하는 방법. |
| 1종 오류 | 위양성. H0이 참인데 기각하는 것. |
| 2종 오류 | 위음성. H0이 거짓인데 기각하지 못하는 것. |
| 통계적 검정력 | 거짓인 H0을 올바르게 기각할 확률. 검정력 = 1 - 2종 오류율. |
| 중심극한정리 | 표본 크기가 커질수록 표본 평균이 정규분포로 수렴함. |
| 모수 검정 | 데이터에 특정 분포(보통 정규)를 가정함. |
| 비모수 검정 | 분포 가정을 하지 않음. 순위나 부호로 동작함. |
