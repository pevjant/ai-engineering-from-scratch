# 볼록성 검사기

최적화 문제가 볼록한지 확인하는 방법, 그리고 답을 얻은 뒤 무엇을 할지 정리합니다.

## 결정 체크리스트

1. 목적 함수가 볼록한가요? (헤시안 양의 준정부호 여부를 확인하거나 합성 규칙을 사용하세요.)
2. 모든 부등호 제약이 g_i(x) <= 0 형태이고 각 g_i가 볼록한가요?
3. 모든 등호 제약이 아핀(선형)인가요?
4. 셋 모두 예라면 문제는 볼록입니다. 수렴이 보장되는 볼록 솔버를 사용하세요.
5. 하나라도 아니오라면 문제는 비볼록입니다. SGD/Adam을 쓰고 국소 최적해를 받아들이세요.

## 함수의 볼록성 검사 방법

| 검사 | 대상 | 방법 |
|---|---|---|
| 이계도함수 >= 0 | 스칼라 함수 f(x) | f''(x)를 계산. 모든 x에서 f''(x) >= 0이면 볼록. |
| 헤시안이 PSD | 다변수 함수 f(x) | H(x)를 계산. 모든 곳에서 고윳값 >= 0이면 볼록. |
| 정의 검사 | 임의의 함수 | 샘플링한 x, y, t에 대해 f(tx + (1-t)y) <= t*f(x) + (1-t)*f(y) 확인. |
| 합성 규칙 | 합성 함수 | 아래 합성 규칙 표 참고. |
| 직선으로 제한 | 다변수 f | 모든 x, v에 대해 g(t) = f(x + tv)가 t에 대해 볼록하면, 그리고 그때만 f는 볼록. |

## 합성 규칙(볼록성 보존)

| 연산 | 결과 |
|---|---|
| f + g (둘 다 볼록) | 볼록 |
| c * f (c > 0, f 볼록) | 볼록 |
| max(f, g) (둘 다 볼록) | 볼록 |
| f(Ax + b), f가 볼록 | 볼록 |
| g(f(x)), g가 볼록 비감소이고 f가 볼록 | 볼록 |
| g(f(x)), g가 볼록 비증가이고 f가 오목 | 볼록 |
| 볼록 함수들의 합 | 볼록 |
| 볼록 함수들의 점별 상한(supremum) | 볼록 |

## 흔한 ML 목적함수: 볼록인가?

| 목적함수 | 볼록? | 이유 |
|---|---|---|
| MSE: (1/n) sum(y - Xw)^2 | 예 | w에 대해 이차형, 헤시안 = (2/n) X^T X는 PSD |
| 로지스틱 손실: sum(log(1 + exp(-y_i * w^T x_i))) | 예 | 볼록 함수들의 합(log-sum-exp 계열) |
| 힌지 손실: sum(max(0, 1 - y_i * w^T x_i)) | 예 | 볼록(선형) 함수들의 최댓값 |
| L2 정규화: lambda * \|\|w\|\|^2 | 예 | 이차형, 헤시안 = 2*lambda*I |
| L1 정규화: lambda * \|\|w\|\|_1 | 예 | 절댓값들의 합(볼록하지만 미분 불가) |
| 릿지 회귀: MSE + L2 | 예 | 두 볼록 함수의 합 |
| LASSO: MSE + L1 | 예 | 두 볼록 함수의 합 |
| 엘라스틱 넷: MSE + L1 + L2 | 예 | 볼록 함수들의 합 |
| SVM(원문제): 힌지 + L2 | 예 | 볼록 함수들의 합 |
| 소프트맥스 교차 엔트로피 | 예(로짓에 대해) | log-sum-exp는 볼록 |
| 신경망(모든 손실) | 아니오 | 비선형 활성화가 비볼록 합성을 만듦 |
| k-평균 목적함수 | 아니오 | 이산 할당 단계 |
| 행렬 분해: \|\|X - UV^T\|\|^2 | 아니오 | U와 V에 대해 쌍선형 |
| GAN 손실 | 아니오 | 미니맥스, 생성자에 대해 비볼록 |
| 대조 손실(InfoNCE) | 아니오 | 음성 샘플이 들어간 지수함수 비율의 로그 |

## 볼록성에 따른 솔버 선택

| 문제 유형 | 솔버 | 수렴 보장 |
|---|---|---|
| 볼록, 매끄러움, 제약 없음 | 경사 하강법 | 전역 최솟값까지 O(1/k) |
| 볼록, 매끄러움, 제약 없음 | L-BFGS | 전역 최솟값으로 초선형 수렴 |
| 볼록, 매끄러움, 제약 없음 | 뉴턴 방법 | 최솟값 근처 2차 수렴(헤시안 계산 가능하면) |
| 볼록, 매끄러움, 제약 있음 | 내부점 방법 | 다항 시간 |
| 볼록, 비매끄러움(L1) | 근접 경사법 / ISTA | 전역 최솟값까지 O(1/k) |
| 볼록, 비매끄러움(L1) | ADMM | 유연, 제약 처리 가능 |
| 볼록, 이차형 | 켤레 기울기법 | n단계 안에 정확히 |
| 비볼록, 매끄러움 | SGD / Adam | 국소 최솟값으로 수렴 |
| 비볼록, 매끄러움 | SGD + 재시작 | 평균적으로 더 나은 국소 최솟값 |
| 비볼록, 매끄러움 | 과다 파라미터화 + SGD | 평평한 최솟값, 좋은 일반화 |

## 흔한 실수

- 손실 함수가 볼록하다는 이유만으로 문제가 볼록하다고 가정하기. 손실은 지금 최적화하는 파라미터에 대해 볼록해야 합니다. 교차 엔트로피는 로짓에 대해 볼록이지만, 입력을 로짓으로 바꾸는 신경망 전체 사상은 비볼록입니다.
- 비볼록 문제에 뉴턴 방법 사용하기. 헤시안에 음의 고윳값이 있으면 뉴턴 방법은 최솟값이 아니라 안장점이나 최댓값 쪽으로 이동할 수 있습니다.
- L1 정규화가 목적함수를 0에서 미분 불가능하게 만든다는 사실 잊기. 표준 경사 하강법은 잘 작동하지 않습니다. 근접 경사 하강법(proximal gradient descent)이나 서브그래디언트 방법을 사용하세요.
- A^T A를 만들면서 조건수 제곱하기. 최소제곱 문제를 풀어야 하는데 A가 조건 나쁘다면 정규 방정식 대신 QR이나 SVD를 쓰세요.
- 확인하지도 않고 비볼록이라 선언하기. 많은 ML 문제(선형 모델, SVM, 로지스틱 회귀)는 볼록이라 더 강력한 솔버의 혜택을 받을 수 있습니다.

## 빠른 검사: 내 문제는 볼록한가?

```
1. 목적함수를 적어본다: 제약 조건 하에서 minimize f(w)
2. f(w)의 각 항에 대해:
   - PSD 행렬을 곁들인 이차형? -> 볼록
   - 노름(norm)? -> 볼록
   - log-sum-exp? -> 볼록
   - w가 비선형으로 들어가는가 (sigmoid(w), w1*w2)? -> 아마 비볼록
3. 모든 제약이 선형이거나 볼록 부등호인가?
4. 모든 항이 볼록이고 제약도 볼록/선형 -> 문제는 볼록
5. 단 하나의 항이라도 비볼록 -> 문제는 비볼록
```
