# 샘플링 전략 선택

텍스트 생성, 베이즈 추론, 몬테카를로 추정, 학습에 맞는 샘플링 방법을 고르는 방법입니다.

## 결정 체크리스트

1. 출력(텍스트, 이미지)을 생성하려는 건가요, 아니면 어떤 양(적분, 기댓값)을 추정하려는 건가요?
2. 목표 분포에서 직접 샘플을 뽑을 수 있나요, 아니면 밀도만 계산할 수 있나요?
3. 목표 분포는 이산형인가요 연속형인가요?
4. 샘플 공간의 차원은 얼마인가요? 낮음(< 5), 중간(5-100), 높음(> 100)?
5. 정확한 샘플이 필요한가요, 근사 샘플로 충분한가요?
6. 샘플링 연산을 통과하는 그래디언트가 필요한가요?

## 각 방법을 언제 쓰나

| 방법 | 언제 사용 | 복잡도 | 정확한가? |
|---|---|---|---|
| 직접 샘플링 | CDF가 있거나 라이브러리 함수를 쓸 수 있음 | 샘플당 O(1) | 예 |
| 역 CDF | 닫힌 형태의 CDF 역함수를 알고 있음(지수, 코시) | 샘플당 O(1) | 예 |
| Box-Muller | 라이브러리 없이 정규 샘플이 필요함 | 샘플당 O(1) | 예 |
| 기각 샘플링 | 목표 PDF를 계산할 수 있고 저차원(1-3) | 샘플당 O(1/수용률) | 예 |
| 중요도 샘플링 | 개별 샘플이 아니라 기댓값이 필요함 | n개 샘플에 O(n) | 근사 |
| 층화 샘플링 | 몬테카를로 추정에서 더 낮은 분산을 원함 | n개 샘플에 O(n) | 근사 |
| 메트로폴리스-해스팅스 | 고차원, 정규화되지 않은 밀도를 계산할 수 있음 | 단계당 O(1) + 번인 | 점근적으로 |
| 깁스 샘플링 | 각 조건부 분포에서 샘플 가능 | 전체 스윕당 O(d) | 점근적으로 |
| HMC/NUTS | 고차원 연속형, 매끄러운 밀도 | 단계당 O(L * d) | 점근적으로 |
| Temperature 샘플링 | LLM 텍스트 생성, 창의성 조절 | 어휘 크기 V에 대해 O(V) | 해당 없음 |
| Top-k 샘플링 | LLM 생성, 가능성 낮은 토큰 제거 | O(V log k) | 해당 없음 |
| Top-p(니클레우스) | LLM 생성, 적응적 후보 집합 | O(V log V) | 해당 없음 |
| 재파라미터화 | 가우시안 샘플링을 통과하는 그래디언트 필요(VAE) | O(d) | 예 |
| Gumbel-Softmax | 범주형 샘플링을 통과하는 그래디언트 필요 | k개 클래스에 O(k) | 근사 |

## LLM 생성 설정

| 사용 사례 | Temperature | Top-p | Top-k | 비고 |
|---|---|---|---|---|
| 사실 기반 질의응답 | 0.0(그리디) | -- | -- | 결정적, 무작위성 없음 |
| 코드 생성 | 0.2-0.5 | 0.9 | -- | 낮은 창의성, 높은 일관성 |
| 일반 대화 | 0.7 | 0.9 | -- | 균형 |
| 창작 | 0.9-1.2 | 0.95 | -- | 더 높은 다양성 |
| 브레인스토밍 | 1.0-1.5 | 0.95 | -- | 최대 다양성, 일관성을 잃을 수 있음 |

Temperature와 top-p는 조합할 수 있습니다. 먼저 temperature를 적용하고(로짓 스케일 조정), 그다음 top-p 필터링을 적용합니다.

## MCMC 방법 선택

| 성질 | 메트로폴리스-해스팅스 | 깁스 | HMC/NUTS |
|---|---|---|---|
| 차원 | 모두 | 모두(100 미만이 최선) | 높음(100 이상) |
| 조건부 분포 필요 | 아니오 | 예 | 아니오 |
| 그래디언트 필요 | 아니오 | 아니오 | 예 |
| 수용률 | ~23%로 조정 | 항상 100% | ~65%로 조정 |
| 상관 | 높음(무작위 걸음) | 중간 | 낮음 |
| 번인 | 김 | 중간 | 짧음 |
| 적합한 용도 | 탐색, 단순 모델 | 켤레(conjugate) 모델, 베이지언 네트워크 | 연속 사후 분포, 심층 확률 모델 |

## 흔한 실수

- 고차원에서 기각 샘플링 사용. 수용률은 차원에 따라 지수적으로 떨어집니다. 5차원을 넘으면 MCMC로 전환하세요.
- MCMC 제안 분포의 분산을 너무 크거나 너무 작게 잡기. 너무 크면 대부분의 제안이 기각되어 연쇄가 멈춥니다. 너무 작으면 모든 제안이 수용되어 연쇄가 느리게 움직입니다. 무작위 걸음 MH(random walk MH)의 목표 수용률은 약 23%입니다.
- 번인 깜빡하기. MCMC의 첫 N개 샘플은 시작점의 영향으로 편향되어 있습니다. 최소 1000단계(복잡한 분포라면 그 이상)는 버리세요.
- 목표와 크게 다른 제안 분포로 중요도 샘플링 사용. 소수의 샘플이 어마어마한 가중치를 받아 추정이 불신뢰해집니다. 유효 샘플 크기(ESS, effective sample size)를 감시하세요: ESS = (sum w_i)^2 / sum(w_i^2).
- 결정적 출력이 필요한 작업(예: 분류, 구조화된 추출)에 temperature > 0 사용. 대신 그리디(T=0)나 빔 서치(beam search)를 쓰세요.
- top-p를 temperature와 조합하지 않기. temperature만으로는 긴 꼬리의 엉터리 토큰을 제거할 수 없습니다. top-p가 그 역할을 합니다.
- 표준 샘플링 연산을 통과해 역전파하기. 연속(가우시안)은 재파라미터화 트릭을, 이산(범주형)은 Gumbel-Softmax를 사용하세요.

## 빠른 참고: 분산 축소 기법

| 기법 | 작동 방식 | 분산 축소 |
|---|---|---|
| 층화 샘플링 | 공간을 층으로 나누고 각 층에서 샘플 | 항상 표준 MC 이하 |
| 대립 변량(antithetic variates) | U와 1-U를 모두 사용 | 단조 함수에 효과적 |
| 제어 변량(control variates) | 평균을 아는 변수를 빼기 | 상관에 비례 |
| 중요도 샘플링 | 더 나은 제안 분포의 샘플에 가중치 부여 | 제안 품질에 따라 다름 |
| 라틴 하이퍼큐브(Latin hypercube) | 각 차원을 독립적으로 층화 | 고차원에서 층화보다 우수 |
