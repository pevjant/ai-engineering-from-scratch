## GitHub에서 이 페이즈 시작하기

**선수 지식:** 페이즈 0 완료, 또는 저장소 루트에서 Python 3.11+와 Git이 동작한다는 것 확인.

**첫 번째 레슨:** [선형대수 직관](01-linear-algebra-intuition/)

저장소 루트에서 이 명령어를 실행하세요:

```bash
python3 phases/01-math-foundations/01-linear-algebra-intuition/code/vectors.py
```

실행한 명령어, 종료 코드, 정규화된 벡터 출력, 사영(projection) 잔차, 그리고
행렬-벡터 곱이 왜 신경망의 레이어인지 한 문장으로 설명한 내용을 잘 보관하세요.

**다음 행동:** 입력 벡터 하나를 바꿔 보고 결과를 예측한 뒤 다시 실행하기.
그다음 [벡터, 행렬과 연산](02-vectors-matrices-operations/)으로 넘어가세요.
