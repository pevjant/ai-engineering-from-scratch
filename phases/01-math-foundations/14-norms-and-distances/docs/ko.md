# 노름과 거리

> 거리 함수가 "비슷하다"의 의미를 정의합니다. 잘못 고르면 그 아래 모든 것이 무너집니다.

**유형:** Build(직접 만들기)
**언어:** Python
**선수 지식:** 페이즈 1, 레슨 01(선형대수 직관), 02(벡터, 행렬과 연산)
**시간:** 약 90분

## 학습 목표

- L1, L2, 코사인, 마할라노비스, 자카드, 편집 거리 함수를 처음부터 직접 구현하기
- 주어진 ML 작업에 맞는 거리 지표를 고르고, 다른 대안이 왜 실패하는지 설명하기
- L1과 L2 노름을 LASSO와 Ridge 정규화, 그리고 그 기하학적 제약 영역과 연결하기
- 같은 데이터셋이라도 지표에 따라 최근접 이웃이 달라지는 것을 보여 주기

## 문제 상황

벡터가 두 개 있습니다. 단어 임베딩일 수도, 사용자 프로필일 수도, 픽셀 배열일 수도 있죠. 알아야 할 것은 하나입니다. 이 둘은 얼마나 가까운가?

답은 전적으로 어떤 거리 함수를 고르느냐에 달려 있습니다. 어떤 지표에서는 최근접 이웃이던 두 데이터 점이 다른 지표에서는 멀리 떨어져 있을 수 있습니다. KNN 분류기, 추천 엔진, 벡터 데이터베이스, 클러스터링 알고리즘, 손실 함수까지 전부 이 선택에 의존합니다. 잘못 고르면 모델이 엉뚱한 것을 최적화합니다.

모든 상황에 맞는 최고의 거리는 없습니다. L2는 공간 데이터에 어울립니다. NLP에서는 코사인 유사도가 왕입니다. 자카드는 집합을 다루고, 편집 거리는 문자열을 다룹니다. 마할라노비스는 상관관계를 반영하고, 바서슈타인(Wasserstein)은 확률 질량을 옮깁니다. 각각이 "비슷하다"에 대해 서로 다른 가정을 담고 있습니다.

이 레슨에서는 주요 거리 함수를 모두 직접 구현하고, 각각이 언제 맞는 도구인지 알려 주며, 같은 데이터라도 어떤 지표를 쓰느냐에 따라 최근접 이웃이 완전히 달라진다는 것을 보여 줍니다.

## 핵심 개념

### 노름: 벡터의 크기 재기

노름(norm)은 벡터의 "크기"를 재는 함수입니다. 두 벡터 사이의 모든 거리 함수는 그 차이의 노름으로 쓸 수 있습니다. d(a, b) = ||a - b||. 즉 노름을 이해하는 것이 거리를 이해하는 것입니다.

### L1 노름(맨해튼 거리)

L1 노름은 모든 성분의 절댓값을 더합니다.

```
||x||_1 = |x_1| + |x_2| + ... + |x_n|
```

맨해튼 거리라고 부르는 이유는, 축 방향으로만 움직일 수 있는 도시 격자에서 얼마나 걸어야 하는지를 재기 때문입니다. 대각선 이동은 없습니다.

```
점 A = (1, 1)
점 B = (4, 5)

L1 거리 = |4-1| + |5-1| = 3 + 4 = 7

격자 위에서 동쪽으로 3블록, 북쪽으로 4블록 걷는 것입니다.
```

L1을 쓰면 좋은 경우:
- 고차원 희소 데이터(텍스트 특성(feature), 원-핫 인코딩)
- 이상치에 강해야 할 때 (차이 하나가 크다고 전체를 지배하지 않음)
- 특성 선택(feature selection) 문제 (L1 정규화는 희소성을 유도함)

L1 정규화(Lasso)와의 연결: 손실 함수에 ||w||_1을 더하면 가중치 절댓값의 합이 벌점으로 작용합니다. 이렇게 하면 작은 가중치가 정확히 0으로 밀려나 자동 특성 선택이 일어납니다. L1 벌점은 가중치 공간에 다이아몬드 모양의 제약 영역을 만들고, 다이아몬드의 모서리는 축 위에 있어서 그 지점에서는 일부 가중치가 0이 됩니다.

손실 함수와의 연결: 평균 절대 오차(MAE)는 예측값과 타깃값 사이의 평균 L1 거리입니다. 모든 오류에 선형적으로 벌점을 매기기 때문에 MSE보다 이상치에 강합니다.

### L2 노름(유클리드 거리)

L2 노름은 직선 거리입니다. 성분 제곱의 합에 제곱근을 씌운 값이죠.

```
||x||_2 = sqrt(x_1^2 + x_2^2 + ... + x_n^2)
```

geometry 시간에 배운 바로 그 거리입니다. n차원 피타고라스 정리죠.

```
점 A = (1, 1)
점 B = (4, 5)

L2 거리 = sqrt((4-1)^2 + (5-1)^2) = sqrt(9 + 16) = sqrt(25) = 5.0

격자를 대각선으로 가로지르는 직선입니다.
```

L2를 쓰면 좋은 경우:
- 저·중차원 연속 데이터
- 특성들의 스케일이 비슷할 때
- 물리적 거리(공간 데이터, 센서 값)
- 픽셀 수준의 이미지 유사도

L2 정규화(Ridge)와의 연결: 손실 함수에 ||w||_2^2을 더하면 큰 가중치에 벌점이 매겨집니다. L1과 달리 가중치를 0으로 밀어내지는 않고, 모든 가중치를 비례적으로 0 쪽으로 줄입니다. L2 벌점은 원형 제약 영역을 만들기 때문에 축 위에 모서리가 없습니다. 가중치는 작아지지만 정확히 0이 되는 경우는 드뭅니다.

손실 함수와의 연결: 평균 제곱 오차(MSE)는 L2 거리를 제곱한 값의 평균입니다. 제곱하기 때문에 큰 오류에 더 무겁게 벌점을 줍니다.

```
MAE (L1 손실):  |y - y_hat|         선형 벌점. 이상치에 강건함.
MSE (L2 손실):  (y - y_hat)^2       이차 벌점. 이상치에 민감함.
```

### Lp 노름: 일반화된 족(family)

L1과 L2는 Lp 노름의 특수한 경우입니다:

```
||x||_p = (|x_1|^p + |x_2|^p + ... + |x_n|^p)^(1/p)
```

p 값에 따라 "단위 볼(unit ball)"(원점에서 거리 1인 모든 점의 집합) 모양이 달라집니다:

```
p=1:    다이아몬드            (축 위에 모서리)
p=2:    원/구                 (익숙한 둥근 볼)
p=3:    슈퍼타원              (모서리가 둥근 사각형)
p=inf:  정사각형/초입방체      (축에 평행한 평평한 면)
```

### L-무한 노름(체비쇼프 거리)

p가 무한대로 가면 Lp 노름은 최대 절댓값 성분으로 수렴합니다.

```
||x||_inf = max(|x_1|, |x_2|, ..., |x_n|)
```

두 점 사이의 거리는 차이가 가장 큰 단 하나의 차원으로 결정됩니다. 나머지 차원은 무시됩니다.

```
점 A = (1, 1)
점 B = (4, 5)

L-무한 거리 = max(|4-1|, |5-1|) = max(3, 4) = 4
```

L-무한을 쓰면 좋은 경우:
- 어느 한 차원의 최악 편차가 중요할 때
- 게임 보드 (체스의 킹은 L-무한으로 움직입니다. 어느 방향이든 한 칸에 비용 1)
- 제조 공차 (모든 차원이 규격 안에 있어야 함)

### 코사인 유사도와 코사인 거리

코사인 유사도는 두 벡터 사이의 각도를 측정하며, 크기는 무시합니다.

```
cos_sim(a, b) = (a . b) / (||a||_2 * ||b||_2)
```

값은 -1(정반대 방향)에서 +1(같은 방향) 사이입니다. 수직인 벡터의 코사인 유사도는 0입니다.

코사인 거리는 이를 거리로 바꾼 것입니다. cosine_distance = 1 - cosine_similarity. 값은 0(같은 방향)에서 2(정반대 방향) 사이입니다.

```
a = (1, 0)    b = (1, 1)

cos_sim = (1*1 + 0*1) / (1 * sqrt(2)) = 1/sqrt(2) = 0.707
cos_dist = 1 - 0.707 = 0.293
```

NLP와 임베딩에서 코사인이 왕인 이유: 텍스트에서는 문서 길이가 유사도에 영향을 주면 안 됩니다. 고양이에 대한 문서가 다른 고양이 문서의 두 배 길이여도 여전히 "비슷"해야 하죠. 코사인 유사도는 크기(길이)를 무시하고 방향만 봅니다. 단어 분포가 같고 길이만 다른 두 문서는 같은 방향을 가리키므로 코사인 유사도가 1.0입니다.

코사인 유사도를 쓰면 좋은 경우:
- 텍스트 유사도 (TF-IDF 벡터, 단어 임베딩, 문장 임베딩)
- 크기는 잡음이고 방향이 신호인 모든 도메인
- 추천 시스템 (사용자 선호 벡터)
- 임베딩 검색 (벡터 데이터베이스는 거의 항상 코사인이나 내적을 사용)

### 내적 유사도 vs 코사인 유사도

두 벡터의 내적은 다음과 같습니다:

```
a . b = a_1*b_1 + a_2*b_2 + ... + a_n*b_n
      = ||a|| * ||b|| * cos(angle)
```

코사인 유사도는 양쪽 크기로 정규화한 내적입니다. 두 벡터가 이미 단위 정규화되어 있으면(크기 = 1) 내적과 코사인 유사도는 같습니다.

```
||a|| = 1이고 ||b|| = 1이면:
    a . b = cos(a와 b 사이의 각도)
```

언제 달라지나: 내적에는 크기 정보가 섞여 들어옵니다. 크기가 큰 벡터일수록 내적 점수가 높아지죠. "인기 있는" 항목을 더 위에 랭킹하고 싶은 일부 검색 시스템에서는 이게 중요합니다. 크기가 암묵적인 품질 또는 중요도 신호 역할을 하는 겁니다.

```
a = (3, 0)    b = (1, 0)    c = (0, 1)

dot(a, b) = 3     dot(a, c) = 0
cos(a, b) = 1.0   cos(a, c) = 0.0

둘 다 방향에 대해서는 같은 말을 하지만, 내적은 크기까지 반영한다.
```

실전에서는:
- 순수한 방향성 유사도가 필요하면 코사인 유사도를 씁니다
- 크기가 의미 있는 정보를 담고 있으면 내적을 씁니다
- 많은 벡터 데이터베이스(Pinecone, Weaviate, Qdrant)는 둘 중 고를 수 있게 해 줍니다
- 임베딩이 L2 정규화되어 있다면 어떤 걸 고르든 차이가 없습니다

### 마할라노비스 거리

유클리드 거리는 모든 차원을 똑같이 취급합니다. 하지만 특성들이 서로 상관되어 있거나 스케일이 다르면 L2는 그릇된 결과를 줍니다.

마할라노비스 거리는 데이터의 공분산 구조를 반영합니다.

```
d_M(x, y) = sqrt((x - y)^T * S^(-1) * (x - y))
```

여기서 S는 데이터의 공분산 행렬입니다.

직관적으로는 이렇습니다. 마할라노비스 거리는 먼저 데이터를 비상관화·정규화(화이트닝)한 뒤, 그 변환된 공간에서 L2 거리를 계산합니다. S가 단위행렬이면(특성들이 무상관이고 분산이 1) 마할라노비스 거리는 유클리드 거리와 같아집니다.

```
예: 키와 몸무게는 서로 상관되어 있다.
키 6'2"(약 188cm)에 몸무게 180파운드(약 82kg)면 흔한 체형이다.
키 5'0"(약 152cm)에 180파운드면 드문 체형이다.

유클리드 거리는 둘 다 평균에서 똑같이 멀다고 말할 수 있다.
마할라노비스 거리는 키-몸무게 상관관계를 반영해서
두 번째 사람을 이상치로 올바르게 잡아낸다.
```

마할라노비스 거리를 쓰면 좋은 경우:
- 이상치 탐지 (평균에서 마할라노비스 거리가 큰 점이 이상치)
- 특성의 스케일과 상관관계가 제각각일 때의 분류
- 신뢰할 만한 공분산 행렬을 추정할 만큼 데이터가 충분할 때
- 제조 품질 관리 (다변량 공정 모니터링)

### 자카드 유사도(집합용)

자카드 유사도는 두 집합이 겹치는 정도를 측정합니다.

```
J(A, B) = |A intersect B| / |A union B|
```

값은 0(겹치는 게 없음)에서 1(완전히 같은 집합) 사이입니다. 자카드 거리 = 1 - 자카드 유사도.

```
A = {cat, dog, fish}
B = {cat, bird, fish, snake}

교집합 = {cat, fish}         크기 = 2
합집합 = {cat, dog, fish, bird, snake}  크기 = 5

자카드 유사도 = 2/5 = 0.4
자카드 거리 = 0.6
```

자카드를 쓰면 좋은 경우:
- 태그, 카테고리, 특성 집합 비교
- 단어 존재 여부(빈도가 아님) 기반의 문서 유사도
- 근사 중복 탐지 (자카드의 MinHash 근사)
- 이진 특성 벡터 비교 (존재/부재 데이터)
- 세그멘테이션 모델 평가 (Intersection over Union = 자카드)

### 편집 거리(Levenshtein 거리)

편집 거리는 한 문자열을 다른 문자열로 바꾸는 데 필요한 최소 문자 단위 연산 횟수입니다. 연산은 삽입, 삭제, 치환입니다.

```
"kitten" -> "sitting"

kitten -> sitten  (k를 s로 치환)
sitten -> sittin  (e를 i로 치환)
sittin -> sitting (g를 삽입)

편집 거리 = 3
```

동적 계획법으로 계산합니다. (i, j) 칸이 문자열 A의 앞 i글자와 문자열 B의 앞 j글자 사이의 편집 거리가 되도록 행렬을 채워 나갑니다.

```
        ""  s  i  t  t  i  n  g
    ""   0  1  2  3  4  5  6  7
    k    1  1  2  3  4  5  6  7
    i    2  2  1  2  3  4  5  6
    t    3  3  2  1  2  3  4  5
    t    4  4  3  2  1  2  3  4
    e    5  5  4  3  2  2  3  4
    n    6  6  5  4  3  3  2  3
```

편집 거리를 쓰면 좋은 경우:
- 맞춤법 검사와 교정
- DNA 서열 정렬 (가중치 있는 연산 사용)
- 퍼지 문자열 매칭
- 지저분한 텍스트 데이터의 중복 제거

### KL 발산(거리는 아니지만 거리처럼 쓰임)

KL 발산은 한 확률 분포가 다른 분포와 얼마나 다른지를 측정합니다. 레슨 09에서 다루지만, 거리가 아닌데도 거리처럼 쓰는 사람들이 많아서 이 논의에 들어갑니다.

```
D_KL(P || Q) = sum(p(x) * log(p(x) / q(x)))
```

결정적인 성질: KL 발산은 대칭이 아닙니다(NOT).

```
D_KL(P || Q) != D_KL(Q || P)
```

즉 거리 지표의 기본 요건을 충족하지 못합니다. 삼각 부등식도 성립하지 않습니다. 이것은 거리가 아니라 발산(divergence)입니다.

순방향 KL(D_KL(P || Q))은 "평균 추구(mean-seeking)"입니다. Q가 P의 모든 봉우리(mode)를 커버하려 합니다.
역방향 KL(D_KL(Q || P))은 "봉우리 추구(mode-seeking)"입니다. Q가 P의 한 봉우리에만 집중합니다.

KL 발산이 등장하는 곳:
- VAE (ELBO의 KL 항이 잠재 분포를 사전 분포 쪽으로 밀어 넣음)
- 지식 증류 (학생 모델이 교사 모델의 분포를 맞추려 함)
- RLHF (KL 벌점이 파인튜닝된 모델을 베이스 모델 가까이 묶어 둠)
- 정책 경사 방법 (정책 업데이트를 제약)

### 바서슈타인 거리(Earth Mover's Distance)

바서슈타인 거리는 한 확률 분포를 다른 분포로 바꾸는 데 필요한 최소 "일(work)"을 측정합니다. 이렇게 생각하세요. 한 분포가 흙더미이고 다른 쪽이 구멍이라면, 흙을 얼마나 옮기고 얼마나 멀리 옮겨야 할까?

```
W(P, Q) = 모든 수송 계획 gamma에 대해 E[d(x, y)]의 하한(inf)
```

1차원 분포에서는 누적분포함수(CDF)의 절댓값 차이의 적분으로 단순화됩니다:

```
W_1(P, Q) = integral |CDF_P(x) - CDF_Q(x)| dx
```

바서슈타인이 중요한 이유:
- 진짜 거리 지표입니다 (대칭, 삼각 부등식 성립)
- 분포가 겹치지 않아도 그래디언트를 줍니다 (KL 발산은 무한대로 감)
- 이 성질 덕분에 바서슈타인 GAN(WGAN)의 핵심이 되었고, 원조 GAN의 학습 불안정성 문제를 해결했습니다

```
겹치지 않는 분포:

P: [1, 0, 0, 0, 0]    Q: [0, 0, 0, 0, 1]

KL 발산: 무한대 (0의 로그)
바서슈타인: 4 (질량을 전부 4칸 옮김)

바서슈타인은 의미 있는 그래디언트를 준다. KL은 그렇지 못하다.
```

바서슈타인을 쓰면 좋은 경우:
- GAN 학습 (WGAN, WGAN-GP)
- 겹치지 않을 수 있는 분포 비교
- 최적 수송(optimal transport) 문제
- 이미지 검색 (색 히스토그램 비교)

### 손실 함수와의 연결

손실 함수는 예측값과 타깃값 사이에 적용한 거리 함수입니다.

```
손실 함수            사용하는 거리            동작
MSE                 L2 제곱                 큰 오류에 무겁게 벌점
MAE                 L1                      모든 오류에 똑같이 벌점
Huber loss          큰 오류엔 L1,            둘의 장점: 이상치에 강건하고,
                    작은 오류엔 L2           0 근처에서 그래디언트가 매끄러움
Cross-entropy       KL 발산                 분포 불일치를 측정
Hinge loss          max(0, margin - d)      마진 아래에만 벌점
Triplet loss        L2 (보통)               양성은 당겨오고 음성은 밀어냄
Contrastive loss    L2                      비슷한 쌍은 가깝게, 다른 쌍은
                                            마진 밖으로
```

### 정규화와의 연결

정규화는 손실 함수에 가중치에 대한 노름 벌점을 더하는 것입니다.

```
L1 정규화(Lasso):   loss + lambda * ||w||_1
  -> 희소한 가중치. 일부 가중치가 정확히 0이 됨.
  -> 자동 특성 선택.
  -> 해가 모서리를 가짐 (0에서 미분 불가능).

L2 정규화(Ridge):   loss + lambda * ||w||_2^2
  -> 작은 가중치. 모든 가중치가 0 쪽으로 줄어듦.
  -> 특성 선택 없음 (정확히 0이 되는 것이 없음).
  -> 해가 모든 곳에서 매끄러움.

Elastic Net:                  loss + lambda_1 * ||w||_1 + lambda_2 * ||w||_2^2
  -> L1의 희소성과 L2의 안정성을 결합.
  -> 상관된 특성 무리가 함께 유지되거나 함께 버려짐.
```

L1은 희소성을 만들고 L2는 그렇지 않은 이유: 2차원 가중치 공간의 제약 영역을 그려 보세요. L1은 다이아몬드이고 L2는 원입니다. 손실 함수의 등고선(타원)이 다이아몬드에 닿는 지점은 모서리일 확률이 가장 높은데, 그곳에서는 가중치 하나가 0입니다. 반면 원에는 매끄러운 점에서 닿으므로 두 가중치가 모두 0이 아닙니다.

### 최근접 이웃 탐색

모든 거리 함수는 최근접 이웃 탐색 문제를 함축합니다. 질의점 하나가 주어지면 데이터셋에서 가장 가까운 점들을 찾는 거죠.

정확한 최근접 이웃 탐색은 n개 점, d차원 데이터셋에서 질의당 O(n * d)입니다. 데이터셋이 크면 너무 느립니다.

근사 최근접 이웃(ANN) 알고리즘은 약간의 정확도를 대가로 엄청난 속도를 얻습니다:

```
알고리즘           접근 방식                        사용처
KD-trees          축에 정렬된 공간 분할             scikit-learn (저차원)
Ball trees        중첩된 초구(hypersphere)          scikit-learn (중차원)
LSH               무작위 해시 투영                  근사 중복 탐지
HNSW              계층적 탐색 가능 small-world      FAISS, Qdrant, Weaviate
                  그래프
IVF               클러스터 기반 검색이 있는         FAISS (십억 규모)
                  역파일 인덱스
Product quant.    벡터를 압축하고 압축된             FAISS (메모리 제약 시)
                  공간에서 검색
```

HNSW(Hierarchical Navigable Small World)는 현대 벡터 데이터베이스의 지배적인 알고리즘입니다. 각 노드가 자신의 근사 최근접 이웃과 연결된 다층 그래프를 만듭니다. 탐색은 최상위 레이어(희소, 긴 점프)에서 시작해 최하위 레이어(촘촘, 짧은 점프)로 내려갑니다.

## 활용하기

가장 흔한 실전 용도는 벡터 데이터베이스에서 비슷한 항목 찾기입니다.

```python
import numpy as np

def cosine_similarity_matrix(X):
    norms = np.linalg.norm(X, axis=1, keepdims=True)
    norms = np.where(norms == 0, 1, norms)
    X_normalized = X / norms
    return X_normalized @ X_normalized.T

embeddings = np.random.randn(1000, 768)

sim_matrix = cosine_similarity_matrix(embeddings)

query_idx = 0
similarities = sim_matrix[query_idx]
top_k = np.argsort(similarities)[::-1][1:6]
print(f"Top 5 most similar to item 0: {top_k}")
print(f"Similarities: {similarities[top_k]}")
```

`model.encode(text)`를 호출하고 벡터 데이터베이스를 검색할 때, 후드 아래에서는 이런 일이 벌어집니다. 임베딩 모델이 텍스트를 벡터로 바꿉니다. 벡터 데이터베이스는 질의 벡터와 저장된 모든 벡터 사이의 코사인 유사도(또는 내적)를 계산하되, 전부 검사하지 않도록 ANN 알고리즘을 사용합니다.

| 용어 | 사람들이 말하는 방식 | 실제 의미 |
|------|----------------|----------------------|
| 노름 | "벡터의 크기" | 벡터를 음이 아닌 스칼라로 대응시키는 함수. 삼각 부등식, 절대 동차성, 영벡터에서만 0이라는 조건을 만족함 |
| L1 노름 | "맨해튼 거리" | 성분 절댓값의 합. 최적화에서 희소성을 만들고 이상치에 강건함 |
| L2 노름 | "유클리드 거리" | 성분 제곱합의 제곱근. 유클리드 공간의 직선 거리 |
| Lp 노름 | "일반화된 노름" | 성분 절댓값의 p제곱합의 p제곱근. L1과 L2는 특수 사례 |
| L-무한 노름 | "최대 노름" 또는 "체비쇼프 거리" | 최대 절댓값 성분. p가 무한대로 갈 때의 Lp 극한 |
| 코사인 유사도 | "벡터 사이의 각도" | 양쪽 크기로 정규화한 내적. 범위는 -1부터 +1. 벡터 길이를 무시함 |
| 코사인 거리 | "1에서 코사인 유사도를 뺀 값" | 코사인 유사도를 거리로 바꾼 것. 범위는 0부터 2 |
| 내적 | "정규화하지 않은 코사인" | 성분별 곱의 합. 코사인 유사도에 양쪽 크기를 곱한 값과 같음 |
| 마할라노비스 거리 | "상관관계를 아는 거리" | 데이터 공분산 행렬로 화이트닝(비상관화·정규화)한 공간에서의 L2 거리 |
| 자카드 유사도 | "집합 겹침" | 교집합 크기를 합집합 크기로 나눈 값. 벡터가 아니라 집합용 |
| 편집 거리 | "Levenshtein 거리" | 한 문자열을 다른 문자열로 바꾸는 최소 삽입·삭제·치환 횟수 |
| KL 발산 | "분포 사이의 거리" | 진짜 거리가 아님(비대칭). P를 Q로 인코딩할 때 드는 추가 비트를 측정 |
| 바서슈타인 거리 | "흙 옮기는 거리(Earth mover's distance)" | 한 분포의 질량을 다른 분포로 옮기는 최소 일. 진짜 거리 지표임 |
| 근사 최근접 이웃 | "ANN 탐색" | 정확한 탐색보다 훨씬 빠르게 근사 최근접 점을 찾는 알고리즘(HNSW, LSH, IVF) |
| HNSW | "그 벡터 DB 알고리즘" | Hierarchical Navigable Small World 그래프. 빠른 근사 최근접 이웃 탐색용 다층 그래프 |
| L1 정규화 | "Lasso" | 손실에 가중치의 L1 노름을 더함. 가중치를 0으로 밀어냄(희소성) |
| L2 정규화 | "Ridge" 또는 "weight decay" | 손실에 가중치의 L2 노름 제곱을 더함. 희소성 없이 가중치를 0 쪽으로 줄임 |
| Elastic Net | "L1 + L2" | L1과 L2 정규화를 결합. 상관된 특성 무리를 어느 하나만 쓸 때보다 잘 처리함 |
