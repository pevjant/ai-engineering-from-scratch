# ML을 위한 정보 이론

머신러닝 시스템에서 엔트로피, 교차 엔트로피, KL 발산, 상호 정보량을 언제 쓰는지 정리합니다.

## 판단 체크리스트

1. 단일 분포의 불확실성을 측정할 때? **엔트로피**를 씁니다.
2. 모델이 참 레이블을 얼마나 잘 근사하는지 측정할 때? **교차 엔트로피**를 씁니다(이것이 바로 분류 손실입니다).
3. 두 분포 사이의 거리를 측정할 때? **KL 발산**을 씁니다.
4. 두 변수가 관련 있는지 확인할 때? **상호 정보량**을 씁니다.
5. 언어 모델 품질을 보고할 때? **퍼플렉서티**(교차 엔트로피의 지수)를 씁니다.
6. 한 모델을 다른 모델로 증류할 때? 교사(teacher)에서 학생(student) 방향의 **KL 발산**을 최소화합니다.

## 측도별 사용 시점

| 측도 | 공식 | 용도 | ML 적용 |
|---|---|---|---|
| 엔트로피 H(P) | -sum(p log p) | 이 분포는 얼마나 불확실한가? | 데이터 복잡도, 최대 엔트로피 모델 |
| 교차 엔트로피 H(P,Q) | -sum(p log q) | 모델 Q는 참 분포 P를 얼마나 잘 예측하는가? | 분류 손실, 언어 모델 손실 |
| KL 발산 D(P\|\|Q) | sum(p log(p/q)) | P와 Q는 얼마나 다른가? | VAE 손실(ELBO), 지식 증류, RLHF |
| 상호 정보량 I(X;Y) | H(X) - H(X\|Y) | Y는 X에 대해 얼마나 알려 주는가? | 특성 선택, 표현 학습 |
| 퍼플렉서티 | exp(H(P,Q)) 또는 2^H | 모델은 얼마나 헤매는가? | 언어 모델 평가 |
| 조건부 엔트로피 H(X\|Y) | -sum(p(x,y) log p(x\|y)) | Y를 알고 난 뒤 X에 남는 불확실성 | 특성의 정보력 |

## 핵심 관계

```
교차 엔트로피  = 엔트로피 + KL 발산
H(P, Q)        = H(P)   + D_KL(P || Q)

학습 중에는 H(P)가 상수이므로:
  교차 엔트로피 최소화 = KL 발산 최소화

상호 정보량 = 엔트로피 - 조건부 엔트로피
I(X; Y) = H(X) - H(X|Y) = H(Y) - H(Y|X)

퍼플렉서티 = exp(nat 단위 교차 엔트로피)
           = 2^(비트 단위 교차 엔트로피)
```

|---|---|---|
| 정보량: -log(p) | -log2(p) | -ln(p) |
| 엔트로피: -sum(p log p) | bits | nats |

| PyTorch 기본값 | -- | nats |

## 값 해석하기

| 엔트로피 값 | 의미 |
|---|---|
| 0 | 결정론적. 하나의 결과가 확률 1. |
| log(n) | 최대 불확실성. n개 결과에 대한 균등 분포. |
| 낮음 | 분포가 뾰족함. 모델이 확신함. |
| 높음 | 분포가 평평함. 모델이 불확실함. |

| 퍼플렉서티 값 | 언어 모델 품질 |
|---|---|
| 1 | 완벽한 예측(실전에서는 일어나지 않음) |
| 10 | 평균적으로 비슷한 가능성의 토큰 약 10개 중에서 고르는 수준 |
| 50 | 표준 벤치마크 기준 GPT-2 수준 |
| < 10 | 대표성이 좋은 도메인의 최고 수준 |

## 흔한 실수

- KL 발산을 계산해 놓고 대칭인 것처럼 다루기. D_KL(P||Q) != D_KL(Q||P)입니다. 대칭 측도가 필요하면 Jensen-Shannon 발산을 쓰세요: JS = 0.5 * KL(P||M) + 0.5 * KL(Q||M), 단 M = 0.5*(P+Q).
- 원-핫 레이블에서 교차 엔트로피가 -log(p_true_class)로 단순해진다는 것을 잊기. 참 분포가 원-핫이면 모든 클래스에 걸쳐 합을 구할 필요가 없습니다.
- 코드에서는 로그 밑 2를 쓰면서 보고는 nat으로 하기(또는 그 반대). PyTorch는 기본으로 자연로그를 씁니다. nat을 비트로 바꾸려면 log2(e) = 1.4427을 곱하세요.
- 비어 있는 사건이나 확률 0 사건의 엔트로피 계산. 관례: 0 * log(0) = 0. lim(p->0) p*log(p) = 0이기 때문입니다.
- 어휘 크기가 다른 모델들의 퍼플렉서티 비교하기. 어휘 5만 개에 퍼플렉서티 30인 모델과 어휘 1만 개에 퍼플렉서티 30인 모델은 직접 비교할 수 없습니다.

## 프로덕션 ML에서 각 개념이 나타나는 곳

| 개념 | 나타나는 곳 |
|---|---|
| 교차 엔트로피 손실 | 모든 분류 모델(nn.CrossEntropyLoss) |
| KL 발산 | VAE ELBO, PPO 클리핑, 지식 증류 |
| 엔트로피 정규화 | 강화 학습의 탐험 보너스(엔트로피가 높을수록 탐험이 많음) |
| 상호 정보량 | 특성 선택, InfoNCE 손실(대조 학습) |
| 퍼플렉서티 | 언어 모델 벤치마크(낮을수록 좋음) |
| 레이블 스무딩 | 원-핫을 소프트 타깃으로 바꿔 교차 엔트로피의 과신을 줄임 |
| 온도 스케일링(temperature scaling) | 소프트맥스 전에 로짓을 T로 나눠 출력의 엔트로피를 조절 |
