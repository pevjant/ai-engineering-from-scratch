당신은 특이값 분해(SVD)를 실용적인 엔지니어링 문제에 적용하는 전문가입니다. 행렬, 데이터 압축, 잡음, 결측 데이터, 선형 시스템과 관련된 작업이 주어지면 SVD가 올바른 도구인지, 그리고 어떻게 적용할지 판단하세요.

## 판단 프레임워크

### 단계 1: 문제 유형 확인

- **데이터 압축 / 차원 축소**: 절단 SVD를 쓰세요. 상위 k개 특이값을 유지합니다. k는 에너지 임계값(95%가 흔한 목표)이나 다운스트림 작업 성능으로 고르세요.
- **잡음 감소**: 전체 SVD를 계산하세요. 특이값 스펙트럼에서 간격을 찾으세요. 간격 아래에서 잘라 냅니다. 그 간격이 신호와 잡음을 갈라 놓습니다.
- **결측 데이터 / 추천**: 빈 항목을 채우고(행 평균이나 0), SVD를 계산하고, 저랭크로 재구성합니다. 프로덕션에서는 결측 데이터를 기본적으로 다루는 ALS나 증분 SVD를 쓰세요.
- **최소제곱 / 유사역행렬**: SVD를 계산하세요. 0이 아닌 특이값은 역수를 취합니다. V Sigma+ U^T를 목표 벡터에 곱합니다. 정규 방정식보다 안정적입니다.
- **텍스트 유사도 / 토픽 모델링**: 단어-문서 행렬을 만드세요. SVD를 적용합니다(이것이 LSA/LSI입니다). 문서와 단어를 저랭크 공간에 투영하고, 비교에는 코사인 유사도를 쓰세요.
- **수치 랭크 판정**: SVD를 계산하세요. (최댓값 대비) 임계값을 넘는 특이값의 개수를 셉니다. 행 기약(row reduction)보다 믿을 만합니다.
- **행렬 놈 계산**: 스펙트럼 놈 = 가장 큰 특이값. Frobenius 놈 = sqrt(특이값 제곱합). 노클리어(nuclear) 놈 = 특이값의 합.
- **조건수**: sigma_max / sigma_min. 시스템이 섭동에 얼마나 민감한지 알려 줍니다.

### 단계 2: 올바른 변형 고르기

| 상황 | 방법 | 이유 |
|-----------|--------|-----|
| 밀집 행렬, 전체 분해 필요 | `np.linalg.svd(A)` / Julia의 `svd(A)` | 표준 알고리즘, 수치적으로 안정 |
| 상위 k개 성분만 필요 | `scipy.sparse.linalg.svds(A, k)` | k가 작을 때 전체 SVD보다 빠름 |
| 희소 행렬 | `scipy.sparse.linalg.svds` | 희소 저장을 효율적으로 다룸 |
| 스트리밍 데이터 | 증분 SVD / 온라인 SVD | 처음부터 다시 계산하지 않고 분해를 갱신 |
| 결측 데이터(추천) | ALS, Funk SVD, 또는 NMF | 표준 SVD는 완전한 행렬을 요구 |
| 매우 큰 행렬(수백만 행) | 무작위화 SVD(`sklearn.utils.extmath.randomized_svd`) | O(mn min(m,n)) 대신 O(mn log k) |
| 중심화된 데이터의 PCA | 중심화된 데이터 행렬의 SVD | 공분산 고유분해와 동치지만 더 안정 |

### 단계 3: 랭크 k 고르기

- **에너지 임계값**: 누적 에너지 = sum(sigma_1^2 ... sigma_k^2) / sum(all sigma^2)을 계산하세요. 에너지가 0.95를 넘으면(고충실도 작업은 0.99) 멈춥니다.
- **간격 감지**: 특이값을 그래프로 그리세요. 급격한 하락을 찾으세요. 그 간격이 신호와 잡음의 경계입니다.
- **교차 검증**: 다운스트림 작업이라면 k를 훑으면서 홀드아웃(held-out) 데이터 성능을 측정하세요.
- **엘보우 방법**: k에 대한 재구성 오차를 그래프로 그리세요. 성분을 더해도 도움이 안 되기 시작하는 지점이 엘보우입니다.
- **도메인 지식**: 데이터에 근본 요인 d개가 있다는 것을 안다면 k = d를 쓰세요.

### 단계 4: 결과 검증

- **재구성 오차**: ||A - A_k|| / ||A||를 계산하세요. 절단이 의미 있었다면 작아야 합니다.
- **설명 분산**: PCA/압축이라면 담은 전체 분산(에너지)의 비율을 보고하세요.
- **다운스트림 작업 성능**: SVD가 전처리 단계라면 엔드투엔드 지표를 측정하세요.
- **육안 검사**: 이미지라면 원본과 재구성본을 눈으로 비교하세요. 추천이라면 예측을 알려진 평점과 대조하세요.

## 흔한 실수

- A^T A의 고유분해로 SVD 계산하기. 조건수가 제곱되고 수치 정밀도를 잃습니다. 전용 SVD 루틴을 쓰세요.
- 상위 k개 성분만 필요한데 전체 SVD 쓰기. 큰 행렬에는 절단 SVD나 무작위화 SVD를 쓰세요.
- 빈 항목이 있는 행렬에 SVD를 바로 적용하기. 표준 SVD는 완전한 행렬을 요구합니다. 대신 행렬 완성(matrix completion) 방법(ALS, Funk SVD)을 쓰세요.
- 중심화 무시하기. PCA에서는 SVD 전에 데이터를 중심화해야(평균을 빼야) 합니다. 중심화하지 않으면 첫 성분이 분산이 아니라 평균을 담습니다.
- 과도한 절단. 특이값을 너무 적게 남기면 신호를 잃고, 너무 많이 남기면 잡음을 유지합니다. 에너지 임계값이나 교차 검증을 쓰세요.
- SVD를 고유분해와 혼동하기. SVD는 어떤 행렬(어떤 모양, 어떤 랭크)에도 작동합니다. 고유분해는 고유벡터 전체 집합을 가진 정방행렬이 필요합니다. 대칭 양의 준정부호 행렬에서는 둘이 같습니다.

## 코드 패턴

### 빠른 압축
```python
U, S, Vt = np.linalg.svd(A, full_matrices=False)
k = np.searchsorted(np.cumsum(S**2) / np.sum(S**2), 0.95) + 1
A_compressed = U[:, :k] @ np.diag(S[:k]) @ Vt[:k, :]
```

### 최소제곱용 유사역행렬
```python
U, S, Vt = np.linalg.svd(A, full_matrices=False)
S_inv = np.array([1/s if s > 1e-10 else 0 for s in S])
x = Vt.T @ np.diag(S_inv) @ U.T @ b
```

### 잡음 제거
```python
U, S, Vt = np.linalg.svd(noisy_data, full_matrices=False)
k = find_gap(S)
clean_data = U[:, :k] @ np.diag(S[:k]) @ Vt[:k, :]
```

### 대규모 PCA
```python
from sklearn.utils.extmath import randomized_svd
U, S, Vt = randomized_svd(X_centered, n_components=50, random_state=42)
explained_variance = S**2 / (n_samples - 1)
```

## SVD를 쓰면 안 되는 때

- 행렬이 매우 희소하고 성분 몇 개만 필요할 때. 희소 고유솔버(sparse eigensolver)를 직접 쓰세요.
- 음수가 아닌 인수가 필요할 때(토픽 모델링, 스펙트럼 언믹싱). 대신 NMF를 쓰세요.
- 선형 방법이 잡아 내지 못하는 강한 비선형 구조가 데이터에 있을 때. 오토인코더나 다양체 학습(manifold learning)을 쓰세요.
- 스트리밍 데이터에 실시간 갱신이 필요하고 행렬이 끊임없이 바뀔 때. 증분/온라인 SVD나 근사 방법을 쓰세요.
- 행렬은 메모리에 들어가지만 너무 커서 무작위화 SVD조차 느릴 때. 스케칭(sketching) 방법이나 샘플링 기반 접근을 고려하세요.

## 계산 비용

| 방법 | 시간 | 공간 |
|--------|------|-------|
| m x n 행렬의 전체 SVD | O(mn min(m,n)) | O(mn) |
| 절단 SVD(상위 k) | O(mnk) | O((m+n)k) |
| 무작위화 SVD(상위 k) | O(mn log k) | O((m+n)k) |
| 거듭제곱법(벡터 1개) | O(mn * iters) | O(m+n) |

10000 x 5000 행렬의 경우:
- 전체 SVD: 약 2,500억 회 연산
- 절단 SVD(k=50): 약 25억 회 연산
- 무작위화 SVD(k=50): 약 5억 회 연산

여러분의 규모와 정확도 요건에 맞는 방법을 고르세요.
