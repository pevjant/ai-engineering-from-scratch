# 모달리티 정렬용 투영 레이어(Projection Layer for Modality Alignment)

> 비전 인코더는 이미지 토큰을 만들어 냅니다. 텍스트 디코더는 텍스트 토큰을 소비합니다. 둘은 서로 다른 벡터 공간에 삽니다. 작은 2층 MLP가 이미지 토큰을 텍스트 임베딩 공간으로 투영하고, 짝이 맞는 캡션에 대한 코사인 정렬 손실이 두 공간을 일치시켜 당깁니다. 그 투영이 비전-언어 모델에서 가장 작은 부품이자, 전이(transfer)에 가장 중요한 부품입니다.

**유형:** Build
**언어:** Python
**선수 지식:** 페이즈 19 레슨 30-37 (트랙 B 기초)
**시간:** 약 90분

## 학습 목표

- 이미지 특성을 텍스트 임베딩 공간으로 보내는 2층 MLP 투영을 만든다.
- 목 텍스트 임베딩 테이블을 만든다(사전학습 토크나이저도, 실제 코퍼스도 없이).
- 투영된 이미지 토큰과 짝이 맞는 캡션 임베딩 사이의 코사인 정렬 손실을 계산한다.
- 동결된 비전 인코더와 동결된 텍스트 테이블을 두고 투영만 학습시킨다.

## 문제 상황

`vision_hidden = 768` 차원의 토큰을 만드는 비전 인코더가 있습니다(레슨 58-59). 그 위에 얹고 싶은 텍스트 디코더의 임베딩 차원은 `text_hidden = 512`입니다(다른 숫자라도 마찬가지로 그럴듯합니다). 디코더는 텍스트 모양의 토큰을 기대합니다. 하지만 이미지 토큰은 텍스트 모양이 아닙니다. 비전 전용 사전학습에서 인코더가 학습한 기저 안에 살고 있고, 디코더의 단어 벡터와는 아무 관계가 없습니다.

2층 MLP 투영(linear, GELU, linear)이 그 간극을 잇습니다. 크기가 작아서(약 `768 * 1024 + 1024 * 512 = 1.3M` 파라미터) GPU 한 장에서 몇 분이면 학습되고, 정렬 단계에서 학습해야 하는 유일한 부품입니다. 비전 인코더는 동결됩니다. 텍스트 임베딩 테이블도 동결됩니다. 움직이는 것은 투영뿐입니다. 이것이 2023년 LLaVA가 출시한 레시피이고, BLIP-2가 Q-Former로 재해석한 레시피이며, 이후 모든 오픈 웨이트 VLM이 어떤 형태로든 채택한 레시피입니다.

```mermaid

  Tab --> Txt[텍스트 임베딩 B x 512]
  Img --> Loss[코사인 정렬 손실]
  Txt --> Loss
```

### 투영 전 풀링

비전 인코더는 토큰 197개를 내놓습니다. 텍스트 쪽에는 캡션 수준의 임베딩이 하나 있습니다. 둘을 정렬하려면 샘플당 이미지 수준 벡터 하나가 필요합니다. CLS 풀링이 가장 단순합니다. 인코더에서 첫 토큰을 가져와 투영합니다. 197개 토큰 전체에 대한 평균 풀링도 또 하나의 선택지이며 SigLIP이 쓰는 방식입니다. 어느 쪽이든 197개 벡터를 하나로 풀링합니다.

### 왜 층이 하나가 아니라 두 개인가

단일 선형 투영은 회전과 크기 조절은 할 수 있지만, 두 공간 사이에 곡률 불일치가 있으면 기저를 맞추지 못합니다. 두 선형 레이어 사이의 GELU는 투영에 비선형 굴곡 하나를 주고, 경험적으로 CLIP 스타일 특성을 언어 모델 임베딩에 정렬하기에 충분합니다. 더 깊은 투영(LLaVA-NeXT는 GLU를 썼고, Qwen-VL은 어텐션 레이어 스택을 썼습니다)은 확장입니다. 2층 MLP가 정석 베이스라인이고, BLIP-2의 Q-Former 투영 헤드도 내부적으로는 이것을 실어 나릅니다.

| 레이어 | 형태 | 파라미터 |
|-------|-------|------------|
| fc1 | `(vision_hidden, projection_hidden)` | `768 * 1024 + 1024` |
| 활성화 | GELU | 0 |
| fc2 | `(projection_hidden, text_hidden)` | `1024 * 512 + 512` |

`768 -> 1024 -> 512` 헤드 기준 약 1.3M 파라미터입니다.

### 코사인 정렬 손실

정렬은 `image_emb == text_emb`를 뜻하지 않습니다. 정렬은 결합 공간에서 `image_emb`가 `text_emb`와 같은 방향을 가리키는 것을 뜻합니다. 코사인 손실은 `1 - cos_sim(image, text)`이며, 0(완벽한 정렬)에서 2(정반대) 사이의 값을 갖습니다. 학습은 쌍별로 이 값을 0으로 밀어갑니다. 레슨 62는 대조적 배치(InfoNCE)로 일반화합니다. 배치 안의 모든 이미지가 자기 캡션에 다른 어떤 캡션보다 가까워야 하는 것이죠. 이 레슨은 동역학이 잘 보이도록 쌍별(per-pair) 버전을 씁니다.

### 동결된 인코더가 핵심 트릭

비전 인코더에는 86M 파라미터가 있습니다. 텍스트 테이블에도 몇백만 개가 더 있습니다. 목 코퍼스에서 이 전부를 학습시키는 것은 처음부터 무리입니다. 둘 다 동결하면 변하는 것은 투영의 1.3M 파라미터뿐이고, 합성 쌍 몇백 스텝이면 손실을 내려가게 하기에 충분합니다. 이것이 바로 어댑터 기반 VLM 전부의 운영 형태입니다. 무거운 부분은 동결되고, 가벼운 다리만 학습됩니다.

## 직접 만들기

`code/main.py`는 다음을 구현합니다:

- `MLPProjector(in_dim, hidden_dim, out_dim)`: GELU 활성화가 있는 2층 선형 MLP.
- `MockTextEmbedding(vocab_size, dim)`: 시드로 결정론적 초기화되는 동결된 임베딩 테이블.
- `make_pair(seed, vocab_size)`: 짝이 맞는 (이미지, 캡션) 샘플을 하나 합성합니다. 캡션은 짧은 id 시퀀스이고, 캡션 임베딩은 토큰 임베딩을 평균 풀링한 것입니다.
- `cosine_alignment_loss(image_emb, text_emb)`: 쌍별 `1 - cos_sim` 목적 함수.
- 비전 인코더와 텍스트 테이블을 동결한 채 32개의 합성 쌍(순환 사용)에 걸쳐 투영을 200스텝 실행하고 25스텝마다 손실을 출력하는 학습 루프.

실행 방법:

```bash
python3 code/main.py
```

출력: 학습 보고서가 초기 손실 약 1.07에서 200스텝 안에 약 0.80으로 내려가는 것을 보여 줍니다. 투영만으로 이미지 토큰을 텍스트 공간 쪽으로 끌어당길 수 있다는 증명입니다. 쌍별 최종 코사인 유사도도 함께 출력됩니다.

## 활용하기

같은 패턴이 모든 오픈 웨이트 VLM에 나타납니다:

- **LLaVA 1.5.** CLIP-ViT-L 히든에서 LLaMA 임베딩 차원으로 가는 2층 GELU MLP 투영. 동결된 비전 인코더, 동결된 LLM, 투영만 학습(그다음 2단계에서 LLM 동결 해제).
- **BLIP-2.** Q-Former가 학습된 쿼리 토큰 32개를 이미지 토큰에 대한 크로스 어텐션으로 통과시킨 뒤 LLM 임베딩 차원으로 투영합니다. Q-Former 맨 끝의 투영 헤드가 이 레슨의 MLP에 해당합니다.
- **MiniGPT-4.** BLIP-2 Q-Former 출력에서 Vicuna 임베딩 차원으로 가는 단일 선형 투영.
- **Qwen-VL.** 여러 층의 크로스 어텐션 어댑터지만, 마지막 부품은 역시 LM 임베딩 차원으로 가는 투영입니다.

형태는 갈리지만 역할은 동일합니다. 이미지 토큰을 풀링하고, 텍스트 임베딩 차원으로 투영하고, 혼자서 학습합니다.

## 테스트

`code/test_main.py`는 다음을 다룹니다:

- 투영기 출력 형태가 설정된 `out_dim`과 일치
- 동결된 텍스트 임베딩 테이블에 `requires_grad` 파라미터가 0개
- 코사인 손실이 같은 벡터에서는 0, 반평행 벡터에서는 2

- 학습 루프가 스텝 0에서 스텝 200 사이에 손실을 줄임


## 연습 문제

1. CLS 풀링을 196개 패치 토큰에 대한 평균 풀링으로 바꾸고 200스텝 후의 최종 손실을 비교해 보세요. 평균 풀링은 합성 데이터에서 보통 더 빨리 학습되고, CLS는 자연 이미지에서 샘플 효율이 더 좋습니다.

2. 코사인 손실에 학습되는 스칼라 온도를 더하고(`cos / tau`), `tau`가 너무 작을 때(그래디언트 노이즈)와 너무 클 때(손실이 높은 곳에서 정체) 무슨 일이 일어나는지 관찰해 보세요.

3. 2층 MLP를 단일 선형 레이어로 바꾸고 손실 격차를 정량화해 보세요. 비선형성은 자연 이미지 특성에서 더 중요하고 합성 특성에서는 덜 중요합니다.

4. 투영기 가중치에 작은 L2 패널티를 더하고 코사인 정렬과 어떻게 상호작용하는지 지켜 보세요(코사인은 스케일 불변이므로 패널티는 대개 쓰이지 않는 방향을 줄입니다).

5. 투영기 가중치를 저장했다가 다시 불러오고, 비전 인코더 역전파 없이 추론을 실행해서 배포 시점에 투영기만 필요하다는 것을 검증해 보세요.

## 핵심 용어

| 용어 | 의미 |
|------|---------------|
| 모달리티 정렬 | 이미지 임베딩과 텍스트 임베딩을 하나의 공유 공간에서 비교 가능하게 만드는 행위 |
| 투영 헤드 | 한 공간을 다른 공간으로 보내는 작은 모듈. 보통 2층 MLP |
| 코사인 유사도 | 내적을 L2 노름의 곱으로 나눈 값 |
| 동결된 인코더 | 비전(또는 텍스트) 모델의 모든 파라미터가 `requires_grad=False`인 상태 |
| 목 코퍼스 | 학습이 데이터셋 다운로드 의존성 없이 이뤄지도록 쓰는 합성 쌍 |
