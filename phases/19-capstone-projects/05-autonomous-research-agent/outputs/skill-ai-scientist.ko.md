> 🇰🇷 이 문서는 한국어 번역본입니다(ELI5 스타일). 원문: [skill-ai-scientist.md](skill-ai-scientist.md)

시드 아이디어와 좁은 도메인, $30 컴퓨팅 예산이 주어지면, 실험 트리 탐색을 돌리고 검토 가능한 LaTeX 논문을 쓰고 재현성 번들을 내놓는 에이전트를 만듭니다.

만들기 계획:

1. 문헌 패스: Semantic Scholar Graph API + OpenAlex. 초록을 FAISS에 캐싱하고 1페이지짜리 도메인 다이제스트를 생성합니다.
2. 트리 탐색: `expand(node) -> children`(자식당 설정 편집 하나)과 `score(node) = novelty*0.4 + quality*0.5 + budget*0.1`로 실험 노드 위의 최적 우선 확장을 구현합니다.
3. 노드별 샌드박스: 모든 실험은 `docker run --network=none --memory=8g --cpus=2 --pids-limit=256 --read-only` 또는 동등한 E2B 정책으로 돕니다. 결정론적 시드, 자원 상한 강제.
4. 플랜-실행-검증: 검증 단계는 손실 수렴, 베이스라인 실행, 소거 실험이 주장을 고립했는지 확인합니다.
5. 작성자: LaTeX를 생성하고 PDF로 컴파일하고, 레이아웃과 주장-증거 정렬에 대한 비평을 위해 PDF를 Claude Opus 4.7 비전 모드에 넣고, 최대 3회 반복합니다.
6. 리뷰어 앙상블: 다섯 판정자(Opus 4.7, GPT-5.4, Gemini 3 Pro, DeepSeek R1, Qwen3-Max)가 NeurIPS 루브릭(신선도, 엄밀성, 명료성, 재현성, 임팩트)으로 점수를 매깁니다. 평균 < 4.0이면 작성자에게 돌아갑니다.
7. 레드팀: 적대적 과제(포크 폭탄, 파일시스템 탈출, LLM이 작성한 네트워크 호출)를 통합합니다. 전부 막히는지 확인합니다. `red_team.md`를 발행합니다.
8. 재현성 번들: paper.pdf + review.md + 트리 탐색 트레이스 JSON + 시드 + W&B 실행 링크 + 샌드박스 설정 + 한 줄 재실행 명령.

채점 기준:

| 가중치 | 기준 | 측정 |
|:-:|---|---|
| 25 | 논문 품질 | 같은 시드 주제의 공개 워크숍 논문 대비 블라인드 루브릭 검토 |
| 20 | 실험 엄밀성 | 베이스라인, 시드, 소거 실험. 모든 주장이 결과 표의 칸으로 뒷받침 |
| 20 | 비용과 컴퓨팅 규율 | 논문당 $30 상한 강제, Langfuse로 추적 |
| 20 | 안전 | 샌드박스 레드팀 통과. 네트워크 정책과 킬 스위치를 기록된 시도로 검증 |
| 15 | 재현성 | 한 명령 재실행이 같은 시드로 논문을 재현 |

하드 리젝트(무조건 반려):

- 샌드박스 밖에서 돌아가는 실험. 이 캡스톤의 전체 명제는 실행이 가둬진다는 것입니다.
- 컴파일된 PDF를 다시 읽지 않는 작성자 단계(비전 비평은 하중을 떠받치는 핵심입니다).
- 베이스라인, 시드, 소거 섹션이 없는 논문.
- 하드 상한이 아니라 사후 경고로만 강제되는 비용 예산.

거절 규칙:

- 사람의 명시적 재정의 없이 리뷰어 평균이 4.0/5 미만인 논문을 발행하는 것을 거절하세요.
- 샌드박스 안에서 네트워크 접근이 필요한 시드 아이디어의 실행을 거절하세요. 대신 별도의 읽기 전용 데이터셋 볼륨을 추가하세요.
- 레드팀을 실행하고 기록하지 않은 논문의 재실행을 거절하세요.

출력: 트리 탐색 엔진, 샌드박스 정책, 작성자/리뷰어 루프, 재현성 번들과 함께한 세 개의 예시 실행, 레드팀 보고서, 비용 대장 csv, 그리고 Sakana v2 실패 모드 중 무엇을 재현했고 완화가 어떻게 작동했는지 이름으로 적은 보고서가 담긴 저장소.
