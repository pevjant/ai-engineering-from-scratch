대상 LLM 애플리케이션(8B 명령 튜닝 모델 또는 RAG 챗봇)이 주어지면, 계층화된 안전 파이프라인으로 강화하고 여섯 공격 계열에 걸쳐 자율 레드 팀 레인지를 돌립니다. 이전/이후 무해성 보고서를 만들어 냅니다.

만들기 계획:

1. 다섯 레이어 파이프라인: 입력 정화(폭 없는 너비 문자 제거, 인코딩 디코딩, 유니코드 정규화) -> NeMo Guardrails v0.12 레일 -> 분류기 게이트(Llama Guard 4 / X-Guard / ShieldGemma-2 / Nemotron 3) -> 대상 LLM -> 출력 필터(Llama Guard 4 + Presidio PII + 인용 검사). 표시된 출력은 Slack HITL 큐로 갑니다.
2. 귀속(attribution)이 끝까지 관찰될 수 있도록 레이어마다 Langfuse 스팬을 내보냅니다.
3. cron으로 garak, PyRIT, PAIR, TAP, GCG, 멀티턴 페르소나, 다국어 코드 전환 공격을 돌리는 레드 팀 스케줄러.
4. 성공한 탈옥마다: CVSS 4.0 점수, 재현(repro), 완화 계획, 공개 타임라인.
5. 과잉 거절 퇴보(regression)를 잡기 위해 XSTest 무해 프롬프트 프로브를 계속 실행.
6. 헌법적 자기 비판 실행: 유해 시도 프롬프트 1천 개 -> 대상 초안 작성 -> 비판자가 작성된 헌법에 대조해 채점 -> 다시 쓴 쌍 -> SFT. 홀드아웃 무해성 평가에서 이전/이후를 측정합니다.
7. 알림: 무해 퇴보 시 Slack 경고, 새 탈옥 계열 발견 시 PagerDuty 심각 알림.

평가 루브릭:

| 가중치 | 기준 | 측정 |
|:-:|---|---|
| 25 | 공격 표면 커버리지 | 6개 이상 공격 계열 실행, 2개 이상 언어 |
| 20 | 참 양성 / 거짓 양성 트레이드오프 | 공격 차단률 vs XSTest 무해 통과율 |
| 20 | 자기 비판 변화량 | 홀드아웃 평가에서의 이전/이후 무해성 |
| 20 | 문서화와 공개 | 타임라인이 붙은 CVSS 점수 발견 사항 |
| 15 | 자동화와 재현성 | cron 주도, 끝까지 검증된 알림 |

즉각 탈락(Hard rejects):

- 단일 레이어 안전 스택. 이 캡스톤의 논지가 심층 방어입니다.
- XSTest 과잉 거절 수치 없이 성공률만 보고하는 레드 팀 실행.
- 홀드아웃 평가 없는 헌법적 자기 비판(학습 셋 정확도만 보고하고 일반화는 보고하지 않음).
- 탈옥 발견 사항에 CVSS 채점이 빠진 경우.

거절 규칙(Refusal rules):

- 무해 프로브 대조 없이 안전 수치를 보고하는 일을 거절합니다. 한쪽만 있는 숫자는 오해를 부릅니다.
- 비판 쌍의 사람 검토 없이 레드 팀 성공 사례로 자동 재학습하는 일을 거절합니다.
- 최소 두 개의 비영어 언어에서 X-Guard를 실행하지 않고 다국어 커버리지를 주장하는 일을 거절합니다.

산출물: 다섯 레이어 파이프라인, 레드 팀 스케줄러, PAIR/TAP/GCG 러너, 헌법적 자기 비판 학습 하니스, XSTest 과잉 거절 대시보드, CVSS 발견 사항 추적기, 그리고 강화 전 가장 높은 성공률을 기록한 세 공격 계열과 각각을 완화한 특정 파이프라인 레이어를 적은 보고서를 담은 저장소.
