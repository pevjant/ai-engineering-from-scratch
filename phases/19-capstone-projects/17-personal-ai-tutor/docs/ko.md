# 캡스톤 17 — 개인 AI 튜터 (적응형, 멀티모달, 메모리 포함)

> Khanmigo(Khan Academy), Duolingo Max, Google LearnLM / Gemini for Education, Quizlet Q-Chat, Synthesis Tutor가 2026년에 모두 대규모 적응형 멀티모달 튜터링을 출시했습니다. 공통 형태는 소크라테스식 정책(정답을 그냥 알려주지 않음), 상호작용이 있을 때마다 갱신되는 학습자 모델(베이지안 지식 추적 방식), 음성 + 텍스트 + 사진 수학 입력, 커리큘럼 그래프 검색, 간격 반복 스케줄링, 그리고 연령에 맞는 콘텐츠를 위한 강력한 안전 필터입니다. 이 캡스톤은 과목 특화 튜터(K-12 대수학 또는 파이썬 입문)를 출시하고, 학습자 10명으로 2주짜리 학습 효과 연구를 수행하며, 콘텐츠 안전 감사를 통과하는 것입니다.

**유형:** 캡스톤
**사용 언어:** Python(백엔드, 학습자 모델), TypeScript(웹 앱), SQL(Postgres + Neo4j로 커리큘럼 그래프)
**선수 지식:** 페이즈 5(NLP), 페이즈 6(음성), 페이즈 11(LLM 엔지니어링), 페이즈 12(멀티모달), 페이즈 14(에이전트), 페이즈 17(인프라), 페이즈 18(안전)
**활용하는 페이즈:** P5 · P6 · P11 · P12 · P14 · P17 · P18
**소요 시간:** 30시간

## 문제

적응형 튜터링은 예전에는 에드테크 연구의 틈새 분야였습니다. 그러나 2026년이 되자 소비자 제품이 되었습니다. Khanmigo는 미국 학구 대부분에 배포되어 있습니다. Duolingo Max는 수천만 MAU(월간 활성 사용자)에 도달했습니다. Google의 LearnLM / Gemini for Education은 Google Classroom의 튜터링을 떠받칩니다. Quizlet Q-Chat은 플래시카드 옆에 자리 잡았습니다. Synthesis Tutor는 '호기심 많은 아이들을 위한 튜터'로 입소문을 냈습니다. 공통 요소는 이렇습니다: 멀티모달 입력(타이핑, 말하기, 수식 사진 찍기), 소크라테스식 교육법(먼저 묻고, 나중에 설명), 상호작용이 있을 때마다 갱신되는 학습자 모델, 그리고 엄격한 연령 적합성 안전.

여러분은 특정 학습자 집단을 위한 튜터 하나를 만듭니다. 측정 기준은 실제 학습 효과 연구입니다: 학습자 10명, 2주간의 사전 테스트와 사후 테스트 점수. 음성 루프는 자연스럽게 느껴져야 하고(캡스톤 03 서브 스택), 메모리는 프라이버시를 존중해야 하며, 안전 필터는 K-12 대상 COPPA를 의식한 레드팀(red-team) 시험을 통과해야 합니다.

## 개념

네 가지 구성 요소가 있습니다. **튜터 정책**은 소크라테스식 루프입니다: 학습자가 정답을 달라고 하면 유도 질문을 돌려주고, 맞히면 다음 개념으로 넘어가고, 막히면 단계적 힌트(scaffolded hint)를 줍니다. **학습자 모델**은 베이지안 지식 추적(Bayesian knowledge tracing, 또는 간단한 변형)으로, 상호작용이 있을 때마다 커리큘럼 노드별 숙련도 확률을 갱신합니다. **커리큘럼 그래프**는 선수 관계 에지를 가진 개념들의 Neo4j 그래프이고, 정책은 이 그래프를 탐색해 다음 개념을 고릅니다. **메모리**는 과거 상호작용, 실수, 선호를 담는 에피소드 + 의미 저장소(agentmemory 스타일)입니다.

UX는 멀티모달입니다. 타이핑한 답에는 텍스트 입력. LiveKit + Whisper를 통한 음성 입력(캡스톤 03 재사용). dots.ocr 또는 PaliGemma 2를 통한 수학 문제 사진 입력. Cartesia Sonic-2를 통한 음성 출력. 안전은 Llama Guard 4에 연령 적합성 필터(성인 콘텐츠, 폭력, 자해 차단)와 COPPA를 의식한 메모리 보존 정책을 더해 사용합니다.

학습 효과 연구가 산출물입니다. 학습자 10명, 사전 테스트와 사후 테스트, 2주. 학습 향상 변화량과 신뢰 구간을 보고하세요. 비적응형 베이스라인(튜터 정책 없이 같은 콘텐츠를 선형으로 전달)과 비교합니다.

## 아키텍처

```
학습자 기기
  |
  +-- 텍스트         -> 웹 앱
  +-- 음성        -> LiveKit Agents (ASR + TTS)
  +-- 사진 수학   -> dots.ocr / PaliGemma 2
       |
       v
  튜터 정책 (LangGraph)
       - 소크라테스식 의사 결정 헤드
       - 다음 개념 선택기 (커리큘럼 그래프 탐색)
       - 힌트 스캐폴딩
       - 숙련도 갱신
       |
       v
  학습자 모델 (BKT / 문항 반응 이론)
       - 개념별 숙련도 확률
       - 간격 반복 스케줄러 (SM-2 또는 FSRS)
       |
       v
  메모리 (agentmemory 스타일)
       - 에피소드: 모든 상호작용
       - 의미: 학습된 실수, 선호
       - 보존 정책: COPPA / GDPR 대응
       |
       v
  커리큘럼 그래프 (Neo4j)
       - 선수 관계 에지
       - 연결된 OER 콘텐츠
       |
       v
  안전:
    Llama Guard 4 + 연령 적합성 필터
    메모리 접근은 학습자 ID 범위로 보호
```

## 스택

- 과목 선택: K-12 대수학 또는 파이썬 입문 (하나를 골라 깊이 파기)
- 튜터 정책: Claude Sonnet 4.7 위의 LangGraph (프롬프트 캐싱 사용)
- 학습자 모델: 베이지안 지식 추적(클래식) 또는 간격 조절용 FSRS
- 커리큘럼 그래프: 개념 + 선수 관계 에지 + OER 콘텐츠의 Neo4j
- 메모리: agentmemory 스타일 영구 벡터 + 에피소드 + 의미 저장소
- 음성: LiveKit Agents 1.0 + Cartesia Sonic-2 (캡스톤 03 서브 스택 재사용)
- 사진 수학: 수식 인식용 dots.ocr 또는 PaliGemma 2
- 안전: Llama Guard 4 + 자체 연령 적합성 필터
- 평가(eval): Bloom 수준별 문제 생성, 사전/사후 테스트 하네스, 학습 효과 연구 도구

## 만들어 보기

1. **커리큘럼 그래프.** 선수 관계 에지를 가진 50~150개 개념 노드(예: "수직선"부터 "근의 공식"까지의 K-12 대수학)의 Neo4j 그래프를 만듭니다. 노드마다 OER 콘텐츠(Open Textbook, OpenStax)를 붙입니다.

2. **학습자 모델.** 베이지안 지식 추적을 추정(guess), 실수(slip), 학습률(learn-rate) 사전 확률로 초기화합니다. 상호작용마다 개념별 숙련도를 갱신합니다. 학습자별로 상태를 저장합니다.

3. **튜터 정책.** LangGraph 노드 구성: `read_signal`(학습자의 답이 정답 / 부분 정답 / 막힘 중 무엇이었나?), `select_concept`(커리큘럼 그래프를 탐색해 최우선 개념 선택), `scaffold`(소크라테스식 프롬프트), `update_mastery`.

4. **메모리.** 모든 상호작용은 에피소드 저장소에 기록됩니다. 실수와 선호는 의미 메모리로 승격됩니다. COPPA 대응 보존 정책: 1년 후 자동 삭제, 부모 접근 가능.

5. **음성 경로.** 튜터 정책에 붙은 LiveKit Agents 워커. ASR은 Whisper-v3-turbo. TTS는 Cartesia Sonic-2. 끼어들기(barge-in) 지원(캡스톤 03 메커니즘 재사용).

6. **사진 수학 경로.** 이미지를 업로드하거나 촬영하면 dots.ocr 또는 PaliGemma 2로 수식을 인식하고, 구조화된 입력으로 튜터에 넘깁니다.

7. **안전.** 모든 모델 출력은 Llama Guard 4 + 연령 적합성 필터(자해, 성인 콘텐츠, 폭력 차단)를 통과합니다. 메모리 접근은 학습자 ID로 범위가 한정되고, 삭제를 위한 부모 접근 화면을 제공합니다.

8. **학습 효과 연구.** 학습자 10명, 사전 테스트(표준화된 30문항 베이스라인), 2주간 튜터 상호작용(주 3회), 사후 테스트. 같은 콘텐츠를 쓰는 비적응형 베이스라인 집단 10명과 비교합니다.

9. **주간 진도 보고서.** 학습자별로 탐색한 주제, 숙련도 추이, 추천 다음 단계를 담은 PDF 요약을 자동 생성합니다.

## 사용 예

```
학습자: "3x + 6 = 12가 왜 x = 2를 뜻하는지 모르겠어요"
[신호]   막힘
[개념]  '변수 분리' (선수 개념: 덧셈-뺄셈-등식)
[힌트] "양변에서 어떤 수를 빼면 좋을까요?"
학습자: "6"
[신호]   정답
[숙련도]  덧셈-뺄셈-등식: 0.62 -> 0.77
[개념]  '변수 분리' 계속
[힌트] "좋아요. 이제 3x / 3은 얼마가 될까요?"
```

## 연습 문제

1. 학습 효과 연구를 적응형 학습자 모델을 쓴 경우와 쓰지 않은 경우(개념 순서 무작위)로 돌려 보세요. 변화량을 보고하세요. 적응형이 이길 것이라고 예상되지만, 그 차이의 크기가 진짜 흥미로운 숫자입니다.

2. 멀티모달 프로브를 추가하세요: 같은 개념 질문을 텍스트, 음성, 사진으로 전달합니다. 학습자가 선호하는 방식일 때 더 빨리 수렴하는지 측정하세요.

3. 부모 대시보드를 만드세요: 연습한 주제, 숙련도 추이, 다가오는 개념, 안전 이벤트(가드레일 적중 내역). COPPA에 맞춰 만드세요.

4. 언어 전환 모드를 추가하세요: 튜터가 스페인어 입력을 받고 스페인어로 가르칩니다. X-Guard 커버리지를 측정하세요.

5. 메모리 프라이버시를 스트레스 테스트하세요: 음성 클립 재수집 공격으로도 학습자 A가 학습자 B의 데이터를 볼 수 없는지 검증하세요. 시도된 접근을 로그로 남기고 알림을 보내세요.

## 핵심 용어

| 용어 | 사람들이 말하는 표현 | 실제 의미 |
|------|-----------------|------------------------|
| 소크라테스식 정책 | "물어보되, 정답을 쏟아붓지 않는다" | 튜터가 정답을 주는 대신 유도 질문을 던짐 |
| 베이지안 지식 추적 | "BKT" | 개념별 숙련도 확률을 위한 클래식 학습자 모델 방정식 |
| FSRS | "Free Spaced Repetition Scheduler" | SM-2보다 나은 2024년식 간격 반복 스케줄러 |
| 커리큘럼 그래프 | "개념 DAG" | 선수 관계 에지를 가진 개념들의 Neo4j 그래프 |
| 에피소드 메모리 | "상호작용별 로그" | 나중에 꺼내 볼 수 있게 저장된 모든 상호작용 |
| 의미 메모리 | "학습된 패턴 저장소" | 에피소드에서 승격된, 압축된 실수와 선호 |
| COPPA | "아동 프라이버시법" | 13세 미만 아동의 데이터 수집을 제한하는 미국 법률 |
