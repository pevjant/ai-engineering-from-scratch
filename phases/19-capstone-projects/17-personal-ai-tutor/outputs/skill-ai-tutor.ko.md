> 🇰🇷 이 문서는 한국어 번역본입니다(ELI5 스타일). 원문: [skill-ai-tutor.md](skill-ai-tutor.md)

과목 하나(K-12 대수학 또는 파이썬 입문)가 주어지면, 텍스트 + 음성 + 사진 수학 입력, 베이지안 지식 추적 학습자 모델, 커리큘럼 그래프 기반 개념 선택, COPPA 대응 메모리, 안전 필터를 갖춘 개인 튜터를 만듭니다. 학습자 10명으로 2주짜리 학습 효과 연구를 실행합니다.

빌드 계획:

1. Neo4j의 커리큘럼 그래프: 선수 관계 에지와 연결된 OER 콘텐츠(OpenStax, Open Textbook)를 갖춘 50~150개 개념 노드.
2. 학습자 모델: 개념별 추정(guess)/실수(slip)/학습률(learn-rate) 사전 확률을 둔 베이지안 지식 추적; 학습자별 상태 저장.
3. 튜터 정책(프롬프트 캐싱을 쓰는 Claude Sonnet 4.7 위의 LangGraph): read_signal -> select_concept (그래프 탐색) -> scaffold (소크라테스식) -> update_mastery.
4. 메모리: agentmemory 스타일 영구 에피소드 + 의미 저장소; COPPA 대응 1년 후 자동 삭제; 부모가 접근 가능한 삭제.
5. 음성: Whisper-v3-turbo ASR과 Cartesia Sonic-2 TTS를 갖춘 LiveKit Agents 워커; 캡스톤 03 파이프라인 재사용.
6. 사진 수학: 수식 인식용 dots.ocr 또는 PaliGemma 2; 구조화된 입력을 튜터에 전달.
7. 안전: Llama Guard 4 입력/출력 검사; 자해/성인/폭력을 막는 연령 적합성 필터; 학습자별 메모리 격리.
8. 학습자별 주간 PDF 진도 보고서.
9. 학습 효과 연구: 학습자 10명, 사전 테스트(표준화된 30문항 베이스라인), 2주간 세션(주 3회), 사후 테스트; 비적응형 선형 집단과 비교.

하드 리젝트(절대 탈락):

- 다음 질문을 던지는 대신 정답을 쏟아붓는 튜터 정책. 소크라테스식은 필수 요건입니다.
- 상호작용마다 갱신되지 않는 학습자 모델. BKT가 최소 기준선입니다.
- COPPA 대응 보존 정책이 없는 메모리. K-12 대상에게는 용납할 수 없습니다.
- 비적응형 베이스라인 집단 없이 주장하는 학습 효과.

거부 규칙:

- 입력과 출력 양쪽에 Llama Guard 4가 없으면 배포를 거부합니다.
- 부모가 접근 가능한 삭제 화면 없이 학습자 데이터를 저장하는 것을 거부합니다.
- 비적응형 베이스라인을 함께 돌리지 않고 "적응형"이라고 주장하는 것을 거부합니다.

산출물: 커리큘럼 그래프, BKT 학습자 모델, LangGraph 튜터 정책, 멀티모달 입력 처리기, LiveKit 음성 파이프라인, 안전 파이프라인, 부모 대시보드, 학습 효과 연구 실행기, 사전/사후 테스트 하네스, 그리고 신뢰 구간과 함께 선형 베이스라인 대비 학습 향상 변화량을 문서화한 보고서를 담은 저장소.
