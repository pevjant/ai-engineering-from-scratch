# 레드팀 도구 — Garak, Llama Guard, PyRIT

> 세 가지 프로덕션 도구가 2026년 레드팀 스택을 규정합니다. Llama Guard(Meta) — 14개 MLCommons 위험 범주로 파인튜닝한 Llama-3.1-8B 분류기; 2025년 Llama Guard 4는 Llama 4 Scout에서 프루닝한, 본래부터 멀티모달인 12B 분류기입니다. Garak(NVIDIA) — 환각, 데이터 유출, 프롬프트 인젝션, 독성, 탈옥에 대한 정적·동적·적응형 프로브를 갖춘 오픈소스 LLM 취약점 스캐너입니다. PyRIT(Microsoft) — Crescendo, TAP, 커스텀 컨버터 체인으로 깊은 공략을 수행하는 다중 턴 레드팀 캠페인 도구입니다. Llama Guard 3는 Meta의 "Llama 3 Herd of Models"(arXiv:2407.21783)에, Llama Guard 3-1B-INT4는 arXiv:2411.17713에, Garak의 프로브 아키텍처는 github.com/NVIDIA/garak에 문서화되어 있습니다. 이 도구들은 레드팀 연구(레슨 12~15)와 배포(레슨 17 이상) 사이의 2026년 프로덕션(운영 환경) 인터페이스입니다.

**유형:** Build
**언어:** Python (표준 라이브러리, 도구 아키텍처 시뮬레이터 및 Llama Guard 스타일 분류기 목업)
**선수 지식:** 페이즈 18 · 12~15 (탈옥과 IPI)
**시간:** 약 75분

## 학습 목표

- Llama Guard 3/4의 안전 스택에서의 위치를 설명합니다: 입력 분류기, 출력 분류기, 아니면 둘 다.
- 14개 MLCommons 위험 범주를 말하고, 눈에 띄지 않는 하나(코드 인터프리터 남용)를 짚습니다.
- Garak의 프로브 아키텍처를 설명합니다: 프로브, 감지기(detector), 하네스.
- PyRIT의 다중 턴 캠페인 구조와, Garak 프로브와의 결합 방식을 설명합니다.

## 문제 상황

레슨 12~15는 공격 표면을 제시했습니다. 프로덕션 배포에는 반복 가능하고 확장 가능한 평가가 필요합니다. 2026년을 지배하는 도구 셋: Llama Guard(방어 분류기), Garak(스캐너), PyRIT(캠페인 오케스트레이터). 각자 레드팀 수명 주기의 다른 계층을 겨냥합니다.

## 개념

### Llama Guard (Meta)

Llama Guard 3는 MLCommons AILuminate 14개 범주에 대한 입력/출력 분류용으로 파인튜닝한 Llama-3.1-8B 모델입니다:
- 폭력 범죄, 비폭력 범죄, 성 관련, 아동 성착취물(CSAM), 명예훼손
- 전문 조언, 프라이버시, 지식재산권, 무차별 무기, 혐오
- 자살/자해, 성적 콘텐츠, 선거, 코드 인터프리터 남용

8개 언어를 지원합니다. 사용법: LLM 앞에(입력 모더레이션), LLM 뒤에(출력 모더레이션), 또는 둘 다 배치합니다. 두 용도는 서로 다른 훈련 분포를 만들어 냅니다 — Llama Guard 3는 둘 다를 처리하는 단일 모델로 출시됩니다.

Llama Guard 3-1B-INT4(arXiv:2411.17713, 440MB, 모바일 CPU에서 초당 약 30토큰)는 양자화된 엣지 변형입니다.

Llama Guard 4(2025년 4월)는 12B, 본래부터 멀티모달, Llama 4 Scout에서 프루닝한 모델입니다. 텍스트 + 이미지를 함께 받아들이는 하나의 분류기로, 기존의 8B 텍스트 버전과 11B 비전 버전을 모두 대체합니다.

### Garak (NVIDIA)

오픈소스 취약점 스캐너입니다. 아키텍처:
- **프로브(probes).** 환각, 데이터 유출, 프롬프트 인젝션, 독성, 탈옥을 위한 공격 생성기. 정적(고정 프롬프트), 동적(생성된 프롬프트), 적응형(대상 출력에 반응).
- **감지기(detectors).** 예상 실패 양상 — 유독성, 유출, 탈옥 — 에 대해 출력을 채점합니다.
- **하네스(harnesses).** 프로브-감지기 쌍을 관리하고, 캠페인을 실행하고, 보고서를 생성합니다.

TrustyAI는 Garak을 Llama-Stack 실드(Prompt-Guard-86M 입력 분류기, Llama-Guard-3-8B 출력 분류기)와 통합해 엔드투엔드 실드 대상 평가를 수행합니다. 등급 기반 채점(TBSA)은 이분법적 합격/불합격을 대체합니다 — 같은 프로브에서 모델은 심각도 등급 3에서는 통과하고 등급 5에서는 실패할 수 있습니다.

### PyRIT (Microsoft)

Python Risk Identification Toolkit. 다중 턴 레드팀 캠페인 도구입니다. 다음을 중심으로 구성됩니다:
- **컨버터(converters).** 시드 프롬프트를 변형합니다 — 의역, 인코딩, 번역, 롤플레이.
- **오케스트레이터(orchestrators).** 캠페인을 실행합니다: Crescendo(에스컬레이션), TAP(분기), RedTeaming(커스텀 루프).
- **채점.** LLM을 판사로 또는 분류기를 판사로 사용합니다.

PyRIT은 Garak의 무거운 사촌입니다. Garak은 수천 개의 단일 턴 프로브를 돌리고, PyRIT은 특정 실패 양상을 깨뜨리도록 설계된 깊은 다중 턴 캠페인을 돌립니다.

### 스택

모델 양쪽에 Llama Guard를 놓습니다. 회귀(regression)를 위해 Garak을 매일 밤 돌립니다. 출시 전 캠페인을 위해 PyRIT을 돌립니다. 이것이 대부분의 프로덕션 배포의 2026년 기본 구성입니다.

### 평가의 함정

- **판사 신원.** 세 도구 모두 LLM 판사를 쓸 수 있습니다; 판사의 보정(calibration) 상태가 보고된 ASR을 좌우합니다(레슨 12). 도구와 함께 판사를 명시하십시오.
- **프로브 노후화.** 모델이 프로브에 패치를 적용하면 Garak 프로브는 낡습니다. 적응형 프로브(PAIR 형태)는 정적 프로브보다 덜 낡습니다.
- **정상 콘텐츠에 대한 Llama Guard의 거짓 양성(FPR).** 초기 Llama Guard 버전은 정치적·LGBTQ+ 콘텐츠를 과잉 표지했습니다; Llama Guard 3/4의 보정은 개선되었지만 배포별 보정은 되어 있지 않습니다.

### 페이즈 18에서의 위치

## Use It

`code/main.py`는 장난감 Llama Guard 스타일 분류기(14개 범주 위의 키워드 + 의미 특성), 장난감 Garak 하네스(프로브-감지기 루프), PyRIT 스타일 다중 턴 컨버터 체인을 만듭니다. 목업 대상을 상대로 세 도구를 돌려 보면 서로 다른 커버리지 특성을 관찰할 수 있습니다.

## 연습 문제

1. `code/main.py`를 실행합니다. Llama Guard 스타일 분류기의 단일 턴 공격 대 다중 턴 공격 탐지율을 비교합니다.

2. 새 Garak 프로브를 구현합니다: base64로 인코딩된 유해 요청. Llama Guard 스타일 분류기의 그것에 대한 탐지를 측정합니다.

3. PyRIT 스타일 컨버터 체인에 "프랑스어로 번역한 뒤 의역" 컨버터를 추가합니다. 공격 성공률을 다시 측정합니다.

4. Llama Guard 3의 위험 범주 목록을 읽습니다. 훈련 데이터가 정상적인 개발자 콘텐츠에 현실적으로 높은 거짓 양성률을 만들어 낼 범주 둘을 찾습니다.

5. Garak과 PyRIT의 설계 원칙을 비교합니다. 각각이 올바른 도구가 되는 배포 상황을 논증합니다.
