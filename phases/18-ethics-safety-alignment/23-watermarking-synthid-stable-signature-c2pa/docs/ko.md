# 워터마킹 — SynthID, Stable Signature, C2PA

> 세 기술이 2026년 AI 생성 콘텐츠 출처(provenance)의 뼈대를 이룹니다. SynthID(Google DeepMind) — 2023년 8월 이미지 워터마킹으로 출발해 2024년 5월 텍스트+비디오로 확장(Gemini + Veo), 2024년 10월 Responsible GenAI Toolkit을 통해 텍스트 부분 오픈소스화, 2025년 11월 Gemini 3 Pro와 함께 통합 멀티미디어 감지기 공개. 텍스트 워터마킹은 다음 토큰 샘플링 확률을 알아차리지 못할 정도로 조정합니다. 이미지/비디오 워터마크는 압축, 잘라내기, 필터, 프레임레이트 변경을 견딥니다. Stable Signature(Fernandez 등, ICCV 2023, arXiv:2303.15435) — 잠재 확산(latent diffusion) 디코더를 파인튜닝해 모든 출력에 고정 메시지를 심습니다. 10%만 남기고 잘라낸 생성 이미지도 FPR<1e-6에서 90% 넘게 탐지됩니다. 후속 연구 "Stable Signature is Unstable"(arXiv:2405.07145, 2024년 5월) — 파인튜닝이 품질을 유지하면서 워터마크를 제거합니다. C2PA — 암호학적으로 서명된, 변조 방지 메타데이터 표준(C2PA 2.2 Explainer 2025). 워터마킹과 C2PA는 상호 보완적입니다. 메타데이터는 제거할 수 있지만 더 풍부한 출처 정보를 담고, 워터마크는 트랜스코딩을 통과해도 남지만 담는 정보가 적습니다.

**유형:** Build
**언어:** Python (표준 라이브러리, 토큰 워터마크 삽입 + 탐지)
**선수 지식:** 페이즈 10 · 04(샘플링), 페이즈 01 · 09(정보 이론)
**시간:** 약 75분

## 학습 목표

- 토큰 수준 워터마킹(SynthID-text 방식)과 그것이 탐지되는 메커니즘을 설명할 수 있습니다.
- Stable Signature와 그것을 무너뜨린 2024년 제거 공격을 설명할 수 있습니다.
- C2PA의 역할과 워터마킹과의 상호 보완 관계를 말할 수 있습니다.
- 핵심 한계들, 즉 모델 종속 신호, 패러프레이즈(의역)에서의 취약성, 의미 보존 공격(arXiv:2508.20228)을 설명할 수 있습니다.

## 해결할 문제

2023-2024년 딥페이크와 AI 생성 콘텐츠가 정치·소비자 영역에 대규모로 들어왔습니다. 워터마킹은 제안된 기술적 출처 신호입니다. 생성 시점에 표식을 남기고, 나중에 그것을 탐지합니다. 2025년 증거: 어떤 워터마크도 무조건적으로 견고하지는 않습니다. 하지만 C2PA 메타데이터와 층을 이루면 조합이 쓸 만한 출처 이야기를 만들어 줍니다.

## 핵심 개념

### 텍스트 워터마킹 (SynthID-text 방식)

Kirchenbauer 등 2023의 메커니즘을 Google이 프로덕션화한 것입니다:

1. 각 디코딩 단계에서 이전 K개 토큰을 해시해 어휘를 "녹색" 집합과 "빨간" 집합으로 나누는 의사난수 분할을 만듭니다.
2. 녹색 로짓에 δ를 더해 샘플링이 녹색 집합 쪽으로 기울게 합니다.
3. 생성물에는 우연히 나올 확률보다 녹색 토큰이 더 많아집니다.

탐지: 각 프리픽스를 다시 해시하고, 생성물 속 녹색 토큰 수를 세어 z-점수를 계산합니다. 워터마크된 텍스트는 z-점수가 0보다 크고, 사람이 쓴 텍스트는 대략 0입니다.

성질:
- 읽는 사람에게는 알아차리지 못합니다(δ가 충분히 작아 품질 손실이 미미합니다).
- 어휘 분할 함수에 접근할 수 있으면 탐지할 수 있습니다.
- 패러프레이즈에는 견디지 못합니다. 글을 다시 쓰면 신호가 파괴됩니다.

SynthID-text는 2024년 10월 Google의 Responsible GenAI Toolkit으로 오픈소스화되었습니다.

### Stable Signature (이미지)

Fernandez 등 ICCV 2023. 잠재 확산 디코더를 파인튜닝해, 생성되는 모든 이미지에 잠재 표현 안에 고정된 이진 메시지가 심기게 합니다. 탐지는 신경망 디코더로 잠재 표현에서 메시지를 읽어냅니다. 콘텐츠의 10%만 남기고 잘라낸 이미지도 FPR<1e-6에서 90% 넘게 탐지됩니다.

2024년 5월 "Stable Signature is Unstable"(arXiv:2405.07145): 디코더를 파인튜닝하면 이미지 품질을 유지한 채 워터마크가 제거됩니다. 생성 후의 적대적 파인튜닝은 싸고, 이 워터마크의 적대 강건성은 제한적입니다.

### SynthID 통합 감지기 (2025년 11월)

Gemini 3 Pro와 함께 공개: 텍스트, 이미지, 오디오, 비디오의 SynthID 신호를 하나의 API로 읽는 멀티미디어 감지기입니다. Google의 출처 스택을 통합합니다.

### C2PA

Coalition for Content Provenance and Authenticity. 암호학적으로 서명된 변조 방지 메타데이터 표준입니다. C2PA 2.2 Explainer(2025). C2PA 매니페스트는 출처 주장(누가 만들었는가, 언제, 어떤 변형을 거쳤는가)을 생성자의 키로 서명해 기록합니다.

워터마킹과의 보완 관계:
- 메타데이터는 제거할 수 있지만, 워터마크는 (쉽게는) 제거할 수 없습니다.
- 메타데이터는 풍부합니다(전체 출처 체인). 워터마크는 몇 비트를 담습니다.
- C2PA는 플랫폼 채택에 의존합니다. 워터마크는 자동으로 심깁니다.

Google은 Search, Ads, "이 이미지 정보"에서 둘 다 통합하고 있습니다.

### 한계

- **모델 종속.** SynthID는 SynthID가 켜진 모델의 생성물에만 붙습니다. SynthID 없는 모델의 생성물은 워터마크가 없으므로, "SynthID 신호가 없다"는 진위의 증거가 아닙니다.
- **패러프레이즈.** 텍스트 워터마크는 의미를 보존하는 의역을 견디지 못합니다.
- **변형 공격.** arXiv:2508.20228(2025)은 텍스트 워터마크와 다수의 이미지 워터마크를 모두 파괴하는 의미 보존 공격을 보여 줍니다.
- **파인튜닝 제거.** "Stable Signature is Unstable"에 따르면 생성 후 파인튜닝이 심어진 워터마크를 제거합니다.

## 사용해 보기

`code/main.py`는 장난감 텍스트 워터마크를 만듭니다. 토큰은 0..N-1의 정수이고, 워터마크된 샘플링은 해시로 정의된 녹색 집합 쪽으로 기웁니다. 탐지기는 녹색 토큰 z-점수를 계산합니다. 1,000토큰 생성물에서의 탐지를 관찰하고, 패러프레이즈가 신호를 파괴하는 것을 지켜보며, 사람이 쓴 텍스트에서의 거짓양성률을 측정할 수 있습니다.

## 출시하기

이 레슨은 `outputs/skill-provenance-audit.md`를 산출물로 만듭니다. 출처 주장이 붙은 콘텐츠 배포가 주어지면, 워터마크 메커니즘(있다면), C2PA 서명 체인(있다면), 각각의 적대 강건성, 모달리티별 커버리지를 감사(audit)합니다.

## 연습 문제

1. `code/main.py`를 실행합니다. 워터마크된 1,000토큰 생성물과 사람이 쓴 텍스트의 z-점수를 보고합니다. 95% 신뢰 임계값에서의 거짓양성률을 찾습니다.

2. 30%의 토큰을 동의어로 바꾸는 패러프레이즈 공격을 구현합니다. z-점수를 다시 측정합니다.

3. Kirchenbauer 등 2023의 6장(강건성)을 읽습니다. 텍스트 워터마크는 패러프레이즈에서 무너지는데 이미지 워터마크는 잘라내기를 견디는 이유는 무엇인가?

4. SynthID-text + C2PA 메타데이터를 함께 쓰는 배포를 설계합니다. 소비자가 보게 될 출처 체인을 기술하고, 각 구성 요소의 고장 모드를 하나씩 찾습니다.

5. 2024년 "Stable Signature is Unstable" 결과는 파인튜닝이 이미지 워터마크를 제거함을 보입니다. 이 공격을 제한하는 배포 통제를 설계합니다. 예를 들어 파인튜닝된 체크포인트의 서명된 릴리스를 요구할 수 있습니다.

## 핵심 용어

| 용어 | 사람들이 말하는 표현 | 실제 의미 |
|------|---------------------|-----------|
| SynthID | "구글의 워터마크" | 텍스트, 이미지, 오디오, 비디오를 아우르는 출처 신호 |
| 토큰 워터마크 | "Kirchenbauer 방식" | 녹색 토큰 z-점수로 탐지하는, 기울어진 샘플링 기반 텍스트 워터마크 |
| Stable Signature | "이미지 워터마크" | 파인튜닝된 디코더 워터마크. ICCV 2023 |
| C2PA | "그 메타데이터 표준" | 암호학적으로 서명된 변조 방지 출처 메타데이터 |
| 패러프레이즈 강건성 | "의역하면 깨지나" | 텍스트 워터마크의 성질. 현재는 제한적 |

| 크로스 모달 감지기 | "통합 SynthID" | 2025년 11월 공개, 모달리티를 아우르는 통합 API |
