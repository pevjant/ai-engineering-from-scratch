# LLM을 위한 차등 프라이버시(Differential Privacy)

> DP-SGD는 여전히 표준입니다. 노이즈를 섞은 그래디언트 업데이트가 형식적인 (엡실론, 델타) 보장을 제공합니다. 다만 연산·메모리·성능 오버헤드가 상당하고, 2025년에는 매개변수 효율적인 DP 파인튜닝(LoRA + DP-SGD)이 흔한 구성입니다(ACM 2025). 긴장 관계에 있는 두 갈래 증거: 카나리아 기반 멤버십 추론(Duan 등, 2024)은 언어 모델에 대해 제한적인 성공만을 보고했고, 학습 데이터 추출(Carlini 등, 2021; Nasr 등, 2025)은 상당한 양의 축자적 암기(verbatim memorization)를 복원해 냈습니다. 해소(arXiv:2503.06808, 2025년 3월): 차이는 측정 대상에 있습니다. '살짝 심어 넣은 카나리아' 대 '가장 잘 추출되는 데이터'가 다른 것입니다. 새로운 카나리아 설계는 섀도우 모델 없이 손실 기반 MIA를 가능케 했고, 실제 데이터로 현실적인 DP 보장을 걸고 학습한 LLM에 대한 최초의 의미 있는 DP 감사를 이루어 냈습니다. 대안들: PMixED(arXiv:2403.15638) — 다음 토큰 분포에 대한 전문가 혼합(mixture of experts)으로 추론 시점의 프라이빗 예측을 제공. DP 합성 데이터 생성(Google Research 2024). 떠오르는 공격: LLM 피드백을 통한 차등 프라이버시 역전(Differential Privacy Reversal via LLM Feedback) — 신뢰도 점수 누출입니다.

**유형:** Build
**언어:** Python (표준 라이브러리, DP-SGD 노이즈 주입 및 ε-δ 어카운턴트 시연)
**선수 지식:** 페이즈 01 · 09(정보 이론), 페이즈 10 · 01(대형 모델 학습)
**시간:** 약 60분

## 학습 목표

- (엡실론, 델타)-차등 프라이버시를 정의하고 DP-SGD 레시피를 말할 수 있습니다.
- 2024-2025년의 긴장 관계, 즉 카나리아 MIA와 학습 데이터 추출이 서로 다른 그림을 그리는 이유를 설명할 수 있습니다.
- PMixED를 설명하고, 왜 추론 시점의 프라이빗 예측이 DP 학습의 대안이 되는지 설명할 수 있습니다.
- LLM 피드백을 통한 차등 프라이버시 역전 공격을 설명할 수 있습니다.

## 해결할 문제

LLM은 암기합니다. Carlini 등 2021은 프로덕션 언어 모델이 요청하면 학습 텍스트를 축자적으로 재현한다는 것을 보였습니다. DP는 형식적 방어입니다. 어떤 단일 학습 예제에도 출력이 증명 가능하게 둔감하도록 학습시키는 것입니다. 2024-2025년 증거에 따르면 DP-SGD는 필요하지만, 실제 배포된 ε 값은 위협 모델과 맞지 않을 수 있습니다.

## 핵심 개념

### (ε, δ)-차등 프라이버시

무작위 알고리즘 M이 하나의 예제만 다른 임의의 두 데이터셋과 임의의 사건 S에 대해
P(M(D) in S) <= e^ε * P(M(D') in S) + δ를 만족하면 M은 (ε, δ)-DP입니다.

해석: 출력 분포가 (ε로 매개변수화된) 충분히 가까워서, 확률 δ를 제외하면 어떤 단일 개인의 기여도도 신뢰 있게 추론될 수 없습니다.

### DP-SGD

Abadi 등 2016. 표준 레시피:
1. 미니배치를 샘플링합니다.
2. 예제별 그래디언트를 계산합니다.
3. 각 예제별 그래디언트를 임계값 C로 클리핑합니다.
4. 클리핑된 그래디언트들을 더하고 표준편차 σ * C의 가우시안 노이즈를 더합니다.
5. 노이즈가 섞인 합으로 파라미터를 업데이트합니다.

프라이버시 비용은 어카운턴트(Moments Accountant, Rényi DP 어카운턴트)가 추적합니다. LLM 문헌에서 보고된 ε 값은 위협 모델, 데이터 민감도, 성능 목표에 따라 크게 다릅니다. 보편적으로 "안전한" 기본 ε은 없습니다. 일부 LLM 학습 설정에서 공개된 예는 대략 ε ≈ 1–10에 걸쳐 있지만 이는 예시일 뿐 권장 기본값이 아닙니다. 낮은 ε은 일반적으로 더 많은 노이즈를 요구하며 성능 손실을 키울 수 있습니다.

### LoRA + DP-SGD

프론티어 모델 전체를 DP-SGD 하는 것은 감당할 수 없습니다. LoRA(Hu 등 2022)는 그래디언트 업데이트를 작은 어댑터로 제한해 예제별 그래디언트 저장량을 줄입니다. LoRA + DP-SGD가 2025년의 흔한 구성입니다. DP 보장은 어댑터에 적용되고, 베이스 모델은 고정됩니다.

### 2024-2025년의 긴장

두 갈래 증거:

- **카나리아 MIA(Duan 등 2024).** 학습 데이터에 고유한 카나리아를 심고, 멤버십 추론 공격자가 이를 식별할 수 있는지 측정합니다. 언어 모델에 대해 제한적인 성공만을 보고했습니다. MIA가 어렵다는 시사입니다.
- **학습 데이터 추출(Carlini 2021, Nasr 등 2025).** 프리픽스로 모델을 촉구하고, 학습 데이터의 축자적 텍스트를 복원하는지 측정합니다. 상당한 암기를 보고했습니다. 중요한 의미에서는 MIA가 쉽다는 시사입니다.

2025년 3월의 해소(arXiv:2503.06808): 둘은 다른 것을 잽니다. MIA는 심어 넣은 카나리아에 대해 "예제 e가 D에 있나?"를 묻습니다. 추출은 "D에서 무엇을 뽑아낼 수 있나?"를 묻습니다. 프라이버시에 중요한 것은 '가장 잘 추출되는' 예제인데, 카나리아는 추출되기 쉽게 최적화되어 있지 않으므로 이를 과소 보고합니다.

새로운 카나리아 설계. 섀도우 모델 없는 손실 기반 MIA. 실제 데이터에서 현실적인 DP 보장으로 학습한 LLM에 대한 최초의 의미 있는 DP 감사.

### DP 학습의 대안들

- **PMixED(arXiv:2403.15638).** 추론 시점의 프라이빗 예측입니다. 다음 토큰 분포에 대한 전문가 혼합(mixture of experts); 각 전문가는 학습 데이터의 샤드를 보고, 집계 시 노이즈를 더해 DP를 만듭니다. DP 학습을 아예 피합니다.
- **DP 합성 데이터 생성(Google Research 2024).** DP-SGD로 LoRA 파인튜닝을 하고, 합성 데이터를 샘플링한 뒤, 그 합성 데이터로 하류 분류기를 학습합니다.

둘 다 전체 DP 학습의 성능 비용을 우회하지만, 대신 다른 위협 모델의 비용을 치릅니다.

### LLM 피드백을 통한 차등 프라이버시 역전(DP Reversal via LLM Feedback)

2025년에 떠오르는 공격입니다. DP로 학습된 모델의 신뢰도 점수를 오라클 삼아 개인을 재식별합니다. 출력 자체가 누출하지 않아도 신뢰도 분포는 누출할 수 있습니다.

방어: 신뢰도를 노출하지 않거나, 노출 전에 잘라내기(truncation)나 양자화를 합니다. 이것은 (ε, δ)-DP 학습에 더해지는 별도의 요구 사항입니다.

## 사용해 보기

`code/main.py`는 장난감 이진 분류 데이터셋에서 DP-SGD를 시뮬레이션합니다. 노이즈 승수 σ와 클리핑 노름 C를 쓸어 보며 (ε, δ) 예산과 정확도 비용을 추적할 수 있습니다. "카나리아 공격"은 고유한 학습 예제를 하나 심고, 로그 손실 검사가 DP 전후에서 그것을 탐지할 수 있는지 측정합니다.

## 출시하기

이 레슨은 `outputs/skill-dp-audit.md`를 산출물로 만듭니다. 언어 모델 배포에 대한 DP 주장이 주어지면, (ε, δ) 값, 사용한 어카운턴트, MIA 평가 프로토콜, 그리고 신뢰도 노출 벡터가 평가되었는지를 감사(audit)합니다.

## 연습 문제

1. `code/main.py`를 실행합니다. σ를 {0.5, 1.0, 2.0}로 쓸어 보며 (ε, δ)-정확도 트레이드오프를 보고합니다. 성능이 무너지는 지점을 찾습니다.

2. 카나리아 삽입과 로그 손실 검사를 구현합니다. σ = 1.0에서 DP-SGD 전후의 탐지율을 측정합니다.

3. Nasr 등 2025(학습 데이터 추출)를 읽습니다. 중간 정도의 ε에서도 추출 성공이 무너지지 않는 이유는 무엇인가? 이것이 '평가로서의 MIA'에 대해 무엇을 시사하는가?

4. PMixED(arXiv:2403.15638)를 사용해 전적으로 추론 시점에서 동작하는 배포를 설계합니다. PMixED가 다루지만 DP-SGD가 다루지 않는 위협 모델은 무엇인가?

5. LLM 피드백을 통한 DP 역전 공격을 스케치합니다. 신뢰도 점수 누출을 제한하는 대응책을 설계하고 배포 비용을 추정합니다.

## 핵심 용어

| 용어 | 사람들이 말하는 표현 | 실제 의미 |
|------|---------------------|-----------|
| DP | "(ε, δ)-차등 프라이버시" | 형식적 프라이버시: 인접 데이터셋 변경에서 출력 분포가 가까움 |
| DP-SGD | "노이즈 섞은 SGD" | 그래디언트 클리핑 + 가우시안 노이즈 추가. 표준 DP 학습 |
| LoRA + DP-SGD | "효율적인 프라이빗 파인튜닝" | 저랭크 어댑터에 적용한 DP-SGD. 2025년 표준 구성 |
| MIA | "멤버십 추론" | 예제가 학습 데이터에 있었는지 판별하는 공격 |
| 카나리아 | "심어 넣은 워터마크 예제" | DP 누출을 측정하는 데 쓰는 고유한 학습 예제 |
| PMixED | "프라이빗 추론 혼합" | 다음 토큰 분포에 대한 mixture-of-experts로 만드는 추론 시점 DP |
| DP 역전 | "신뢰도 누출 공격" | 모델의 신뢰도를 재식별 오라클로 쓰는 공격 |
