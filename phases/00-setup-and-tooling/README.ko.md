# 페이즈 0: 셋업과 도구 (Setup & Tooling)

> 이후의 모든 학습을 위해 환경을 먼저 준비하세요.

## GitHub에서 이 페이즈 시작하기

**선수 지식:** 없음. 시작하려면 Git과 Python 3.11 이상만 있으면 됩니다. 다른 도구들은
선택한 루트(route)에 필요할 때에만 설치합니다.

**첫 번째 레슨:** [개발 환경](01-dev-environment/)

저장소 루트에서 루트 인지 사전 점검(preflight)을 실행해 보세요:

```bash
python3 phases/00-setup-and-tooling/01-dev-environment/code/verify.py --route beginner
```

실행한 명령어, 저장소 루트에서의 작업 디렉터리, 종료 코드, 필수 검사 결과, 그리고
출력된 `Next:` 명령어를 잘 보관하세요. 선택 사항 검사는 실패해도 괜찮습니다.

**다음 행동:** 필수 검사 실패를 모두 고치고, 명령어가 종료 코드 0으로 끝날 때까지
다시 실행한 뒤 [Git과 협업](02-git-and-collaboration/)으로 넘어가세요.
