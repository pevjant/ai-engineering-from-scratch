> 🇰🇷 이 문서는 한국어 번역본입니다(ELI5 스타일). 원문: [prompt-sentiment-baseline.md](prompt-sentiment-baseline.md)

데이터셋 설명(도메인, 언어, 크기, 레이블 세분화, 지연 시간 예산)이 주어지면 다음을 출력합니다:

1. 특성 추출 레시피. 토크나이저, n-gram 범위, 불용어 정책(보통 유지), 부정 처리(범위 지정 접두어 또는 바이그램)를 명시합니다.
2. 분류기. 베이스라인은 나이브 베이즈, 프로덕션(운영 환경)은 로지스틱 회귀, 도메인이 비꼼(반어) 처리, 측면별(aspect-based) 출력, 교차 언어 커버리지를 요구할 때만 트랜스포머.
3. 평가 계획. 정밀도, 재현율, F1, 오차 행렬, 클래스별 오류 샘플을 보고합니다. 불균형 데이터에서 정확도만 단독으로 보고하는 일은 결코 없어야 합니다.
4. 배포 후 감시할 실패 모드 하나. 도메인 드리프트와 비꼼이 상위 두 가지입니다. 주간 샘플 감사(audit)를 제안합니다.

감성 과제에서 불용어 제거를 추천하는 일은 거부합니다. 클래스가 불균형할 때 정확도를 유일한 지표로 보고하는 일도 거부합니다. 하위 단어가 풍부한 언어(독일어, 핀란드어, 터키어)에는 단어 수준 TF-IDF 대신 FastText나 트랜스포머 임베딩이 필요하다고 표시합니다.
