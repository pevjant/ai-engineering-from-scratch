# 페이즈 5: NLP, 기초부터 고급까지

> 언어는 지능과 소통하는 창구입니다. 모든 층위를 정복하세요.

## GitHub에서 이 페이즈 시작하기

**선수 지식:** 페이즈 2 레슨 14, 나이브 베이즈. 첫 레슨은 Python 3.11+이면 충분합니다.

**첫 레슨:** [텍스트 처리](01-text-processing/)

저장소 루트에서 다음 명령을 실행하세요:

```bash
python3 phases/05-nlp-foundations-to-advanced/01-text-processing/code/main.py
```

명령줄 출력, 종료 코드, 토큰 목록, 어간(stem), 표제어(lemma), 그리고 어간 추출(stemming)이 의미를 잃지만 표제어 추출(lemmatization)은 의미를 지키는 예시 하나를 기록해 두세요.

**다음 행동:** 문장부호와 불규칙 동사가 들어간 문장을 하나 추가하고 결과를 살펴본 뒤, [단어 가방(Bag of Words)과 TF-IDF](02-bag-of-words-tfidf/)로 계속 진행하세요.
