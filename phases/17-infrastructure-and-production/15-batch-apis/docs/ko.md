# 배치 API — 업계 표준이 된 50% 할인

> 모든 주요 프로바이더가 50% 할인과 약 24시간 처리 시간을 내건 비동기 배치 API를 제공합니다. OpenAI, Anthropic, Google, 그리고 대부분의 추론 플랫폼(Fireworks 배치 티어, Together 배치)이 같은 패턴을 구현합니다. 배치에 프롬프트 캐싱을 스택으로 얹으면 하룻밤 파이프라인 비용이 동기식 무캐시의 약 10%로 내려옵니다. 규칙은 무자비할 만큼 단순합니다: 대화형이 아니라면 배치로 가야 합니다. 콘텐츠 생성 파이프라인, 문서 분류, 데이터 추출, 보고서 생성, 대량 라벨링, 카탈로그 태깅 — 24시간 지연을 견딜 수 있는 것은 무엇이든, 배치로 옮기기 전까지는 놓쳐버리는 돈입니다. 2026년 프로덕션(운영 환경) 패턴은 모든 신규 LLM 워크로드를 세 갈래 차선으로 분류하는 것입니다: 대화형(캐싱과 함께 동기식), 준대화형(폴백이 있는 비동기 큐), 배치(하룻밤, 캐시된 입력 스택). 대화형처럼 보이면서 사실 몇 분 지연을 견딜 수 있는 워크로드가 가장 많이 낭비합니다.

**유형:** 학습
**언어:** Python (표준 라이브러리, 배치 vs 동기 비용 시뮬레이터 장난감 버전)
**선수 지식:** 페이즈 17 · 14 (프롬프트 & 시맨틱 캐싱)
**시간:** 약 45분

## 학습 목표

- 세 가지 프로바이더 배치 API(OpenAI, Anthropic, Google)와 공통의 50% 할인 + 24시간 처리 보장을 말할 수 있습니다.
- 하룻밤 분류 워크로드에 배치 + 캐시 입력을 스택으로 얹은 비용을 계산하고, 동기식 무캐시 베이스라인과 비교할 수 있습니다.
- 워크로드를 대화형 / 준대화형 / 배치로 분류하고 그 차선을 정당화할 수 있습니다.
- 두 가지 트랩의 이름을 말할 수 있습니다: 부분 대화형(사용자가 24시간보다 빠른 것을 기대함)과 출력 스키마 드리프트(배치 파일 포맷이 프로바이더마다 다름).

## 문제 상황

팀이 밤마다 돌아가는 보고서 생성 파이프라인을 출시했습니다. 5만 개 문서를 요약하고, 요약본을 클러스터링하고, 경영진용 브리프 초안을 작성합니다. 동기식으로 돌리면 4시간이 걸리고 밤마다 $2,000입니다. 배치 API 소식을 듣게 됩니다.

배치를 쓰면 50% 할인입니다. 여기에 시스템 프롬프트(5만 호출이 모두 공유)에 프롬프트 캐싱도 켭니다. 스택으로 묶으면 청구액이 밤당 $180으로 떨어집니다 — 베이스라인의 약 9%입니다. 같은 파이프라인, 설정 변경 세 번.

배치는 LLM 비용 도구상자에서 아무도 당기지 않는 가장 저렴한 레버입니다. 이유는 대부분 조직적인 것입니다. SLA는 실제로 "아침까지"인데 팀은 "실시간"이라고 생각합니다. 이 레슨은 청구액의 90%를 테이블에 두고 오지 않는 법에 관한 것입니다.

## 개념

### 세 가지 배치 API

**OpenAI Batch API**: 요청 목록을 담은 JSONL 파일 업로드. 24시간 처리 약속(실제로는 보통 2-8시간). 입력·출력 토큰 모두 50% 할인. `/v1/batches` 엔드포인트. 캐시 자격이 되는 입력은 그 위에 캐시 입력 가격까지 적용됩니다.

**Anthropic Message Batches**: JSONL 업로드. 24시간 처리. 50% 할인. `cache_control`을 지원합니다 — 캐시 쓰기는 명시적으로, 읽기는 배치 안에서 자동으로 일어납니다.

**Google Vertex AI Batch Prediction**: BigQuery 또는 GCS 입력. Gemini에 대해 비슷한 50% 할인. Vertex 파이프라인과 통합됩니다.

### 본질: 느린 게 아니라 비동기입니다

배치는 "24시간 안에 돌려주겠다"는 약속이지 "24시간이 걸린다"는 뜻이 아닙니다. 전형적인 P50은 2-6시간입니다. 프로바이더는 GPU 여유가 남는 한가한 시간대에 여러분의 배치를 스케줄링합니다.

### 캐싱과 스택으로 묶기

같은 4K 토큰 시스템 프롬프트를 쓰는 5만 문서 요약 작업:

- 동기식 무캐시: 50000 × ($입력 × 4000 + $출력 × 200), 정가 기준.
- 동기식 캐시: 첫 쓰기 이후 시스템 프롬프트가 캐시됨; 나머지 49999건은 입력이 10배 저렴.
- 배치 캐시: 위 전부에 더해 읽기·쓰기 모두 50% 할인.

그 스택: 배치 + 캐시 = 동기식 무캐시 청구액의 약 10%. 하룻밤 돌고 공유 시스템 프롬프트가 있는 워크로드라면 무조건 이 조합을 써야 합니다.

### 워크로드 분류

**대화형** — 사용자가 응답을 기다립니다. TTFT가 중요합니다. 프롬프트 캐싱과 함께 동기 호출. 배치 불가.

**준대화형** — 사용자가 작업을 제출하고 몇 분 뒤 확인합니다. 배치를 쓸 수 없으면 동기로 폴백하는 비동기 큐. 적당한 볼륨의 RAG 인덱싱 같은 것.

**배치** — 사용자가 "아침까지" 또는 "다음 시간까지" 결과를 기대합니다. 콘텐츠 파이프라인, 대규모 분류, 오프라인 분석. 항상 배치, 항상 캐싱 스택.

흔한 실수: 파이프라인이 프로덕션이라는 이유로 전부 대화형으로 분류하는 것. 프로덕션은 지연 시간 명세가 아닙니다 — SLA가 명세입니다.

### 부분 대화형 트랩

대화형처럼 보이지만 5-10분을 견딜 수 있는 기능이 있습니다. 예: "새로고침" 버튼이 달린 밤마다의 고객 건강 보고서. 사용자가 새로고침을 누르고, 10분 기다림은 괜찮습니다. 팀은 이걸 동기식으로 출시합니다. 동시 새로고침 50건은 배치해서 이메일로 전달하는 방식보다 10배 비용이 듭니다.

물어야 할 질문: "이 사용자에게 24시간은 무슨 의미인가?" 대답이 "눈치채지도 못할 것"이라면 배치하세요.

### 출력 스키마 트랩

배치 파일 포맷은 프로바이더마다 다릅니다:

- OpenAI: JSONL, 한 줄에 요청 하나.
- Anthropic: JSONL, 한 줄에 메시지 하나; 응답 포맷이 안에 포함.
- Vertex: TFRecord를 담은 BigQuery 테이블 또는 GCS 프리픽스.

프로바이더들 가운데 "단 하나의 배치 클라이언트"를 만들겠다는 것은 프로바이더별 어댑터 코드를 뜻합니다. 멀티 프로바이더 배치를 내세우는 게이트웨이(Portkey, 일부 LiteLLM 티어)도 원래 포맷을 얇게 감싸기만 합니다.

### 기억해야 할 숫자들

- 프로바이더 공통 배치 할인: 입력 + 출력 정가에서 50%.
- 처리 SLA: 24시간 보장, 전형적인 P50은 2-6시간.
- 스택 배치 + 캐시 입력: 동기식 무캐시 비용의 약 10%.
- 워크로드 분류 규칙: 24시간 지연을 받아들일 수 있다면 항상 배치.

## 연습 문제

1. `code/main.py`를 실행하세요. 3K 토큰 시스템 프롬프트와 500 토큰 출력으로 10만 문서 파이프라인을 돌릴 때, 풀 스택(배치 + 캐시)의 동기 베이스라인 대비 절감액을 계산하세요.
2. 여러분이 아는 실제 제품의 기능 세 가지를 고르세요. 각각 대화형/준대화형/배치로 분류하세요.
3. 사용자가 보고서가 3시간 걸렸다고 불평합니다. 배치 오분류였을까요, 정당한 대화형이었을까요? 판단 기준을 작성하세요.
4. 배치 API 반환 SLA는 24시간인데 P99는 20시간입니다. 사용자에게 이걸 어떻게 알리시겠습니까 — 경계 사례에서 다운스트림 시스템은 어떻게 동작하나요?
5. 손익분기를 계산하세요: 공유 프리픽스 길이가 얼마일 때 배치 + 캐시가 자체 예약 GPU로 밤새 돌리는 것보다 저렴해지나요?

## 핵심 용어

| 용어 | 사람들이 말하는 표현 | 실제 의미 |
|------|----------------|------------------------|
| Batch API | "비동기 할인" | 50% 할인 + 24시간 처리 |
| JSONL | "배치 포맷" | 한 줄에 JSON 요청 하나; OpenAI/Anthropic 표준 |
| Message Batches | "Anthropic 배치" | Anthropic 배치 API 제품명 |
| Batch prediction | "Vertex 배치" | Vertex AI의 배치 API 제품 |
| 처리 SLA | "24시간 약속" | 보장이지 전형이 아님; 전형은 2-6시간 |
| 워크로드 분류 | "대화형 판단" | 대화형 / 준대화형 / 배치 라우팅 결정 |
| 출력 스키마 | "응답 포맷" | 프로바이더별 JSONL 배치; 호환 안 됨 |
| 스택 할인 | "배치 + 캐시" | 둘 다 적용되면 무캐시 동기 청구액의 약 10% |
