# 비용 절감 프리미티브로서의 모델 라우팅

> 동적 브로커가 모든 요청을 평가하고(작업 유형, 토큰 길이, 임베딩 유사도, 신뢰도) 간단한 질의는 저렴한 모델로 보내며, 복잡한 것은 프론티어(최상위) 모델로 에스컬레이션합니다. 모델 캐스케이딩이라고도 부릅니다. 프로덕션(운영 환경) 사례 연구는 미국/영국/유럽 배포에서 품질 동일(iso-quality) 조건으로 20-60% 비용 절감을 보여줍니다; 대용량 SaaS에서 30% 라우팅 효율 개선은 연간 수억 원대(6자릿수 달러) 절감으로 이어집니다. 2026년 상황은 LLM 추론 가격이 연간 약 10배씩 떨어졌다는 것입니다 — GPT-4급 토큰은 2022년 말 $20/M에서 2026년 약 $0.40/M으로 내려왔습니다. 이 하락의 대부분은 더 나은 서빙 스택(페이즈 17 · 04-09) 덕분이지 하드웨어 때문이 아닙니다. 라우팅은 그 가격 하락을 제품 품질 회귀 없이 마진으로 바꾸는 방법입니다. 실패 양상은 저가 모델 드리프트입니다: 라우트가 40%를 더 약한 모델로 밀어 넣고, 추론 작업에서 품질이 3-5% 떨어지는데, 한 분기 동안 아무도 눈치채지 못합니다. 라우트는 오프라인 평가 세트만이 아니라 온라인 품질 메트릭으로 관문을 쳐야 합니다.

**유형:** 학습
**언어:** Python (표준 라이브러리, 캐스케이딩 라우터 시뮬레이터 장난감 버전)
**선수 지식:** 페이즈 17 · 01 (관리형 LLM 플랫폼), 페이즈 17 · 19 (AI 게이트웨이)
**시간:** 약 60분

## 학습 목표

- 모델 캐스케이딩을 설명할 수 있습니다: 저가 모델 우선 + 신뢰도 확인, 낮은 신뢰도에서 에스컬레이션.
- 네 가지 라우팅 신호(작업 분류, 프롬프트 길이, 알려진 어려운 집합과의 임베딩 유사도, 1차 판정의 자기 신뢰도)를 나열할 수 있습니다.
- 목표 라우팅 비율과 품질 손실 허용치에서 예상 혼합 비용을 계산할 수 있습니다.
- 저가 모델의 잠입(creep)을 잡아내는 드리프트 모니터링 메트릭(온라인 품질 관문)의 이름을 말할 수 있습니다.

## 문제 상황

서비스가 GPT-5로 월 $80k를 씁니다. 분석 결과 쿼리의 70%는 간단합니다: "파리는 지금 몇 시야?" "이 문장을 다시 표현해 줘." Haiku급 모델은 비용의 3%만으로 그런 것들을 완벽히 처리합니다. 30%는 GPT-5의 추론 능력이 필요합니다 — 코딩, 수학, 멀티스텝 계획.

70%는 저가 모델로, 30%는 고가 모델로 보내면 같은 제품 품질에서 청구액이 약 65% 떨어집니다. 이것이 라우팅입니다. 요령은 품질을 떨어뜨리지 않고 브로커를 만드는 것입니다.

## 개념

### 네 가지 라우팅 신호

1. **작업 분류**: 단순/복잡/코드생성/수학/채팅. 규칙 기반 분류기, 작은 LLM(Haiku급, $0.25/M), 또는 레이블 달린 버킷과의 임베딩 유사도로 구현할 수 있습니다. 출력: 라우트 = 저가 / 균형 / 프론티어.

2. **프롬프트 길이**: 4K 토큰을 넘는 프롬프트는 일관성을 위해 프론티어가 필요할 때가 많습니다. 500 토큰 미만이면 보통 필요 없습니다.

3. **알려진 어려운 집합과의 임베딩 유사도**: 쿼리가 어려운 것으로 알려진 버킷과 가깝다면(코사인 > 0.88) 바로 프론티어로 에스컬레이션합니다.

4. **1차 판정의 자기 신뢰도**: 저가 모델로 보냅니다; 모델의 로그 확률(log-probs)이 낮은 신뢰도를 보이거나, 거절하거나, 애매한 표현을 내놓으면 프론티어에서 재시도합니다. 트래픽의 약 10%에 P95 지연이 더해지지만 나머지 90%에서 50% 이상을 절약합니다.

### 세 가지 패턴

**사전 라우팅(pre-route)** (앞단에 분류기): 지연 약 5-10ms 추가; 전체적으로 가장 빠름.

**캐스케이드** (저가 우선, 낮은 신뢰도에서 에스컬레이션): 중간값 지연 약 1.2배(저가 실행 + 검증), 에스컬레이션 시 약 2배. 최고의 품질 하한선.

**앙상블 라우팅** (샘플에 대해 저가와 프론티어를 병렬 실행, 보상 모델이 선택): 품질 최고, 비용 최고; 중요한 A/B에만 사용.

### 구현

AI 게이트웨이(페이즈 17 · 19)는 라우팅을 노출합니다. LiteLLM에는 폴백과 비용 기반 라우팅이 있는 `router` 설정이 있습니다. Portkey에는 가드 + 라우팅이 있습니다. Kong AI Gateway는 플러그인 기반 라우팅입니다. OpenRouter의 모델 마켓플레이스는 추천 API를 노출합니다.

오픈소스: RouteLLM (LMSYS), Not Diamond (상용), Prompt Mule.

### 2026년 가격 곡선

| 모델 등급 | 2022년 말 | 2026년 | 변화 |
|-------------|-----------|------|--------|
| GPT-4급 품질 | 약 $20/M | 약 $0.40/M | 50배 저렴 |
| 프론티어 (GPT-5, Claude 4) | — | 약 $3-10/M | 새 등급 |

개선의 대부분은 서빙 효율입니다 — 페이즈 17 · 04-09의 핵심 레슨들이 프로바이더 측 비용 하락으로 모습을 드러낸 것입니다. 라우팅은 모든 사용자가 저가 티어로 옮겨오기를 기다리는 대신, 애플리케이션 계층에서 그 개선분을 챙기는 방법입니다.

### 진짜 위험은 드리프트입니다

라우트가 40%를 저가 모델로 보냅니다. 6개월에 걸쳐 작업 분포가 바뀝니다(사용자가 세련워지고, 더 긴 질문을 합니다). 라우터는 눈치채지 못합니다. 분류기가 1분기 데이터로 학습됐기 때문입니다. 품질은 조용히 떨어집니다. 충분히 크게 불평하는 사람도 없습니다. 결국 패배한 경쟁사 벤치마크에서 알게 됩니다.

라우트는 온라인 품질 메트릭으로 관문을 쳐야 합니다:

- 라우트별 사용자 좋아요/싫어요.
- 라우트별 홀드아웃 샘플(5%)에 대한 자동 LLM 심사.
- 에스컬레이션율: 캐스케이드가 30%를 넘게 위로 올리고 있다면 저가 모델에 과하게 실리고 있는 것입니다.
- 라우트별 거절률.

### 기억해야 할 숫자들

- 2026년 품질 동일 라우팅 절감: 20-60% 사례 연구.
- 2022-2026 LLM 가격 하락: 합산 연간 약 10배.
- GPT-4급 2022년 vs 2026년: 약 $20/M → 약 $0.40/M.
- 캐스케이드 지연 영향: 중간값 약 1.2배, 에스컬레이션 약 2배 (트래픽의 약 10%).

## 연습 문제

1. `code/main.py`를 실행하세요. 어떤 정확도 하한선에서 캐스케이드가 사전 라우팅을 이기나요?
2. 사용자 기반의 30%는 엔터프라이즈(복잡한 쿼리), 70%는 무료 티어(단순)입니다. 라우팅 비율을 설계하세요. 어떤 온라인 메트릭이 관문이 되나요?
3. 어떤 라우트가 품질을 2% 떨어뜨리지만 40%를 절약합니다. 출시해도 될까요? 제품에 따라 다릅니다 — 양쪽 입장을 논증하세요.
4. OpenAI / Anthropic API의 logprobs로 신뢰도 확인을 구현하세요. 시작 임계값은 얼마로 하시겠습니까?
5. 6개월에 걸쳐 에스컬레이션율이 8%에서 22%로 올라갑니다. 원인 세 가지와 각각의 해법을 진단하세요.

## 핵심 용어

| 용어 | 사람들이 말하는 표현 | 실제 의미 |
|------|----------------|------------------------|
| 모델 라우팅 | "비용 브로커" | 요청별 모델 동적 선택 |
| 모델 캐스케이드 | "저가 우선 에스컬레이션" | 저가로 실행, 낮은 신뢰도면 프론티어로 넘어감 |
| 사전 라우팅 | "분류 먼저" | 앞단 분류기; 재실행 없음 |
| 앙상블 라우팅 | "병렬 선택" | 여러 개 실행, 보상 모델이 최선 선택 |
| 에스컬레이션율 | "상위 라우팅 %" | 에스컬레이션된 캐스케이드 요청의 비율 |
| RouteLLM | "LMSYS 라우터" | 오픈소스 라우터 라이브러리 |
| Not Diamond | "상용 라우터" | SaaS 모델 라우팅 제품 |
| 드리프트 | "저가 잠입" | 라우터가 모르는 사이에 일어나는 분포 변화 |
| 온라인 품질 관문 | "실시간 검사" | 실제 트래픽을 샘플링하는 자동 LLM 심사 |
