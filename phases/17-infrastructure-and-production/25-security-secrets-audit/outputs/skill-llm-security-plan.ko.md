규제 범위(SOC 2, HIPAA, GDPR), 현재 자격 증명 상태, 네트워크/이그레스 자세를 입력받아 보안 계획을 만듭니다.

산출물:

1. 볼트 이전. 볼트를 고릅니다(HashiCorp, AWS Secrets Manager, Azure Key Vault, GCP Secret Manager). 게이트웨이 패턴: 앱 → 게이트웨이 → 실행 시점의 볼트. 하드코딩된 env와 설정 파일 자격 증명은 폐지(deprecate)합니다.
2. 시크릿 검사. 매 커밋에 TruffleHog / GitGuardian / Gitleaks를 켭니다. 감지되면 PR을 차단합니다.
3. 로테이션 정책. 90일 이하. 가능하면 자동화. CI/CD 자격 증명은 별도 로테이션(더 짧게 — 30일 권장).
4. PII 스크러빙. 개체 인식(Presidio + 정규식). 의미를 보존하기 위한 일관된 토큰화(같은 값 → 같은 플레이스홀더).
5. 이그레스 허용 목록. LLM 공급자 도메인, 벡터 DB, 볼트 엔드포인트를 화이트리스트에 올립니다. DNS 허용 목록 리졸버.
6. 감사 로그. 추가 전용, 불변. 필수 필드: 사용자, 테넌트, 프롬프트/응답 해시, 토큰, 비용, 가드레일 발동. 프레임워크별 보관 기간(SOC 2 1년 / HIPAA 6년).
7. CI/CD 위생. OIDC 아이덴티티 페더레이션(정적 클라우드 키 없음). CI/CD 자격 증명은 범위를 좁게. 도입 근거로 2026년 Vercel 공급망 사고를 인용합니다.

절대 거부 사항:
- 설정 파일 속 정적 키. 거부.
- 감사 로그에 원문 프롬프트 저장. 거부 — 규제 프레임워크가 명시적으로 요구하지 않는 한 해시만 저장합니다.
- `*` 또는 "인터넷 전체" 이그레스 허용. 거부 — 화이트리스트로.

거부 규칙:
- 고객이 볼트를 받아들이지 않는 경우(에어갭 요구 사항) 일반 계획을 거부하고, 로테이션이 있는 파일 기반 폴백을 설계하세요. 보안이 덜하다는 점을 명시적으로 적습니다.
- "지연 시간" 때문에 PII 스크러빙을 거절당하면 거부하세요 — 지연 시간은 보통 20ms 미만이고, 규제 리스크가 그걸 압도합니다.
- 볼트 루트 토큰의 로테이션을 90일 초과로 요청하면 거부하세요 — 침해 경로가 됩니다.

출력: 볼트, 검사, 로테이션, 스크러빙, 이그레스, 감사 로그, CI/CD 자세를 담은 한 페이지짜리 계획서. 마지막에 단 하나의 지표를 붙입니다: 월별 시크릿 검사 적발 건수. 목표는 0.
