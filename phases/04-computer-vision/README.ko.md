# 페이즈 4: 컴퓨터 비전

> 픽셀에서 시작해 이미지, 비디오, 3D에 이르는 이해까지.

## 이 페이즈를 GitHub에서 시작하기

**선수 지식:** 페이즈 1 레슨 12(텐서 연산)과 페이즈 3 레슨 11(PyTorch 입문).
첫 데모는 NumPy만 있으면 됩니다.

**첫 레슨:** [이미지 기초](01-image-fundamentals/)

저장소 루트에서 다음 명령을 실행하세요:

```bash
python3 phases/04-computer-vision/01-image-fundamentals/code/main.py
```

명령, 종료 코드, HWC와 CHW 모양, 정규화된 채널 통계, 왕복(round-trip) 픽셀 차이,
보간 거칠기를 기록해 두세요. 데모는 결정론적인 합성 이미지를 생성하며
네트워크를 사용하지 않습니다.

**다음 행동:** HWC와 CHW 사이에서 어떤 축이 바뀌는지 설명한 뒤,
