# 페이즈 11: LLM 엔지니어링

> LLM을 프로덕션(운영 환경) 애플리케이션에서 실제로 일하게 만들어 봅니다.

## 이 페이즈를 GitHub에서 시작하기

**선수 지식:** 페이즈 10 레슨 01~05, 또는 토크나이제이션, 데이터 파이프라인, 사전학습, 스케일링에 상응하는 지식.

**첫 레슨:** [프롬프트 엔지니어링](01-prompt-engineering/)

저장소 루트에서 다음 명령을 실행하세요:

```bash
python3 phases/11-llm-engineering/01-prompt-engineering/code/prompt_engineering.py
```

명령어, 종료 코드, 생성된 프롬프트 메타데이터, 테스트 결과, 그리고 출력 차이를 일으킨 프롬프트 변경 한 건을 함께 보관하세요. 데모는 모의(simulated) 모델 응답을 사용하므로 API 키가 필요 없습니다.

**다음 행동:** 어떤 프롬프트 변수가 동작을 바꿨는지, 그 이유는 무엇인지 설명한 뒤 [퓨샷, 사고 사슬, 사고 나무](02-few-shot-cot/)로 계속 진행하세요.
